# ОГЭ №11. Поиск информации в файлах

## Что проверяет задание

Нужно найти нужную информацию в одном или нескольких текстовых документах, предоставленных вместе с заданием.

Здесь проверяется не программирование, а умение быстро работать с электронными документами и поиском.

## Основной инструмент

Используйте поиск по тексту:

```text
Ctrl + F
```

В зависимости от программы это может называться «Найти», «Поиск» или «Поиск в документе».

## Алгоритм решения

1. Внимательно прочитайте вопрос и определите ключевое слово: фамилию, название, населённый пункт, термин и т. п.
2. Откройте подходящий файл.
3. Запустите поиск `Ctrl + F`.
4. Введите ключевое слово или его устойчивую часть.
5. Просмотрите найденные фрагменты вместе с соседними предложениями.
6. Найдите именно тот факт, который требуется в вопросе.
7. Запишите ответ в требуемом формате.

## Если точный поиск ничего не нашёл

Попробуйте:

- убрать окончание слова;
- искать только фамилию вместо имени и фамилии;
- использовать часть длинного названия;
- проверить другое написание буквы `ё/е`;
- искать не ответ, а объект, о котором спрашивается.

## Пример

Вопрос:

> В каком году родился Александр Сергеевич Пушкин?

Вместо поиска всей фразы достаточно искать:

```text
Пушкин
```

После нахождения нужного фрагмента читаем предложение вокруг совпадения и извлекаем год.

## Несколько файлов

Если материалов несколько, сначала посмотрите на названия файлов и папок. Они часто подсказывают, где находится нужная информация.

Не стоит открывать каждый файл подряд, если по структуре каталога можно сузить поиск.

## Частые ошибки

- читать весь документ с начала вместо использования поиска;
- вводить слишком длинную фразу, которой в тексте нет дословно;
- брать первое найденное число без чтения контекста;
- путать однофамильцев или похожие названия;
- записывать лишние слова, когда требуется только число или название.

## Памятка

Главный принцип задания:

```text
ключевое слово -> Ctrl + F -> контекст -> точный ответ
```
