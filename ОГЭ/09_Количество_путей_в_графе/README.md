# ОГЭ №9. Количество путей в графе

## Что проверяет задание

Нужно определить количество различных путей из одной вершины ориентированного графа в другую.

Обычно граф устроен так, что движение идёт только вперёд и циклов нет.

## Основная идея

Количество способов попасть в вершину равно сумме количеств способов попасть во все вершины, из которых в неё ведут стрелки.

## Алгоритм

1. В начальной вершине поставьте `1`.
2. Двигайтесь по графу от начала к концу.
3. Для каждой следующей вершины сложите числа у всех её непосредственных предшественников.
4. Полученное число запишите возле вершины.
5. Число у конечной вершины и есть ответ.

## Пример

Пусть есть дороги:

```text
A -> B
A -> C
B -> D
C -> D
B -> E
D -> E
```

Начинаем:

```text
A = 1
```

В B можно попасть только из A:

```text
B = 1
```

В C также только из A:

```text
C = 1
```

В D можно попасть из B и C:

```text
D = B + C = 1 + 1 = 2
```

В E можно попасть из B и D:

```text
E = B + D = 1 + 2 = 3
```

Ответ: `3`.

## Почему метод работает

Каждый путь в очередную вершину обязательно заканчивается одной из входящих в неё стрелок. Поэтому все пути можно разбить на группы по предыдущей вершине и сложить их количества.

## Если путь должен проходить через определённую вершину

Если требуется найти количество путей из A в Z, проходящих через K, удобно отдельно посчитать:

```text
A -> K
```

и

```text
K -> Z
```

а затем перемножить количества:

```text
количество(A -> K) * количество(K -> Z)
```

## Если через вершину проходить нельзя

Исключите эту вершину и все переходы через неё из подсчёта.

## Частые ошибки

- считать количество стрелок вместо количества путей;
- забывать складывать несколько входящих вариантов;
- считать маршруты в обратном направлении;
- дважды учитывать один и тот же путь;
- при обязательной промежуточной вершине складывать результаты вместо умножения.

## Памятка

Начальная вершина получает `1`. Каждая следующая — сумму значений всех вершин, из которых в неё можно прийти.
