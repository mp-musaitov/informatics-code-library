# ОГЭ №14. Электронные таблицы

## Что проверяет задание

Нужно обработать данные в электронной таблице и получить требуемые числовые результаты.

Обычно необходимо:

- отобрать строки по условию;
- посчитать количество подходящих записей;
- найти сумму или среднее;
- использовать формулы или фильтр.

Названия команд и расположение элементов интерфейса могут немного отличаться между версиями Microsoft Excel, но принципы работы остаются одинаковыми.

## Сначала изучите таблицу

Перед вычислениями определите:

1. что означает каждая строка;
2. что означает каждый столбец;
3. где находятся заголовки;
4. какие условия нужно выполнить одновременно.

## Способ 1. Фильтр

Если нужно найти записи по нескольким признакам, часто проще всего использовать фильтр.

Например:

> Найти количество товаров категории «Книги» стоимостью больше 500 рублей.

Устанавливаем:

```text
Категория = Книги
Цена > 500
```

После этого можно визуально проверить и посчитать оставшиеся строки.

Если после фильтра требуется вычисление только по **видимым строкам**, нужно убедиться, что выбранная функция действительно игнорирует скрытые строки. Обычная формула вроде:

```text
=СУММ(C2:C100)
```

сама по себе не означает «суммировать только видимые после фильтра строки».

Для вычислений по отфильтрованным данным удобно использовать функцию `ПРОМЕЖУТОЧНЫЕ.ИТОГИ`.

Например, сумма видимых значений:

```text
=ПРОМЕЖУТОЧНЫЕ.ИТОГИ(9;C2:C100)
```

Часто используемые номера функций:

```text
1 — среднее
2 — количество чисел
4 — максимум
5 — минимум
9 — сумма
```

Заучивать эти номера необязательно: главное понимать, что **фильтр скрывает строки, но обычная формула не всегда исключает их из вычисления**.

## Способ 2. Вспомогательный столбец

Можно создать новый столбец и для каждой строки проверять условие формулой.

Например, если категория находится в `B2`, а цена в `C2`:

```text
=И(B2="Книги";C2>500)
```

В некоторых программах и локализациях названия функций и разделители аргументов могут отличаться.

## Основные вычисления

### Сумма

```text
=СУММ(C2:C100)
```

### Среднее

```text
=СРЗНАЧ(C2:C100)
```

### Максимум

```text
=МАКС(C2:C100)
```

### Минимум

```text
=МИН(C2:C100)
```

### Количество числовых ячеек

```text
=СЧЁТ(C2:C100)
```

Названия функций зависят от языка интерфейса: например, в англоязычном Excel используются `SUM`, `AVERAGE`, `MAX`, `MIN`, `COUNT`.

## Построение диаграммы

В задании может потребоваться не только вычислить значения, но и представить их на диаграмме.

Общий порядок работы:

1. Подготовьте данные, которые должны попасть на диаграмму.
2. Выделите категории и соответствующие им числовые значения.
3. Вставьте диаграмму требуемого типа.
4. Проверьте, какие данные стали секторами или столбцами.
5. Добавьте легенду, если она требуется.
6. Включите подписи данных.
7. Проверьте, что на диаграмме отображаются именно те значения, которые требует условие.

### Круговая диаграмма

Для круговой диаграммы особенно важно различать:

- **категорию** — что обозначает сектор;
- **значение** — число, соответствующее категории;
- **процент** — долю категории от общей суммы.

Если по условию на секторах должны быть указаны числовые значения, одних процентов недостаточно.

Перед завершением задания проверьте:

```text
правильный тип диаграммы
→ правильные категории
→ правильные значения
→ легенда
→ нужные подписи данных
```

Названия команд и расположение настроек диаграммы могут отличаться в разных версиях Excel.

## Несколько условий

Очень внимательно следите за словами:

```text
И
ИЛИ
```

Если должны выполняться оба условия — это логическое И.

Если достаточно хотя бы одного — ИЛИ.

## Среднее значение

Среднее считается только среди элементов нужной группы:

```text
сумма подходящих значений / количество подходящих значений
```

Нельзя делить на общее количество строк, если часть строк не удовлетворяет условию.

## Сортировка и фильтрация — не одно и то же

Сортировка меняет порядок строк.

Фильтр временно показывает только строки, удовлетворяющие условию.

Если требуется отбор данных, обычно нужен именно фильтр.

## Частые ошибки

- включать строку заголовков в диапазон вычислений;
- применять условие не к тому столбцу;
- путать И и ИЛИ;
- считать среднее по всей таблице;
- считать, что после включения фильтра любая обычная формула автоматически работает только с видимыми строками;
- путать на диаграмме значения и проценты;
- забывать добавить требуемые подписи данных или легенду;
- вручную пересчитывать большой объём данных;
- случайно изменить исходные значения;
- неверно определить последнюю строку диапазона.

## Памятка

Для №14 полезна последовательность:

```text
понять столбцы -> сформулировать условия -> отфильтровать -> вычислить -> проверить
```

Не начинайте вводить формулы, пока не поняли, какие именно строки должны участвовать в расчёте.
