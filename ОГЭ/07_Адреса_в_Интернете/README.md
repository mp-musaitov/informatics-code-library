# ОГЭ №7. Адреса в Интернете

## Что проверяет задание

Нужно составить адрес интернет-ресурса из отдельных фрагментов.

Главная идея — знать стандартную структуру URL.

## Общая структура

```text
протокол://сервер/путь/файл
```

Например:

```text
https://school.ru/files/task.txt
```

Здесь:

- `https` — протокол;
- `school.ru` — имя сервера;
- `/files/` — путь;
- `task.txt` — имя файла.

## Частые элементы

```text
http
https
ftp
://
/
.
```

Точка обычно разделяет части доменного имени и отделяет расширение файла.

Слеш `/` используется для разделения каталогов и частей пути.

## Алгоритм решения

1. Найдите фрагмент с протоколом.
2. После него поставьте `://`.
3. Соберите имя сервера.
4. После сервера восстановите путь через `/`.
5. В конце поставьте имя файла и расширение.
6. Выпишите номера фрагментов в получившемся порядке.

## Пример

Пусть фрагменты обозначены так:

```text
1) school
2) .ru
3) https
4) ://
5) /test
6) .html
```

Получаем:

```text
https://school.ru/test.html
```

Порядок фрагментов:

```text
3 4 1 2 5 6
```

Если в ответ требуется последовательность цифр без пробелов:

```text
341256
```

## Частые ошибки

- ставить `/` вместо `://` после протокола;
- начинать адрес с имени сайта, забывая протокол;
- путать точку и слеш;
- ставить расширение файла не в конце;
- записывать сам URL, когда требуется последовательность номеров фрагментов.

## Памятка

Сначала мысленно соберите нормальный адрес, и только потом переводите его в номера фрагментов.
