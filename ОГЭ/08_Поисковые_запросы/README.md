# ОГЭ №8. Поисковые запросы

## Что проверяет задание

Задание связано с количеством страниц, найденных по поисковым запросам, и логическими операциями.

Обычно используются два множества:

- страницы, содержащие слово A;
- страницы, содержащие слово B.

## Основные операции

### И — пересечение

```text
A & B
```

Страница должна содержать одновременно A и B.

### ИЛИ — объединение

```text
A | B
```

Страница содержит A, B или оба слова одновременно.

## Главная формула

Для двух множеств:

```text
|A ∪ B| = |A| + |B| - |A ∩ B|
```

Следовательно:

```text
|A ∩ B| = |A| + |B| - |A ∪ B|
```

## Почему нужно вычитать пересечение

Если просто сложить количество страниц по A и по B, страницы, содержащие оба слова, будут посчитаны дважды.

Поэтому один раз пересечение нужно вычесть.

## Пример

По запросу `Python` найдено 8000 страниц.

По запросу `ЕГЭ` — 5000 страниц.

По запросу `Python | ЕГЭ` — 11000 страниц.

Тогда одновременно оба слова содержат:

```text
8000 + 5000 - 11000 = 2000
```

Ответ: `2000`.

## Удобная схема

Обозначьте:

```text
A — только первое множество и пересечение
B — только второе множество и пересечение
A & B — общая часть
A | B — всё объединение
```

Если задача кажется запутанной, нарисуйте два пересекающихся круга.

## Важные соотношения

Пересечение не может быть больше каждого отдельного множества:

```text
|A & B| <= |A|
|A & B| <= |B|
```

Объединение не может быть меньше каждого отдельного множества:

```text
|A | B| >= |A|
|A | B| >= |B|
```

Это помогает быстро проверить ответ.

## Частые ошибки

- считать `И` сложением;
- считать `ИЛИ` обычной суммой без учёта пересечения;
- перепутать объединение и пересечение;
- дважды вычесть общую часть;
- не проверить, получился ли вообще возможный ответ.

## Памятка

Для двух поисковых запросов почти всегда достаточно помнить:

```text
объединение = первое + второе - пересечение
```
