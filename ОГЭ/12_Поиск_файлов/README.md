# ОГЭ №12. Поиск файлов

## Что проверяет задание

Нужно средствами операционной системы найти файлы, удовлетворяющие заданному условию, и определить их количество или другие характеристики.

Условия могут относиться к:

- имени файла;
- расширению;
- расположению;
- содержимому;
- сочетанию нескольких признаков.

## Перед началом

Работайте только с каталогом, который дан в экзаменационном задании. Не ищите по всему компьютеру — это медленнее и может дать лишние результаты.

## Алгоритм

1. Откройте папку с материалами задания.
2. Определите, что именно требуется найти.
3. Используйте строку поиска файлового менеджера.
4. При необходимости уточните расширение или часть имени.
5. Если условие связано с содержимым, проверьте найденные документы.
6. Посчитайте только файлы, полностью удовлетворяющие условию.

## Расширение файла

Расширение — часть имени после последней точки:

```text
report.txt
photo.jpg
table.xlsx
```

Здесь расширения:

```text
txt
jpg
xlsx
```

Для поиска файлов определённого типа часто удобно использовать маску:

```text
*.txt
```

Символ `*` означает произвольную последовательность символов.

## Примеры масок

```text
*.txt       — все файлы с расширением txt
A*.txt      — txt-файлы, имя которых начинается с A
*test*.txt  — txt-файлы, в имени которых встречается test
```

Конкретный синтаксис поиска может немного различаться в разных файловых менеджерах, поэтому ориентируйтесь на программу, установленную на экзаменационном компьютере.

## Если нужно искать текст внутри файлов

Не путайте два разных условия:

```text
слово встречается в имени файла
```

и

```text
слово встречается внутри файла
```

Это разные виды поиска.

## Частые ошибки

- искать по всему компьютеру;
- путать имя и содержимое файла;
- забывать про расширение;
- учитывать папки вместе с файлами;
- считать результаты до окончания поиска;
- включать файлы, удовлетворяющие только части условия.

## Памятка

Сначала разберите условие на признаки:

```text
где искать + имя + расширение + содержимое
```

И только затем запускайте поиск.
