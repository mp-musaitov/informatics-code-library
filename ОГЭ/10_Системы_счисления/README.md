# ОГЭ №10. Системы счисления

## Что проверяет задание

Нужно работать с записью целых чисел в различных позиционных системах счисления.

Чаще всего требуется перевести число из системы с основанием `p` в десятичную или сравнить числа, записанные в разных системах.

## Что означает основание системы

В системе с основанием `p` используются цифры от `0` до `p - 1`.

Например:

- двоичная: `0`, `1`;
- восьмеричная: `0`–`7`;
- десятичная: `0`–`9`;
- шестнадцатеричная: `0`–`9`, `A`–`F`.

## Перевод в десятичную систему

Каждая цифра умножается на соответствующую степень основания.

Например:

```text
1011₂
```

равно:

```text
1 * 2³ + 0 * 2² + 1 * 2¹ + 1 * 2⁰
= 8 + 0 + 2 + 1
= 11
```

## Ещё пример

```text
243₅
```

Переводим:

```text
2 * 5² + 4 * 5¹ + 3 * 5⁰
= 50 + 20 + 3
= 73
```

## Быстрая проверка через Python

Функция `int()` умеет переводить строковую запись числа в десятичное значение:

```python
print(int('1011', 2))  # 11
print(int('243', 5))   # 73
print(int('17', 8))    # 15
```

## Перевод из десятичной системы

Для двоичной, восьмеричной и шестнадцатеричной систем Python имеет готовые функции:

```python
n = 25

print(bin(n))  # 0b11001
print(oct(n))  # 0o31
print(hex(n))  # 0x19
```

Префиксы:

```text
0b — двоичная запись
0o — восьмеричная
0x — шестнадцатеричная
```

Если нужна только запись числа без префикса:

```python
print(bin(25)[2:])  # 11001
```

## Сравнение чисел в разных системах

Надёжный способ — перевести каждое число в десятичную систему, а затем сравнить.

Например:

```text
111₂ = 7
12₅ = 7
10₈ = 8
```

Следовательно:

```text
111₂ = 12₅ < 10₈
```

## Полезная проверка

В записи числа не может быть цифры, которая не существует в данной системе.

Например:

```text
128₈
```

некорректно, потому что в восьмеричной системе цифры `8` нет.

## Частые ошибки

- читать запись как обычное десятичное число;
- начинать степени основания не с нуля справа;
- перепутать основание и показатель степени;
- использовать недопустимую цифру;
- сравнивать записи разной длины без перевода;
- забывать убрать `0b`, `0o`, `0x`, если требуется сама запись числа.

## Памятка

