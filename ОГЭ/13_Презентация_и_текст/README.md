# ОГЭ №13. Создание презентации или текстового документа

## Что проверяет задание

В задании №13 предлагается выполнить практическую работу в одной из двух форм: создать презентацию или оформить текстовый документ по заданному образцу и требованиям.

Главное здесь — не красота «на вкус», а точное выполнение условий.

# Как выполнять №13

Удобно разделить работу на три этапа:

```text
1. Разобрать условие на отдельные требования.
2. Выполнить работу, не отвлекаясь на лишнее оформление.
3. Проверить результат по исходному условию пункт за пунктом.
```

Не стоит пытаться одновременно читать условие, придумывать дизайн и контролировать имя файла. Сначала составьте для себя короткий список обязательных элементов.

# Вариант 13.1. Презентация

## Перед работой

Сначала прочитайте все требования и только потом начинайте оформление.

Обратите внимание на:

- количество слайдов;
- структуру каждого слайда;
- текст;
- изображения;
- размер и расположение объектов;
- требования к шрифту и оформлению;
- имя и формат итогового файла.

## Алгоритм

1. Создайте презентацию.
2. Сразу создайте нужное количество слайдов.
3. Выберите подходящие макеты.
4. Внесите весь обязательный текст.
5. Добавьте требуемые изображения.
6. Настройте размеры и расположение элементов.
7. Проверьте читаемость текста.
8. Сверьте каждый пункт с условием.
9. Сохраните файл в указанном месте и формате.

## Как собирать слайд

Удобный порядок:

```text
макет → текст → изображения → размеры → выравнивание → финальная проверка
```

Если на слайде несколько объектов, сначала разместите их приблизительно, затем выровняйте. Не растягивайте изображение отдельно по ширине или высоте, если из-за этого нарушаются пропорции.

Если в условии указаны конкретные параметры — количество строк, размер шрифта, расположение изображения и т. п. — именно они имеют приоритет над собственным представлением о красивом оформлении.

## Что особенно проверять

- ничего ли не выходит за границы слайда;
- не перекрываются ли объекты;
- сохранены ли пропорции изображений;
- соответствует ли количество слайдов условию;
- нет ли лишних элементов;
- правильно ли назван файл.

# Вариант 13.2. Текстовый документ

## Основная идея

Нужно воспроизвести структуру и оформление документа по заданным требованиям.

Могут потребоваться:

- заголовки;
- абзацы;
- выравнивание;
- шрифты и размеры;
- интервалы;
- списки;
- таблицы;
- изображения;
- колонтитулы или другие элементы оформления.

## Алгоритм

1. Введите или откройте исходный текст.
2. Разделите документ на логические элементы.
3. Настройте параметры страницы, если они заданы.
4. Оформите основной текст.
5. Оформите заголовки.
6. Создайте списки и таблицы штатными средствами программы.
7. Добавьте изображения, если они требуются.
8. Проверьте весь документ по условию.
9. Сохраните его под требуемым именем.

## Абзацы и выравнивание

Если требуется красная строка, интервал, выравнивание по центру или по ширине, используйте параметры абзаца. Не создавайте нужный вид многократным нажатием пробела или Enter.

Если несколько строк должны образовывать список, используйте инструмент списка. Если данные должны располагаться по строкам и столбцам — таблицу.

## Таблицы

Сначала создайте таблицу нужного размера, затем заполните её и только после этого настраивайте ширину столбцов, высоту строк, границы и выравнивание.

Так проще не потерять структуру документа при последующем редактировании.

## Изображения

После вставки изображения проверьте:

- не нарушены ли его пропорции;
- не перекрывает ли оно текст;
- соответствует ли положение условию;
- не вышло ли изображение за границы страницы.

## Не используйте пробелы для оформления

Плохая идея:

```text
слово          слово
```

если требуется таблица, выравнивание или отступ.

Используйте настоящие инструменты редактора:

- таблицы;
- табуляцию;
- выравнивание;
- параметры абзаца.

## Что делать, если образец выглядит сложным

Не пытайтесь сразу повторить весь документ целиком. Разложите его на элементы:

```text
страница
├── заголовок
├── основной текст
├── список
├── таблица
└── изображение
```

После этого оформляйте каждый элемент отдельно. Такой подход снижает количество случайных изменений уже готовой части документа.

## Универсальная стратегия проверки

После завершения пройдитесь по условию ещё раз и буквально отмечайте каждый выполненный пункт:

```text
✓ количество страниц/слайдов
✓ текст
✓ шрифт
✓ размер
✓ выравнивание
✓ изображения
✓ таблицы/списки
✓ имя файла
✓ место сохранения
```

## Частые ошибки

- делать оформление по памяти вместо проверки условия;
- заменять таблицы пробелами;
- растягивать изображения с нарушением пропорций;
- забывать отдельные требования к шрифту или выравниванию;
- сохранять файл не туда или под неправильным именем;
- тратить слишком много времени на декоративные детали, которые не оцениваются.

## Контроль перед сдачей

Последняя проверка должна быть технической, а не визуальной:

```text
1. Открывается ли файл.
2. Правильный ли формат файла.
3. Правильное ли имя.
4. Сохранён ли он в нужной папке.
5. Выполнен ли каждый пункт условия.
6. Нет ли случайно лишних страниц, слайдов или объектов.
```

Только после этого работу можно считать завершённой.

## Памятка

В №13 работает принцип:

```text
условие важнее дизайна
```

Сначала получите все требуемые элементы и параметры, затем улучшайте внешний вид, если осталось время.
