# Автоматическая проверка материалов

Скрипт `check_materials.py` выполняет простые технические проверки, которые помогают не сломать библиотеку при дальнейших изменениях.

Проверяется:

- синтаксис всех `.py` через модуль `ast`;
- существование внутренних ссылок в Markdown;
- наличие `README.md` в темах ЕГЭ, ОГЭ, основ Python и алгоритмов;
- наличие хотя бы одного `.py` в темах основ Python и алгоритмов.

Запустить локально:

```bash
python tools/check_materials.py
```

Та же проверка автоматически запускается через GitHub Actions после изменений в ветке `main` и в pull request.

## Что проверка не делает

Она не определяет правильность решения экзаменационной задачи и не пытается автоматически сравнивать объяснение в README с кодом.

Содержательная синхронизация остаётся частью проверки материала: если меняется алгоритм или важное условие применения, нужно проверить и README, и соответствующий `.py`.

Автоматизация здесь служит страховкой от технических ошибок, а не заменой педагогической проверки.
