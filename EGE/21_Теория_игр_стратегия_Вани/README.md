# ЕГЭ №21. Теория игр — стратегия Вани

## Что проверяет задание

Задание №21 продолжает игру из №19–20, но теперь нужно анализировать более глубокую стратегию **второго игрока**.

В проекте демоверсии ЕГЭ-2027 используются те же правила:

- две кучи камней;
- первый ход делает Петя;
- за ход можно прибавить `4` к одной куче или увеличить одну кучу в `2` раза;
- игра заканчивается, когда сумма камней становится не меньше `133`;
- начальная позиция — `(17, S)`.

Нужно найти наименьшее `S`, при котором одновременно выполняются условия:

1. Ваня может гарантированно выиграть **первым или вторым своим ходом** при любой игре Пети;
2. Ваня не может гарантированно выиграть своим первым ходом.

---

# Главная идея

В №20 мы построили три типа позиций:

```text
win1  → игрок может выиграть следующим ходом
lose1 → любой ход игрока отдаёт сопернику win1
win2  → игрок не может выиграть сразу, но может перевести игру в lose1
```

Для №21 нужен ещё один уровень.

Ваня должен получить после первого хода Пети позицию, из которой он гарантированно выигрывает **не позднее своего второго хода**.

При этом хотя бы при одном первом ходе Пети Ваня не должен иметь гарантированной победы сразу — иначе выполнялось бы более сильное условие «Ваня гарантированно выигрывает первым ходом».

---

# Уже знакомые функции

```python
def moves(x, y):
    return (
        (x + 4, y),
        (x, y + 4),
        (x * 2, y),
        (x, y * 2)
    )


def win1(x, y):
    return x + y < 133 and any(
        sum(p) >= 133
        for p in moves(x, y)
    )


def lose1(x, y):
    return x + y < 133 and all(
        win1(*p)
        for p in moves(x, y)
    )


def win2(x, y):
    return not win1(x, y) and any(
        lose1(*p)
        for p in moves(x, y)
    )
```

---

# Победа первым или вторым ходом

Если игрок уже находится в `win1`, он может победить сразу.

Если позиция относится к `win2`, он может гарантировать победу своим вторым ходом.

Поэтому:

```python
def win12(x, y):
    return win1(x, y) or win2(x, y)
```

`win12` означает:

> игрок гарантированно выигрывает не позднее своего второго хода.

---

# Что должен сделать Петя

Петя ходит первым.

Ваня должен иметь выигрышную стратегию **при любой игре Пети**.

Следовательно, после **каждого** первого хода Пети позиция должна быть выигрышной для Вани не позднее второго хода:

```python
all(win12(*p) for p in moves(17, S))
```

Именно здесь появляется `all()`:

```text
при любой игре Пети → проверить все первые ходы Пети
```

---

# Почему нужно исключить гарантированную победу Вани первым ходом

В условии отдельно сказано, что у Вани **нет** стратегии, позволяющей ему гарантированно выиграть первым ходом.

Гарантированная победа Вани первым ходом означала бы:

```python
all(win1(*p) for p in moves(17, S))
```

То есть после любого первого хода Пети Ваня сразу имеет победный ход.

Это нужно исключить:

```python
not all(win1(*p) for p in moves(17, S))
```

---

# Решение через понятные игровые позиции

```python
def moves(x, y):
    return (
        (x + 4, y),
        (x, y + 4),
        (x * 2, y),
        (x, y * 2)
    )


def win1(x, y):
    return x + y < 133 and any(
        sum(p) >= 133
        for p in moves(x, y)
    )


def lose1(x, y):
    return x + y < 133 and all(
        win1(*p)
        for p in moves(x, y)
    )


def win2(x, y):
    return not win1(x, y) and any(
        lose1(*p)
        for p in moves(x, y)
    )


def win12(x, y):
    return win1(x, y) or win2(x, y)


for S in range(1, 116):
    first_moves = moves(17, S)

    can_win_in_1_or_2 = all(
        win12(*p)
        for p in first_moves
    )

    can_always_win_in_1 = all(
        win1(*p)
        for p in first_moves
    )

    if can_win_in_1_or_2 and not can_always_win_in_1:
        print(S)
        break
```

Здесь код почти буквально повторяет условие задачи:

```text
Ваня выигрывает первым или вторым ходом
при любой игре Пети

И

Ваня не может гарантированно выиграть первым ходом
```

---

# Логика №19–21 в одной схеме

```text
№19
нужно, чтобы существовала подходящая партия
→ any

№20
Петя выбирает подходящий ход,
который выдерживает любой ответ Вани
→ any + all

№21
Ваня должен справиться с любым первым ходом Пети
→ all
```

Главное — не запоминать расположение `any()` и `all()`, а переводить слова условия:

```text
существует / можно выбрать / хотя бы один → any
любой / независимо от / при всех         → all
```

---

# Частые ошибки

1. Проверять только один первый ход Пети, хотя Ваня должен выиграть **при любой игре Пети**.
2. Проверять только `win2` и забывать, что по условию Ваня может выиграть и первым ходом.
3. Не исключать позиции, где Ваня гарантированно выигрывает первым ходом.
4. Путать «может выиграть первым ходом» и «гарантированно выигрывает первым ходом после любого хода Пети».
5. Механически ставить `any()` и `all()`, не переводя текст условия в логику.

# Универсальный шаблон для №19–21

После того как логика отдельных игровых позиций понятна, всю тройку заданий можно решать одной функцией.

Для игры из проекта демоверсии ЕГЭ-2027 шаблон выглядит так:

```python
def f(a, b, m):
    if a + b >= 133:
        return m % 2 == 0

    if m == 0:
        return False

    h = [
        f(a + 4, b, m - 1),
        f(a * 2, b, m - 1),
        f(a, b + 4, m - 1),
        f(a, b * 2, m - 1)
    ]

    return any(h) if (m - 1) % 2 == 0 else all(h)
```

Здесь `m` — количество ходов, которое ещё осталось проверить.

Главная строка:

```python
return any(h) if (m - 1) % 2 == 0 else all(h)
```

автоматически чередует логику двух игроков.

Если после текущего хода достаточно найти **хотя бы одно** подходящее продолжение, используется `any()`.

Если стратегия должна выдержать **любой** ответ соперника, используется `all()`.

---

# Как работает условие окончания игры

```python
if a + b >= 133:
    return m % 2 == 0
```

Игра уже закончилась. Теперь важно понять, **на чьём ходу** это произошло.

Чётность `m` позволяет определить, соответствует ли достигнутая победа нужному игроку.

Поэтому здесь нельзя просто написать:

```python
return True
```

Иначе функция перестанет различать, кто именно сделал победный ход.

# Как использовать один шаблон для №19–21

Для этой игры начальная позиция — `(17, S)`.

### №19

Проверяем ситуацию после двух ходов:

```python
print([S for S in range(1, 116) if f(17, S, 2)])
```

### №20

Петя должен выиграть своим вторым ходом, но не первым:

```python
print([
    S for S in range(1, 116)
    if f(17, S, 3) and not f(17, S, 1)
])
```

Для проекта демоверсии два наименьших значения:

```text
28 48
```

### №21

Ваня должен выиграть первым или вторым своим ходом, но не иметь гарантированной победы первым ходом:

```python
print([
    S for S in range(1, 116)
    if f(17, S, 4) and not f(17, S, 2)
])
```

Получаем:

```text
44 45 50 51
```

По условию №21 требуется наименьшее значение:

```text
44
```

# Что в универсальном шаблоне меняется от задачи к задаче

Сам каркас функции остаётся одинаковым. Обычно нужно изменить только:

```text
1. условие окончания игры;
2. набор возможных ходов;
3. начальную позицию;
4. диапазон S;
5. значения m в строках поиска ответа.
```

Например, если в другой задаче можно прибавлять `1` и умножать на `3`, меняется только список `h`:

```python
h = [
    f(a + 1, b, m - 1),
    f(a * 3, b, m - 1),
    f(a, b + 1, m - 1),
    f(a, b * 3, m - 1)
]
```

---

# Почему этот шаблон изучаем только после №21

На экзамене он действительно удобен: вся тройка №19–21 решается несколькими строками.

Но если начать тему сразу с него, конструкции

```python
m % 2 == 0
```

и

```python
any(h) if (m - 1) % 2 == 0 else all(h)
```

легко превращаются в правила, которые ученик просто запоминает.

После разбора №19, №20 и №21 уже понятно, что за ними стоит:

```text
мой подходящий ход       → any
любой ответ противника   → all
победа нужного игрока    → контроль чётности m
```

Тогда универсальная рекурсия становится не магией, а сокращённой записью уже понятного дерева игры.

# Быстрая памятка

```text
№19–21 — теория игр

Сначала:
win1 / lose1 / win2
→ понимаем игровые позиции и any/all

После №21:
универсальная функция f(a, b, m)

if победа:
    return m % 2 == 0

if m == 0:
    return False

h = все возможные следующие позиции

return any(h) if (m - 1) % 2 == 0 else all(h)

№19 → f(..., 2)
№20 → f(..., 3) and not f(..., 1)
№21 → f(..., 4) and not f(..., 2)
```

Главная мысль №21:

> **Сначала нужно понять смысл игровых позиций. После этого универсальная рекурсия позволяет компактно решить всю тройку №19–21 одним шаблоном.**
