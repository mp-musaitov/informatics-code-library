# ЕГЭ №22. Параллельные процессы

## Что проверяет задание

В задании №22 дана таблица вычислительных процессов.

Для каждого процесса указаны:

- его `ID`;
- длительность выполнения;
- процессы, от которых он зависит.

Независимые процессы могут выполняться параллельно. Зависимый процесс может начаться только после завершения **всех** процессов, от которых он зависит.

В проекте демоверсии ЕГЭ-2027 требуется определить **максимальное количество процессов, которые выполняются параллельно на 7-й миллисекунде**.

Ответ проекта демоверсии: `8`.

---

# Основной принцип

Для каждого процесса нужно определить два момента:

```text
начало выполнения
конец выполнения
```

Если процесс независимый, он начинается на первой миллисекунде:

```text
start = 1
```

Если процесс зависит от других процессов, он может начаться только после завершения последнего из них:

```text
start = max(end зависимостей) + 1
```

Если процесс начинается на миллисекунде `start` и длится `d` миллисекунд, то:

```text
end = start + d - 1
```

Это важный момент.

Например, процесс длительностью 3 мс, начавшийся на 1-й миллисекунде, выполняется на:

```text
1, 2, 3
```

и заканчивается на 3-й мс.

Следующий зависимый процесс может начать работу на 4-й мс.

---

# Пример из условия

Пусть даны процессы:

| ID | Время | Зависит от |
|---:|---:|---|
| 1 | 3 | 0 |
| 2 | 4 | 1 |
| 3 | 2 | 2; 4 |
| 4 | 5 | 0 |
| 5 | 8 | 1; 4 |
| 6 | 3 | 1 |

Процесс `1` независимый:

```text
start = 1
end = 3
```

Процесс `4` независимый:

```text
start = 1
end = 5
```

Процесс `2` зависит от процесса `1`:

```text
start = 4
end = 7
```

Процесс `3` зависит от процессов `2` и `4`.

Они заканчиваются на 7-й и 5-й мс соответственно, поэтому нужно ждать процесс `2`:

```text
start = 8
end = 9
```

Именно поэтому в условии сказано, что процесс `3` начинается на 8-й мс и заканчивается на 9-й.

# Основной способ — Excel

Для большинства вариантов №22 удобно дополнить исходную таблицу двумя столбцами:

| A | B | C | D | E |
|---|---|---|---|---|
| ID | Время | Зависимости | Начало | Конец |

## Независимый процесс

Если в столбце зависимостей стоит `0`:

```text
Начало = 1
Конец = Начало + Время - 1
```

Например, если длительность находится в `B2`, а начало в `D2`:

```excel
=1
```

а конец:

```excel
=D2+B2-1
```

---

# Зависимый процесс

Если процесс зависит от одного процесса, то его начало равно:

```text
конец зависимости + 1
```

Если зависимостей несколько:

```text
максимальный конец среди всех зависимостей + 1
```

То есть логика всегда одна:

```text
сначала должны закончиться ВСЕ зависимости
```

В небольших таблицах значения удобно находить по `ID` и заносить формулу со ссылкой на соответствующие строки.

После определения начала процесса конец считается той же формулой:

```excel
=Начало+Время-1
```

---

# Как понять, выполняется ли процесс в момент t

Процесс выполняется на миллисекунде `t`, если:

```text
start <= t <= end
```

Для 7-й миллисекунды:

```text
start <= 7 <= end
```

В Excel можно добавить ещё один столбец:

```excel
=И(D2<=7;E2>=7)
```

Он вернёт `ИСТИНА`, если процесс активен на 7-й мс.

Чтобы получить количество активных процессов, можно посчитать значения `ИСТИНА` или использовать числовой вариант:

```excel
=--И(D2<=7;E2>=7)
```

и затем сложить столбец.

---

# Почему нельзя просто складывать длительности

Процессы могут выполняться параллельно.

Например:

```text
A: 5 мс
B: 7 мс
```

если они независимы, оба начинают работу на 1-й мс.

Общее время их выполнения не равно:

```text
5 + 7 = 12
```

Они выполняются одновременно, поэтому оба завершатся через:

```text
max(5, 7) = 7 мс
```

Для зависимостей действует та же идея: время определяется не суммой всех процессов, а самой длинной цепочкой зависимостей.

# Альтернативный способ — Python

Python особенно удобен, если процессов много или нужно автоматически рассчитать начало и конец каждого процесса.

Данные можно хранить так:

```python
p = {
    1: (3, []),
    2: (4, [1]),
    3: (2, [2, 4]),
    4: (5, []),
    5: (8, [1, 4]),
    6: (3, [1]),
}
```

Функция вычисляет начало и конец процесса:

```python
start = {}
end = {}


def calc(i):
    if i in end:
        return

    time, deps = p[i]

    for d in deps:
        calc(d)

    if not deps:
        start[i] = 1
    else:
        start[i] = max(end[d] for d in deps) + 1

    end[i] = start[i] + time - 1


for i in p:
    calc(i)
```

После этого количество процессов, выполняющихся на 7-й мс:

```python
count = sum(
    start[i] <= 7 <= end[i]
    for i in p
)

print(count)
```

Здесь выражение

```python
start[i] <= 7 <= end[i]
```

даёт `True` или `False`, а Python при сложении воспринимает их как `1` и `0`.

# Какие типы задач встречаются

После того как для каждого процесса найдены `start` и `end`, большинство вариантов сводятся к простой обработке этих значений.

### 1. Время завершения всех процессов

```text
max(end)
```

### 2. Количество процессов, работающих в момент t

```text
start <= t <= end
```

### 3. Максимальное число одновременно работающих процессов

Нужно проверить количество активных процессов для каждого момента времени.

### 4. Какой процесс начинается последним

Сравниваем значения `start`.

### 5. Сколько процессов завершится за первые t миллисекунд

Проверяем:

```text
end <= t
```

В отдельных вариантах могут добавляться задержки передачи данных или другие условия. Тогда меняется формула начала зависимого процесса, но общий принцип остаётся тем же.

# Как понять, какой способ выбрать

**Excel** удобен, когда:

- файл уже дан в виде таблицы;
- зависимости хорошо видны;
- нужно быстро вычислить начало и конец процессов;
- задача решается несколькими дополнительными столбцами.

**Python** удобен, когда:

- процессов много;
- структура зависимостей сложная;
- хочется автоматически построить расписание;
- требуется перебрать много моментов времени.

Для ЕГЭ основной практический навык — сначала понять зависимости процессов. Инструмент выбирается уже после этого.

---

# Частые ошибки

1. Считать зависимый процесс начинающимся в ту же миллисекунду, в которую заканчивается предыдущий.
2. Писать `end = start + time` вместо `start + time - 1`.
3. При нескольких зависимостях ждать только один процесс вместо самого позднего из них.
4. Складывать длительности независимых процессов, забывая, что они идут параллельно.
5. При проверке конкретной миллисекунды использовать строгое неравенство вместо:

```text
start <= t <= end
```

6. Считать, что порядок строк таблицы обязательно совпадает с порядком выполнения процессов.
7. Путать `ID` процесса с номером строки Excel.

# Быстрая памятка

```text
Независимый процесс:
start = 1

Зависимый процесс:
start = max(end зависимостей) + 1

Конец:
end = start + duration - 1

Активен на t-й мс:
start <= t <= end

Все независимые процессы могут выполняться параллельно.
```

Главная мысль №22:

> **Сначала строим расписание выполнения процессов: для каждого находим начало и конец. После этого вопрос задания обычно превращается в простую проверку этих двух значений.**
