# №8. Комбинаторика и слова

## Что проверяет задание

Задание №8 проверяет умение считать количество последовательностей, слов и чисел при различных ограничениях.

Встречаются задачи, где нужно:

- составлять слова фиксированной длины из заданного алфавита;
- учитывать количество вхождений отдельных букв;
- запрещать или разрешать определённые сочетания;
- считать слова, начинающиеся или заканчивающиеся определённым символом;
- работать с лексикографическим порядком слов;
- считать числа в некоторой системе счисления;
- переставлять буквы уже заданного слова.

Главный вопрос в №8:

> **Можно ли посчитать ответ формулой быстрее, чем перебором?**

Если да — лучше считать вручную. Если ограничений много и они взаимодействуют друг с другом — Python обычно надёжнее.

---

# Основной принцип

Любое слово длины `n` можно рассматривать как последовательность из `n` позиций.

Если на каждую позицию можно поставить `k` символов независимо, то всего слов:

```text
k^n
```

Например, из букв `А`, `Б`, `В` составляют слова длины 4:

```text
3^4 = 81
```

Но как только появляются ограничения, нужно понять, **какие слова допустимы**, и уже затем выбрать удобный способ подсчёта.

---

# Тип 1. Простой перебор всех слов

Если алфавит небольшой, а длина слова умеренная, самый универсальный способ — `itertools.product`.

```python
from itertools import product

alphabet = 'ABC'
count = 0

for word in product(alphabet, repeat=4):
    word = ''.join(word)

    if условие:
        count += 1

print(count)
```

`product(alphabet, repeat=4)` строит все четырёхсимвольные последовательности из символов алфавита.

Если в алфавите `k` символов, а длина слова `n`, программа переберёт:

```text
k^n
```

вариантов.

---

# Пример: ровно две буквы А

Пусть нужно посчитать пятибуквенные слова из букв `А`, `Б`, `В`, в которых буква `А` встречается ровно два раза.

## Python

```python
from itertools import product

alphabet = 'АБВ'
count = 0

for word in product(alphabet, repeat=5):
    word = ''.join(word)

    if word.count('А') == 2:
        count += 1

print(count)
```

## Ручной способ

Сначала выбираем две позиции для букв `А`:

```text
C(5, 2) = 10
```

Оставшиеся три позиции можно заполнить буквами `Б` или `В`:

```text
2^3 = 8
```

Итого:

```text
10 * 8 = 80
```

Для такого условия ручной способ даже быстрее Python.

# Тип 2. Ограничения по началу и концу слова

Например:

> Сколько шестибуквенных слов из букв `А`, `Б`, `В`, `Г` начинаются с согласной и заканчиваются буквой `А`?

Если согласные — `Б`, `В`, `Г`, то:

```text
3 * 4^4 * 1
```

Потому что:

```text
1-я позиция: 3 варианта
2–5-я позиции: по 4 варианта
6-я позиция: только А
```

Python здесь тоже возможен:

```python
from itertools import product

alphabet = 'АБВГ'
count = 0

for word in product(alphabet, repeat=6):
    word = ''.join(word)

    if word[0] in 'БВГ' and word[-1] == 'А':
        count += 1

print(count)
```

Но формула заметно проще.

# Тип 3. Запрещённые сочетания

Если в условии сказано, что слово не должно содержать некоторую подстроку, Python особенно удобен.

Например:

```python
if 'АА' not in word:
    count += 1
```

Несколько запретов:

```python
if 'АА' not in word and 'ББ' not in word:
    count += 1
```

Запрет соседства разных символов:

```python
if 'АБ' not in word and 'БА' not in word:
    count += 1
```

Для сложных ограничений это обычно надёжнее ручного подсчёта.

---

# Тип 4. Ограничения на количество символов

Очень часто используются условия вида:

```python
word.count('А') == 2
word.count('Б') <= 1
word.count('В') >= 1
```

Например:

```python
if word.count('А') == 2 and word.count('Б') <= 1:
    count += 1
```

Важно помнить:

```text
== 2   — ровно 2 раза
<= 2   — не более 2 раз
>= 2   — не менее 2 раз
```

# Тип 5. Все символы различны

Если символы не должны повторяться, есть два удобных подхода.

## Способ 1. `permutations`

Если основное условие задачи — **символы не повторяются**, лучше сразу использовать `permutations`.

Например, четырёхбуквенные слова из букв `АБВГД` без повторений:

```python
from itertools import permutations

count = 0

for word in permutations('АБВГД', 4):
    word = ''.join(word)
    count += 1

print(count)
```

Ручной способ:

```text
5 * 4 * 3 * 2 = 120
```

## Способ 2. `product` + `set`

Если запрет повторений — только одно из нескольких условий, иногда удобнее перебрать все слова через `product` и проверить уникальность символов отдельно.

```python
from itertools import product

count = 0

for word in product('АБВГДЕ', repeat=5):
    s = ''.join(word)

    if len(s) == len(set(s)):
        count += 1

print(count)
```

Здесь:

```python
len(s) == len(set(s))
```

означает, что количество всех символов совпадает с количеством уникальных символов, то есть повторов нет.

Такой способ особенно удобен, если одновременно нужно проверять и другие ограничения:

```python
if len(s) == len(set(s)) and s[0] != 'А' and 'БВ' not in s:
    count += 1
```

Если повторения разрешены, нужен `product`. Если повторения запрещены и других сложных условий нет, `permutations` обычно короче и быстрее.

## Короткая шпаргалка: `product` и `permutations`

```python
product('АБВГ', repeat=3)  # слова длины 3, повторы возможны
permutations('АБВГ', 3)    # длина 3, без повторений
permutations('АБВГ')       # перестановки всех 4 символов
```

Важно:

```text
product       → длина задаётся через repeat=
permutations  → нужная длина передаётся вторым аргументом
```

Если у `permutations` второй аргумент не указан, используются **все переданные элементы**.

# Тип 6. Перестановка букв заданного слова

Иногда нужно переставить все буквы уже данного слова.

Например, слово:

```text
КОТ
```

Тогда:

```python
from itertools import permutations

for word in permutations('КОТ'):
    print(''.join(word))
```

Получим все 6 перестановок.

Если в исходном слове есть повторяющиеся буквы, обычный `permutations` создаёт одинаковые варианты несколько раз.

Например:

```python
from itertools import permutations

words = set(permutations('МАМА'))
print(len(words))
```

`set()` удаляет повторы.

Для ручного подсчёта числа различных перестановок используется формула:

```text
n! / (n1! * n2! * ...)
```

где `n1`, `n2`, ... — количества одинаковых букв.

Для `МАМА`:

```text
4! / (2! * 2!) = 6
```

# Тип 7. Числа в системе счисления

В №8 могут встречаться последовательности цифр, которые фактически являются числами в некоторой системе счисления.

Например:

> Сколько пятизначных семеричных чисел удовлетворяют условию?

Можно перебирать цифры как строки:

```python
from itertools import product

count = 0

for digits in product('0123456', repeat=5):
    number = ''.join(digits)

    if number[0] == '0':
        continue

    if условие:
        count += 1

print(count)
```

Здесь особенно важно:

```python
if number[0] == '0':
    continue
```

Потому что пятизначное число не может начинаться с нуля.

# Тип 8. Слова в алфавитном порядке

Если все слова одинаковой длины расположены в алфавитном порядке, их удобно связать с числами в системе счисления.

Например, алфавит:

```text
А, Б, В, Г
```

Можно заменить буквы цифрами:

```text
А → 0
Б → 1
В → 2
Г → 3
```

Тогда последовательность слов соответствует последовательности чисел в системе счисления с основанием 4:

```text
ААА → 000₄
ААБ → 001₄
ААВ → 002₄
ААГ → 003₄
АБА → 010₄
...
```

Если нумерация слов начинается с 1, то:

```text
номер слова = значение соответствующего числа + 1
```

Это позволяет находить номер слова без полного перебора.

---

# Альтернативный способ для алфавитного порядка — Python

Для небольшого количества слов можно просто построить список:

```python
from itertools import product

alphabet = 'АБВГ'

for i, word in enumerate(product(alphabet, repeat=3), 1):
    word = ''.join(word)

    if word == 'ВБА':
        print(i)
        break
```

`enumerate(..., 1)` сразу нумерует слова начиная с 1.

# Как понять, какой способ выбрать

## Формула удобнее, если

- позиции независимы;
- ограничение простое;
- нужно только выбрать позиции или символы;
- задача сводится к степени, произведению, сочетаниям или перестановкам.

Например:

```text
ровно 2 буквы А
первая буква — согласная
все символы различны
```

## Python удобнее, если

- ограничений много;
- запрещены соседние символы;
- одновременно проверяются несколько условий;
- легко забыть какой-нибудь случай;
- ручной подсчёт требует большого количества разбиений на случаи.

Главный принцип:

> **Если формула очевидна — считай формулой. Если приходится долго разбирать случаи — перебирай Python.**

# Частые ошибки

## 1. Перепутать `product` и `permutations`

```text
product      — символы могут повторяться
permutations — выбранные символы не повторяются
```

## 2. Забыть `repeat`

Нужно:

```python
product(alphabet, repeat=5)
```

а не просто:

```python
product(alphabet)
```

У `permutations` параметра `repeat=` нет:

```python
permutations(alphabet, 5)
```

Если второй аргумент не указан, переставляются все элементы:

```python
permutations(alphabet)
```

## 3. Не преобразовать кортеж в строку

`product` возвращает кортеж:

```python
('А', 'Б', 'В')
```

Для удобной работы со строковыми методами:

```python
word = ''.join(word)
```

## 4. Неправильно понять формулировку

```text
ровно 2       → == 2
не более 2    → <= 2
не менее 2    → >= 2
```

## 5. Забыть, что число не начинается с нуля

При переборе чисел обязательно отдельно проверяем первую цифру.

## 6. Перебирать слишком много лишнего

Если условие легко считается формулой, не нужно запускать перебор миллионов вариантов.

## 7. Использовать `permutations` при повторяющихся буквах и забыть о дублях

Если переставляются буквы слова вроде `МАМА`, одинаковые перестановки нужно удалить или посчитать вручную по формуле.

## 8. Ошибиться на единицу в алфавитном порядке

Если первой последовательности соответствует число `0`, а нумерация слов начинается с `1`, то:

```text
номер = значение + 1
```

# Быстрая памятка

```text
1. Определи алфавит и длину слова.
2. Выясни, разрешены ли повторения.
3. Выпиши все ограничения отдельно.
4. Если позиции независимы — попробуй формулу.
5. Если условий много — используй product.
6. Если символы не должны повторяться — используй permutations или проверку через set.
7. Если permutations вызывается без второго аргумента — переставляются все элементы.
8. Для повторяющихся букв учитывай одинаковые перестановки.
9. Для чисел не допускай ведущий ноль.
10. Для алфавитного порядка подумай о системе счисления.
11. После написания условия проверь его на одном допустимом и одном недопустимом слове.
```
