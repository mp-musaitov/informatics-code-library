# №9. Электронные таблицы

## Что проверяет задание

Задание №9 проверяет умение обрабатывать числовые данные в электронной таблице и отбирать строки по одному или нескольким условиям.

В проекте демоверсии ЕГЭ-2027 используется таблица, где в каждой строке записано несколько натуральных чисел. Нужно посчитать количество строк, для которых одновременно выполняются заданные условия.

Чаще всего встречаются проверки на:

- различность или повторяемость чисел;
- максимум и минимум;
- сумму и среднее;
- чётность;
- порядок возрастания или убывания;
- количество чисел, удовлетворяющих условию;
- сочетание сразу нескольких условий.

---

# Основной принцип

Каждую строку таблицы нужно рассматривать отдельно.

Алгоритм почти всегда один и тот же:

1. Проверить первое условие.
2. Проверить второе условие.
3. Объединить условия через `И`.
4. Получить для строки `1` или `0`.
5. Просуммировать результат по всем строкам.

То есть задача сводится к вопросу:

> **Подходит ли эта строка?**

---

# Основной способ — электронная таблица

Для №9 Excel или LibreOffice Calc обычно удобнее всего, потому что исходные данные уже находятся в таблице.

Предположим, числа строки записаны в ячейках:

```text
A2:E2
```

А в столбце `F` мы проверяем условие.

После этого формулу из `F2` протягиваем вниз и считаем количество подходящих строк.

---

# Полезные функции

## Максимум

```excel
=MAX(A2:E2)
```

## Минимум

```excel
=MIN(A2:E2)
```

## Сумма

```excel
=SUM(A2:E2)
```

## Среднее значение

```excel
=AVERAGE(A2:E2)
```

В русской локализации Excel названия функций могут отображаться как `МАКС`, `МИН`, `СУММ`, `СРЗНАЧ`.

---

# Тип 1. Все числа в строке различны

Для небольшой строки удобнее всего проверить количество вхождений каждого числа.

Например, для пяти чисел:

```excel
=AND(COUNTIF(A2:E2;A2)=1;COUNTIF(A2:E2;B2)=1;COUNTIF(A2:E2;C2)=1;COUNTIF(A2:E2;D2)=1;COUNTIF(A2:E2;E2)=1)
```

Смысл простой:

```text
каждое число должно встречаться в строке ровно один раз
```

Если хотя бы одно число повторяется, условие станет ложным.

---

# Тип 2. Максимум, минимум и сумма остальных чисел

Пусть в строке пять чисел.

Сумма трёх чисел, которые не являются максимумом и минимумом:

```excel
=SUM(A2:E2)-MAX(A2:E2)-MIN(A2:E2)
```

Например, условие:

> удвоенная сумма максимального и минимального не больше суммы остальных трёх

записывается так:

```excel
=2*(MAX(A2:E2)+MIN(A2:E2))<=SUM(A2:E2)-MAX(A2:E2)-MIN(A2:E2)
```

---

# Пример по формату демоверсии ЕГЭ-2027

В каждой строке находится пять натуральных чисел.

Нужно посчитать строки, в которых одновременно:

1. все числа различны;
2. удвоенная сумма максимального и минимального не больше суммы остальных трёх.

Удобно разбить решение на два вспомогательных столбца.

## Столбец F — все числа различны

```excel
=AND(COUNTIF(A2:E2;A2)=1;COUNTIF(A2:E2;B2)=1;COUNTIF(A2:E2;C2)=1;COUNTIF(A2:E2;D2)=1;COUNTIF(A2:E2;E2)=1)
```

## Столбец G — второе условие

```excel
=2*(MAX(A2:E2)+MIN(A2:E2))<=SUM(A2:E2)-MAX(A2:E2)-MIN(A2:E2)
```

## Столбец H — оба условия сразу

```excel
=AND(F2;G2)
```

После этого формулы протягиваются вниз.

Количество подходящих строк можно получить, например, так:

```excel
=COUNTIF(H:H;TRUE)
```

# Быстрый способ для второго условия

Условие

```text
2 * (max + min) <= сумма остальных
```

можно преобразовать.

Поскольку:

```text
сумма остальных = общая сумма - max - min
```

получаем:

```text
2(max + min) <= sum - max - min
```

Переносим:

```text
3(max + min) <= sum
```

Поэтому можно записать короче:

```excel
=3*(MAX(A2:E2)+MIN(A2:E2))<=SUM(A2:E2)
```

Но на экзамене сначала лучше понять исходное условие, а уже потом сокращать формулу.

---

# Тип 3. Чётные и нечётные числа

Проверка чётности числа:

```excel
=MOD(A2;2)=0
```

Для нечётного:

```excel
=MOD(A2;2)=1
```

Если нужно посчитать количество чётных чисел в строке, удобно использовать вспомогательные ячейки или функцию `SUMPRODUCT`.

Но если условие можно проверить проще, не стоит усложнять формулу.

---

# Тип 4. Числа расположены по возрастанию

Для строки из пяти чисел:

```excel
=AND(A2<B2;B2<C2;C2<D2;D2<E2)
```

Если допускается равенство:

```excel
=AND(A2<=B2;B2<=C2;C2<=D2;D2<=E2)
```

Важно внимательно читать формулировку:

```text
по возрастанию        → обычно строго <
неубывание            → <=
```

---

# Тип 5. Количество чисел, удовлетворяющих условию

Например, сколько чисел в строке больше 50:

```excel
=COUNTIF(A2:E2;">50")
```

Ровно три числа больше 50:

```excel
=COUNTIF(A2:E2;">50")=3
```

Не менее трёх:

```excel
=COUNTIF(A2:E2;">50")>=3
```

---

# Тип 6. Уникальное число в строке

Если нужно проверить, что конкретное значение встречается в строке ровно один раз:

```excel
=COUNTIF(A2:E2;A2)=1
```

Это один из самых полезных приёмов в №9.

Он позволяет проверять условия вида:

```text
число встречается в строке один раз
число повторяется
все числа различны
есть ровно два одинаковых числа
```

# Альтернативный способ — Python

Если удобнее работать с данными как со списками, условие часто записывается очень компактно.

Для одной строки:

```python
s = [10, 20, 30, 40, 50]

if len(s) == len(set(s)):
    print('Все числа различны')
```

Для условия с максимумом и минимумом:

```python
if 2 * (max(s) + min(s)) <= sum(s) - max(s) - min(s):
    print('Условие выполнено')
```

Оба условия:

```python
if len(s) == len(set(s)) and 2 * (max(s) + min(s)) <= sum(s) - max(s) - min(s):
    count += 1
```

# Универсальный шаблон Python

Если данные сохранены в текстовом или CSV-файле и разделены пробелами:

```python
count = 0

with open('9.csv') as f:
    for line in f:
        s = [int(x) for x in line.split()]

        if условие1 and условие2:
            count += 1

print(count)
```

Для примера демоверсии:

```python
count = 0

with open('9.csv') as f:
    for line in f:
        s = [int(x) for x in line.split()]

        if len(s) == len(set(s)) and 2 * (max(s) + min(s)) <= sum(s) - max(s) - min(s):
            count += 1

print(count)
```

Важно: исходный экзаменационный файл обычно удобнее обрабатывать именно в электронной таблице. Python стоит использовать, если файл уже удобно преобразован в текстовый формат или если условия проще записать кодом.

# Как понять, какой способ выбрать

## Электронная таблица удобнее, если

- исходный файл уже открыт в Excel/Calc;
- условия легко записываются через `MAX`, `MIN`, `SUM`, `COUNTIF`;
- нужно быстро протянуть формулу на тысячи строк;
- требуется увидеть, какие именно строки подошли.

## Python удобнее, если

- условий много;
- удобно использовать `set`, `max`, `min`, `sum`;
- формула в таблице получается слишком громоздкой;
- нужно быстро перебрать строки после экспорта данных в текстовый формат.

Главный принцип:

> **В №9 не нужно бояться больших таблиц: формула пишется один раз, а затем протягивается на все строки.**

---

# Частые ошибки

1. Проверять условия по отдельности и забыть объединить их через `AND`.
2. Перепутать `>` и `>=`, `<` и `<=`.
3. Забыть вычесть максимум и минимум из общей суммы, когда требуется сумма остальных чисел.
4. Считать максимум или минимум по неправильному диапазону.
5. При проверке различности использовать только соседние сравнения — одинаковые числа могут находиться далеко друг от друга.
6. Неправильно протянуть формулу из-за абсолютных ссылок `$`.
7. Считать количество подходящих строк вручную вместо `COUNTIF` или суммы вспомогательного столбца.
8. В Python пытаться напрямую читать `.xlsx` обычным `open()` без предварительного преобразования формата.

# Быстрая памятка

```text
MAX      → максимальное число
MIN      → минимальное число
SUM      → сумма
AVERAGE  → среднее
COUNTIF  → количество ячеек по условию
AND      → одновременно выполняются все условия
MOD      → остаток от деления

все числа различны:
каждое число встречается в строке ровно 1 раз

сумма остальных:
SUM - MAX - MIN

несколько условий:
AND(условие1; условие2; ...)
```

Главный навык в №9 — перевести текст условия в несколько простых проверок и не пытаться написать одну гигантскую формулу сразу.
