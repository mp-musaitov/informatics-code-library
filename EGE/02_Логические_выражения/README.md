# №2. Логические выражения и таблицы истинности

## Что проверяет задание

В задании №2 дана часть таблицы истинности логической функции. Имена переменных в столбцах таблицы неизвестны. Нужно определить, **какой переменной соответствует каждый столбец**.

Главная трудность здесь обычно не в вычислении самой функции, а в правильном сопоставлении переменных со столбцами.

## Что нужно знать

Основные логические операции:

| Запись в условии | Python | Смысл |
|---|---|---|
| ¬A | `not A` | НЕ |
| A ∧ B | `A and B` | И |
| A ∨ B | `A or B` | ИЛИ |
| A → B | `A <= B` | импликация |
| A ≡ B | `A == B` | эквивалентность |

### Импликация

Импликация `A → B` ложна только в одном случае:

```text
A = 1
B = 0
```

В Python для значений `0` и `1` удобно использовать:

```python
A <= B
```

Также можно записать по определению:

```python
(not A) or B
```

## Основной принцип

Не нужно пытаться угадывать порядок переменных по внешнему виду таблицы.

Нужно перебрать возможные соответствия:

```text
столбец 1 → одна переменная
столбец 2 → другая переменная
...
```

и проверить, при каком порядке все приведённые строки таблицы дают указанное значение функции.

Если переменных четыре, существует всего:

```text
4! = 24
```

варианта их расположения. Компьютер проверяет их практически мгновенно.

# Основной способ — Python

Для большинства вариантов №2 это наиболее надёжный способ.

Допустим, функция имеет вид:

```text
F = (x ∧ ¬y) ∨ (y ≡ z)
```

Сначала переводим её в Python:

```python
f = (x and not y) or (y == z)
```

Затем проверяем возможные значения переменных.

## Полный перебор значений

```python
from itertools import product

for x, y, z in product([0, 1], repeat=3):
    f = (x and not y) or (y == z)

    if f == 1:
        print(x, y, z, int(f))
```

`product([0, 1], repeat=3)` создаёт все восемь наборов значений трёх логических переменных.

Для четырёх переменных:

```python
for x, y, z, w in product([0, 1], repeat=4):
    ...
```

будет проверено 16 наборов.

## Когда в условии неизвестен порядок столбцов

Удобно перебрать перестановки имён переменных:

```python
from itertools import permutations

for p in permutations('xyzw'):
    print(p)
```

Python переберёт все 24 возможных порядка:

```text
('x', 'y', 'z', 'w')
('x', 'y', 'w', 'z')
...
```

Для реального задания нужно для каждой перестановки подставить значения строк таблицы в соответствующие переменные и проверить функцию.

### Универсальная идея

```python
from itertools import permutations

rows = [
    # значения четырёх неизвестных столбцов и F
    (0, 1, 0, 1, 1),
    (1, 0, 0, 1, 0),
]

for names in permutations('xyzw'):
    ok = True

    for row in rows:
        values = dict(zip(names, row[:4]))

        x = values['x']
        y = values['y']
        z = values['z']
        w = values['w']

        # Здесь записывается функция из конкретного задания
        f = (x and not y) or (z == w)

        if int(f) != row[4]:
            ok = False
            break

    if ok:
        print(*names)
```

> Строки `rows` и выражение `f` всегда нужно заменить данными из конкретного задания.

# Альтернативный способ — ручной анализ

Python здесь удобен, но задание можно решать и логически.

Особенно полезно искать строки, где функция принимает значение, которое сильно ограничивает переменные.

Например:

```text
A ∧ B = 1
```

сразу означает:

```text
A = 1
B = 1
```

А условие

```text
A ∨ B = 0
```

означает:

```text
A = 0
B = 0
```

Для импликации:

```text
A → B = 0
```

однозначно получаем:

```text
A = 1
B = 0
```

Такие фрагменты позволяют быстро определить часть переменных, а оставшиеся сопоставить по другим строкам.

## Полезные свойства

### И

```text
A ∧ B = 1  →  оба равны 1
A ∧ B = 0  →  хотя бы один равен 0
```

### ИЛИ

```text
A ∨ B = 0  →  оба равны 0
A ∨ B = 1  →  хотя бы один равен 1
```

### Импликация

```text
A → B = 0  →  A = 1, B = 0
```

### Эквивалентность

```text
A ≡ B = 1  →  A = B
A ≡ B = 0  →  A ≠ B
```

# Как понять, какой способ выбрать

## Python удобнее, если

- переменных четыре;
- выражение длинное;
- в таблице несколько строк;
- ручное сопоставление получается запутанным;
- нужно быстро проверить найденный ответ.

## Ручной анализ удобнее, если

- в выражении есть очевидный фрагмент;
- одна строка сразу задаёт значения нескольких переменных;
- порядок переменных можно восстановить за несколько логических шагов.

На экзамене полезно владеть обоими подходами: иногда ручное решение занимает меньше минуты, а иногда перебор Python значительно надёжнее.

# Частые ошибки

## 1. Путать импликацию

Неверно считать, что:

```text
A → B
```

означает обычное сравнение или `A and B`.

Запомните единственный ложный случай:

```text
1 → 0 = 0
```

## 2. Неправильно расставлять скобки

Сложное выражение лучше переносить в Python практически дословно и явно ставить скобки:

```python
f = ((x <= y) and (not z)) or w
```

## 3. Перепутать значение функции

В таблице могут быть приведены строки как для `F = 1`, так и для `F = 0`.

Нельзя проверять только наборы, где функция истинна.

## 4. Считать неизвестные столбцы уже подписанными

Если в условии сказано, что порядок переменных неизвестен, первый столбец вовсе не обязан быть `x`, второй — `y` и т. д.

## 5. Найти подходящий порядок по одной строке и остановиться

Правильное соответствие должно удовлетворять **всем строкам**, данным в условии.

## 6. Забыть про разные строки таблицы истинности

Если по условию показаны различные строки полной таблицы истинности, один и тот же набор значений переменных нельзя использовать как две разные строки.

# Быстрая памятка

```text
1. Перепиши логическое выражение без ошибок.
2. Обрати внимание на значение F в каждой строке.
3. Попробуй найти сильное логическое ограничение вручную.
4. Если сопоставление неудобно — перебери порядок переменных в Python.
5. Проверь найденный порядок на ВСЕХ строках.
6. Запиши переменные именно в том порядке, который требует условие.
```

## Мини-шпаргалка Python

```python
# НЕ
not x

# И
x and y

# ИЛИ
x or y

# импликация x → y
x <= y

# эквивалентность
x == y
```

Главная идея задания №2: **не строить огромную таблицу наугад, а использовать данные из её фрагмента для восстановления порядка переменных**.
