# ЕГЭ №20. Теория игр — выигрышная стратегия Пети

## Что проверяет задание

Задания №19–21 используют одно и то же описание игры, но задают разные вопросы о стратегии игроков.

В проекте демоверсии ЕГЭ-2027:

- есть две кучи камней;
- первый ход делает Петя;
- за ход можно прибавить `4` к одной куче или увеличить одну кучу в `2` раза;
- игра заканчивается, когда сумма камней становится не меньше `133`;
- начальная позиция — `(17, S)`, где `1 ≤ S ≤ 115`.

В №20 нужно найти два наименьших значения `S`, при которых:

1. Петя не может выиграть первым ходом;
2. у Пети есть такой первый ход, после которого он сможет выиграть своим вторым ходом **при любом ответном ходе Вани**.

Ключевое отличие от №19 — здесь речь уже идёт не просто о возможном развитии партии, а о **гарантированной выигрышной стратегии**.

---

# Главная идея

У Пети есть выигрышная стратегия, если он может выбрать такой ход, который работает независимо от действий Вани.

Поэтому здесь появляются два разных логических слова:

```text
существует ход Пети  → any()
любой ход Вани       → all()
```

Это основа решения №20.

---

# Разберём последовательность ходов

Начальная позиция:

```text
(17, S)
```

Дальше:

```text
Петя делает первый ход
        ↓
позиция p1
        ↓
Ваня делает любой ответный ход
        ↓
позиция v1
        ↓
Петя должен иметь возможность выиграть
```

То есть Петя выбирает свой первый ход, но после этого мы обязаны проверить **все возможные ответы Вани**.

---

# Возможные ходы

Удобно сразу вынести правила игры в отдельную функцию:

```python
def moves(x, y):
    return (
        (x + 4, y),
        (x, y + 4),
        (x * 2, y),
        (x, y * 2)
    )
```

Так код почти буквально повторяет условие задачи.

---

# Победа за один ход

Сначала удобно описать отдельной функцией ситуацию, когда игрок может победить следующим ходом:

```python
def win1(x, y):
    return x + y < 133 and any(
        sum(p) >= 133
        for p in moves(x, y)
    )
```

`win1(x, y)` означает:

> из позиции `(x, y)` существует хотя бы один ход, который сразу завершает игру победой.

Поэтому используется `any()`.

---

# Позиция, из которой противник обречён

Теперь рассмотрим позицию, в которой игрок сам ещё не победил, но **любой его ход** отдаёт сопернику победу за один ход.

```python
def lose1(x, y):
    return x + y < 133 and all(
        win1(*p)
        for p in moves(x, y)
    )
```

Здесь `all()` принципиален.

Если хотя бы после одного хода соперник не сможет сразу выиграть, значит гарантии уже нет.

---

# Победа своим вторым ходом

Теперь Петя должен:

- не иметь возможности выиграть сразу;
- сделать такой первый ход, после которого Ваня попадёт в проигрышную позицию `lose1`.

```python
def win2(x, y):
    return not win1(x, y) and any(
        lose1(*p)
        for p in moves(x, y)
    )
```

Это очень важная конструкция:

```text
not win1(...)   → Петя не выигрывает первым ходом
any(...)        → существует подходящий первый ход Пети
lose1(...)      → после него любой ответ Вани позволяет Пете победить
```

---

# Решение демоверсии

```python
def moves(x, y):
    return (
        (x + 4, y),
        (x, y + 4),
        (x * 2, y),
        (x, y * 2)
    )


def win1(x, y):
    return x + y < 133 and any(
        sum(p) >= 133
        for p in moves(x, y)
    )


def lose1(x, y):
    return x + y < 133 and all(
        win1(*p)
        for p in moves(x, y)
    )


def win2(x, y):
    return not win1(x, y) and any(
        lose1(*p)
        for p in moves(x, y)
    )


ans = []

for S in range(1, 116):
    if win2(17, S):
        ans.append(S)

print(ans[:2])
```

Для проекта демоверсии получаем два наименьших значения:

```text
28 48
```

# Почему в №20 появляются и `any()`, и `all()`

Сравним две фразы.

### «Петя может сделать ход, который приводит к нужной позиции»

Нам достаточно **одного** подходящего хода:

```python
any(...)
```

### «Петя выиграет независимо от того, как ответит Ваня»

Нужно, чтобы условие выполнялось для **всех** ответов Вани:

```python
all(...)
```

Поэтому полезно переводить формулировку задачи прямо в Python:

```text
есть ход             → any
существует ход       → any
может сделать        → any

при любом ходе       → all
независимо от хода   → all
при всех ответах     → all
```

---

# Альтернативный способ: универсальная рекурсивная функция

Задания №19–21 часто решают одной рекурсивной функцией, в которую передают количество оставшихся ходов.

Например:

```python
def f(x, y, m):
    if x + y >= 133:
        return m % 2 == 0

    if m == 0:
        return False

    h = [f(*p, m - 1) for p in moves(x, y)]

    if m % 2 == 1:
        return any(h)
    else:
        return all(h)
```

Такой подход короче и особенно удобен, когда нужно быстро решить сразу №19–21.

Но у него есть недостаток: ученику сложнее понять, **почему именно здесь `any`, а здесь `all`**.

Поэтому сначала полезнее научиться мыслить через игровые позиции `win1`, `lose1`, `win2`, а уже потом переходить к универсальному шаблону.

---

# Как понять, какой способ выбрать

Для изучения темы удобнее функции:

```text
win1 → победа первым ходом
lose1 → любой ход отдаёт сопернику победу
win2 → победа своим вторым ходом
```

Они хорошо показывают смысл каждой позиции.

Для быстрого решения всей тройки №19–21 после понимания логики удобна универсальная рекурсивная функция.

---

# Частые ошибки

1. Использовать `any()` для ходов Вани, хотя Петя должен выиграть **при любом** его ответе.
2. Забыть условие, что Петя не может выиграть первым ходом.
3. Проверять только один удобный ответ Вани.
4. Считать, что «есть выигрышная стратегия» означает существование одной удачной партии.
5. Путать позицию игрока с позицией после его хода.
6. Проверять только сумму в текущей позиции и забывать перебрать следующие ходы.
7. Искать одно значение `S`, хотя в №20 требуется два значения.

---

# Быстрая памятка

```text
№20 — Петя выигрывает вторым ходом

moves → все возможные ходы

win1:
есть ход, которым можно победить
→ any

lose1:
любой ход позволяет сопернику победить
→ all

win2:
Петя не выигрывает сразу,
но существует первый ход в lose1
→ not win1 + any(lose1)

существует / можно выбрать → any
при любом / независимо от ответа → all
```

Главная мысль №20:

> **Выигрышная стратегия — это не одна удачная последовательность ходов. Петя должен выбрать ход, после которого победа сохраняется при любом ответе Вани.**
