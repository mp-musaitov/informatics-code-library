# 🎓 ЕГЭ по информатике

Материалы по подготовке к ЕГЭ: теория, алгоритмы, примеры, готовые шаблоны и несколько способов решения там, где это полезно.

> Раздел строится по проекту КИМ ЕГЭ-2027, опубликованному ФИПИ 28 августа 2026 года. После публикации окончательной версии структуру нужно будет перепроверить.

## Главный принцип раздела

Мы не привязываем номер задания к одному инструменту.

Для каждого типа задачи сначала разбирается **основной принцип решения**, затем показывается наиболее рациональный способ. Если задачу удобно решать иначе, добавляется **альтернативный способ**.

Типовая структура материала:

1. что проверяет задание;
2. какие типы задач встречаются;
3. основной принцип или алгоритм;
4. основной способ решения;
5. альтернативный способ;
6. как понять, какой способ выбрать;
7. пример;
8. частые ошибки;
9. памятка.

Например, разные варианты задания №9 могут быть удобнее в Excel или Python. Поэтому «основной способ» выбирается для конкретного типа задачи, а не навсегда для всего номера.

## 🔄 Важные изменения 2027

В проекте ЕГЭ-2027 сохраняются 27 заданий, но изменена тематика нескольких позиций:

- **№10** — IP-адресация и маски подсети;
- **№13** — анализ хода исполнения алгоритма;
- **№23** — алгоритмические задачи на графах.

Старое задание на информационный поиск средствами текстового процессора больше не занимает позицию №10.

Для №27 также изменён формат записи ответа в проекте демоверсии.

## 🧭 Как будем строить каждую папку

Для простого задания достаточно одного подробного `README.md`.

Для заданий с несколькими существенно разными типами задач создаются дополнительные материалы и программы. Например:

```text
24_Обработка_строк/
├── README.md
├── Максимальная_цепочка.py
├── Поиск_подстрок.py
└── Расстояние_между_символами.py
```

А крупные алгоритмические задания могут иметь внутренние подразделы:

```text
27_Анализ_данных/
├── README.md
├── Чтение_данных.py
├── Визуализация.py
├── Разделение_на_кластеры.py
└── Поиск_центра_кластера.py
```

## 🛠 Выбор способа решения

В материалах будут использоваться четыре обозначения:

- **Основной принцип** — логика, которую нужно понять независимо от инструмента;
- **Основной способ** — наиболее удобное решение конкретного типа задачи;
- **Альтернативный способ** — полноценный другой путь;
- **Быстрый способ** — короткий приём, если он действительно надёжен.

Цель раздела — не просто научить получать ответ, а научить ученика выбирать подходящий инструмент для задачи.
