## Демоверсия ЕГЭ-2027

В файле описаны частицы. Для каждой частицы заданы:

- координаты `x`, `y`;
- компоненты скорости `Vx`, `Vy`;
- масса `m`;
- признак от `I` до `VII`.

Кинетическая энергия частицы:

```text
E = m · (Vx² + Vy²) / 2
```

Все частицы нужно разбить ровно на **4 кластера** так, чтобы внутри каждого кластера разность энергий любых двух частиц не превышала `R = 2`.

Центром кластера называется **одна из частиц этого кластера**, для которой сумма модулей разностей её энергии с энергиями всех остальных частиц кластера минимальна.

После этого требуется найти:

- `Q1` — наибольшее евклидово расстояние между двумя частицами одного кластера, имеющими признак `II`;
- `Q2` — максимальную кинетическую энергию среди центров кластеров.

В ответ записываются:

```text
int(Q1 * 10000) int(Q2 * 10000)
```

# 1. Главная идея задачи

В демоверсии-2027 кластеризация выполняется **не по координатам**, а по кинетической энергии.

Это принципиально важно.

Координаты понадобятся позже — для вычисления `Q1`.

Сначала для каждой частицы вычисляем:

```python
E = m * (vx ** 2 + vy ** 2) / 2
```

После этого удобно представить частицу так:

```python
[x, y, vx, vy, m, mark, E]
```

или, если остальные параметры дальше не нужны:

```python
[x, y, mark, E]
```

---

# 2. Чтение файла

В файле могут использоваться десятичные запятые, поэтому удобно сразу заменить их точками.

```python
particles = []

with open('27.txt') as f:
    for s in f:
        x, y, vx, vy, m, mark = s.replace(',', '.').split()

        x = float(x)
        y = float(y)
        vx = float(vx)
        vy = float(vy)
        m = float(m)

        E = m * (vx ** 2 + vy ** 2) / 2

        particles.append([x, y, mark, E])
```

`split()` без аргументов подходит особенно хорошо: по условию между значениями может быть один или несколько пробелов и/или символов табуляции.

# 3. Как разбить частицы на кластеры

Условие говорит:

```text
|E1 - E2| <= R
```

для любых двух частиц одного кластера.

В демоверсии:

```text
R = 2
K = 4
```

Если отсортировать частицы по энергии, частицы каждого кластера будут находиться рядом.

```python
particles.sort(key=lambda p: p[3])
```

После сортировки можно последовательно собирать кластеры.

```python
R = 2
clusters = []

for p in particles:
    if not clusters:
        clusters.append([p])
    elif p[3] - clusters[-1][0][3] <= R:
        clusters[-1].append(p)
    else:
        clusters.append([p])
```

Почему сравниваем с **первой** энергией текущего кластера, а не только с предыдущей?

Потому что условие должно выполняться для **любых двух** частиц кластера.

Например:

```text
1.0   2.5   4.0
```

При `R = 2` соседние разности равны `1.5`, но между `1.0` и `4.0` разность уже `3.0`.

Поэтому проверки только соседних элементов недостаточно.

После разбиения полезно проверить:

```python
print(len(clusters))
print([len(cl) for cl in clusters])
```

По условию демоверсии должно получиться ровно **4 кластера**.

# 4. Центр кластера

В этой задаче центр — не среднее значение и не средняя точка.

Центр обязательно является **одной из частиц кластера**.

Для каждой частицы нужно найти сумму:

```text
|E - E1| + |E - E2| + ...
```

и выбрать частицу с минимальной суммой.

Прямой вариант:

```python
def center(cl):
    best = None
    best_sum = None

    for p in cl:
        s = sum(abs(p[3] - q[3]) for q in cl)

        if best_sum is None or s < best_sum:
            best_sum = s
            best = p

    return best
```

Здесь снова удобно использовать `None`: до первой проверенной частицы лучшего значения ещё нет.

---

# 5. Быстрый способ найти центр именно в демоверсии

Здесь расстояние между объектами при выборе центра определяется только выражением

```text
|E1 - E2|
```

Для набора чисел сумма модулей отклонений минимальна на **медиане**.

Поэтому после сортировки энергий центр кластера фактически соответствует медианной энергии.

Но для учебного решения универсальнее сначала понимать прямой алгоритм с суммой модулей. Он буквально повторяет определение центра из условия и меньше зависит от того, как будет изменена формулировка задания.

---

# 6. Евклидово расстояние

Для `Q1` используются уже координаты частиц.

```python
from math import hypot


def dist(p1, p2):
    return hypot(p1[0] - p2[0], p1[1] - p2[1])
```

То же самое без `hypot`:

```python
def dist(p1, p2):
    return ((p1[0] - p2[0]) ** 2 +
            (p1[1] - p2[1]) ** 2) ** 0.5
```

---

# 7. Находим Q1

Нужны только частицы с признаком `II`.

Причём две частицы должны принадлежать **одному кластеру**.

```python
Q1 = None

for cl in clusters:
    a = [p for p in cl if p[2] == 'II']

    for i in range(len(a)):
        for j in range(i + 1, len(a)):
            d = dist(a[i], a[j])

            if Q1 is None or d > Q1:
                Q1 = d
```

Почему `j` начинается с `i + 1`?

Так мы:

- не сравниваем частицу саму с собой;
- не проверяем одну и ту же пару дважды.

---

# 8. Находим Q2

Сначала находим центры всех кластеров:

```python
centers = [center(cl) for cl in clusters]
```

Энергия хранится в элементе `p[3]`.

```python
Q2 = max(p[3] for p in centers)
```

---

# 9. Формируем ответ

По условию проекта демоверсии-2027:

```python
print(int(Q1 * 10000), int(Q2 * 10000))
```

Важно использовать именно `int()`, если условие требует **целую часть**, а не округление.

```python
int(12.999)
```

даёт:

```text
12
```

а

```python
round(12.999)
```

даст `13`.

# 10. Полный шаблон демоверсии-2027

```python

def dist(p1, p2):
    return hypot(p1[0] - p2[0], p1[1] - p2[1])


def center(cl):
    best = None
    best_sum = None

    for p in cl:
        s = sum(abs(p[3] - q[3]) for q in cl)

        if best_sum is None or s < best_sum:
            best_sum = s
            best = p

    return best


particles = []

with open('27.txt') as f:
    for s in f:
        x, y, vx, vy, m, mark = s.replace(',', '.').split()

        vy = float(vy)
        m = float(m)

        particles.append([x, y, mark, E])


R = 2

particles.sort(key=lambda p: p[3])

clusters = []

for p in particles:
    if not clusters:

    elif p[3] - clusters[-1][0][3] <= R:

print(len(clusters))
print([len(cl) for cl in clusters])

centers = [center(cl) for cl in clusters]
```

# 11. Классические варианты №27 с кластерами на плоскости

В других вариантах кластеризация может выполняться не по энергии, а непосредственно по координатам точек.

Тогда общий порядок решения обычно такой:

```text
файл
 ↓
чтение точек
 ↓
визуализация
 ↓
разделение на кластеры
 ↓
поиск центра каждого кластера
 ↓
вычисление требуемых величин
```

Для визуального анализа можно построить диаграмму рассеяния в Excel или временно вывести точки средствами Python.

Самое важное — **не переносить способ разбиения из одной задачи в другую**. Границы кластеров определяются конкретными данными.

# 12. Центр по евклидовым расстояниям

В классических вариантах центр часто определяется как точка кластера, для которой сумма евклидовых расстояний до остальных точек минимальна.

Это уже другая функция:

```python
def center_xy(cl):
    best = None
    best_sum = None

    for p in cl:
        s = sum(dist(p, q) for q in cl)

        if best_sum is None or s < best_sum:
            best_sum = s
            best = p

    return best
```

Нельзя автоматически заменять такой центр средним арифметическим координат.

Если в условии сказано, что центр — **точка кластера**, ответ должен быть одной из исходных точек.

# 13. Как понять, какой алгоритм нужен

Сначала буквально выписываем три определения из условия:

```text
1. По какой характеристике строятся кластеры?
2. Что именно называется центром?
3. Какие величины нужно вывести?
```

Например, в демоверсии-2027:

```text
кластеризация → по кинетической энергии
центр → минимум суммы разностей энергий
Q1 → расстояние по координатам
Q2 → энергия центра
```

То есть в одной задаче одновременно используются **две разные метрики**.

# 14. Частые ошибки

### Ошибка 1. Делить частицы на кластеры по координатам

В демоверсии-2027 кластеры определяются кинетической энергией.

### Ошибка 2. Искать центр как среднее значение

Центр по условию — одна из существующих частиц.

### Ошибка 3. Сравнивать только соседние энергии

Условие `R` должно выполняться для любых двух частиц одного кластера.

### Ошибка 4. Для Q1 сравнивать частицы разных кластеров

Нужны две частицы с признаком `II` **внутри одного кластера**.

### Ошибка 5. Использовать энергию вместо расстояния в Q1

Кластеры строятся по энергии, но `Q1` считается по координатам.

### Ошибка 6. Использовать `round()`

Если требуется целая часть, используется `int()`.

### Ошибка 7. Сразу писать огромную программу

№27 проще решать этапами и после каждого этапа проверять промежуточный результат.
