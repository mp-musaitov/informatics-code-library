## Демоверсия ЕГЭ-2027

В файле описаны частицы. Для каждой частицы заданы:

- координаты `x`, `y`;
- компоненты скорости `Vx`, `Vy`;
- масса `m`;
- признак от `I` до `VII`.

Кинетическая энергия частицы:

```text
E = m · (Vx² + Vy²) / 2
```

Все частицы нужно разбить ровно на **4 кластера** так, чтобы внутри каждого кластера разность энергий любых двух частиц не превышала `R = 2`.

Центром кластера называется **одна из частиц этого кластера**, для которой сумма модулей разностей её энергии с энергиями всех остальных частиц кластера минимальна.

После этого требуется найти:

- `Q1` — наибольшее евклидово расстояние между двумя частицами одного кластера, имеющими признак `II`;
- `Q2` — максимальную кинетическую энергию среди центров кластеров.

В ответ записываются:

```text
int(Q1 * 10000) int(Q2 * 10000)
```

# 1. Главная идея задачи

В демоверсии-2027 кластеризация выполняется **не по координатам**, а по кинетической энергии.

Координаты понадобятся позже — для вычисления `Q1`.

```python
E = m * (vx ** 2 + vy ** 2) / 2
```

Удобное представление частицы:

```python
[x, y, mark, E]
```


`split()` без аргументов корректно обрабатывает пробелы и табуляции.

# 3. Как разбить частицы на кластеры

Условие `|E1 - E2| <= R` должно выполняться для любых двух частиц одного кластера.

```python
R = 2
particles.sort(key=lambda p: p[3])

clusters = []

for p in particles:
    if not clusters:
        clusters.append([p])
    elif p[3] - clusters[-1][0][3] <= R:
        clusters[-1].append(p)
    else:
        clusters.append([p])
```

Сравниваем с первой энергией текущего кластера, а не только с предыдущей. Например, при `R = 2` значения `1.0, 2.5, 4.0` попарно соседствуют близко, но `4.0 - 1.0 = 3.0`, поэтому все три в один кластер входить не могут.

Полезная проверка:

```python
print(len(clusters))
print([len(cl) for cl in clusters])
```

По условию демоверсии должно получиться 4 кластера.

# 4. Центр кластера

Центр обязательно является одной из частиц кластера. Для каждой частицы считаем сумму модулей разностей энергий.

```python
def center(cl):
    best = None
    best_sum = None

    for p in cl:
        s = sum(abs(p[3] - q[3]) for q in cl)

        if best_sum is None or s < best_sum:
            best_sum = s
            best = p

    return best
```

В демоверсии есть и быстрый математический факт: сумма модулей отклонений минимальна на медиане. Но прямой алгоритм лучше показывает определение центра из условия.

---

# 5. Евклидово расстояние

Формула расстояния между `(x1, y1)` и `(x2, y2)`:

```text
√((x1 - x2)² + (y1 - y2)²)
```

Но в рабочем коде проще использовать готовую функцию Python:

```python
from math import dist

d = dist((x1, y1), (x2, y2))
```

Если частица хранится как `[x, y, mark, E]`, передаём только координаты:

```python
d = dist(p1[:2], p2[:2])
```

Формулу полезно понимать, но переписывать её вручную каждый раз нет необходимости.

# 6. Находим Q1

Нужны только частицы с признаком `II`, причём обе должны принадлежать одному кластеру.

```python
from math import dist

Q1 = None

for cl in clusters:
    a = [p for p in cl if p[2] == 'II']

    for i in range(len(a)):
        for j in range(i + 1, len(a)):
            d = dist(a[i][:2], a[j][:2])

            if Q1 is None or d > Q1:
                Q1 = d
```

`j` начинается с `i + 1`, чтобы не сравнивать частицу саму с собой и не проверять одну пару дважды.

```python
centers = [center(cl) for cl in clusters]
```

# 9. Полный шаблон демоверсии-2027

```python
from math import dist


def center(cl):
    best = None
    best_sum = None

    for p in cl:
        s = sum(abs(p[3] - q[3]) for q in cl)

        if best_sum is None or s < best_sum:
            best_sum = s
            best = p

    return best


particles = []

with open('27.txt') as f:
    for s in f:
        x, y, vx, vy, m, mark = s.replace(',', '.').split()

        x = float(x)
        y = float(y)
        vx = float(vx)
        vy = float(vy)
        m = float(m)

        E = m * (vx ** 2 + vy ** 2) / 2
        particles.append([x, y, mark, E])


R = 2
particles.sort(key=lambda p: p[3])

clusters = []

for p in particles:
    if not clusters:
        clusters.append([p])
    elif p[3] - clusters[-1][0][3] <= R:
        clusters[-1].append(p)
    else:
        clusters.append([p])

centers = [center(cl) for cl in clusters]

Q1 = None

for cl in clusters:
    a = [p for p in cl if p[2] == 'II']

    for i in range(len(a)):
        for j in range(i + 1, len(a)):
            d = dist(a[i][:2], a[j][:2])

            if Q1 is None or d > Q1:
                Q1 = d

Q2 = max(p[3] for p in centers)

print(int(Q1 * 10000), int(Q2 * 10000))
```

# 11. Центр по евклидовым расстояниям

В классических вариантах центр часто определяется как точка кластера, для которой сумма евклидовых расстояний до остальных точек минимальна.

Если точки хранятся как пары `[x, y]`, код получается особенно простым:

```python
from math import dist


def center_xy(cl):
    best = None
    best_sum = None

    for p in cl:
        s = sum(dist(p, q) for q in cl)

        if best_sum is None or s < best_sum:
            best_sum = s
            best = p

    return best
```

Нельзя автоматически заменять такой центр средним арифметическим координат: по условию центр обычно должен быть одной из исходных точек.

---

# 12. Как понять, какой способ использовать

Сначала определяем, по какой величине строятся кластеры.

- разность энергий → работаем с энергиями;
- расположение точек → работаем с координатами;
- сумма евклидовых расстояний → используем `math.dist()`;
- сумма модулей разностей одной характеристики → работаем с этой характеристикой.

# 13. Частые ошибки

1. Кластеризовать по координатам в демоверсии-2027, хотя кластеры определяются по энергии.
2. Сравнивать только соседние энергии.
3. Считать центром среднее значение вместо одной из исходных частиц.
4. Искать `Q1` среди всех частиц, а не только среди `II` внутри одного кластера.
5. Сравнивать частицу саму с собой.
6. Использовать `round()` вместо `int()`, когда нужна целая часть.
7. Передавать в `dist()` всю запись `[x, y, mark, E]` вместо координат `p[:2]`.
