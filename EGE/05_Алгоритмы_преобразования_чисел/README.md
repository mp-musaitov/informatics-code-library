# №5. Алгоритмы преобразования чисел

## Что проверяет задание

В задании №5 описывается алгоритм, который получает натуральное число `N`, преобразует его запись по заданным правилам и получает новое число `R`.

Обычно требуется найти:

- минимальное или максимальное `N`, при котором `R` удовлетворяет условию;
- значение `R` для подходящего `N`;
- исходное число по результату работы алгоритма.

Чаще всего алгоритм работает с **двоичной записью**, но принцип одинаков и для других систем счисления.

---

# Основной принцип

Задание удобно разделять на две независимые части:

```text
N → выполнить алгоритм → R
```

а затем:

```text
проверить условие для R
```

То есть программа почти всегда строится так:

```python
for n in range(...):
    # 1. преобразовать n
    # 2. получить r
    # 3. проверить условие
```

Главное — **точно перенести алгоритм из условия**, не пытаясь сразу упростить его в уме.

---

# Основной способ — Python

## Базовый шаблон

```python
for n in range(1, 1000):
    s = bin(n)[2:]

    # действия из условия

    r = int(s, 2)

    if условие:
        print(n, r)
```

Здесь:

```python
bin(n)
```

возвращает строку вида:

```text
0b10110
```

Поэтому:

```python
bin(n)[2:]
```

оставляет только двоичную запись:

```text
10110
```

Обратное преобразование:

```python
r = int(s, 2)
```

переводит двоичную строку в десятичное число.

---

# Тип 1. Дописывание битов

Допустим, к двоичной записи числа нужно справа дописать `01`.

```python
s = bin(n)[2:]
s += '01'
r = int(s, 2)
```

Если дописывается один символ:

```python
s += '1'
```

Если символ нужно добавить слева:

```python
s = '1' + s
```

Важно различать левую и правую стороны записи.

---

# Тип 2. Условие зависит от чётности N

Например:

- если `N` чётное — дописать `0`;
- если `N` нечётное — дописать `1`.

```python
s = bin(n)[2:]

if n % 2 == 0:
    s += '0'
else:
    s += '1'

r = int(s, 2)
```

Проверять чётность можно и по последнему двоичному разряду, но `n % 2` обычно читается проще.

---

# Тип 3. Сумма цифр двоичной записи

В двоичной записи сумма цифр равна количеству единиц.

```python
s = bin(n)[2:]

if s.count('1') % 2 == 0:
    s += '0'
else:
    s += '1'
```

То же самое можно записать через сумму цифр:

```python
sum(map(int, s))
```

Для двоичной строки обычно проще:

```python
s.count('1')
```

---

# Тип 4. Повторение алгоритма несколько раз

Если правило выполняется два раза подряд, важно после первого шага работать уже с **изменённой строкой**.

```python
s = bin(n)[2:]

for _ in range(2):
    if s.count('1') % 2 == 0:
        s += '0'
    else:
        s += '1'

r = int(s, 2)
```

Нельзя на каждом шаге снова брать исходную запись `N`, если условие говорит продолжать преобразование полученной записи.

---

# Тип 5. Замена или перестановка разрядов

Поскольку `s` — строка, удобно использовать срезы.

Первый символ:

```python
s[0]
```

Последний:

```python
s[-1]
```

Все символы кроме первого:

```python
s[1:]
```

Все кроме последнего:

```python
s[:-1]
```

Например, поменять местами первый и последний символы:

```python
s = s[-1] + s[1:-1] + s[0]
```

Перед такими операциями нужно учитывать длину строки.

---

# Тип 6. Добавление остатка от деления

Если по условию нужно дописать остаток от деления числа на 2:

```python
s += str(n % 2)
```

Если остаток вычисляется от суммы цифр:

```python
remainder = s.count('1') % 2
s += str(remainder)
```

Если основание или делитель другой, остаток может быть не одной двоичной цифрой — тогда нужно внимательно читать условие и способ записи результата.

---

# Поиск минимального N

Допустим, нужно найти минимальное `N`, для которого:

```text
R > 100
```

```python
for n in range(1, 1000):
    s = bin(n)[2:]
    s += '01'
    r = int(s, 2)

    if r > 100:
        print(n)
        break
```

`break` здесь важен: числа перебираются по возрастанию, поэтому первый найденный `N` и будет минимальным.

---

# Поиск минимального R

Это уже другой вопрос.

Если требуется найти **минимальное значение R**, удовлетворяющее условию, нельзя автоматически считать, что первый подходящий `N` даст минимальный `R`.

Надёжный вариант:

```python
answers = []

for n in range(1, 1000):
    s = bin(n)[2:]

    # алгоритм
    s += '01'

    r = int(s, 2)

    if r > 100:
        answers.append(r)

print(min(answers))
```

Если доказано, что алгоритм сохраняет возрастание результата при увеличении `N`, можно использовать более короткий поиск, но без такого доказательства безопаснее собрать подходящие результаты.

---

# Поиск максимального N

Если диапазон поиска известен:

```python
answers = []

for n in range(1, 1000):
    s = bin(n)[2:]

    # алгоритм

    r = int(s, 2)

    if условие:
        answers.append(n)

print(max(answers))
```

Или сохранить последнее подходящее значение:

```python
answer = None

for n in range(1, 1000):
    ...

    if условие:
        answer = n

print(answer)
```

---

# Как выбрать границу перебора

В школьных решениях часто встречается:

```python
range(1, 1000)
```

или даже:

```python
range(1, 10000)
```

Это удобно, но важно понимать смысл.

Если требуется **минимальное N**, можно идти от 1 вверх и остановиться после первого подходящего результата.

Если ищется максимум, диапазон должен гарантированно охватывать все возможные ответы. Его лучше оценивать из условия, а не выбирать случайно.

---

# Альтернативный способ — математический анализ

Некоторые варианты №5 можно решить без полного перебора.

Например, дописывание справа одного двоичного нуля:

```text
101 → 1010
```

эквивалентно умножению числа на 2:

```text
R = 2N
```

Дописывание справа единицы:

```text
101 → 1011
```

даёт:

```text
R = 2N + 1
```

Дописать справа два бита `ab` означает:

```text
R = 4N + значение(ab₂)
```

Например, для `01`:

```text
R = 4N + 1
```

Поэтому простые варианты иногда решаются обычным неравенством быстрее, чем программой.

## Когда этот способ особенно удобен

- только дописываются фиксированные биты;
- преобразование легко выразить формулой;
- нет сложных условий по количеству единиц;
- требуется минимальное или максимальное число и получается простое неравенство.

---

# Быстрый способ — сначала понять, потом кодировать

Перед написанием программы полезно вручную прогнать алгоритм для одного небольшого числа.

Например:

```text
N = 6
```

Двоичная запись:

```text
110
```

Если нужно дописать `01`:

```text
11001₂ = 25
```

После этого тот же пример можно проверить программой:

```python
n = 6
s = bin(n)[2:]
s += '01'
print(s)
print(int(s, 2))
```

Если программа выдаёт ожидаемый результат, вероятность ошибки при переносе алгоритма существенно ниже.

---

# Как понять, какой способ выбрать

## Python — основной выбор, если

- алгоритм содержит несколько шагов;
- действия зависят от чётности или количества единиц;
- правило повторяется;
- нужно перебрать много `N`;
- требуется найти экстремальное значение среди результатов.

## Рассуждение удобнее, если

- преобразование сводится к `2N`, `2N + 1`, `4N + ...`;
- условие легко превращается в неравенство;
- ответ получается за несколько арифметических действий.

Хорошая стратегия на экзамене: увидеть математическое упрощение — использовать его; если преобразование громоздкое — не тратить время и написать короткий перебор.

---

# Частые ошибки

## 1. Не убрать `0b`

```python
bin(10)
```

даёт:

```text
0b1010
```

Для работы с цифрами обычно нужно:

```python
bin(10)[2:]
```

## 2. Забыть преобразовать строку обратно в число

После изменения `s` это всё ещё строка:

```python
r = int(s, 2)
```

## 3. Проверять условие для N вместо R

Если сказано:

```text
полученное число R больше 100
```

проверять нужно:

```python
if r > 100:
```

а не `n > 100`.

## 4. Перепутать минимальное N и минимальное R

Это разные величины. Всегда перечитывайте последнюю фразу задания.

## 5. Выполнять второй шаг над исходной строкой

Если алгоритм последовательно преобразует запись, каждый следующий шаг выполняется над уже изменённым результатом.

## 6. Перепутать строку и число

Нельзя написать:

```python
s += 1
```

если `s` — строка.

Нужно:

```python
s += '1'
```

## 7. Использовать слишком маленький диапазон

Отсутствие вывода иногда означает не ошибку алгоритма, а то, что ответ просто не попал в выбранный диапазон.

---

# Универсальный шаблон №5

```python
for n in range(1, 10000):
    s = bin(n)[2:]

    # ==================================
    # Алгоритм из условия задания
    # ==================================

    r = int(s, 2)

    if условие:
        print(n, r)
        break
```

Если нужен не первый подходящий `N`, а минимум/максимум среди результатов, сохраняйте подходящие значения в список или отдельную переменную.

---

# Краткая памятка

```text
1. Возьми N.
2. Переведи его в нужную систему счисления.
3. Выполни правила СТРОГО по порядку.
4. Получи R.
5. Проверь условие именно для той величины, о которой спрашивают.
6. Определи: нужен первый ответ, минимум или максимум.
7. Проверь алгоритм вручную на одном небольшом N.
```

## Мини-шпаргалка Python

```python
bin(n)[2:]        # двоичная запись без 0b
int(s, 2)         # из двоичной записи в десятичное число
s.count('1')      # количество единиц
s += '0'          # дописать 0 справа
s = '1' + s       # дописать 1 слева
n % 2             # остаток от деления на 2
```

Главная идея №5: **сначала точно реализовать преобразование `N → R`, а уже потом заниматься поиском ответа**.
