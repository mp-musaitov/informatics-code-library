# ЕГЭ №14. Системы счисления

## Что проверяет задание

В задании №14 нужно работать с позиционными системами счисления: переводить числа, анализировать их цифры, вычислять большие выражения и подбирать неизвестную цифру.

В проекте демоверсии ЕГЭ-2027 основной пример имеет вид: несколько чисел записаны в системе счисления с основанием 22, одна цифра `x` неизвестна, нужно подобрать её так, чтобы значение выражения делилось на заданное число.

Но в банке заданий встречаются и другие типы: подсчёт цифр в записи большого числа, перебор параметра `x`, поиск основания системы счисления и анализ выражений со степенями основания.

---

# Основной принцип

Любое число в системе счисления с основанием `p` можно представить как сумму цифр, умноженных на степени основания.

Например:

```text
123₅ = 1·5² + 2·5¹ + 3·5⁰
```

В Python готовая функция `int()` умеет переводить строковую запись числа в десятичную систему:

```python
print(int('123', 5))
```

Результат:

```text
38
```

Но `int()` работает с основаниями только от 2 до 36.

# Тип 1. Неизвестная цифра и делимость

Это тип, представленный в демоверсии ЕГЭ-2027.

Пусть операнды записаны в системе с основанием 22 и в нескольких числах одна и та же цифра обозначена `x`.

Нужно:

```text
1. перебрать допустимые значения x;
2. подставить x во все числа;
3. перевести числа в десятичную систему;
4. вычислить выражение;
5. проверить делимость;
6. выбрать минимальное или максимальное x по условию;
7. выполнить требуемое действие с найденным значением выражения.
```

## Основной способ — Python

Если неизвестная цифра может принимать значения от 0 до 21, удобнее перебирать именно **числовое значение цифры**, а не символы алфавита.

Для этого можно написать функцию перевода числа, в котором `x` уже задан числом.

```python
def value(digits, base):
    n = 0
    for d in digits:
        n = n * base + d
    return n
```

Например:

```python
print(value([2, 7, 3, 9], 22))
```

Такой способ работает и для оснований больше 36.

Для неизвестной цифры:

```python
base = 22

for x in range(base):
    a = value([2, 7, x, 9, 8, 8, 7, 6], base)
    b = value([2, 6, x, 5, 1], base)
    c = value([7, 1, 1, x, 5], base)

    s = a + b + c

    if s % 21 == 0:
        print(x, s // 21)
        break
```

> Числа в списках нужно заменить числами из конкретного задания.

Если требуется **наименьшее** `x`, перебираем:

```python
for x in range(base):
```

и после первого ответа используем `break`.

Если требуется **наибольшее** `x`, можно идти в обратном порядке:

```python
for x in range(base - 1, -1, -1):
```

# Быстрый вариант через `int()`

Если основание не больше 36, можно использовать строку цифр.

Например, для основания 22:

```python
alphabet = '0123456789abcdefghijkl'

for x in alphabet:
    a = int(f'27{x}98876', 22)
    b = int(f'26{x}51', 22)
    c = int(f'711{x}5', 22)

    s = a + b + c

    if s % 21 == 0:
        print(x, s // 21)
        break
```

Здесь:

```python
int('1a', 22)
```

понимает букву `a` как цифру со значением 10.

## Что лучше использовать?

`int(..., base)` короче и удобнее для оснований до 36.

Функция `value()` универсальнее и помогает лучше понять устройство позиционной системы счисления.

# Тип 2. Подсчёт цифр в записи большого числа

Часто дано выражение вида:

```text
7^170 + 7^100 - x
```

и нужно узнать, сколько нулей или других цифр содержится в его записи в системе счисления с основанием 7.

Для этого не обязательно строить строку.

Последняя цифра числа в системе с основанием `p` равна:

```python
n % p
```

После удаления этой цифры остаётся:

```python
n //= p
```

Универсальный шаблон:

```python
n = 7**170 + 7**100 - 100
p = 7
count = 0

while n > 0:
    digit = n % p

    if digit == 0:
        count += 1

    n //= p

print(count)
```

Чтобы считать другую цифру, меняем условие:

```python
if digit == 6:
```

# Тип 3. Перебор параметра x и подсчёт цифр

Например, нужно найти наибольшее `x`, при котором в записи выражения ровно 71 нуль.

```python
for x in range(1, 2031):
    n = 7**170 + 7**100 - x
    count = 0

    while n > 0:
        if n % 7 == 0:
            count += 1
        n //= 7

    if count == 71:
        print(x)
```

Если перебор идёт по возрастанию, программа выведет все подходящие значения. Последнее будет максимальным.

Можно сразу перебирать в обратном порядке:

```python
for x in range(2030, 0, -1):
    ...
    if count == 71:
        print(x)
        break
```

# Тип 4. Перевод десятичного числа в систему счисления

Универсальный алгоритм:

```python
def to_base(n, base):
    digits = []

    while n > 0:
        digits.append(n % base)
        n //= base

    return digits[::-1]
```

Например:

```python
print(to_base(38, 5))
```

получим:

```text
[1, 2, 3]
```

Такой формат особенно удобен в №14, потому что цифры могут быть больше 9 и нам часто нужно не вывести число красиво, а **проанализировать значения его цифр**.

Например:

```python
digits = to_base(n, 19)
print(digits.count(0))
print(sum(d > 9 for d in digits))
```

# Тип 5. Найти основание системы счисления

Если известно:

```text
201ₚ = 51₁₀
```

то можно составить уравнение:

```text
2p² + 0p + 1 = 51
```

или подобрать основание программно:

```python
for p in range(3, 100):
    if 2 * p**2 + 1 == 51:
        print(p)
```

Почему начинаем с 3?

Потому что в числе `201ₚ` используется цифра 2, значит основание должно быть **больше максимальной цифры**:

```text
p > 2
```

# Тип 6. Выражение уже почти записано в нужной системе

Иногда выражение состоит из степеней того же основания:

```text
13·19^500 + 7·19^350 + 16·19^200 + ...
```

Каждый коэффициент фактически задаёт цифру на соответствующей позиции, если:

```text
0 ≤ коэффициент < основание.
```

Поэтому иногда огромные степени вообще не нужно вычислять.

Например:

```text
4·7³ + 2·7² + 5
```

это сразу:

```text
4205₇
```

потому что коэффициенты 4, 2, 0, 5 являются цифрами семеричной записи.

Это полезный **быстрый способ**, но он работает только тогда, когда между разрядами не возникает переносов и заимствований.

---

# Отрицательные слагаемые и заимствование

Выражения вида:

```text
7^100 - 1
```

не стоит буквально вычислять вручную.

В семеричной системе:

```text
7^100 = 1 и затем 100 нулей
```

поэтому:

```text
7^100 - 1
```

даёт 100 цифр `6`.

Общий принцип:

```text
p^n - 1
```

в системе с основанием `p` состоит из `n` цифр:

```text
(p - 1)(p - 1)...(p - 1)
```

Такие закономерности иногда позволяют решить №14 значительно быстрее Python.

# Как понять, какой способ выбрать

**Неизвестная цифра + делимость** → перебор `x` в Python.

**Нужно посчитать цифры огромного числа** → остатки `% base` и целочисленное деление `// base`.

**Нужно найти x по количеству цифр** → внешний перебор `x` + внутренний разбор числа по цифрам.

**Нужно найти основание** → уравнение или короткий перебор основания.

**Выражение состоит из степеней нужного основания** → сначала посмотрите, нельзя ли прочитать запись числа прямо по коэффициентам.

# Частые ошибки

## 1. Перебирать недопустимые цифры

В системе с основанием `p` допустимы значения:

```text
0, 1, ..., p - 1
```

Поэтому:

```python
for x in range(p):
```

---

## 2. Считать, что цифра всегда один символ

При основаниях больше 10 цифры со значениями 10, 11, 12 и т. д. часто обозначаются буквами.

Поэтому для вычислений надёжнее думать о **значении цифры**, а не о её символе.

---

## 3. Использовать `int()` для основания больше 36

Так нельзя:

```python
int(s, 50)
```

Для таких оснований используйте собственную функцию перевода.

---

## 4. Перепутать цифру и её количество

```python
n % p
```

даёт **значение очередной цифры**, а не количество цифр.

---

## 5. Забыть изменить n в цикле

Такой цикл бесконечен:

```python
while n > 0:
    digit = n % p
```

Нужно обязательно:

```python
n //= p
```

---

## 6. Взять первое найденное x, когда требуется максимальное

`break` после первого ответа подходит только тогда, когда порядок перебора соответствует условию задачи.

---

## 7. Забыть про допустимость цифр при поиске основания

Если в записи есть цифра 8, основание не может быть 8 или меньше.

---

# Быстрая памятка

```text
Из p-ричной в десятичную (p ≤ 36):
int(s, p)

Последняя цифра в системе p:
n % p

Удалить последнюю цифру:
n //= p

Допустимые значения неизвестной цифры:
range(p)

Проверка делимости:
n % d == 0

Количество нужных цифр:
while n > 0:
    if n % p == digit:
        count += 1
    n //= p

p^n - 1:
n цифр со значением p - 1
```

Главная идея задания №14:

> **Не пытайтесь сначала переводить огромное число целиком. Определите, что именно требуется узнать о его записи, и работайте только с нужными цифрами или параметрами.**
