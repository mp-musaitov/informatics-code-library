# ЕГЭ №18. Робот и электронная таблица

## Что проверяет задание

В задании №18 нужно обработать поле в электронной таблице и определить максимальную и минимальную сумму, которую может собрать Робот при движении по разрешённым маршрутам.

В проекте демоверсии ЕГЭ-2027:

- поле имеет размер `N × N`, где `1 < N < 30`;
- Робот начинает движение из левой верхней клетки;
- разрешены команды **вправо** и **вниз**;
- между клетками могут находиться стены;
- пройти сквозь стену нельзя;
- в каждой клетке находится монета достоинством от 1 до 100;
- при посещении клетки Робот забирает монету;
- нужно найти максимальную и минимальную итоговые суммы среди всех возможных маршрутов до конечных клеток.

Для файла демоверсии ответ:

```text
2598 803
```

---

# Основной принцип

Это задача на **динамическое программирование**.

Не нужно перебирать все маршруты Робота.

Для каждой клетки достаточно знать лучший результат, с которым Робот может в неё попасть.

Если Робот движется только вправо и вниз, попасть в клетку можно:

```text
из клетки сверху
или
из клетки слева
```

Поэтому для максимальной суммы действует идея:

```text
значение клетки + максимум(сверху, слева)
```

Для минимальной:

```text
значение клетки + минимум(сверху, слева)
```

Но учитывать можно только те направления, из которых **нет стены**.

---

# Основной способ: электронная таблица

Удобнее всего создать рядом с исходным полем ещё одну таблицу такого же размера.

В исходной таблице остаются стоимости монет, а во второй постепенно вычисляется накопленная сумма.

Для поиска максимума будем хранить в каждой клетке:

> максимальную сумму, с которой Робот может попасть в эту клетку.

Для минимума — минимальную.

---

# Начальная клетка

В левой верхней клетке Робот начинает маршрут и сразу забирает монету.

Поэтому значение накопленной суммы в начальной клетке равно стоимости самой клетки.

Если исходная клетка находится в `B2`, то в таблице результатов сначала записываем:

```text
=B2
```

---

# Первая строка

В клетки первой строки Робот может попасть только **слева**.

Поэтому, если стены нет:

```text
новая сумма = сумма слева + стоимость текущей клетки
```

Например:

```text
=C2+B2
```

где одна ссылка указывает на стоимость текущей клетки, а другая — на накопленную сумму предыдущей клетки.

Конкретные адреса зависят от расположения исходной и вспомогательной таблиц.

---

# Первый столбец

Аналогично, в клетки первого столбца Робот может попасть только **сверху**.

```text
новая сумма = сумма сверху + стоимость текущей клетки
```

---

# Остальные клетки

Если в клетку можно попасть и сверху, и слева, для максимальной суммы выбираем лучший из двух предыдущих результатов:

```text
стоимость клетки + МАКС(сумма сверху; сумма слева)
```

Например:

```text
=B2+МАКС(C1;B1)
```

Адреса здесь условные: главное понять принцип.

Для минимальной суммы:

```text
стоимость клетки + МИН(сумма сверху; сумма слева)
```

То есть:

```text
=B2+МИН(C1;B1)
```

---

# Стены

Стены — самая важная часть задания.

Если между текущей клеткой и клеткой слева есть стена, значение слева **нельзя использовать**.

Тогда остаётся только путь сверху:

```text
стоимость клетки + сумма сверху
```

Если стена сверху, используем только путь слева:

```text
стоимость клетки + сумма слева
```

Если клетка вообще недостижима, её нельзя использовать для продолжения маршрута.

Поэтому формулы нельзя бездумно протянуть на всё поле и считать, что `МАКС` или `МИН` сами учтут стены.

---

# Почему формулы удобно копировать

На большом участке поля без стен формула для внутренних клеток имеет одинаковую структуру:

```text
=стоимость_клетки+МАКС(сверху;слева)
```

Поэтому достаточно записать формулу один раз и протянуть её по диапазону.

После этого отдельно исправляются клетки около стен.

Для минимальной суммы можно заменить:

```text
МАКС
```

на:

```text
МИН
```

и получить таблицу минимальных накопленных сумм.

---

# Что такое конечная клетка маршрута

В современных вариантах №18 маршрут не обязательно заканчивается в правой нижней клетке.

Конечной считается клетка, из которой Робот уже не может продолжить движение ни вправо, ни вниз из-за границы поля или стен.

Таких клеток может быть несколько.

Поэтому после заполнения таблицы нужно:

1. найти все возможные конечные клетки;
2. посмотреть накопленные суммы в них;
3. среди них выбрать максимальную или минимальную в соответствии с условием.

Это очень важное отличие от старого шаблона «ответ всегда находится в правом нижнем углу».

---

# Как найти максимум

В каждой достижимой клетке храним максимальную сумму до неё.

Для обычной внутренней клетки:

```text
=стоимость+МАКС(сверху;слева)
```

После заполнения поля смотрим значения во всех конечных клетках и выбираем самое большое.

---

# Как найти минимум

Принцип тот же:

```text
=стоимость+МИН(сверху;слева)
```

После заполнения поля выбираем минимальное значение среди конечных клеток.

---

# Почему нельзя просто складывать самые большие монеты

Робот ограничен маршрутом.

Он не может:

- двигаться влево;
- двигаться вверх;
- проходить сквозь стены;
- произвольно выбирать клетки поля.

Поэтому задача состоит не в поиске самых дорогих клеток, а в поиске **лучшего допустимого маршрута**.

---

# Небольшой пример без стен

Пусть поле имеет вид:

```text
1   8   4
3   2   5
7   1   6
```

Для максимума начинаем с `1`.

Первая строка:

```text
1   9   13
```

Первый столбец:

```text
1
4
11
```

Для центральной клетки со значением `2`:

```text
2 + МАКС(9; 4) = 11
```

Для следующей клетки:

```text
5 + МАКС(13; 11) = 18
```

Так постепенно заполняется всё поле.

Мы не перебираем маршруты целиком — в каждой клетке сохраняем только лучший результат.

---

# Альтернативный способ: Python

Сам принцип динамического программирования можно реализовать и программно.

Для поля без стен:

```python
a = [
    [1, 8, 4],
    [3, 2, 5],
    [7, 1, 6]
]

n = len(a)
dp = [[0] * n for _ in range(n)]

dp[0][0] = a[0][0]

for j in range(1, n):
    dp[0][j] = dp[0][j - 1] + a[0][j]

for i in range(1, n):
    dp[i][0] = dp[i - 1][0] + a[i][0]

for i in range(1, n):
    for j in range(1, n):
        dp[i][j] = a[i][j] + max(dp[i - 1][j], dp[i][j - 1])

print(dp[n - 1][n - 1])
```

Для минимума достаточно заменить:

```python
max(...)
```

на:

```python
min(...)
```

Но в реальном задании стены показаны **форматированием электронной таблицы**, поэтому основной способ решения №18 — именно Excel/Calc. Переносить расположение стен вручную в Python обычно неудобнее, чем решить задачу непосредственно в таблице.

---

# Как понять, какой способ выбрать

## Excel/Calc — основной способ

Используйте электронную таблицу, если:

- исходный файл уже дан в формате таблицы;
- стены показаны границами ячеек;
- нужно быстро учитывать расположение стен;
- требуется получить ответ непосредственно по экзаменационному файлу.

## Python — полезен для понимания алгоритма

Python удобен:

- для изучения динамического программирования;
- если поле и стены уже представлены в удобном программном формате;
- для проверки собственного алгоритма на небольших примерах.

---

# Частые ошибки

## 1. Считать, что ответ всегда в правом нижнем углу

В современных вариантах конечных клеток может быть несколько.

Нужно выбрать ответ среди **всех конечных клеток**.

---

## 2. Не учитывать стены

Формула

```text
=стоимость+МАКС(сверху;слева)
```

верна только тогда, когда оба пути действительно разрешены.

---

## 3. Использовать недостижимую клетку

Если Робот не может попасть в некоторую клетку, значение из неё нельзя использовать при расчёте следующих клеток.

---

## 4. Перепутать максимум и минимум

Для максимальной суммы:

```text
МАКС
```

Для минимальной:

```text
МИН
```

---

## 5. Забыть стоимость начальной клетки

Робот забирает монету и из начальной клетки.

---

## 6. Забыть стоимость конечной клетки

Монета конечной клетки тоже входит в накопленную сумму.

---

## 7. Смотреть только на большие числа

Большая монета может находиться на маршруте, к которому Робот не может попасть из-за стен.

---

# Быстрая памятка

```text
№18 — Робот

1. Открыть исходную электронную таблицу.
2. Создать рядом таблицу накопленных сумм.
3. Начальная клетка = стоимость начальной клетки.
4. Первая строка — приход только слева.
5. Первый столбец — приход только сверху.
6. Остальные клетки:

   максимум:
   стоимость + МАКС(сверху; слева)

   минимум:
   стоимость + МИН(сверху; слева)

7. Учитывать стены: запрещённое направление в формулу не включать.
8. Не использовать недостижимые клетки.
9. Найти все конечные клетки маршрута.
10. Среди них выбрать требуемые максимальную и минимальную суммы.
```

Главная мысль:

> В каждой клетке хранится лучший результат пути до неё. Поэтому все маршруты перебирать не нужно.
