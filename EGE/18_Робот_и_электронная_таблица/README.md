# ЕГЭ №18. Робот и электронная таблица

## Что проверяет задание

В задании №18 нужно обработать поле в Excel и определить максимальную и минимальную сумму, которую может собрать Робот при движении по разрешённым маршрутам.

В проекте демоверсии ЕГЭ-2027:

- поле имеет размер `N × N`, где `1 < N < 30`;
- Робот начинает движение из левой верхней клетки;
- разрешены команды **вправо** и **вниз**;
- между клетками могут находиться стены;
- пройти сквозь стену нельзя;
- в каждой клетке находится монета достоинством от 1 до 100;
- при посещении клетки Робот забирает монету;
- нужно найти максимальную и минимальную итоговые суммы среди всех возможных маршрутов до конечных клеток.

Для файла демоверсии ответ:

```text
2598 803
```

---

# Основной принцип

Это задача на **динамическое программирование**.

Не нужно перебирать все маршруты Робота. Для каждой клетки достаточно знать лучший результат, с которым Робот может в неё попасть.

Если Робот движется только вправо и вниз, попасть в клетку можно сверху или слева.

Для максимальной суммы:

```text
значение клетки + максимум(сверху, слева)
```

Для минимальной:

```text
значение клетки + минимум(сверху, слева)
```

Но учитывать можно только те направления, из которых **нет стены**.

---

# Основной способ: Excel

Удобнее всего создать рядом с исходным полем ещё одну таблицу такого же размера.

В исходной таблице остаются стоимости монет, а во второй постепенно вычисляется накопленная сумма.

Для поиска максимума в каждой клетке храним максимальную сумму, с которой Робот может в неё попасть. Для минимума — минимальную.

---

# Начальная клетка

В левой верхней клетке Робот начинает маршрут и сразу забирает монету.

Поэтому накопленная сумма в начальной клетке равна стоимости самой клетки.

Если исходная клетка находится в `B2`, в таблице результатов записываем:

```excel
=B2
```

---

# Первая строка и первый столбец

В клетки первой строки Робот может попасть только **слева**:

```text
новая сумма = сумма слева + стоимость текущей клетки
```

В клетки первого столбца — только **сверху**:

```text
новая сумма = сумма сверху + стоимость текущей клетки
```

---

# Остальные клетки

Если в клетку можно попасть и сверху, и слева, для максимальной суммы:

```excel
=стоимость_клетки+МАКС(сумма_сверху;сумма_слева)
```

Для минимальной суммы:

```excel
=стоимость_клетки+МИН(сумма_сверху;сумма_слева)
```

Конкретные адреса ячеек зависят от расположения исходной и вспомогательной таблиц.

---

# Стены

Стены — самая важная часть задания.

Если между текущей клеткой и клеткой слева есть стена, значение слева **нельзя использовать**. Тогда остаётся только путь сверху.

Если стена сверху, используем только путь слева.

Если клетка вообще недостижима, её нельзя использовать для продолжения маршрута.

Поэтому формулы нельзя бездумно протянуть на всё поле и считать, что `МАКС` или `МИН` сами учтут стены.

---

# Копирование формул

На большом участке поля без стен формула имеет одинаковую структуру, поэтому её можно протянуть по диапазону, а затем отдельно исправить клетки около стен.

Для максимума используется `МАКС`, для минимума — `МИН`.

---

# Что такое конечная клетка маршрута

Маршрут не обязательно заканчивается в правой нижней клетке.

Конечной считается клетка, из которой Робот уже не может продолжить движение ни вправо, ни вниз из-за границы поля или стен.

Таких клеток может быть несколько.

После заполнения таблицы нужно найти все конечные клетки, посмотреть накопленные суммы в них и выбрать требуемый максимум или минимум.

---

# Небольшой пример без стен

Пусть поле имеет вид:

```text
1   8   4
3   2   5
7   1   6
```

Для максимума начинаем с `1`.

Первая строка:

```text
1   9   13
```

Первый столбец:

```text
1
4
11
```

Для центральной клетки со значением `2`:

```text
2 + МАКС(9; 4) = 11
```

Для клетки со значением `5`:

```text
5 + МАКС(13; 11) = 18
```

Так постепенно заполняется всё поле.

---

# Альтернативный способ: Python

Сам принцип динамического программирования можно реализовать программно.

Для поля без стен:

```python
a = [
    [1, 8, 4],
    [3, 2, 5],
    [7, 1, 6]
]

n = len(a)
dp = [[0] * n for _ in range(n)]

dp[0][0] = a[0][0]

for j in range(1, n):
    dp[0][j] = dp[0][j - 1] + a[0][j]

for i in range(1, n):
    dp[i][0] = dp[i - 1][0] + a[i][0]

for i in range(1, n):
    for j in range(1, n):
        dp[i][j] = a[i][j] + max(dp[i - 1][j], dp[i][j - 1])

print(dp[n - 1][n - 1])
```

Для минимума `max` заменяется на `min`.

Но в экзаменационном задании стены показаны форматированием таблицы, поэтому основной способ решения №18 — **Excel**. Переносить расположение стен вручную в Python обычно неудобнее.

---

# Как понять, какой способ выбрать

## Excel — основной способ

Используйте Excel, если исходный файл уже дан в формате электронной таблицы, стены показаны границами ячеек и требуется получить ответ непосредственно по экзаменационному файлу.

## Python — для понимания алгоритма

Python полезен для изучения динамического программирования и проверки алгоритма на небольших примерах.

---

# Частые ошибки

1. Считать, что ответ всегда находится в правом нижнем углу.
2. Не учитывать стены при использовании `МАКС` или `МИН`.
3. Использовать значение из недостижимой клетки.
4. Перепутать максимум и минимум.
5. Забыть стоимость начальной клетки.
6. Забыть стоимость конечной клетки.
7. Смотреть только на большие числа, не учитывая допустимые маршруты.

---

# Быстрая памятка

```text
№18 — Робот

1. Открыть исходный файл в Excel.
2. Создать рядом таблицу накопленных сумм.
3. Начальная клетка = стоимость начальной клетки.
4. Первая строка — приход только слева.
5. Первый столбец — приход только сверху.
6. Внутренняя клетка:
   максимум → стоимость + МАКС(сверху; слева)
   минимум  → стоимость + МИН(сверху; слева)
7. Обязательно учитывать стены.
8. Не использовать недостижимые клетки.
9. Найти все конечные клетки.
10. Выбрать требуемый максимум или минимум среди них.
```

Главная идея:

> В каждой клетке сохраняем лучший результат пути до неё, а не перебираем все маршруты целиком.
