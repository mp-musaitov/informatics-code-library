# ЕГЭ №19. Теория игр — первый ход

## Что проверяет задание

Задания №19–21 образуют один блок на **теорию игр**. Правила игры у них общие, но вопрос каждый раз разный.

В №19 обычно нужно определить начальное значение `S`, при котором возможна заданная ситуация после первых ходов игроков.

В проекте демоверсии ЕГЭ-2027:

- есть две кучи камней;
- первый ход делает Петя;
- за один ход можно добавить `4` камня в одну из куч или увеличить одну из куч в `2` раза;
- игра заканчивается, когда сумма камней становится не меньше `133`;
- в первой куче сначала `17` камней, во второй — `S`, где `1 ≤ S ≤ 115`;
- известно, что **Ваня выиграл своим первым ходом**;
- нужно найти минимальное значение `S`, при котором такая ситуация возможна.

№19 важно читать буквально: здесь не сказано, что Ваня должен выигрывать после **любого** хода Пети. Достаточно, чтобы существовал такой первый ход Пети, после которого Ваня сможет выиграть своим первым ходом.

---

# Основной принцип

В задачах на игры нельзя просто искать последовательность ходов, которая заканчивается победой нужного игрока.

Нужно внимательно различать два слова:

```text
существует подходящий ход  → достаточно одного варианта
при любых ходах соперника → должны подходить все варианты
```

Именно отсюда позже появляются `any()` и `all()`.

Для №19 из демоверсии достаточно найти хотя бы одну цепочку:

```text
начальная позиция
→ неудачный ход Пети
→ победный ход Вани
```

---

# Сначала определяем условие победы

В демоверсии игра заканчивается, когда:

```python
x + y >= 133
```

где `x` и `y` — размеры двух куч.

Позиция с суммой меньше `133` ещё не является конечной.

---

# Какие ходы возможны

Из позиции `(x, y)` можно получить четыре позиции:

```python
(x + 4, y)
(x, y + 4)
(x * 2, y)
(x, y * 2)
```

Удобно сразу записать отдельную функцию:

```python
def moves(x, y):
    return (
        (x + 4, y),
        (x, y + 4),
        (x * 2, y),
        (x, y * 2)
    )
```

Это почти дословный перевод правил игры на Python.

---

# Основной способ: перебор первых двух ходов

Для №19 не обязательно сразу строить универсальную рекурсивную функцию для всех трёх игровых заданий.

Условие относится только к первому ходу Пети и первому ходу Вани, поэтому его можно записать напрямую.

```python
def moves(x, y):
    return (
        (x + 4, y),
        (x, y + 4),
        (x * 2, y),
        (x, y * 2)
    )

for S in range(1, 116):
    ok = False

    for p in moves(17, S):
        if sum(p) >= 133:
            continue

        for v in moves(*p):
            if sum(v) >= 133:
                ok = True
                break

        if ok:
            break

    if ok:
        print(S)
        break
```

Здесь программа буквально проверяет условие задачи:

1. перебираем `S`;
2. перебираем возможный первый ход Пети;
3. Петя этим ходом не должен закончить игру;
4. перебираем ответы Вани;
5. если хотя бы один ответ Вани завершает игру, ситуация возможна.

---

# Более компактная запись через any()

Ту же мысль можно записать короче:

```python
def moves(x, y):
    return (
        (x + 4, y),
        (x, y + 4),
        (x * 2, y),
        (x, y * 2)
    )

for S in range(1, 116):
    ok = any(
        sum(p) < 133 and
        any(sum(v) >= 133 for v in moves(*p))
        for p in moves(17, S)
    )

    if ok:
        print(S)
        break
```

Эта запись короче, но для первого знакомства вложенные циклы обычно понятнее.

---

# Что означает any()

```python
any(условия)
```

возвращает `True`, если **хотя бы одно** условие истинно.

В игровых задачах это соответствует фразам:

```text
может сделать ход
существует ход
после некоторого хода
такая ситуация возможна
```

То есть игроку достаточно иметь **один подходящий вариант**.

---

# Что означает all()

```python
all(условия)
```

возвращает `True`, только если истинны **все** условия.

В игровых задачах это соответствует фразам:

```text
при любом ходе противника
независимо от того, как будет ходить противник
гарантированно выигрывает
```

Для №19 демоверсии `all()` ещё не требуется, но в №20–21 он становится ключевым.

---

# Почему №19 нельзя автоматически решать как №20 и №21

У трёх заданий одни правила игры, но разные логические требования.

В №19 демоверсии сказано:

> Ваня выиграл своим первым ходом. Укажите минимальное S, при котором такая ситуация возможна.

Это означает существование подходящей партии.

А в №20 уже появляется требование:

```text
независимо от того, как будет ходить Ваня
```

Это совсем другая логика: там нужно доказывать выигрышную стратегию.

Поэтому нельзя механически использовать одну и ту же проверку для №19, №20 и №21.

---

# Альтернативный способ: рассуждение с конца

№19 часто можно решить вообще без программы.

Полезно рассуждать от победной позиции назад:

```text
Какая позиция позволит Ване закончить игру одним ходом?

Как Петя может оставить Ване такую позицию?

При каком минимальном S это возможно?
```

Такой способ особенно удобен, если ходов мало и граница победы легко анализируется.

Python в этом случае можно использовать для проверки ответа.

---

# Один важный нюанс: «неудачный ход Пети»

Если по условию Ваня выиграл своим первым ходом, значит после первого хода Пети игра ещё продолжалась.

Поэтому позиция после хода Пети должна удовлетворять:

```python
x + y < 133
```

Если Петя уже получил `133` или больше, игра закончилась его победой и до хода Вани дело не дошло бы.

---

# Как понять, какой способ выбрать

Для №19 удобно начать с обычного перебора первых двух ходов, если нужно наглядно увидеть логику задачи.

Если числа позволяют быстро рассуждать с конца, ручной анализ может оказаться ещё короче.

Универсальную рекурсивную функцию имеет смысл вводить уже при переходе к №20–21, где появляются гарантированные стратегии и несколько уровней игры.

---

# Частые ошибки

1. Считать, что Ваня должен выиграть после любого хода Пети, хотя в №19 сказано только, что такая ситуация возможна.
2. Забыть, что первый ход делает Петя.
3. Считать победной позицию только при `x + y == 133`, хотя условие говорит `не менее 133`.
4. Разрешить Ване ход после того, как Петя уже завершил игру.
5. Перебирать только изменения второй кучи — игрок может менять любую из двух куч.
6. Путать `any()` и `all()`.
7. Сразу заучивать сложную рекурсивную функцию, не понимая, что именно означает каждый уровень игры.

---

# Быстрая памятка

```text
№19 — теория игр

1. Выписать условие окончания игры.
2. Выписать все возможные ходы.
3. Определить, чей ход первый.
4. Перевести формулировку задачи на язык логики.

существует подходящий ход → any
при любом ходе соперника → all

В демоверсии №19:
Петя делает первый ход,
этим ходом не заканчивает игру,
после некоторого такого хода
Ваня может закончить игру своим первым ходом.
```

Главный навык №19 — не запоминание конкретного кода, а умение увидеть в формулировке, где требуется **существование хода**, а где — **гарантия при любых действиях соперника**.
