# ЕГЭ №17. Обработка числовой последовательности

## Что проверяет задание

В задании №17 нужно написать небольшую программу, которая обрабатывает последовательность чисел из файла.

Обычно требуется:

- найти некоторое значение по всей последовательности: минимум, максимум, минимальное/максимальное число с определённым свойством;
- рассмотреть **пары соседних элементов**;
- отобрать пары по условию;
- вывести количество подходящих пар и один экстремум: максимальную/минимальную сумму, произведение и т. п.

В проекте демоверсии ЕГЭ-2027 требуется найти пары соседних элементов, в которых остаток от деления на 33 хотя бы одного элемента равен минимальному элементу всей последовательности.

---

# Главный принцип

Большинство задач №17 удобно решать по одной схеме:

```text
1. прочитать все числа из файла;
2. найти значение, от которого зависит условие;
3. пройти по соседним элементам;
4. проверить условие пары;
5. обновить счётчик и нужный экстремум.
```

Главная идея:

> сначала вычисляем характеристику всей последовательности, а уже потом проверяем пары.

---

# Чтение файла

Если в файле по одному числу в строке:

```python
f = open('17.txt')
a = [int(x) for x in f]
```

После этого `a` — список всех чисел.

Можно записать и так:

```python
with open('17.txt') as f:
    a = [int(x) for x in f]
```

Для ЕГЭ оба варианта подходят. Первый обычно проще для ученика.

---

# Как перебирать соседние пары

Если элементы имеют индексы:

```text
0 1 2 3 4 ...
```

то пары:

```text
(a[0], a[1])
(a[1], a[2])
(a[2], a[3])
...
```

Поэтому используем:

```python
for i in range(len(a) - 1):
    x = a[i]
    y = a[i + 1]
```

`len(a) - 1` нужен потому, что для последнего элемента уже нет следующего.

---

# Универсальный шаблон №17

```python
f = open('17.txt')
a = [int(x) for x in f]

# значение, которое нужно найти по всей последовательности
m = min(a)

count = 0
best = None

for i in range(len(a) - 1):
    x = a[i]
    y = a[i + 1]

    if УСЛОВИЕ:
        count += 1
        value = x + y

        if best is None or value > best:
            best = value

print(count, best)
```

Этот шаблон удобно адаптировать почти под любой вариант с соседними парами.

# Демоверсия ЕГЭ-2027

В файле дана последовательность натуральных чисел.

Нужно найти пары соседних элементов, в которых:

```text
остаток от деления на 33 хотя бы одного элемента
равен минимальному элементу всей последовательности.
```

Сначала находим минимум:

```python
m = min(a)
```

Условие для одного числа:

```python
x % 33 == m
```

Для пары условие «хотя бы один» означает `or`:

```python
x % 33 == m or y % 33 == m
```

Полное решение:

```python
f = open('17.txt')
a = [int(x) for x in f]

m = min(a)

count = 0
max_sum = 0

for i in range(len(a) - 1):
    x = a[i]
    y = a[i + 1]

    if x % 33 == m or y % 33 == m:
        count += 1
        max_sum = max(max_sum, x + y)

print(count, max_sum)
```

Для файла демоверсии ответ:

```text
622 174933
```

---

# Что означает «хотя бы один»

Это одна из самых частых формулировок.

Если хотя бы один элемент должен удовлетворять условию:

```python
условие(x) or условие(y)
```

Например:

```python
x % 7 == 0 or y % 7 == 0
```

Если условию должны удовлетворять оба:

```python
условие(x) and условие(y)
```

---

# Тип 1. Хотя бы один элемент пары обладает свойством

Например, хотя бы один элемент делится на 17:

```python
if x % 17 == 0 or y % 17 == 0:
    ...
```

Хотя бы один элемент оканчивается на 5:

```python
if x % 10 == 5 or y % 10 == 5:
    ...
```

Хотя бы один элемент больше найденного значения `m`:

```python
if x > m or y > m:
    ...
```

---

# Тип 2. Ровно один элемент обладает свойством

Например, ровно один элемент пары делится на 7.

Удобный способ:

```python
if (x % 7 == 0) + (y % 7 == 0) == 1:
    ...
```

Почему это работает:

```text
False → 0
True  → 1
```

Поэтому сумма двух логических выражений показывает, сколько элементов удовлетворяет условию.

Этот приём очень полезен в №17.

---

# Тип 3. Оба элемента обладают свойством

Например, оба элемента нечётные:

```python
if x % 2 != 0 and y % 2 != 0:
    ...
```

Или оба меньше некоторого значения `m`:

```python
if x < m and y < m:
    ...
```

---

# Тип 4. Условие связано с минимумом или максимумом последовательности

Часто сначала требуется найти особый элемент.

Минимум:

```python
m = min(a)
```

Максимум:

```python
m = max(a)
```

Например, минимальный элемент, кратный 17:

```python
m = min(x for x in a if x % 17 == 0)
```

Максимальный элемент, оканчивающийся на 13:

```python
m = max(x for x in a if x % 100 == 13)
```

После этого `m` используется в условии для пары.

---

# Тип 5. Сравнение суммы пары с найденным значением

Например:

```text
сумма пары больше максимального элемента,
оканчивающегося на 25
```

Сначала:

```python
m = max(x for x in a if x % 100 == 25)
```

Затем:

```python
if x + y > m:
    ...
```

---

# Тип 6. Количество элементов пары, удовлетворяющих условию

Например, хотя бы один элемент трёхзначный:

```python
if (100 <= x <= 999) or (100 <= y <= 999):
    ...
```

Ровно один трёхзначный:

```python
if (100 <= x <= 999) + (100 <= y <= 999) == 1:
    ...
```

Оба трёхзначные:

```python
if (100 <= x <= 999) and (100 <= y <= 999):
    ...
```

---

# Тип 7. Работа с последними цифрами

Число оканчивается на 7:

```python
x % 10 == 7
```

На 17:

```python
x % 100 == 17
```

На 123:

```python
x % 1000 == 123
```

Для отрицательных чисел в некоторых вариантах безопаснее сравнивать модуль:

```python
abs(x) % 100 == 17
```

Всегда смотрите на формулировку конкретного задания.

# Что нужно найти после отбора пар

Чаще всего ответ состоит из двух чисел.

## Количество пар

```python
count += 1
```

## Максимальная сумма

```python
max_sum = max(max_sum, x + y)
```

## Минимальная сумма

Надёжный вариант:

```python
min_sum = None

...

if min_sum is None or x + y < min_sum:
    min_sum = x + y
```

## Максимальное произведение

```python
max_product = max(max_product, x * y)
```

Выбираем именно ту характеристику, которую требует условие.

---

# Почему `best = 0` подходит не всегда

Если все числа натуральные и требуется максимальная сумма, можно написать:

```python
max_sum = 0
```

Но если в последовательности могут быть отрицательные числа, это опасно.

Например, реальные подходящие суммы:

```text
-15
-8
-20
```

Тогда программа с начальным `max_sum = 0` ошибочно оставит 0.

Универсальный вариант:

```python
best = None

if best is None or value > best:
    best = value
```

---

# Альтернативный способ: zip

Соседние пары можно получить и так:

```python
for x, y in zip(a, a[1:]):
    if условие:
        ...
```

Например:

```python
for x, y in zip(a, a[1:]):
    if x % 33 == m or y % 33 == m:
        ...
```

Это коротко, но для обучения обычно понятнее индексный вариант:

```python
for i in range(len(a) - 1):
```

# Как понять, что делать в задаче

Полезно переводить условие на язык программы по частям.

Например:

```text
«найдите минимальный элемент последовательности»
```

→

```python
m = min(a)
```

```text
«рассмотрите пары идущих подряд элементов»
```

→

```python
for i in range(len(a) - 1):
```

```text
«хотя бы один»
```

→

```python
or
```

```text
«ровно один»
```

→

```python
condition1 + condition2 == 1
```

```text
«максимальная сумма»
```

→

```python
max(...)
```

То есть №17 удобно решать не целиком в голове, а переводить каждую фразу условия в отдельную строку программы.

# Частые ошибки

## 1. Перебирать все возможные пары

Неправильно:

```python
for x in a:
    for y in a:
        ...
```

Если сказано **два идущих подряд элемента**, нужны только соседние пары.

---

## 2. Выйти за границу списка

Неправильно:

```python
for i in range(len(a)):
    x = a[i]
    y = a[i + 1]
```

На последнем шаге `a[i + 1]` не существует.

Правильно:

```python
for i in range(len(a) - 1):
```

---

## 3. Перепутать `or` и `and`

```text
хотя бы один → or
оба           → and
```

---

## 4. Неправильно понять «ровно один»

`or` означает «хотя бы один», а не «ровно один».

Для ровно одного:

```python
condition1 + condition2 == 1
```

---

## 5. Найти минимум только среди элементов пар

Если сказано «минимальный элемент последовательности», минимум ищется среди **всех** чисел:

```python
m = min(a)
```

---

## 6. Сравнить не ту величину

Например, условие:

```text
остаток от деления на 33 равен минимуму
```

означает:

```python
x % 33 == m
```

а не:

```python
x == m
```

---

## 7. Обновлять экстремум вне условия

Нужно:

```python
if условие:
    count += 1
    max_sum = max(max_sum, x + y)
```

Иначе в максимум попадут пары, которые вообще не подходят.

---

# Быстрая памятка

```python
f = open('17.txt')
a = [int(x) for x in f]

m = min(a)

count = 0
best = None

for i in range(len(a) - 1):
    x = a[i]
    y = a[i + 1]

    if УСЛОВИЕ:
        count += 1
        value = x + y

        if best is None or value > best:
            best = value

print(count, best)
```

Полезные конструкции:

```python
min(a)
max(a)

x % 17 == 0
x % 10 == 7
x % 100 == 17

condition_x or condition_y
condition_x and condition_y
condition_x + condition_y == 1

for i in range(len(a) - 1):
    x = a[i]
    y = a[i + 1]
```

Главная схема №17:

> **прочитать → найти опорное значение → перебрать соседние пары → проверить условие → посчитать → найти экстремум.**
