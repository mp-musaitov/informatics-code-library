# ЕГЭ №17. Обработка числовой последовательности

## Что проверяет задание

В задании №17 нужно написать программу, которая обрабатывает последовательность чисел из файла.

Перед решением важно понять, **какие элементы требуется рассматривать вместе**. Встречаются разные формулировки:

- два соседних элемента;
- три соседних элемента;
- несколько идущих подряд элементов;
- два различных элемента последовательности, которые могут находиться в любых местах.

После этого обычно нужно проверить условие, посчитать подходящие группы и найти максимум или минимум некоторой величины.

В проекте демоверсии ЕГЭ-2027 рассматриваются пары соседних элементов.

---

# Главный принцип

Сначала определяем **тип перебора**, а уже потом записываем условие.

```text
соседняя пара      → a[i:i+2]
соседняя тройка    → a[i:i+3]
группа из k подряд → a[i:i+k]

любые два различных элемента
                    → a[i], a[j], где i < j
```

Для соседних элементов удобно использовать **срезы**. Тогда текущая пара, тройка или другая группа становится отдельным маленьким списком, который можно удобно обрабатывать генераторами списков.

---

# Чтение файла

Если в файле по одному числу в строке:

```python
f = open('17.txt')
a = [int(x) for x in f]
```

После этого `a` — список всех чисел.

Можно записать и так:

```python
with open('17.txt') as f:
    a = [int(x) for x in f]
```

Для ЕГЭ оба варианта подходят.

---

# Соседние пары

Для последовательности:

```text
10 20 30 40
```

соседние пары:

```text
[10, 20]
[20, 30]
[30, 40]
```

Получаем их срезом:

```python
for i in range(len(a) - 1):
    t = a[i:i + 2]
```

Здесь `t` — текущая пара.

Например, если нужно проверить, что ровно один элемент пары делится на 7:

```python
for i in range(len(a) - 1):
    t = a[i:i + 2]
    b = [x for x in t if x % 7 == 0]

    if len(b) == 1:
        ...
```

Такой способ особенно удобен, когда условие звучит как:

```text
«хотя бы один элемент...»
«ровно один элемент...»
«оба элемента...»
```

---

# Соседние тройки

Если требуется рассматривать **три идущих подряд элемента**:

```python
for i in range(len(a) - 2):
    t = a[i:i + 3]
```

Например, нужно выбрать тройки, в которых ровно два элемента — четырёхзначные числа, оканчивающиеся на 3:

```python
for i in range(len(a) - 2):
    t = a[i:i + 3]

    b = [x for x in t
         if 1000 <= abs(x) <= 9999 and abs(x) % 10 == 3]

    if len(b) == 2:
        ...
```

Здесь сначала создаётся текущая тройка `t`, затем из неё выбираются элементы, удовлетворяющие условию.

Это позволяет буквально переводить текст задачи в программу:

```text
«ровно два элемента тройки обладают свойством»
                    ↓
b = [x for x in t if УСЛОВИЕ]
                    ↓
len(b) == 2
```

---

# Универсальная группа из k соседних элементов

Для группы длины `k`:

```python
for i in range(len(a) - k + 1):
    t = a[i:i + k]
```

Почему именно:

```python
len(a) - k + 1
```

Потому что последний допустимый срез должен ещё содержать все `k` элементов.

Для пары `k = 2`:

```python
len(a) - 1
```

Для тройки `k = 3`:

```python
len(a) - 2
```

---

# Генераторы списков внутри пары или тройки

После получения текущей группы `t` удобно выбрать из неё элементы с нужным свойством.

Например, элементы, кратные 17:

```python
b = [x for x in t if x % 17 == 0]
```

Четырёхзначные элементы:

```python
b = [x for x in t if 1000 <= abs(x) <= 9999]
```

Элементы, оканчивающиеся на 3:

```python
b = [x for x in t if abs(x) % 10 == 3]
```

После этого количество подходящих элементов определяется через `len(b)`:

```python
len(b) >= 1   # хотя бы один
len(b) == 1   # ровно один
len(b) == 2   # ровно два
len(b) == len(t)   # подходят все элементы группы
```

Такой способ особенно удобен для троек и более длинных групп: условие почти не усложняется.

# Характеристика всей последовательности и текущей группы

В №17 часто сначала нужно найти некоторое значение **по всей последовательности**.

Например, максимальный четырёхзначный элемент, оканчивающийся на 3:

```python
b = [x for x in a
     if 1000 <= abs(x) <= 9999 and abs(x) % 10 == 3]

m = max(b)
```

А затем внутри каждой тройки проверить другое условие:

```python
for i in range(len(a) - 2):
    t = a[i:i + 3]

    p = [x for x in t
         if 1000 <= abs(x) <= 9999 and abs(x) % 10 == 3]

    if len(p) == 2 and sum(t) > m:
        ...
```

Здесь один и тот же приём используется дважды:

```text
a → выбрать подходящие элементы всей последовательности

t → выбрать подходящие элементы текущей тройки
```

---

# Универсальный шаблон для соседних групп

```python
f = open('17.txt')
a = [int(x) for x in f]

# характеристика всей последовательности
m = ...

count = 0
best = None

for i in range(len(a) - 2):
    t = a[i:i + 3]

    b = [x for x in t if УСЛОВИЕ_ДЛЯ_ОДНОГО_ЭЛЕМЕНТА]

    if УСЛОВИЕ_ДЛЯ_ГРУППЫ:
        count += 1
        value = sum(t)

        if best is None or value > best:
            best = value

print(count, best)
```

Для пары достаточно заменить:

```python
range(len(a) - 2)
a[i:i + 3]
```

на:

```python
range(len(a) - 1)
a[i:i + 2]
```

---

# `best = None`

Для поиска максимума или минимума удобно использовать:

```python
best = None
```

Это означает:

> подходящего значения пока нет.

Когда встречается первая подходящая группа, её значение сохраняется независимо от того, положительное оно, отрицательное или равно нулю.

Максимум:

```python
if best is None or value > best:
    best = value
```

Минимум:

```python
if best is None or value < best:
    best = value
```

Этот способ не требует заранее подбирать «очень большое» или «очень маленькое» начальное число.

# Два различных элемента последовательности

Отдельный тип задач:

> Под парой подразумеваются два различных элемента последовательности. Порядок элементов в паре не важен.

Здесь элементы **не обязаны стоять рядом**.

Например, для последовательности:

```text
10 20 30 40
```

рассматриваются:

```text
(10, 20)
(10, 30)
(10, 40)
(20, 30)
(20, 40)
(30, 40)
```

Шаблон:

```python
for i in range(len(a)):
    for j in range(i + 1, len(a)):
        x = a[i]
        y = a[j]

        if УСЛОВИЕ:
            ...
```

`j` начинается с `i + 1`, поэтому:

- элемент не образует пару сам с собой;
- одна и та же пара не считается дважды;
- всегда выполняется `i < j`.

## Различные элементы — не обязательно различные значения

Например:

```text
25 10 25
```

два числа `25` находятся на разных позициях, поэтому могут образовать пару:

```text
(25, 25)
```

Не нужно писать:

```python
x != y
```

если этого отдельно не требует условие.

## Универсальный шаблон

```python
f = open('17.txt')
a = [int(x) for x in f]

count = 0
best = None

for i in range(len(a)):
    for j in range(i + 1, len(a)):
        x = a[i]
        y = a[j]

        if УСЛОВИЕ:
            count += 1
            value = x + y

            if best is None or value > best:
                best = value

print(count, best)
```

Примеры условий:

```python
# сумма кратна 120
if (x + y) % 120 == 0:
    ...

# произведение не кратно 14
if (x * y) % 14 != 0:
    ...

# разность кратна 80, порядок не важен
if abs(x - y) % 80 == 0:
    ...
```

# Демоверсия ЕГЭ-2027

В файле дана последовательность натуральных чисел.

Нужно найти пары **соседних** элементов, в которых остаток от деления на 33 хотя бы одного элемента равен минимальному элементу всей последовательности.

Сначала:

```python
m = min(a)
```

Для текущей пары можно использовать срез:

```python
for i in range(len(a) - 1):
    t = a[i:i + 2]
```

Подходящие элементы текущей пары:

```python
b = [x for x in t if x % 33 == m]
```

Нужно, чтобы таких элементов был хотя бы один:

```python
len(b) >= 1
```

Полное решение:

```python
f = open('17.txt')
a = [int(x) for x in f]

m = min(a)
count = 0
best = None

for i in range(len(a) - 1):
    t = a[i:i + 2]
    b = [x for x in t if x % 33 == m]

    if len(b) >= 1:
        count += 1
        value = sum(t)

        if best is None or value > best:
            best = value

print(count, best)
```

Для файла демоверсии ответ:

```text
622 174933
```

---

# Когда лучше использовать `x`, `y`, а когда срез

Для простой соседней пары иногда короче записать:

```python
x = a[i]
y = a[i + 1]

if x % 17 == 0 or y % 17 == 0:
    ...
```

Но если условие связано с **количеством элементов**, удовлетворяющих свойству, удобнее срез и генератор списка:

```python
t = a[i:i + 2]
b = [x for x in t if x % 17 == 0]

if len(b) == 1:
    ...
```

Для троек срез обычно ещё удобнее:

```python
t = a[i:i + 3]
b = [x for x in t if УСЛОВИЕ]

if len(b) == 2:
    ...
```

Главная цель — выбрать запись, которая делает условие задачи проще и понятнее.

# Частые условия

Элемент делится на 17:

```python
x % 17 == 0
```

Элемент не делится на 17:

```python
x % 17 != 0
```

Элемент оканчивается на 7:

```python
abs(x) % 10 == 7
```

Элемент оканчивается на 17:

```python
abs(x) % 100 == 17
```

Трёхзначное число:

```python
100 <= abs(x) <= 999
```

Четырёхзначное число:

```python
1000 <= abs(x) <= 9999
```

Минимум всей последовательности:

```python
m = min(a)
```

Максимум среди элементов с условием:

```python
m = max(x for x in a if УСЛОВИЕ)
```

# Как понять, какой перебор нужен

```text
«два соседних элемента»
«два идущих подряд элемента»
        ↓
t = a[i:i+2]
```

```text
«три соседних элемента»
«тройка идущих подряд элементов»
        ↓
t = a[i:i+3]
```

```text
«k идущих подряд элементов»
        ↓
t = a[i:i+k]
```

```text
«два различных элемента последовательности»
«порядок элементов в паре не важен»
        ↓
два вложенных цикла, j начинается с i + 1
```

После выбора перебора отдельно переводим каждое условие задачи в Python.

# Частые ошибки

## 1. Не прочитать, какие элементы образуют пару или группу

Нельзя автоматически считать, что №17 всегда решается через соседнюю пару.

---

## 2. Ошибиться в границе цикла

Для пары:

```python
range(len(a) - 1)
```

Для тройки:

```python
range(len(a) - 2)
```

Общее правило:

```python
range(len(a) - k + 1)
```

---

## 3. Перебирать все пары, когда нужны соседние

Для соседних элементов не нужны два вложенных цикла.

---

## 4. Перебирать только соседей, когда нужны любые два элемента

Если сказано «два различных элемента последовательности», нужны все пары разных позиций.

---

## 5. Считать одну произвольную пару дважды

Используйте:

```python
for j in range(i + 1, len(a)):
```

---

## 6. Путать разные элементы и разные значения

Одинаковые числа на разных позициях — разные элементы последовательности.

---

## 7. Неправильно посчитать количество элементов с нужным свойством

Для тройки условие «ровно два» удобно записывать так:

```python
b = [x for x in t if УСЛОВИЕ]

if len(b) == 2:
    ...
```

---

## 8. Найти характеристику только внутри текущей группы

Если сказано «максимальный элемент последовательности», его нужно искать по всему `a`, а не только по `t`.

---

## 9. Обновлять максимум или минимум вне условия

Правильно:

```python
if УСЛОВИЕ:
    count += 1
    value = ...

    if best is None or value > best:
        best = value
```

1. Прочитать файл.

5. Проверить количество или другое условие группы.

Главное правило:

> Сначала определяем, какие элементы рассматриваются вместе. Затем превращаем их в удобную группу и только после этого проверяем условие.
