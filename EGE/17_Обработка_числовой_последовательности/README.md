# ЕГЭ №17. Обработка числовой последовательности

## Что проверяет задание

В задании №17 нужно написать программу, которая обрабатывает последовательность чисел из файла.

Прежде всего нужно определить, **что именно в условии называется парой**. Встречаются два принципиально разных типа:

1. **пара соседних элементов** — два элемента, идущих подряд;
2. **пара различных элементов последовательности** — любые два элемента, находящиеся на разных позициях.

После этого обычно требуется отобрать пары по условию и вывести количество подходящих пар и некоторый экстремум: максимальную или минимальную сумму, произведение и т. п.

В проекте демоверсии ЕГЭ-2027 используется первый тип: пары соседних элементов.

---

# Главный принцип

Перед написанием цикла найдите в условии определение пары.

```text
«два идущих подряд элемента»
        ↓
соседние пары
        ↓
(a[i], a[i + 1])
```

```text
«два различных элемента последовательности»
        ↓
любые две разные позиции
        ↓
(a[i], a[j]), где i < j
```

Это определяет сам способ перебора. Все остальные условия — делимость, остатки, сумма, произведение, минимум последовательности — проверяются уже внутри выбранного перебора.

---

# Чтение файла

Если в файле по одному числу в строке:

```python
f = open('17.txt')
a = [int(x) for x in f]
```

После этого `a` — список всех чисел.

Можно записать и так:

```python
with open('17.txt') as f:
    a = [int(x) for x in f]
```

Для ЕГЭ оба варианта подходят. Первый обычно проще для ученика.

---

# Тип пар A. Соседние элементы

Если элементы имеют индексы:

```text
0 1 2 3 4 ...
```

то рассматриваются пары:

```text
(a[0], a[1])
(a[1], a[2])
(a[2], a[3])
...
```

Шаблон:

```python
for i in range(len(a) - 1):
    x = a[i]
    y = a[i + 1]

    if УСЛОВИЕ:
        ...
```

`len(a) - 1` нужен потому, что у последнего элемента уже нет следующего.

## Универсальный шаблон для соседних пар

```python
f = open('17.txt')
a = [int(x) for x in f]

m = min(a)
count = 0
best = None

for i in range(len(a) - 1):
    x = a[i]
    y = a[i + 1]

    if УСЛОВИЕ:
        count += 1
        value = x + y
        if best is None or value > best:
            best = value

print(count, best)
```

# Тип пар B. Два различных элемента последовательности

В некоторых задачах прямо сказано:

> Под парой подразумеваются два различных элемента последовательности. Порядок элементов в паре не важен.

Здесь элементы **не обязаны стоять рядом**.

Если последовательность:

```text
10 20 30 40
```

то рассматриваются пары:

```text
(10, 20)
(10, 30)
(10, 40)
(20, 30)
(20, 40)
(30, 40)
```

Используем два индекса:

```python
for i in range(len(a)):
    for j in range(i + 1, len(a)):
        x = a[i]
        y = a[j]

        if УСЛОВИЕ:
            ...
```

Почему второй цикл начинается с `i + 1`? Это сразу гарантирует, что один элемент не образует пару сам с собой, одна и та же пара не считается дважды и всегда выполняется `i < j`.

## Важно: различные элементы — не обязательно различные значения

Речь идёт о **разных позициях**.

Например:

```text
25 10 25
```

два числа `25` находятся на разных позициях, поэтому они могут образовать пару `(25, 25)`.

Нельзя добавлять условие:

```python
x != y
```

если этого отдельно не требует задача.

## Универсальный шаблон для любых двух различных элементов

```python
f = open('17.txt')
a = [int(x) for x in f]

count = 0
best = None

for i in range(len(a)):
    for j in range(i + 1, len(a)):
        x = a[i]
        y = a[j]

        if УСЛОВИЕ:
            count += 1
            value = x + y
            if best is None or value > best:
                best = value

print(count, best)
```

Примеры условий:

```python
# сумма кратна 120
if (x + y) % 120 == 0:
    ...

# произведение не кратно 14
if (x * y) % 14 != 0:
    ...

# разность кратна 80, порядок не важен
if abs(x - y) % 80 == 0:
    ...
```

# Демоверсия ЕГЭ-2027

В файле дана последовательность натуральных чисел.

Нужно найти пары **соседних** элементов, в которых остаток от деления на 33 хотя бы одного элемента равен минимальному элементу всей последовательности.

```python
f = open('17.txt')
a = [int(x) for x in f]

m = min(a)
count = 0
max_sum = 0

for i in range(len(a) - 1):
    x = a[i]
    y = a[i + 1]

    if x % 33 == m or y % 33 == m:
        count += 1
        max_sum = max(max_sum, x + y)

print(count, max_sum)
```

Для файла демоверсии ответ:

```text
622 174933
```

# Условия внутри пары

После того как выбран правильный способ перебора, сами условия записываются одинаково и для соседних, и для произвольных пар.

## Хотя бы один элемент обладает свойством

```python
if условие(x) or условие(y):
    ...
```

Например:

```python
if x % 17 == 0 or y % 17 == 0:
    ...
```

## Ровно один элемент обладает свойством

```python
if условие(x) + условие(y) == 1:
    ...
```

Например:

```python
if (x % 7 == 0) + (y % 7 == 0) == 1:
    ...
```

`False` превращается в 0, `True` — в 1.

## Оба элемента обладают свойством

```python
if условие(x) and условие(y):
    ...
```

---

# Условие связано с минимумом или максимумом последовательности

Минимум:

```python
m = min(a)
```

Максимум:

```python
m = max(a)
```

Минимальный элемент, кратный 17:

```python
m = min(x for x in a if x % 17 == 0)
```

Максимальный элемент, оканчивающийся на 13:

```python
m = max(x for x in a if x % 100 == 13)
```

После этого `m` используется в условии пары.

---

# Сравнение суммы пары с найденным значением

Например, сумма пары должна быть больше максимального элемента, оканчивающегося на 25:

```python
m = max(x for x in a if x % 100 == 25)

...

if x + y > m:
    ...
```

---

# Количество элементов пары, удовлетворяющих условию

Хотя бы один трёхзначный:

```python
if (100 <= x <= 999) or (100 <= y <= 999):
    ...
```

Ровно один трёхзначный:

```python
if (100 <= x <= 999) + (100 <= y <= 999) == 1:
    ...
```

Оба трёхзначные:

```python
if (100 <= x <= 999) and (100 <= y <= 999):
    ...
```

---

# Работа с последними цифрами

```python
x % 10 == 7       # оканчивается на 7
x % 100 == 17     # оканчивается на 17
x % 1000 == 123   # оканчивается на 123
```

Для отрицательных чисел в некоторых вариантах безопаснее сравнивать модуль:

```python
abs(x) % 100 == 17
```

Всегда смотрите на формулировку конкретного задания.

---

# Что нужно найти после отбора пар

Количество:

```python
count += 1
```

Максимальная сумма:

```python
max_sum = max(max_sum, x + y)
```

Минимальная сумма:

```python
min_sum = None

if min_sum is None or x + y < min_sum:
    min_sum = x + y
```

Максимальное произведение:

```python
max_product = max(max_product, x * y)
```

---

# Почему `best = 0` подходит не всегда

Если все числа натуральные и требуется максимальная сумма, `max_sum = 0` подходит.

Но если возможны отрицательные числа, подходящие суммы тоже могут быть отрицательными. Тогда надёжнее:

```python
best = None

if best is None or value > best:
    best = value
```

# Альтернативный способ для соседних пар: zip

```python
for x, y in zip(a, a[1:]):
    if УСЛОВИЕ:
        ...
```

Это коротко, но для обучения обычно понятнее индексный вариант.

---

# Как понять, какой перебор нужен

```text
«два идущих подряд элемента»
«соседние элементы»
        ↓
for i in range(len(a) - 1)
```

```text
«два различных элемента последовательности»
«порядок элементов в паре не важен»
        ↓
for i in range(len(a)):
    for j in range(i + 1, len(a)):
```

После выбора перебора переводим остальные части условия:

```text
«хотя бы один» → or
«оба» → and
«ровно один» → сумма логических условий == 1
«максимальная сумма» → ищем max
«минимальная сумма» → ищем min
```

# Частые ошибки

## 1. Не прочитать определение пары

Нельзя автоматически считать, что в №17 всегда нужны соседние элементы.

## 2. Перебирать все пары, когда нужны соседние

Если сказано **два идущих подряд элемента**, нужен один цикл по `a[i]` и `a[i + 1]`.

## 3. Перебирать только соседей, когда нужны любые два элемента

Если сказано **два различных элемента последовательности**, нужны все пары разных позиций.

## 4. Считать одну пару дважды

В произвольных парах используйте:

```python
for j in range(i + 1, len(a)):
```

а не полный второй цикл от нуля.

## 5. Путать разные элементы и разные значения

Одинаковые числа на разных позициях — это разные элементы. Не добавляйте `x != y`, если этого нет в условии.

## 6. Выйти за границу списка при соседних парах

```python
for i in range(len(a) - 1):
```

## 7. Перепутать `or` и `and`

```text
хотя бы один → or
оба           → and
```

## 8. Неправильно понять «ровно один»

`or` означает «хотя бы один». Для ровно одного:

```python
condition1 + condition2 == 1
```

## 9. Найти минимум не по всей последовательности

Если сказано «минимальный элемент последовательности»:

```python
m = min(a)
```

## 10. Обновлять экстремум вне условия

Экстремум обновляется только для подходящей пары.
