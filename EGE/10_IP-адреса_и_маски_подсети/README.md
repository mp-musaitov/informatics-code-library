# №10. IP-адреса и маски подсети

## Что проверяет задание

В проекте ЕГЭ-2027 задание №10 посвящено IP-адресации и маскам подсети.

В демоверсии 2027 года дан IP-адрес узла и маска, а требуется найти адрес сети. В других задачах этого же типа могут спрашивать:

- адрес сети;
- маску или длину префикса;
- количество адресов в сети;
- находятся ли два узла в одной сети;
- количество адресов, удовлетворяющих дополнительному условию;
- допустимое значение неизвестного октета.

---

# Основной принцип

IPv4-адрес состоит из 32 бит, то есть из четырёх октетов по 8 бит:

```text
192.168.159.86
```

Маска тоже состоит из 32 бит. В корректной маске сначала идут единицы, а затем нули.

Например:

```text
255.255.252.0
```

в двоичном виде:

```text
11111111.11111111.11111100.00000000
```

Единицы маски обозначают часть адреса, относящуюся к сети, нули — часть адреса узла.

Главная формула:

```text
адрес сети = IP-адрес AND маска
```

То есть применяется побитовая конъюнкция.

---

# Побитовое И

Для каждого бита:

```text
1 AND 1 = 1
1 AND 0 = 0
0 AND 1 = 0
0 AND 0 = 0
```

Поэтому при нахождении адреса сети часть адреса, закрытая нулями маски, превращается в нули.

---

# Тип 1. Найти адрес сети

Это тип задания из демоверсии ЕГЭ-2027.

Дано:

```text
IP:    192.168.159.86
маска: 255.255.252.0
```

## Ручной способ

Первые два октета маски равны 255, значит они сохраняются:

```text
192.168
```

Последний октет маски равен 0, значит последний октет адреса сети:

```text
0
```

Остаётся третий октет:

```text
159 = 10011111
252 = 11111100
```

Применяем AND:

```text
10011111
11111100
--------
10011100
```

```text
10011100₂ = 156
```

Получаем адрес сети:

```text
192.168.156.0
```

В демоверсии требуется сумма октетов:

```text
192 + 168 + 156 + 0 = 516
```

Ответ:

```text
516
```

---

# Основной способ на Python — модуль `ipaddress`

Для задач с сетями удобно использовать стандартный модуль Python `ipaddress`.

```python
from ipaddress import ip_network

net = ip_network('192.168.159.86/255.255.252.0', strict=False)

print(net.network_address)
```

Результат:

```text
192.168.156.0
```

`strict=False` означает: перед нами может быть адрес обычного узла, а не уже готовый адрес сети.

Если нужно получить сумму октетов:

```python
from ipaddress import ip_network

net = ip_network('192.168.159.86/255.255.252.0', strict=False)
address = str(net.network_address)

print(sum(map(int, address.split('.'))))
```

---

# Альтернативный способ — вручную через двоичные числа

Если модуль `ipaddress` ещё не изучался, можно выполнять AND самостоятельно.

```python
ip = [192, 168, 159, 86]
mask = [255, 255, 252, 0]

network = []

for i in range(4):
    network.append(ip[i] & mask[i])

print(network)
print(sum(network))
```

Оператор `&` — побитовое И.

Результат:

```text
[192, 168, 156, 0]
516
```

# Маска и длина префикса

Маску часто записывают не четырьмя числами, а количеством единиц в ней.

Например:

```text
255.255.255.0
```

это:

```text
/24
```

потому что в маске 24 единицы.

```text
255.255.252.0 = /22
```

С помощью Python:

```python
from ipaddress import ip_network

net = ip_network('192.168.159.86/255.255.252.0', strict=False)

print(net.prefixlen)
```

Результат:

```text
22
```

---

# Полезная таблица значений октета маски

Внутри маски переход от единиц к нулям может выглядеть только так:

```text
00000000 = 0
10000000 = 128
11000000 = 192
11100000 = 224
11110000 = 240
11111000 = 248
11111100 = 252
11111110 = 254
11111111 = 255
```

Других значений отдельного «переходного» октета корректной маски быть не может.

# Тип 2. Найти количество адресов в сети

Если длина префикса равна `n`, то под адрес узла остаётся:

```text
32 - n
```

бит.

Количество всех IP-адресов в сети:

```text
2^(32 - n)
```

Например, сеть `/24`:

```text
2^(32 - 24) = 2^8 = 256
```

В Python:

```python
from ipaddress import ip_network

net = ip_network('192.168.1.10/24', strict=False)
print(net.num_addresses)
```

Результат:

```text
256
```

Важно: если в задаче спрашивают именно **все IP-адреса сети**, обычно считаются все адреса сети. Если формулировка говорит о допустимых адресах узлов, отдельно проверяй, нужно ли исключать адрес сети и широковещательный адрес.

---

# Тип 3. Проверить, находятся ли два IP в одной сети

Для одной и той же маски нужно сравнить их адреса сети.

```python
from ipaddress import ip_network

ip1 = ip_network('192.168.10.25/24', strict=False)
ip2 = ip_network('192.168.10.200/24', strict=False)

print(ip1.network_address == ip2.network_address)
```

Если получено `True`, узлы находятся в одной сети при данной маске.

---

# Тип 4. Найти подходящую маску

Если маска неизвестна, удобно перебрать длину префикса от 0 до 32.

Например, нужно найти маски, при которых два адреса принадлежат одной сети:

```python
from ipaddress import ip_network

ip1 = '202.3.20.24'
ip2 = '202.3.27.11'

for mask in range(33):
    net1 = ip_network(f'{ip1}/{mask}', strict=False)
    net2 = ip_network(f'{ip2}/{mask}', strict=False)

    if net1.network_address == net2.network_address:
        print(mask)
```

После этого из подходящих значений выбирается то, которое требуется по условию: максимальное, минимальное и т. д.

---

# Тип 5. Посчитать адреса с дополнительным условием

Иногда нужно перебрать все адреса сети и проверить число единиц, нулей или другое свойство двоичной записи.

```python
from ipaddress import ip_network

net = ip_network('192.168.1.0/24')
count = 0

for ip in net:
    if bin(int(ip)).count('1') == 10:
        count += 1

print(count)
```

Полезная конструкция:

```python
bin(int(ip)).count('1')
```

показывает количество единиц в 32-битном представлении IP-адреса.

---

# Что даёт объект сети в `ipaddress`

```python
from ipaddress import ip_network

net = ip_network('192.168.159.86/22', strict=False)

print(net.network_address)   # адрес сети
print(net.netmask)           # маска
print(net.prefixlen)         # длина префикса
print(net.num_addresses)     # количество адресов
print(net.broadcast_address) # широковещательный адрес
```

Для ЕГЭ чаще всего достаточно именно этих свойств.

# Как понять, какой способ выбрать

## Ручной способ удобнее, если

- дана конкретная маска;
- нужно только найти адрес сети;
- меняется один октет;
- побитовое И легко выполнить вручную.

## `ipaddress` удобнее, если

- нужно перебирать маски;
- нужно определить границы сети;
- нужно считать адреса сети;
- есть дополнительные условия для IP-адресов;
- ручное решение становится громоздким.

Главный принцип:

> **Сначала пойми, что делает маска, а затем используй `ipaddress` для автоматизации.**

---

# Частые ошибки

1. Забыть `strict=False`, когда в `ip_network()` передаётся адрес узла, а не готовый адрес сети.
2. Перепутать адрес сети и IP-адрес узла.
3. Считать, что маска может содержать нули между единицами — корректная маска устроена как последовательность единиц, после которой идут только нули.
4. Неправильно перевести октет в двоичную систему и потерять ведущие нули.
5. Перепутать количество единиц маски и количество бит узла.
6. При условии про все IP-адреса сети использовать `net.hosts()` и случайно исключить граничные адреса.
7. Перебирать вручную сотни или тысячи адресов, когда это проще сделать через `for ip in net`.

# Быстрая памятка

```text
IPv4 = 32 бита = 4 октета по 8 бит

адрес сети:
IP AND маска

маска:
сначала единицы, затем нули

количество адресов сети:
2^(32 - длина_префикса)

Python:
ip_network('IP/маска', strict=False)

network_address   → адрес сети
netmask           → маска
prefixlen         → число единиц в маске
num_addresses     → число адресов сети
broadcast_address → широковещательный адрес

перебор всех адресов:
for ip in net:

число единиц в IP:
bin(int(ip)).count('1')
```

Главный навык в №10 — понимать связь между IP-адресом, маской и адресом сети, а не просто запоминать готовую строку кода.
