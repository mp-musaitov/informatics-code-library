# ЕГЭ №24. Обработка строк из файла

## Что проверяет задание

В №24 нужно написать программу, которая анализирует длинную строку из текстового файла и находит непрерывный фрагмент, удовлетворяющий заданным условиям.

В проекте демоверсии ЕГЭ-2027 файл состоит из символов:

```text
0 6 7 8 9 - *
```

Нужно найти максимальную длину непрерывной последовательности, являющейся корректным арифметическим выражением с целыми неотрицательными числами.

Дополнительно:

- два знака операций не могут стоять рядом;
- в записи числа нет ведущих нулей;
- число `0` не имеет знака.

Ответ проекта демоверсии:

```text
154
```

---

# Главная идея №24

У задания нет одного универсального кода на все случаи.

Зато почти всегда работает одна и та же схема мышления:

```text
1. считать строку;
2. понять, что делает фрагмент неправильным;
3. разбить строку по запрещённым ситуациям
   или пройти её окном;
4. проверить оставшиеся кандидаты;
5. найти максимум / минимум / количество.
```

Главное — сначала перевести текст условия в свойства строки, а уже затем писать код.

---

# Чтение файла

Если весь файл представляет собой одну строку:

```python
with open('24.txt') as f:
    s = f.read().strip()
```

После этого `s` — обычная строка Python.

Полезные операции:

```python
len(s)            # длина
s.count('A')      # количество A
s.find('ABC')     # первое вхождение
s.replace('X', ' ') # замена
s.split()         # разбиение
```

---

# Тип 1. Запрещённый символ

Например, нужно найти максимальную последовательность без `X`.

Самый простой способ — заменить `X` пробелом и разбить строку:

```python
s = s.replace('X', ' ')
parts = s.split()
print(max(len(x) for x in parts))
```

Можно ещё короче:

```python
print(max(map(len, s.split('X'))))
```

Если запрещённых символов несколько:

```python
for c in 'XYZ':
    s = s.replace(c, ' ')

print(max(map(len, s.split())))
```

---

# Тип 2. Запрещённая пара или подстрока

Например, в искомой цепочке не должно быть `AA`.

Можно использовать запрещённую пару как границу:

```python
parts = s.split('AA')
print(max(map(len, parts)))
```

Но здесь нужно быть внимательным: при `split()` сама разделяющая подстрока исчезает. Если по условию один из её символов может входить в искомую цепочку, простое разбиение может потерять правильный ответ.

Поэтому `split()` используем только тогда, когда точно понимаем границы допустимого фрагмента.

---

# Тип 3. Не более K определённых символов

Например:

> найти максимальную длину фрагмента, содержащего не более 10 букв `A`.

Здесь удобно использовать метод двух указателей — скользящее окно.

```python
left = 0
cnt = 0
best = 0

for right in range(len(s)):
    if s[right] == 'A':
        cnt += 1

    while cnt > 10:
        if s[left] == 'A':
            cnt -= 1
        left += 1

    best = max(best, right - left + 1)

print(best)
```

Идея:

```text
left ........ right
      окно
```

`right` расширяет окно, а `left` сдвигается только тогда, когда условие нарушено.

---

# Тип 4. Ровно K символов

Если требуется **ровно** `K` символов, недостаточно просто поддерживать условие `<= K`.

После восстановления корректного окна максимум обновляем только при точном количестве:

```python
left = 0
cnt = 0
best = 0

for right in range(len(s)):
    if s[right] == 'A':
        cnt += 1

    while cnt > 10:
        if s[left] == 'A':
            cnt -= 1
        left += 1

    if cnt == 10:
        best = max(best, right - left + 1)

print(best)
```

---

# Тип 5. Чередование символов

Например, рядом не должны стоять две буквы или две цифры.

Можно проверять соседние символы:

```python
def same_type(a, b):
    return a.isalpha() == b.isalpha()

best = 1
cur = 1

for i in range(1, len(s)):
    if not same_type(s[i - 1], s[i]):
        cur += 1
    else:
        cur = 1

    best = max(best, cur)

print(best)
```

Такой проход выполняется за один просмотр строки.

# Тип 6. Корректная запись выражения или числа

Это один из самых важных современных типов №24.

Нужно понимать не отдельный символ, а **структуру записи**:

```text
число → операция → число → операция → число ...
```

При этом могут быть дополнительные ограничения:

- нет двух операций подряд;
- нет ведущих нулей;
- определённые операции разрешены или запрещены;
- выражение не может начинаться или заканчиваться операцией;
- число `0` может обрабатываться отдельно.

Именно к этому типу относится проект демоверсии ЕГЭ-2027.

---

# Демоверсия-2027: как рассуждать

Алфавит:

```text
цифры: 0, 6, 7, 8, 9
операции: - и *
```

Корректное выражение должно состоять из чисел, разделённых одиночными операциями.

Например:

```text
67-8*906
```

может быть корректным по структуре.

А такие фрагменты требуют исправления границ:

```text
67**89     # две операции подряд
-67        # выражение начинается со знака
89*        # выражение заканчивается знаком
067        # ведущий ноль
0-...      # отдельно проверяем требование про знак у нуля
```

Поэтому задача сводится к поиску самого длинного фрагмента, внутри которого не нарушаются правила записи выражения.

Для такого типа часто удобны два подхода:

1. последовательная обработка строки / скользящее окно;
2. регулярные выражения.

Для обучения основным считаем первый способ: он лучше показывает алгоритм и не требует знания синтаксиса `re`.

---

# Регулярные выражения — полезная альтернатива

Для сложных шаблонов модуль `re` может значительно сократить решение.

Пример простой структуры «число, затем несколько пар операция + число»:

```python
import re

pattern = r'[1-9][0-9]*(?:[-*][1-9][0-9]*)*'
parts = re.findall(pattern, s)
print(max(map(len, parts)))
```

Но регулярное выражение нужно составлять строго под конкретное условие.

Не стоит заучивать одну строку `re` как универсальный шаблон №24.

---

# Тип 7. Поиск чисел внутри строки

Иногда файл содержит буквы, цифры и другие символы, а нужно найти число с определённым свойством.

Удобный приём — заменить все символы, которые не относятся к нужному алфавиту, пробелами:

```python
allowed = '0123456789ABCDEF'

for c in set(s):
    if c not in allowed:
        s = s.replace(c, ' ')

numbers = s.split()
```

После этого каждый элемент `numbers` — кандидат на число.

Для другой системы счисления можно использовать:

```python
value = int(x, 16)
```

---

# Тип 8. Условия на начало и конец

Например, последовательность должна:

- начинаться с цифры;
- заканчиваться буквой;
- содержать ровно `K` определённых символов.

Здесь важно не только поддерживать условие внутри окна, но и проверять его границы:

```python
if cnt == K and s[left].isdigit() and s[right].isalpha():
    best = max(best, right - left + 1)
```

# Как понять, какой способ выбрать

```text
есть явный запрещённый символ
→ replace / split

простое условие на соседние символы
→ один проход по строке

не более / ровно K объектов
→ скользящее окно или позиции нужных символов

сложная структура выражения
→ последовательный алгоритм или re

нужно выделить числа из текста
→ заменить посторонние символы пробелами + split
```

Не нужно пытаться решать все варианты №24 одним методом.

---

# Частые ошибки

1. Использовать `readline()` и случайно считать только первую строку, когда файл может содержать несколько строк.
2. Забыть `.strip()` и получить `\n` в конце строки.
3. Путать «не более K» и «ровно K».
4. При `split()` забыть, что разделитель удаляется.
5. Искать только первое подходящее вхождение.
6. Перебирать все подстроки двумя вложенными циклами там, где достаточно одного прохода.
7. Забывать проверить начало и конец найденной последовательности.
8. При работе с числами не учитывать ведущие нули.
9. Считать регулярное выражение универсальным решением для любого №24.
10. Использовать `eval()` для проверки арифметического выражения — это обычно не нужно и только усложняет решение.

# Быстрая памятка

```python
with open('24.txt') as f:
    s = f.read().strip()
```

Дальше сначала задаём себе вопрос:

```text
Что именно ломает подходящую последовательность?
```

И выбираем инструмент:

```text
split / replace     → простые границы
один проход         → соседние символы
скользящее окно     → ограничения на количество
re                  → сложный шаблон
int(x, base)        → числа в системе счисления
```

Главная мысль №24:

> **Не начинайте с кода. Сначала сформулируйте правила, по которым символ можно добавить к текущей последовательности и по которым последовательность приходится обрывать или сдвигать.**
