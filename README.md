# informatics-code-library

Личная база алгоритмов, решений задач ЕГЭ/ОГЭ и полезных фрагментов кода на Python.

## Структура

- [`Python`](Python/) — основы Python, полезные шаблоны и примеры кода.
- [`Algorithms`](Algorithms/) — алгоритмы и типовые приёмы решения задач.
- [`EGE`](EGE/) — материалы и шаблоны по заданиям ЕГЭ по информатике.
- [`OGE`](OGE/) — материалы и шаблоны по заданиям ОГЭ по информатике.

## Как устроены материалы

По возможности каждый файл оформляется как небольшая шпаргалка:

1. краткое объяснение идеи;
2. типовой код;
3. несколько примеров;
4. частые ошибки и замечания.

## Уже добавлено

- [`Python/Basics/input-output.py`](Python/Basics/input-output.py) — ввод и вывод данных, `input()`, `print()`, преобразование типов и ввод нескольких чисел через пробел.

## Принципы библиотеки

- один файл — одна законченная тема или приём;
- понятные имена файлов и папок;
- комментарии и пояснения можно писать по-русски;
- экзаменационные решения хранятся отдельно от общих алгоритмов;
- готовые заготовки для копирования складываются в `Python/Templates`.
