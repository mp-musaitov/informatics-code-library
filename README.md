## Как пользоваться библиотекой

Каждый учебный файл по возможности устроен одинаково:

1. краткое объяснение темы;
2. типовой код;
3. примеры;
4. частые ошибки;
5. универсальные шаблоны.

Можно открыть нужную тему прямо в браузере и использовать её как шпаргалку во время занятия или повторения.
