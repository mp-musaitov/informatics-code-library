# ОГЭ №15. Исполнитель Робот

## Что проверяет задание

Нужно составить алгоритм для исполнителя Робот, который работает на клетчатом поле со стенами.

Обычно требуется написать программу, которая подходит не для одного конкретного рисунка, а для целого класса допустимых обстановок.

## Основные команды движения

В учебных средах синтаксис может различаться, но смысл команд один:

```text
вверх
вниз
влево
вправо
```

Также используются команды закрашивания клетки и проверки стен.

## Главное правило безопасности

Робот не должен пытаться пройти через стену.

Поэтому перед движением, если наличие стены заранее неизвестно, проверяйте условие.

Условная схема:

```text
пока справа свободно
    вправо
```

## Как решать задачу

1. Определите, где Робот может находиться в начале.
2. Найдите ориентиры: стены, углы, проходы.
3. Разбейте маршрут на простые этапы.
4. Для повторяющихся действий используйте цикл.
5. Если направление зависит от обстановки — используйте условие.
6. Проверьте алгоритм не только на рисунке из примера, но и на других допустимых расположениях стен.

## Цикл до стены

Очень распространённый приём:

```text
пока справа свободно
    закрасить
    вправо
```

После выхода из цикла Робот находится возле стены.

Обратите внимание: в зависимости от условия задачи может потребоваться отдельно закрасить последнюю клетку.

## Движение вдоль стены

Если стена используется как ориентир, удобно двигаться до её конца.

Например, идея:

```text
пока сверху стена
    вправо
```

Такой алгоритм не зависит от заранее известной длины стены.

## Почему фиксированное число шагов часто плохо

Программа вида:

```text
вправо
вправо
вправо
вправо
```

работает только для конкретного расположения объектов.

Если длина участка заранее неизвестна, нужен цикл с условием.

## Проверка алгоритма

После написания задайте себе вопросы:

- может ли Робот врезаться в стену;
- закрашены ли все требуемые клетки;
- не закрашиваются ли лишние;
- остановится ли каждый цикл;
- работает ли программа при другой допустимой длине стены;
- зависит ли решение от случайного размера рисунка.

## Частые ошибки

- двигаться в неизвестном направлении без проверки стены;
- забывать последнюю клетку после цикла;
- использовать фиксированное количество шагов вместо условия;
- создавать бесконечный цикл;
- решать только изображённый пример, а не общий случай;
- путать условие «свободно» и «стена».

## Памятка

В №15 хороший алгоритм обычно строится вокруг ориентиров:

```text
стена -> угол -> конец стены -> свободный проход
```

Если расстояние заранее неизвестно, почти наверняка нужен цикл, а не ручное повторение команд.
