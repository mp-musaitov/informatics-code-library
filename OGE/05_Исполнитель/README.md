# ОГЭ №5. Формальный исполнитель

## Что проверяет задание

Умение проследить выполнение короткой программы формальным исполнителем и определить исходное число, результат или параметр программы.

Обычно исполнитель имеет две команды, например:

```text
1. прибавь 3
2. умножь на 2
```

Программа задаётся последовательностью номеров команд:

```text
1212
```

## Если известно начальное число

Просто выполняйте команды строго по порядку.

Например, начальное число `2`, команды:

```text
1. +3
2. ×2
```

Программа `121`:

```text
2 → 5 → 10 → 13
```

Ответ: `13`.

## Если нужно найти исходное число

Удобнее идти **с конца программы к началу**, выполняя обратные действия.

Для команд:

```text
+3  ↔ -3
×2  ↔ ÷2
```

Например, после программы `121` получилось `13`.

Идём назад:

```text
13 → 10 → 5 → 2
     -3    ÷2   -3
```

Исходное число: `2`.

## Алгоритм решения

### Прямой ход

1. Записать начальное значение.
2. Читать программу слева направо.
3. После каждой команды записывать новое значение.
4. Не выполнять несколько команд в уме одновременно.

### Обратный ход

1. Начать с конечного значения.
2. Читать программу справа налево.
3. Каждую команду заменить обратной.
4. Полученное в конце число будет исходным.

## Табличный способ

Для длинной программы удобно писать:

```text
команда:   1   2   1
значение:  2   5  10  13
```

Так значительно меньше вероятность потерять промежуточное значение.

## Проверка в Python

```python
x = 2
program = '121'

for command in program:
    if command == '1':
        x += 3
    else:
        x *= 2

print(x)
```

## Частые ошибки

- меняют порядок выполнения команд;
- применяют команду к исходному числу вместо текущего значения;
- при обратном ходе читают программу слева направо;
- забывают заменить действие на обратное;
- путают номер команды с самим действием.

## Короткая памятка

```text
Вперёд: программа слева направо.
Назад: программа справа налево + обратные действия.
```
