# ОГЭ №6. Анализ программ

## Что проверяет задание

Нужно определить, сколько запусков программы при заданных входных данных приведут к требуемому результату.

Обычно программа:

1. получает одно или несколько чисел;
2. проверяет условие `if`;
3. выводит один из двух ответов.

## Алгоритм решения

1. Переведите условие программы на обычный язык.
2. Для каждого набора входных данных подставьте значения в условие.
3. Определите, истинно условие или ложно.
4. Посмотрите, какой результат напечатает программа.
5. Посчитайте только подходящие запуски.

## Логические операции

В Python:

```python
and  # И
or   # ИЛИ
not  # НЕ
```

Приоритет основных операций:

1. арифметические действия;
2. сравнения;
3. `not`;
4. `and`;
5. `or`.

Если есть сомнения — используйте скобки.

## Пример

```python
x = int(input())
y = int(input())

if x > 5 and y < 10:
    print('YES')
else:
    print('NO')
```

Для пары `(7, 8)` оба условия истинны, поэтому программа напечатает `YES`.

Для `(7, 12)` второе условие ложно, поэтому ответ — `NO`.

## Быстрая проверка через Python

Если наборов много, их можно проверить программой:

```python
data = [(7, 8), (7, 12), (3, 5), (10, 2)]
count = 0

for x, y in data:
    if x > 5 and y < 10:
        count += 1

print(count)
```

## Частые ошибки

- считать строки входных данных вместо запусков программы;
- путать `and` и `or`;
- не учитывать строгие знаки `>` и `<`;
- смотреть только на часть сложного условия;
- считать, сколько раз условие истинно, когда в вопросе требуется другой вывод программы.

## Памятка

Не пытайтесь «угадывать» работу программы. Для каждой строки данных последовательно вычисляйте значение условия и только после этого определяйте вывод.
