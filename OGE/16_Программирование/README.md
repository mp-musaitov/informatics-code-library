# ОГЭ №16. Программирование

## Что проверяет задание

Нужно написать программу для обработки последовательности целых чисел в соответствии с условием задачи.

Это одно из заданий ОГЭ, где особенно полезны универсальные шаблоны Python.

## Типовая структура

Чаще всего программа должна:

1. получить количество чисел `N`;
2. считать `N` чисел;
3. проверить каждое число по условию;
4. посчитать количество подходящих элементов;
5. одновременно найти сумму, максимум, минимум или другой показатель;
6. вывести требуемый результат.

## Базовый шаблон

```python
n = int(input())
count = 0

for _ in range(n):
    x = int(input())

    if условие:
        count += 1

print(count)
```

## Если нужны количество и сумма

```python
n = int(input())
count = 0
total = 0

for _ in range(n):
    x = int(input())

    if условие:
        count += 1
        total += x

print(count)
print(total)
```

## Если нужны количество и максимум

Надёжный вариант:

```python
n = int(input())
count = 0
maximum = None

for _ in range(n):
    x = int(input())

    if условие:
        count += 1

        if maximum is None or x > maximum:
            maximum = x

print(count)
print(maximum)
```

Почему не всегда стоит начинать с `maximum = 0`? Потому что подходящие числа могут оказаться отрицательными.

## Если требуется минимум

```python
minimum = None

if условие:
    if minimum is None or x < minimum:
        minimum = x
```

## Несколько условий

Например, число должно быть положительным и делиться на 3:

```python
if x > 0 and x % 3 == 0:
    ...
```

Хотя бы одно из условий:

```python
if условие1 or условие2:
    ...
```

## Проверка последней цифры

```python
x % 10
```

Например:

```python
if x % 10 == 7:
    ...
```

Для условий на цифры отрицательных чисел часто удобнее работать с `abs(x)`.

## Проверка делимости

```python
if x % 5 == 0:
    ...
```

Не делится:

```python
if x % 5 != 0:
    ...
```

## Среднее значение

Если среднее требуется только среди подходящих чисел:

```python
if count > 0:
    average = total / count
```

Делить нужно на количество подходящих элементов, а не на `n`.

## Как проверять программу

Перед сдачей придумайте маленький собственный тест, для которого ответ легко вычислить вручную.

Например:

```text
5
2
3
6
7
9
```

Если программа считает числа, кратные 3, правильный результат — `3`.

## Частые ошибки

- использовать `range(n + 1)` вместо `range(n)`;
- забыть преобразовать `input()` в `int`;
- перепутать `%` и `/`;
- считать все элементы вместо подходящих;
- обновлять максимум вне нужного условия;
- начинать максимум с нуля при возможных отрицательных значениях;
- делить среднее на `n` вместо `count`;
- выводить результаты не в том порядке.
