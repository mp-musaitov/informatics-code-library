# ОГЭ №4. Графы и кратчайший путь

## Что проверяет задание

Умение работать со схемой дорог и таблицей расстояний и находить длину кратчайшего пути между двумя пунктами.

## Основные понятия

- **вершина** — пункт, город или объект;
- **ребро** — дорога между двумя вершинами;
- **вес ребра** — длина дороги;
- **путь** — последовательность дорог от начальной вершины к конечной;
- **длина пути** — сумма весов всех его рёбер.

## Главная идея

Нужно сравнивать не количество дорог, а их **суммарную длину**.

Самый короткий по числу рёбер маршрут не обязательно имеет минимальную длину.

## Алгоритм решения

1. Найти начальную и конечную вершины.
2. Выписать возможные разумные маршруты между ними.
3. Для каждого маршрута сложить длины дорог.
4. Сравнить полученные суммы.
5. Выбрать минимальную.

## Пример

Пусть имеются дороги:

```text
А—Б = 4
А—В = 7
Б—В = 2
Б—Г = 8
В—Г = 3
```

Найдём кратчайший путь из А в Г.

Возможные варианты:

```text
А → Б → Г       4 + 8 = 12
А → В → Г       7 + 3 = 10
А → Б → В → Г   4 + 2 + 3 = 9
```

Кратчайший путь имеет длину `9`.

## Работа с таблицей

Если расстояния представлены таблицей, сначала определите, какие пункты соединены непосредственно. Пустая ячейка обычно означает отсутствие прямой дороги.

Для неориентированных дорог таблица симметрична относительно главной диагонали.

## Полезный приём

Не обязательно перебирать бессмысленные маршруты, которые многократно возвращаются в уже посещённые вершины: положительные длины дорог только увеличат путь.

## Частые ошибки

- выбирают маршрут с наименьшим количеством дорог;
- забывают сложить одно из расстояний;
- считают отсутствующую дорогу дорогой длины 0;
- путают названия вершин в таблице;
- находят один маршрут и не проверяют, существует ли более короткий.
