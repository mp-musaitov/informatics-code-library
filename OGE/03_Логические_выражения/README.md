# ОГЭ №3. Логические выражения

## Что проверяет задание

Умение анализировать простые логические выражения и находить значения, при которых выражение истинно или ложно.

## Основные операции

```text
НЕ  — отрицание
И   — конъюнкция
ИЛИ — дизъюнкция
```

В Python им соответствуют:

```python
not
and
or
```

## Как читать условия

### И

Выражение истинно, только если истинны обе части:

```text
x > 5 И x < 10
```

означает:

```text
5 < x < 10
```

### ИЛИ

Достаточно истинности хотя бы одной части:

```text
x < 3 ИЛИ x > 10
```

### НЕ

Меняет значение условия на противоположное:

```text
НЕ (x > 5)
```

эквивалентно:

```text
x <= 5
```

## Полезные отрицания

```text
НЕ (x > a)  → x <= a
НЕ (x < a)  → x >= a
НЕ (x >= a) → x < a
НЕ (x <= a) → x > a
НЕ (x = a)  → x ≠ a
```

## Алгоритм решения

1. Определить логические операции.
2. Начать со скобок и отрицаний.
3. Перевести каждое условие на обычный язык или отметить его на числовой прямой.
4. Для `И` найти пересечение условий.
5. Для `ИЛИ` объединить подходящие значения.
6. Проверить, требуется истинность или ложность выражения.

## Пример

Для какого целого `x` истинно выражение:

```text
(x > 3) И (x < 6)
```

Подходят целые числа:

```text
4, 5
```

## Проверка перебором в Python

Если нужно проверить рассуждение:

```python
for x in range(-100, 101):
    if x > 3 and x < 6:
        print(x)
```

## Частые ошибки

- путают `И` и `ИЛИ`;
- забывают раскрыть `НЕ`;
- теряют знак равенства при отрицании `>` или `<`;
- ищут истинные значения, когда в условии спрашивают ложные;
- не учитывают, что требуется целое число.
