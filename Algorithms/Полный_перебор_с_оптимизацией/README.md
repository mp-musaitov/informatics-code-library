# Полный перебор с оптимизацией

Этот приём подходит для задач, где нужно перебрать несколько взаимосвязанных вариантов и выбрать лучший по некоторому критерию: минимальной сумме, максимальному значению, минимальной длине и т. п.

Главная идея:

```text
1. Перебираем первый объект.
2. Для каждого первого объекта перебираем второй.
3. Проверяем пару целиком.
4. Если пара допустима — вычисляем её характеристику.
5. Сохраняем лучший найденный результат.
```

Такой подход особенно удобен, когда количество неизвестных небольшое и полный перебор остаётся быстрым.

---

## Пример: два кодовых слова и условие Фано

Пусть уже известны коды:

```text
Н → 0
К → 10
```

Нужно подобрать ещё два кодовых слова так, чтобы выполнялось условие Фано, а суммарная длина всех кодовых слов была минимальной.

Вместо жадного выбора первого подходящего кода перебираем **все допустимые пары**.

```python
def fano(codes):
    for a in codes:
        for b in codes:
            if a != b and b.startswith(a):
                return False
    return True


codes = ['0', '10']
MAX_LENGTH = 5

best_sum = 10 ** 9
best_codes = None

for length1 in range(1, MAX_LENGTH + 1):
    for n1 in range(2 ** length1):
        code1 = bin(n1)[2:].zfill(length1)

        if code1 in codes:
            continue

        if not fano(codes + [code1]):
            continue

        # Второй код не короче первого.
        # Так мы не перебираем одну и ту же пару дважды.
        for length2 in range(length1, MAX_LENGTH + 1):
            for n2 in range(2 ** length2):
                code2 = bin(n2)[2:].zfill(length2)

                if code2 in codes or code2 == code1:
                    continue

                if fano(codes + [code1, code2]):
                    total = sum(map(len, codes)) + length1 + length2

                    if total < best_sum:
                        best_sum = total
                        best_codes = [code1, code2]

print(best_codes)
print(best_sum)
```

Для этого примера получится один из оптимальных наборов:

```text
Н → 0
К → 10
Л → 110
М → 111
```

Суммарная длина:

```text
1 + 2 + 3 + 3 = 9
```

---

## Почему `length2` начинается с `length1`

Если рассматриваются два новых кодовых слова, для минимизации суммы неважно, какое из них названо первым.

Пары

```text
00 и 101
```

и

```text
101 и 00
```

имеют одинаковую суммарную длину и представляют один и тот же набор длин.

Поэтому можно использовать:

```python
for length2 in range(length1, MAX_LENGTH + 1):
```

и не выполнять симметричный перебор дважды.

## Общий шаблон

```python
best = None

for first in варианты_первого:
    for second in варианты_второго:
        if допустима_вся_пара(first, second):
            value = характеристика(first, second)

            if best is None or value < best:
                best = value
```

Для поиска максимума знак сравнения меняется.

---

## Когда использовать

Полный перебор нескольких объектов удобен, если:

- неизвестных немного;
- каждый объект имеет ограниченное число вариантов;
- варианты влияют друг на друга;
- жадный выбор первого подходящего варианта может привести к плохому решению;
- нужно гарантированно найти минимум или максимум.

Если количество объектов большое, число комбинаций быстро растёт. Тогда могут понадобиться другие методы: отсечения, динамическое программирование, поиск с возвратом и т. д.

---

## Главное отличие от жадного алгоритма

Жадный алгоритм делает выбор и сразу его фиксирует:

```text
нашли первый подходящий → взяли его → идём дальше
```

Полный перебор не доверяет первому найденному варианту:

```text
перебрали все допустимые сочетания → сравнили → выбрали лучшее
```

Именно поэтому он надёжнее в задачах на оптимизацию, если размер перебора остаётся небольшим.
