# Algorithms

Общие алгоритмы и типовые приёмы, которые не привязаны к конкретному номеру ЕГЭ или ОГЭ.

## Разделы

- [Полный перебор с оптимизацией](Полный_перебор_с_оптимизацией/) — перебор нескольких взаимосвязанных вариантов с выбором минимального или максимального результата.

План дальнейших разделов: поиск, сортировки, перебор, графы, динамическое программирование, поиск с возвратом и другие часто используемые алгоритмические идеи.
