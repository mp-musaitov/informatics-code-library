# ЕГЭ №25. Маски, делители и числовые задачи

## Что проверяет задание

В №25 обычно требуется написать программу, которая перебирает числа и отбирает те, которые удовлетворяют одному или нескольким условиям.

Чаще всего встречаются два больших типа задач:

1. **маски чисел** — число должно соответствовать шаблону и делиться на заданное число;
2. **делители и свойства числа** — нужно найти делители, простые делители, количество делителей, сумму/разность делителей и т. п.

Главная идея задания:

> **Не перебирать больше, чем нужно. Сначала использовать самые сильные ограничения, затем проверять остальные условия.**

---

# 1. Маски чисел

В маске используются два специальных символа:

```text
?  → ровно одна произвольная цифра
*  → любая последовательность цифр, в том числе пустая
```

Например:

```text
123*4?5
```

подходят, например:

```text
123405
12300405
```

---

# Основной способ для масок: перебирать только кратные числа

Если в условии сказано, что число должно делиться, например, на `1917`, нет смысла перебирать все числа подряд.

Вместо:

```python
for n in range(1, 10 ** 10 + 1):
    if n % 1917 == 0:
        ...
```

сразу перебираем только кратные:

```python
for n in range(1917, 10 ** 10 + 1, 1917):
    ...
```

Это уменьшает количество проверяемых чисел примерно в `1917` раз.

---

# Проект демоверсии ЕГЭ-2027

Нужно найти все натуральные числа, не превышающие `10^10`, которые:

- соответствуют маске `3?12?14*5`;
- делятся на `1917`.

Для каждого найденного числа нужно вывести само число и результат деления на `1917`.

---

# Основной способ: регулярное выражение

Маска

```text
3?12?14*5
```

переводится в регулярное выражение:

```text
3\d12\d14\d*5
```

где:

```text
\d   → одна цифра
\d*  → любое количество цифр, в том числе ноль
```

Решение:

```python
import re

pattern = re.compile(r'3\d12\d14\d*5')

for n in range(1917, 10 ** 10 + 1, 1917):
    if pattern.fullmatch(str(n)):
        print(n, n // 1917)
```

`fullmatch()` проверяет, что **вся строка целиком** соответствует маске.

Результат для проекта демоверсии:

```text
351261495   183235
3212614035  1675855
3412614645  1780185
3712414275  1936575
3912414885  2040905
```

---

# Альтернатива: fnmatch

Для масок ЕГЭ символы `?` и `*` по смыслу очень похожи на шаблоны модуля `fnmatch`.

Поэтому ту же задачу можно решить ещё короче:

```python
from fnmatch import fnmatchcase

for n in range(1917, 10 ** 10 + 1, 1917):
    if fnmatchcase(str(n), '3?12?14*5'):
        print(n, n // 1917)
```

Для обычных цифровых масок этот способ очень удобен.

Но нужно помнить:

> `fnmatch` работает со строками. Сначала число обязательно превращаем в `str`.

---

# Какой способ выбрать для маски

```text
Простая маска из цифр, ? и *
→ fnmatchcase удобно и коротко

Нужно точно управлять шаблоном
или появляются дополнительные условия
→ регулярное выражение
```

На экзамене важно не название инструмента, а то, чтобы решение было понятным и надёжным.

---

# Частая ошибка: перебирать все числа до 10^10

Так делать нельзя:

```python
for n in range(1, 10 ** 10 + 1):
    ...
```

Это слишком большой перебор.

Если известно, что число делится на `k`, нужно сразу идти с шагом `k`:

```python
for n in range(k, limit + 1, k):
    ...
```

# 2. Делители числа

Вторая большая группа №25 — задачи на делители.

Простейший вариант:

```python
n = 100

divisors = []

for d in range(1, n + 1):
    if n % d == 0:
        divisors.append(d)

print(divisors)
```

Для `100` получим:

```text
1 2 4 5 10 20 25 50 100
```

Но для больших чисел такой перебор слишком медленный.

---

# Главный приём для делителей: перебор до корня

Если `d` — делитель числа `n`, то второй делитель равен:

```text
n // d
```

Например, для `100`:

```text
2 ↔ 50
4 ↔ 25
5 ↔ 20
10 ↔ 10
```

Поэтому достаточно проверять делители только до `sqrt(n)`.

Универсальный шаблон:

```python
def divisors(n):
    d = set()

    for i in range(1, int(n ** 0.5) + 1):
        if n % i == 0:
            d.add(i)
            d.add(n // i)

    return sorted(d)
```

Использование:

```python
print(divisors(100))
```

Результат:

```text
[1, 2, 4, 5, 10, 20, 25, 50, 100]
```

`set()` удобен потому, что для полного квадрата один и тот же делитель может встретиться дважды.

---

# Делители без 1 и самого числа

Очень часто в условии сказано:

> не считая 1 и самого числа

Тогда:

```python
def divisors(n):
    d = set()

    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            d.add(i)
            d.add(n // i)

    d.discard(n)

    return sorted(d)
```

---

# Минимальный и максимальный нетривиальные делители

Если нужны только минимальный и максимальный делители, нет смысла собирать полный список.

Минимальный делитель можно найти так:

```python
def min_divisor(n):
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            return d

    return None
```

Если минимальный нетривиальный делитель равен `d`, то максимальный нетривиальный делитель:

```python
n // d
```

Поэтому:

```python
def min_max_divisors(n):
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            return d, n // d

    return None
```

---

# Пример: разность максимального и минимального делителя

Пусть нужно вычислить:

```text
K = максимальный делитель - минимальный делитель
```

без учёта `1` и самого числа.

```python
def k(n):
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            return n // d - d

    return 0
```

Почему можно сразу сделать `return`?

Потому что первый найденный делитель — минимальный, а парный ему делитель `n // d` — максимальный.

---

# Количество делителей

Если нужно посчитать количество делителей:

```python
def count_divisors(n):
    count = 0

    for d in range(1, int(n ** 0.5) + 1):
        if n % d == 0:
            count += 2

    if int(n ** 0.5) ** 2 == n:
        count -= 1

    return count
```

Для полного квадрата корень учитывается только один раз.

Например:

```text
36
```

имеет делители:

```text
1 2 3 4 6 9 12 18 36
```

Их `9`, а не `10`, потому что пара

```text
6 × 6
```

содержит один и тот же делитель.

---

# Проверка на простое число

Простое число имеет ровно два натуральных делителя:

```text
1 и само число
```

Шаблон:

```python
def is_prime(n):
    if n < 2:
        return False

    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            return False

    return True
```

---

# Простые делители

Если нужны именно простые делители числа:

```python
def prime_divisors(n):
    result = []

    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            if is_prime(d):
                result.append(d)

            second = n // d

            if second != d and is_prime(second):
                result.append(second)

    return sorted(result)
```

Но если задача требует только минимальный простой делитель, полный список обычно не нужен.

Первый найденный делитель `d > 1` автоматически будет простым.

Почему?

Если бы `d` был составным, у него существовал бы меньший делитель, который мы встретили бы раньше.

# Поиск первых нескольких подходящих чисел

Типичная формулировка:

> найдите первые пять чисел, больших `N`, удовлетворяющих условию.

Универсальная схема:

```python
n = N + 1
count = 0

while count < 5:
    if условие:
        print(n)
        count += 1

    n += 1
```

Например:

```python
n = 750001
count = 0

while count < 5:
    K = k(n)

    if K != 0 and K % 7 == 0:
        print(n, K)
        count += 1

    n += 1
```

for n in range(left, right + 1):

# Важная оптимизация: сначала дешёвые проверки

Если у числа несколько условий, сначала проверяем то, что вычисляется быстрее.

Например:

```python
for n in range(...):
    if n % 17 != 0:
        continue

    d = divisors(n)

    if len(d) == 8:
        print(n)
```

Лучше сначала проверить делимость, чем для каждого числа строить список делителей.

# Маска + делимость

Если одновременно есть маска и делимость:

```python
from fnmatch import fnmatchcase

for n in range(k, limit + 1, k):
    if fnmatchcase(str(n), mask):
        print(n, n // k)
```

Это один из самых универсальных шаблонов №25.

# Когда регулярное выражение особенно удобно

Например, маска:

```text
12?4*7
```

Можно записать:

```python
r'12\d4\d*7'
```

А если в условии появляются дополнительные ограничения на конкретные цифры, регулярное выражение иногда получается понятнее, чем ручная работа со строкой.

---

# Альтернативный способ без специальных модулей

Иногда маску можно проверить обычными строковыми операциями.

Например, для маски:

```text
123*45
```

достаточно:

```python
s = str(n)

if s.startswith('123') and s.endswith('45'):
    ...
```

Для простой маски это может быть даже понятнее регулярного выражения.

# Типы задач №25, которые стоит уметь узнавать

### Маски

```text
? → одна цифра
* → любое число цифр
```

### Делители

```text
количество делителей
сумма делителей
минимальный / максимальный делитель
разность или сумма крайних делителей
делители с дополнительным условием
```

### Простые числа

```text
проверка простоты
простые делители
минимальный / максимальный простой делитель
```

### Специальные свойства

Например:

```text
делитель оканчивается на заданную цифру
количество чётных и нечётных делителей
значение функции от делителей
число является квадратом
результат удовлетворяет дополнительному условию
```

Во всех случаях схема одна:

```text
перебрать кандидатов
→ быстро отсеять неподходящие
→ вычислить нужную характеристику
→ проверить условие
→ вывести требуемые значения
```

# Частые ошибки

1. Перебирать все числа до `10^9` или `10^10`, когда известна делимость на `k`.
2. Перебирать делители до `n`, а не до `sqrt(n)`.
3. Забывать добавить парный делитель `n // d`.
4. Дважды учитывать корень у полного квадрата.
5. Забывать исключить `1` и само число, если это требует условие.
6. Путать `?` и `*`: `?` — ровно одна цифра, `*` — любое количество цифр, включая ноль.
7. Использовать `re.match()`, когда нужно проверить всю строку целиком; для этого надёжнее `fullmatch()`.
8. Перебирать все числа подряд, а делимость проверять уже внутри цикла.
9. Создавать полный список делителей, когда по условию нужен только первый, последний или количество.
10. Забывать, что число `1` не является простым.

# Быстрая памятка

```text
МАСКА

? → одна цифра
* → любое количество цифр

Если число делится на k:
range(k, limit + 1, k)

Простая маска:
fnmatchcase(str(n), mask)

Регулярное выражение:
re.fullmatch(pattern, str(n))
```

```text
ДЕЛИТЕЛИ

перебор до корня:
for d in range(1, int(n ** 0.5) + 1):

если n % d == 0:
    один делитель = d
    второй        = n // d
```

```text
ПРОСТОЕ ЧИСЛО

если нашёлся делитель от 2 до sqrt(n)
→ число составное

если не нашёлся
→ число простое
```

Главная мысль №25:

> **Сначала подумай, как сократить перебор. В большинстве задач №25 правильная оптимизация важнее самого условия.**
