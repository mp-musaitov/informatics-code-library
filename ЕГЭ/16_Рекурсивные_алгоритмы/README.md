# ЕГЭ №16. Рекурсивные алгоритмы

## Что проверяет задание

В задании №16 дана рекурсивно определённая функция `F(n)` и требуется вычислить её значение или значение выражения, содержащего несколько значений этой функции.

В проекте демоверсии ЕГЭ-2027 используется классический тип: функция зависит от одного предыдущего значения, а в ответе требуется вычислить выражение с большими аргументами.

Главная идея задания: **не пытаться вычислять огромные значения функции целиком, если в выражении они сокращаются**.

---

# Основной принцип

Рекурсивная функция вызывает сама себя.

Например:

```text
F(1) = 1
F(n) = n · F(n - 1), если n > 1
```

Тогда:

```text
F(5) = 5 · F(4)
F(4) = 4 · F(3)
F(3) = 3 · F(2)
...
```

Но если в задании требуется не само `F(3038)`, а выражение вроде

```text
(F(3038) + 5 · F(3037)) / F(3036),
```

вычислять `F(3038)` полностью бессмысленно.

Нужно раскрыть рекурсию только настолько, чтобы появилась возможность сократить выражение.

---

# Тип 1. Функция зависит от одного предыдущего значения

Пусть:

```text
F(1) = 1
F(n) = n · F(n - 1), если n > 1
```

Тогда:

```text
F(n) = n · F(n - 1)
F(n - 1) = (n - 1) · F(n - 2)
```

Следовательно:

```text
F(n) = n · (n - 1) · F(n - 2)
```

Это позволяет быстро приводить несколько значений функции к общему множителю.

---

# Демоверсия ЕГЭ-2027

В демоверсии функция задана так:

```text
F(1) = 1
F(n) = n · F(n - 1), если n > 1
```

Нужно найти:

```text
(F(3038) + 5 · F(3037)) / F(3036)
```

Раскроем только необходимые значения:

```text
F(3038) = 3038 · F(3037)
F(3037) = 3037 · F(3036)
```

Подставляем:

```text
(3038 · F(3037) + 5 · F(3037)) / F(3036)
```

Выносим общий множитель:

```text
(3038 + 5) · F(3037) / F(3036)
```

Получаем:

```text
3043 · 3037
```

То есть огромные значения `F(3038)`, `F(3037)` и `F(3036)` вообще вычислять не пришлось.

---

# Основной способ — ручное сокращение

Для выражений с большими аргументами это обычно самый быстрый способ.

Алгоритм:

```text
1. Найти самое маленькое значение F(...) в выражении.
2. Раскрыть остальные значения до него.
3. Вынести общий множитель.
4. Сократить одинаковые F(...).
5. Вычислить оставшееся обычное арифметическое выражение.
```

Например:

```text
F(1002) / F(1000)
```

если

```text
F(n) = n · F(n - 1),
```

то:

```text
F(1002) = 1002 · 1001 · F(1000)
```

поэтому:

```text
F(1002) / F(1000) = 1002 · 1001.
```

---

# Тип 2. Несколько ветвей рекурсии

Функция может зависеть от чётности или другого условия:

```text
F(n) = n, если n < 15
F(n) = (n + 6) · F(n - 8), если n ≥ 15 и n чётное
F(n) = (n + 4) · F(n - 6), если n ≥ 15 и n нечётное
```

Здесь перед каждым рекурсивным шагом нужно сначала определить, **какая ветвь условия выполняется**.

В Python:

```python
def f(n):
    if n < 15:
        return n
    if n % 2 == 0:
        return (n + 6) * f(n - 8)
    return (n + 4) * f(n - 6)
```

Но и здесь при выражениях вида

```text
F(a) / F(b)
```

сначала стоит проверить, нельзя ли раскрыть всего несколько шагов и сократить значения вручную.

---

# Тип 3. Функция зависит от двух предыдущих значений

Например:

```text
F(1) = 1
F(2) = 2
F(n) = 2 · F(n - 1) + (n - 2) · F(n - 2)
```

Для небольшого `n` можно просто написать рекурсивную функцию:

```python
def f(n):
    if n == 1:
        return 1
    if n == 2:
        return 2
    return 2 * f(n - 1) + (n - 2) * f(n - 2)

print(f(6))
```

Но при больших `n` такая программа будет многократно вычислять одни и те же значения.

---

# Мемоизация

Если функция разветвляется, удобно запоминать уже вычисленные значения.

```python
from functools import lru_cache

@lru_cache(None)
def f(n):
    if n == 1:
        return 1
    if n == 2:
        return 2
    return 2 * f(n - 1) + (n - 2) * f(n - 2)
```

Теперь каждое значение `F(n)` вычисляется один раз и сохраняется.

Это особенно полезно для функций вида:

```text
F(n) = F(n - 1) + F(n - 2)
```

или

```text
F(n) = F(n - 2) + F(n - 3).
```

---

# Важное ограничение Python: глубина рекурсии

Наивная запись:

```python
def f(n):
    if n == 1:
        return 1
    return n * f(n - 1)

print(f(3038))
```

может привести к ошибке:

```text
RecursionError
```

потому что Python ограничивает глубину рекурсивных вызовов.

Можно увеличить лимит:

```python
import sys
sys.setrecursionlimit(10000)
```

но для задания вроде демоверсии это плохой путь: программа начинает вычислять гигантские числа, которые затем всё равно сокращаются.

**Если выражение можно упростить математически — лучше сделать это до запуска рекурсии.**

---

# Альтернативный способ — итеративное вычисление

Если нужны сами значения функции, рекурсию иногда проще заменить циклом.

Например:

```text
F(1) = 1
F(n) = F(n - 1) + n
```

можно вычислять так:

```python
f = 1

for n in range(2, 101):
    f = f + n

print(f)
```

Здесь рекурсивные вызовы вообще не используются.

---

# Тип 4. Кусочно заданная функция

Например:

```text
F(n) = 3, если n ≤ 30
F(n) = -3 + 2F(n - 29), если 30 < n ≤ 250
F(n) = 2 + F(n - 43), если 250 < n ≤ 900
F(n) = 3 + F(n - 62), если n > 900
```

Перевод в Python практически дословный:

```python
def f(n):
    if n <= 30:
        return 3
    if n <= 250:
        return -3 + 2 * f(n - 29)
    if n <= 900:
        return 2 + f(n - 43)
    return 3 + f(n - 62)
```

Обратите внимание: после того как предыдущие случаи исключены, необязательно повторять все нижние границы.

---

# Тип 5. Две взаимосвязанные функции F и G

Иногда рекурсивно определены сразу две функции:

```text
F(n) = ... G(n - 1) ...
G(n) = ... F(n - 1) ...
```

Тогда в Python создаются две функции:

```python
def f(n):
    if n == 1:
        return 1
    return n + g(n - 1)


def g(n):
    if n == 1:
        return 1
    return 2 * n + f(n - 1)
```

Главное — буквально сохранить зависимости из условия.

---

# Как понять, какой способ выбрать

**Большие аргументы + дробь из F(...)** → сначала ручное раскрытие и сокращение.

**Небольшой аргумент + простая рекурсия** → обычная рекурсивная функция Python.

**Несколько рекурсивных вызовов** → мемоизация или динамическое вычисление.

**Очень глубокая линейная рекурсия** → цикл или математическое упрощение обычно лучше, чем увеличение `setrecursionlimit()`.

**Кусочная функция** → аккуратно переписать все условия в Python.

# Частые ошибки

## 1. Считать огромные значения функции полностью

Если требуется:

```text
F(3038) / F(3036),
```

сначала попробуйте раскрыть `F(3038)` до `F(3036)`.

## 2. Забыть базовый случай

Неправильно:

```python
def f(n):
    return n * f(n - 1)
```

Такая рекурсия никогда нормально не остановится.

## 3. Неправильно переписать условие

Например:

```text
n ≥ 15 и n чётное
```

в Python:

```python
n >= 15 and n % 2 == 0
```

## 4. Использовать обычное деление вместо целочисленного

Если по условию аргумент функции должен оставаться целым:

```python
n // 3
```

а не:

```python
n / 3
```

## 5. Не заметить повторные вычисления

При двух и более рекурсивных вызовах число вычислений может расти очень быстро.

Тогда нужен `@lru_cache(None)` или итеративный способ.

## 6. Считать `setrecursionlimit()` универсальным решением

Он только увеличивает разрешённую глубину вызовов. Он не делает алгоритм быстрее и не устраняет повторные вычисления.

## 7. Использовать `/`, когда ответ должен быть целым

После математического сокращения лучше вычислять уже целое выражение. Если деление гарантированно нацело, в программном решении часто удобнее использовать `//`.

# Быстрая памятка

```text
РЕКУРСИЯ

1. Найти базовый случай.
2. Посмотреть, от каких F(...) зависит функция.
3. Если в ответе дробь — сначала попробовать сократить.
4. Не вычислять огромные F(n), если это не требуется.
5. Одна простая ветвь → обычная рекурсия.
6. Несколько ветвей → подумать о @lru_cache.
7. Очень глубокая рекурсия → цикл или математическое упрощение.
```

Минимальный шаблон:

```python
def f(n):
    if условие_остановки:
        return значение
    return выражение_с_f(...)
```

С мемоизацией:

```python
from functools import lru_cache

@lru_cache(None)
def f(n):
    if условие_остановки:
        return значение
    return выражение_с_f(...)
```
