# №9. Электронные таблицы

## Что проверяет задание

Задание №9 проверяет умение обрабатывать числовые данные в электронной таблице и отбирать строки по одному или нескольким условиям.

В проекте демоверсии ЕГЭ-2027 используется таблица, где в каждой строке записано пять натуральных чисел. Нужно посчитать количество строк, для которых одновременно выполняются два условия:

- все числа различны;
- удвоенная сумма максимального и минимального чисел **больше** суммы оставшихся трёх.

Основной инструмент для №9 — **Microsoft Excel**.

---

# Основной принцип

Каждую строку таблицы рассматриваем отдельно:

```text
1. Проверяем первое условие.
2. Проверяем второе условие.
3. Объединяем условия через И.
4. Получаем ИСТИНА или ЛОЖЬ.
5. Считаем количество подходящих строк.
```

Главный вопрос:

> Подходит ли эта строка под условие задачи?

---

# Основной способ — Excel

Предположим, числа строки находятся в ячейках:

```text
A2:E2
```

Во вспомогательных столбцах удобно проверять отдельные условия, а затем объединять их.

---

# Полезные функции Excel

## Максимум

```excel
=МАКС(A2:E2)
```

## Минимум

```excel
=МИН(A2:E2)
```

## Сумма

```excel
=СУММ(A2:E2)
```

## Среднее значение

```excel
=СРЗНАЧ(A2:E2)
```

## Количество ячеек по условию

```excel
=СЧЁТЕСЛИ(A2:E2;">50")
```

---

# Тип 1. Все числа в строке различны

Для пяти чисел можно проверить, что каждое встречается ровно один раз:

```excel
=И(СЧЁТЕСЛИ(A2:E2;A2)=1;СЧЁТЕСЛИ(A2:E2;B2)=1;СЧЁТЕСЛИ(A2:E2;C2)=1;СЧЁТЕСЛИ(A2:E2;D2)=1;СЧЁТЕСЛИ(A2:E2;E2)=1)
```

Смысл:

```text
каждое число должно встречаться в строке ровно один раз
```

---

# Тип 2. Максимум, минимум и остальные числа

Пусть в строке пять чисел.

Сумма трёх чисел, которые не являются максимумом и минимумом:

```excel
=СУММ(A2:E2)-МАКС(A2:E2)-МИН(A2:E2)
```

Если по условию:

> удвоенная сумма максимального и минимального больше суммы остальных трёх,

то формула:

```excel
=2*(МАКС(A2:E2)+МИН(A2:E2))>СУММ(A2:E2)-МАКС(A2:E2)-МИН(A2:E2)
```

---

# Пример по формату демоверсии ЕГЭ-2027

В каждой строке находится пять натуральных чисел.

Нужно посчитать строки, в которых одновременно:

1. все числа различны;
2. удвоенная сумма максимального и минимального больше суммы остальных трёх.

## Столбец F — все числа различны

```excel
=И(СЧЁТЕСЛИ(A2:E2;A2)=1;СЧЁТЕСЛИ(A2:E2;B2)=1;СЧЁТЕСЛИ(A2:E2;C2)=1;СЧЁТЕСЛИ(A2:E2;D2)=1;СЧЁТЕСЛИ(A2:E2;E2)=1)
```

## Столбец G — второе условие

```excel
=2*(МАКС(A2:E2)+МИН(A2:E2))>СУММ(A2:E2)-МАКС(A2:E2)-МИН(A2:E2)
```

## Столбец H — оба условия

```excel
=И(F2;G2)
```

После этого формулы протягиваются вниз.

Количество подходящих строк:

```excel
=СЧЁТЕСЛИ(H:H;ИСТИНА)
```

---

# Быстрое преобразование второго условия

Исходное условие:

```text
2(max + min) > сумма остальных
```

А сумма остальных:

```text
sum - max - min
```

Получаем:

```text
2(max + min) > sum - max - min
```

Следовательно:

```text
3(max + min) > sum
```

Поэтому можно записать короче:

```excel
=3*(МАКС(A2:E2)+МИН(A2:E2))>СУММ(A2:E2)
```

Но сначала лучше научиться правильно переводить исходное условие, а уже потом сокращать формулу.

---

# Тип 3. Чётные и нечётные числа

Проверка чётности:

```excel
=ОСТАТ(A2;2)=0
```

Проверка нечётности:

```excel
=ОСТАТ(A2;2)=1
```

Количество чётных чисел в строке можно получить так:

```excel
=СУММПРОИЗВ(--(ОСТАТ(A2:E2;2)=0))
```

Например, ровно три чётных числа:

```excel
=СУММПРОИЗВ(--(ОСТАТ(A2:E2;2)=0))=3
```

---

# Тип 4. Числа расположены по возрастанию

Строгое возрастание:

```excel
=И(A2<B2;B2<C2;C2<D2;D2<E2)
```

Неубывание:

```excel
=И(A2<=B2;B2<=C2;C2<=D2;D2<=E2)
```

Важно:

```text
по возрастанию → <
неубывание     → <=
```

---

# Тип 5. Количество чисел, удовлетворяющих условию

Больше 50:

```excel
=СЧЁТЕСЛИ(A2:E2;">50")
```

Ровно три числа больше 50:

```excel
=СЧЁТЕСЛИ(A2:E2;">50")=3
```

Не менее трёх:

```excel
=СЧЁТЕСЛИ(A2:E2;">50")>=3
```

---

# Тип 6. Повторяющиеся и уникальные числа

Проверка конкретного числа:

```excel
=СЧЁТЕСЛИ(A2:E2;A2)=1
```

означает, что значение из `A2` встречается ровно один раз.

Если нужно проверить структуру строки вроде:

```text
ровно одна пара одинаковых чисел,
а остальные числа различны,
```

нельзя ограничиваться проверкой только `A2`. Нужно анализировать частоты всех значений строки.

Для таких задач часто удобно вынести частоты в соседние ячейки или использовать Python как проверочный способ.

---

# Абсолютные ссылки `$`

Знак `$` фиксирует часть адреса ячейки при протягивании формулы.

Например:

```excel
=$A2
```

фиксирует столбец `A`, но номер строки будет меняться.

```excel
=A$2
```

фиксирует строку `2`, но столбец может меняться.

```excel
=$A$2
```

полностью фиксирует ячейку.

В №9 чаще всего диапазон внутри одной строки должен смещаться вниз вместе с формулой, поэтому без необходимости ставить `$` не нужно.

---

# Альтернативный способ — Python

Основной способ решения №9 — Excel. Python можно использовать как проверку или если данные заранее сохранены в текстовом виде.

Для одной строки:

```python
s = [10, 20, 30, 40, 50]

if len(s) == len(set(s)):
    print('Все числа различны')
```

Проверка второго условия демоверсии:

```python
if 2 * (max(s) + min(s)) > sum(s) - max(s) - min(s):
    print('Условие выполнено')
```

Оба условия:

```python
if len(s) == len(set(s)) and 2 * (max(s) + min(s)) > sum(s) - max(s) - min(s):
    count += 1
```

---

# Шаблон Python для текстового файла

Если данные предварительно сохранены в текстовый файл, где числа разделены пробелами:

```python
count = 0

with open('9.txt') as f:
    for line in f:
        s = list(map(int, line.split()))

        if len(s) == len(set(s)) and 2 * (max(s) + min(s)) > sum(s) - max(s) - min(s):
            count += 1

print(count)
```

Обычный `open()` не читает таблицы `.xlsx` или `.ods` как набор числовых строк. Для экзаменационного файла удобнее использовать Excel, а для Python — сначала сохранить данные в текстовый формат.

---

# Как понять, какой способ выбрать

**Excel удобнее**, если исходный файл уже является электронной таблицей, условия легко записываются через `МАКС`, `МИН`, `СУММ`, `СЧЁТЕСЛИ` и нужно быстро протянуть формулу на тысячи строк.

**Python удобнее**, если хочется проверить решение, условия проще выразить через `set`, `max`, `min`, `sum` или файл уже преобразован в текстовый формат.

Главный принцип:

> В №9 формула пишется один раз, а затем протягивается на все строки.

---

# Частые ошибки

1. Проверить условия отдельно и забыть объединить их через `И`.
2. Перепутать `>` и `>=`, `<` и `<=`.
3. Забыть вычесть максимум и минимум, когда нужна сумма остальных чисел.
4. Взять максимум или минимум по неправильному диапазону.
5. Проверять различность только соседних чисел.
6. Неправильно использовать абсолютные ссылки `$`.
7. Считать подходящие строки вручную вместо `СЧЁТЕСЛИ`.
8. Пытаться читать `.xlsx` или `.ods` обычным `open()` в Python.

# Быстрая памятка

```text
МАКС        → максимальное число
МИН         → минимальное число
СУММ        → сумма
СРЗНАЧ      → среднее
СЧЁТЕСЛИ    → количество ячеек по условию
И           → одновременно выполняются все условия
ОСТАТ       → остаток от деления
СУММПРОИЗВ  → подсчёт по массиву условий

все числа различны:
каждое значение встречается ровно 1 раз

сумма остальных:
СУММ - МАКС - МИН

несколько условий:
И(условие1; условие2; ...)
```

Главный навык в №9 — перевести текст условия в несколько простых проверок и не пытаться сразу написать одну огромную формулу.
