# Основной принцип

Любое число в системе счисления с основанием `p` можно представить как сумму цифр, умноженных на степени основания.

Например:

```text
123₅ = 1·5² + 2·5¹ + 3·5⁰
```

В Python готовая функция `int()` умеет переводить строковую запись числа в десятичную систему:

```python
print(int('123', 5))
```

Результат:

```text
38
```

Но `int()` работает с основаниями только от 2 до 36.

# Тип 1. Неизвестная цифра и делимость

Один из вариантов демоверсии ЕГЭ-2027 имеет такой тип: операнды записаны в системе с основанием 22, одна и та же неизвестная цифра обозначена `x`, а значение выражения должно делиться на заданное число.

Нужно:

```text
1. перебрать допустимые значения x;
2. подставить x во все числа;
3. перевести числа в десятичную систему;
4. вычислить выражение;
5. проверить делимость;
6. выбрать минимальное или максимальное x по условию;
7. выполнить требуемое действие с найденным значением выражения.
```

## Универсальный способ через числовые значения цифр

Если неизвестная цифра может принимать значения от `0` до `base - 1`, удобно перебирать именно её числовое значение.

```python
def value(digits, base):
    n = 0
    for d in digits:
        n = n * base + d
    return n
```

Для варианта с основанием 22:

```python
base = 22

for x in range(base):
    a = value([2, 7, x, 9, 8, 8, 7, 6], base)
    b = value([2, 6, x, 5, 1], base)
    c = value([7, 1, 1, x, 5], base)

    s = a + b + c

    if s % 21 == 0:
        print(x, s // 21)
        break
```

Для этого варианта получается:

```text
x = 3
частное = 276296118
```

Если требуется **наименьшее** `x`, перебираем по возрастанию и после первого подходящего значения используем `break`.

Если требуется **наибольшее** `x`, удобнее идти в обратном порядке:

```python
for x in range(base - 1, -1, -1):
```

# Быстрый вариант через `int()`

Если основание не больше 36, можно использовать строковую запись числа.

```python
alphabet = '0123456789abcdefghijkl'

for x in alphabet[:22]:
    a = int(f'27{x}98876', 22)
    b = int(f'26{x}51', 22)
    c = int(f'711{x}5', 22)

    s = a + b + c

    if s % 21 == 0:
        print(x, s // 21)
        break
```

Здесь буквы используются как цифры со значениями больше 9:

```text
a = 10
b = 11
c = 12
...
```

`int(..., base)` короче, но функция `value()` универсальнее и работает с основаниями больше 36.

# Тип 2. Подсчёт цифр в записи большого числа

Другой вариант №14: дано большое арифметическое выражение и требуется узнать, сколько раз определённая цифра встречается в его записи в системе с основанием `p`.

Последняя цифра числа в системе `p`:

```python
n % p
```

После удаления последней цифры:

```python
n //= p
```

Например, для подсчёта нулей:

```python
n = 3 * 3125**8 + 2 * 625**7 - 4 * 625**6 + 3 * 125**5 - 2 * 25**4 - 2025
count = 0

while n > 0:
    if n % 25 == 0:
        count += 1
    n //= 25

print(count)
```

Для варианта демоверсии результат:

```text
10
```

Чтобы считать другую цифру, меняем только условие:

```python
if n % p == digit:
```

# Тип 3. Перебор параметра x и подсчёт цифр

Ещё один вариант демоверсии ЕГЭ-2027:

```text
7^170 + 7^100 - x
```

где `x` — положительное целое число, не превышающее `2030`.

Нужно найти **наибольшее** `x`, при котором в семеричной записи выражения содержится ровно `71` нуль.

Поскольку требуется наибольшее значение, удобно сразу перебирать `x` сверху вниз:

```python
for x in range(2030, 0, -1):
    n = 7**170 + 7**100 - x
    count = 0

    while n > 0:
        if n % 7 == 0:
            count += 1
        n //= 7

    if count == 71:
        print(x)
        break
```

Ответ:

```text
2029
```

Такой порядок перебора лучше, чем выводить все подходящие значения и потом выбирать последнее.

# Тип 4. Перевод десятичного числа в систему счисления

Универсальный алгоритм:

```python
def to_base(n, base):
    digits = []

    while n > 0:
        digits.append(n % base)
        n //= base

    return digits[::-1]
```

Например:

```python
print(to_base(38, 5))
```

получим:

```text
[1, 2, 3]
```

Список цифр удобен, когда нужно не красиво вывести число, а анализировать его запись:

```python
digits = to_base(n, 19)
print(digits.count(0))
print(sum(d > 9 for d in digits))
```

# Тип 5. Найти основание системы счисления

Если известно:

```text
201ₚ = 51₁₀
```

то можно составить уравнение:

```text
2p² + 1 = 51
```

или подобрать основание программно:

```python
for p in range(3, 100):
    if 2 * p**2 + 1 == 51:
        print(p)
        break
```

Начинаем с `3`, потому что основание должно быть больше максимальной цифры записи.

# Тип 6. Выражение состоит из степеней основания

Иногда выражение уже почти записано в нужной системе счисления.

Например:

```text
4·7³ + 2·7² + 5
```

это сразу:

```text
4205₇
```

Коэффициенты можно читать как цифры, если:

```text
0 ≤ коэффициент < основание
```

и между разрядами не возникает переносов или заимствований.

Это часто позволяет решить задачу значительно быстрее, чем вычислять огромное число.

---

# Отрицательные слагаемые и заимствование

Полезная закономерность:

```text
p^n - 1
```

в системе счисления с основанием `p` состоит из `n` цифр со значением `p - 1`.

Например:

```text
7^100 - 1
```

в семеричной системе — это 100 цифр `6`.

Такие свойства стоит проверять до запуска полного перебора.

---

# Как понять, какой способ выбрать

**Неизвестная цифра + делимость** → перебор `x`.

**Подсчёт цифр большого числа** → `% base` и `// base`.

**Поиск x по количеству цифр** → внешний перебор `x` + внутренний разбор числа.

**Поиск основания** → уравнение или короткий перебор `p`.

**Выражение из степеней нужного основания** → сначала проверить, нельзя ли прочитать его запись прямо по коэффициентам.

# Частые ошибки

## 1. Перебирать недопустимые цифры

В системе с основанием `p` допустимы только:

```text
0, 1, ..., p - 1
```

Поэтому:

```python
for x in range(p):
```

## 2. Использовать `int()` для основания больше 36

Так нельзя:

```python
int(s, 50)
```

Для больших оснований используйте собственную функцию перевода.

## 3. Забыть уменьшать число в цикле

Обязательно:

```python
n //= p
```

иначе цикл не закончится.

## 4. Взять первое найденное значение при поиске максимума

Если требуется максимум, либо перебирайте сверху вниз, либо сохраняйте последнее подходящее значение.

## 5. Забыть ограничение на цифры при поиске основания

Если в записи встречается цифра `8`, основание должно быть не меньше `9`.

## 6. Сразу вычислять огромное число вручную

В №14 часто важны только остатки от деления, количество цифр или структура степеней основания. Полное представление числа обычно не требуется.

# Быстрая памятка

```text
Из p-ричной в десятичную при p ≤ 36:
int(s, p)

Последняя цифра числа в системе p:
n % p

Удалить последнюю цифру:
n //= p

Допустимые значения неизвестной цифры:
range(p)

Проверка делимости:
n % d == 0

Подсчёт нужной цифры:
while n > 0:
    if n % p == digit:
        count += 1
    n //= p

p^n - 1:
n цифр со значением p - 1
```

Главная идея задания №14:

> **Не переводите огромное число целиком без необходимости. Сначала определите, что именно требуется узнать о его записи, и работайте только с нужными цифрами или параметрами.**
