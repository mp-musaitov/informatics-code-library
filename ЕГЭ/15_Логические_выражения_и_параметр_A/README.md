# ЕГЭ №15. Логические выражения и параметр A

## Что проверяет задание

В задании №15 требуется подобрать параметр `A`, при котором логическое выражение **истинно при всех допустимых значениях переменных**.

В проекте демоверсии ЕГЭ-2027 дан тип с делимостью и отрезком. В других вариантах встречаются:

- делимость (`ДЕЛ`);
- числовые отрезки;
- выражения с двумя переменными `x`, `y`;
- множества;
- побитовая конъюнкция;
- обычные неравенства.

Главная идея у всех типов одна:

> подобрать `A` так, чтобы **не существовало ни одного набора значений**, на котором выражение ложно.

---

# Основной принцип

Если в условии сказано:

> выражение истинно при любом значении `x`

то для выбранного `A` нужно проверить все интересующие нас `x`.

На Python удобно использовать `all()`:

```python
for A in range(1, 1000):
    if all(F(x, A) for x in range(1, 10000)):
        print(A)
```

Если ищется **наименьшее** `A`, перебираем снизу вверх и после первого ответа делаем `break`.

Если ищется **наибольшее** `A`, можно:

- собрать все подходящие значения;
- или перебирать `A` сверху вниз.

---

# Логические операции в Python

```text
НЕ       → not
И        → and
ИЛИ      → or
A → B    → (not A) or B
A ≡ B    → A == B
```

Импликацию также часто удобно записывать так:

```python
A <= B
```

для логических значений `True` и `False`.

Но запись

```python
(not A) or B
```

обычно понятнее при обучении.

---

# Тип 1. Делимость — ДЕЛ(x, A)

Запись

```text
ДЕЛ(x, A)
```

означает:

> `x` делится на `A` без остатка.

В Python:

```python
x % A == 0
```

Отрицание:

```text
¬ДЕЛ(x, A)
```

```python
x % A != 0
```

---

# Демоверсия ЕГЭ-2027

Дан отрезок

```text
B = [70; 90]
```

и выражение

```text
ДЕЛ(x, A) ∨ ((x ∈ B) → ¬ДЕЛ(x, 22))
```

Нужно найти **наибольшее натуральное A**, при котором выражение истинно для любого целого положительного `x`.

Переведём формулу на Python:

```python
(x % A == 0) or ((not (70 <= x <= 90)) or (x % 22 != 0))
```

Удобнее вынести её в функцию:

```python
def f(x, A):
    return (x % A == 0) or ((not (70 <= x <= 90)) or (x % 22 != 0))
```

Полный перебор:

```python
def f(x, A):
    return (x % A == 0) or ((not (70 <= x <= 90)) or (x % 22 != 0))

for A in range(1000, 0, -1):
    if all(f(x, A) for x in range(1, 10000)):
        print(A)
        break
```

Ответ демоверсии:

```text
88
```

---

# Почему здесь получается 88

Разберём выражение без полного перебора.

Импликация

```text
(x ∈ B) → ¬ДЕЛ(x, 22)
```

ложна только тогда, когда одновременно:

```text
x ∈ B
```

и

```text
x делится на 22.
```

На отрезке `[70; 90]` таким числом является:

```text
88
```

Значит, при `x = 88` вторая часть большого выражения ложна.

Чтобы всё выражение оставалось истинным, должно выполняться:

```text
ДЕЛ(88, A)
```

то есть `A` должно быть делителем 88.

Наибольший натуральный делитель 88 — само число:

```text
A = 88
```

Такое рассуждение быстрее Python.

---

# Главный приём: искать, где формула может стать ложной

Вместо вопроса

> когда эта огромная формула истинна?

часто удобнее спросить:

> **при каких значениях она вообще может стать ложной?**

Особенно полезно помнить:

```text
P → Q
```

ложно только при

```text
P = 1
Q = 0
```

Это часто резко сокращает задачу.

---

# Тип 2. Задачи с числовыми отрезками

Например:

```text
B = [22; 40]
C = [32; 50]

¬(x ∈ A) → ((x ∈ B) ≡ (x ∈ C))
```

Нужно найти минимальную длину отрезка `A`, при которой выражение истинно для всех действительных `x`.

Здесь обычно удобнее **рассуждение на числовой прямой**, а не перебор целых чисел.

Эквиваленция

```text
(x ∈ B) ≡ (x ∈ C)
```

ложна там, где `x` принадлежит ровно одному из отрезков.

Для данных отрезков это области:

```text
[22; 32) и (40; 50]
```

Чтобы импликация не стала ложной, эти области должен закрыть отрезок `A`.

Минимальный единый отрезок:

```text
A = [22; 50]
```

его длина:

```text
50 - 22 = 28
```

---

# Важное замечание про отрезки

Если `x` — **действительное число**, нельзя бездумно заменять отрезок на:

```python
range(...)
```

`range()` содержит только целые числа.

Для точного решения задач с действительными `x` лучше анализировать **границы отрезков**.

Например:

```text
[22; 50]
```

имеет длину:

```text
50 - 22 = 28
```

а не 29.

---

# Python для отрезков: метод контрольных точек

Если хочется проверить рассуждение программой, достаточно рассмотреть границы и точки между ними.

Например, для границ

```text
22, 32, 40, 50
```

можно проверить:

```text
22
27
32
36
40
45
50
```

То есть по одной точке из каждой области, где логические условия не меняются.

Это надёжнее, чем искусственно превращать действительную прямую в набор целых чисел.

# Тип 3. Две переменные x и y

Например:

```text
(x + y <= 27) ∨ (y <= x - 1) ∨ (y >= A)
```

Требуется подобрать `A`, чтобы выражение было истинно при любых натуральных `x` и `y`.

Здесь удобно использовать вложенный перебор:

```python
def f(x, y, A):
    return (x + y <= 27) or (y <= x - 1) or (y >= A)

for A in range(1, 100):
    ok = True

    for x in range(1, 100):
        for y in range(1, 100):
            if not f(x, y, A):
                ok = False
                break

        if not ok:
            break

    if ok:
        print(A)
```

Но диапазоны перебора нужно выбирать **по смыслу условия**, а не механически брать `100` или `1000`.

---

# Короткий вариант через all()

```python
def f(x, y, A):
    return (x + y <= 27) or (y <= x - 1) or (y >= A)

for A in range(1, 100):
    if all(f(x, y, A)
           for x in range(1, 100)
           for y in range(1, 100)):
        print(A)
```

Такой код короче, но вложенные циклы начинающим ученикам иногда проще читать и отлаживать.

# Тип 4. Множества

В условии могут быть заданы конкретные множества и неизвестное множество `A`.

Например:

```text
x ∈ P → (¬(x ∈ Q) ∨ x ∈ A)
```

Для конечных множеств удобно использовать Python `set`:

```python
P = {2, 4, 8, 12, 15}
Q = {3, 6, 8, 15}
```

Принадлежность:

```python
x in P
```

Отрицание принадлежности:

```python
x not in Q
```

Если нужно найти минимальное количество элементов в `A`, сначала определяем те значения `x`, без которых формула становится ложной.

---

# Тип 5. Побитовая конъюнкция

Встречаются условия вида:

```text
x & A = 0
```

В Python побитовое И записывается тем же символом:

```python
x & A
```

Например:

```python
(x & A) == 0
```

Такие задачи удобно решать перебором `A` и `x`:

```python
def f(x, A):
    return ((x & A) == 0) or ...

for A in range(1000):
    if all(f(x, A) for x in range(1000)):
        print(A)
```

Здесь особенно важно не путать:

```python
&     # побитовое И
and   # логическое И
```

Это разные операции.

# Как выбрать границы перебора

Это один из самых важных моментов задания №15.

Нельзя считать универсальным шаблон:

```python
for x in range(1000):
```

Он может случайно дать правильный ответ на тренировочной задаче и ошибиться на другой.

Границы выбираем из условия:

- если есть конкретные константы — смотрим область вокруг них;
- если формула содержит делимость — учитываем возможные кратные;
- если две переменные связаны уравнением или неравенством — используем эту связь;
- если `x` действительный — чаще анализируем границы областей, а не перебираем целые значения.

---

# Универсальный шаблон для одной целой переменной

```python
def f(x, A):
    return ...  # логическое выражение из задания

for A in range(1, 1000):
    if all(f(x, A) for x in range(1, 10000)):
        print(A)
        break
```

Использовать его нужно только после того, как понятно, **почему выбранных границ достаточно**.

---

# Альтернативный шаблон без all()

```python
def f(x, A):
    return ...

for A in range(1, 1000):
    ok = True

    for x in range(1, 10000):
        if not f(x, A):
            ok = False
            break

    if ok:
        print(A)
        break
```

Этот вариант длиннее, зато хорошо показывает логику:

> нашли хотя бы один контрпример → значение `A` не подходит.

---

# Как понять, какой способ выбрать

**Делимость + небольшое число критических значений** → сначала логический анализ.

**Обычные целые переменные и понятные границы** → Python-перебор.

**Действительные отрезки** → анализ числовой прямой и границ.

**Две переменные** → вложенный перебор, если область конечна или её можно разумно ограничить.

**Побитовые условия** → обычно Python.

**Конечные множества** → рассуждение или `set`.

# Частые ошибки

## 1. Проверять, существует ли подходящий x

Нам обычно требуется истинность **для всех** `x`.

Неправильная логика:

```text
нашёл один x, где формула истинна → A подходит
```

Правильно:

```text
нашёл хотя бы один x, где формула ложна → A НЕ подходит
```

---

## 2. Неправильно записать импликацию

Неправильно:

```python
P and Q
```

Правильно:

```python
(not P) or Q
```

---

## 3. Перепутать наименьшее и наибольшее A

Если ищем минимум:

```python
for A in range(1, 1000):
```

Если максимум, удобно идти в обратном направлении:

```python
for A in range(1000, 0, -1):
```

---

## 4. Неправильно записать ДЕЛ

```text
ДЕЛ(x, A)
```

это:

```python
x % A == 0
```

а не:

```python
A % x == 0
```

---

## 5. Использовать range для действительных отрезков

`range(22, 50)` не моделирует всю действительную прямую и даже не включает 50.

---

## 6. Взять случайную границу перебора

`range(1000)` — не доказательство того, что после 999 ничего важного не происходит.

Сначала анализируем условие, потом выбираем диапазон.

---

## 7. Перепутать & и and

```python
x & A
```

работает с битами числа.

```python
P and Q
```

работает с логическими значениями.

---

# Быстрая памятка

```text
ДЕЛ(x, A)       → x % A == 0
¬ДЕЛ(x, A)      → x % A != 0
x ∈ [a; b]      → a <= x <= b
НЕ              → not
И               → and
ИЛИ             → or
P → Q           → (not P) or Q
P ≡ Q           → P == Q
побитовое И      → &
```

Если формула должна быть истинна **для всех** значений:

```python
all(...)
```

или ищем контрпример вручную.

Главный вопрос задания №15:

> **При каких значениях переменных формула может стать ложной и что должен делать параметр A, чтобы этого не произошло?**

Если сначала искать именно ложные случаи, большинство громоздких формул становится заметно проще.
