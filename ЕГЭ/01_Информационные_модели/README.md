# ЕГЭ №1. Информационные модели

## Что проверяет задание

В задании №1 нужно сопоставить граф и таблицу, в которой зашифрованы связи между вершинами.

Обычно дано:

- изображение графа с вершинами, обозначенными буквами;
- таблица, где те же вершины обозначены номерами;
- дополнительные условия, например длина ребра между конкретными вершинами.

Нужно понять, какой номер таблицы соответствует каждой вершине графа, и затем найти требуемое значение.

## Основной принцип

Граф и таблица описывают один и тот же объект.

Поэтому у соответствующих вершин должны совпадать:

1. количество соседей;
2. структура соседства;
3. связи с уже найденными вершинами;
4. дополнительные признаки из условия.

Главная идея:

```text
не угадывать вершины по одной,
а постепенно восстанавливать соответствие по структуре графа
```

## Шаг 1. Посчитать степени вершин

**Степень вершины** — количество рёбер, выходящих из неё.

Например:

```text
A соединена с B, C и D
```

Значит:

```text
степень A = 3
```

В таблице степень вершины определяется количеством заполненных ячеек в соответствующей строке.

Если на графе только одна вершина имеет степень 4, а в таблице только строка `П5` содержит четыре связи, то:

```text
эта вершина = П5
```

Это самый удобный способ начать решение.

## Шаг 2. Найти уникальные вершины

Сначала ищите вершины, которые можно определить однозначно:

- единственная вершина степени 1;
- единственная вершина степени 4;
- вершина, соединённая с двумя уже известными вершинами;
- вершина с уникальным набором соседей.

После нахождения одной вершины остальные часто начинают определяться цепочкой.

## Шаг 3. Использовать соседей

Допустим, установлено:

```text
A = П3
```

На графе вершина `A` соединена с `B`, `C` и `D`.

Тогда в таблице все вершины, соединённые с `П3`, должны соответствовать именно `B`, `C` и `D`.

Теперь сравниваем их степени и связи между собой.

## Шаг 4. Использовать дополнительные условия

Иногда одной структуры недостаточно: граф может быть симметричным, и несколько вариантов соответствия подходят одинаково хорошо.

Тогда условие специально даёт дополнительную информацию.

Например:

> Известно, что дорога между A и D имеет длину 17.

После восстановления возможных соответствий проверяем, какая пара номеров в таблице имеет вес `17`.

Дополнительное условие обычно нужно применять **после анализа структуры**, а не вместо него.

# Основной способ: ручное сопоставление

Для большинства вариантов №1 это самый быстрый способ.

## Алгоритм

1. Посчитать степени всех вершин графа.
2. Посчитать количество связей в строках таблицы.
3. Найти вершины с уникальной степенью.
4. Зафиксировать первое соответствие.
5. Сравнить соседей найденной вершины.
6. Последовательно восстановить остальные вершины.
7. Если осталось несколько вариантов — применить дополнительное условие.
8. Только после этого найти значение, которое спрашивается в задаче.

## Удобная черновая таблица

Во время решения можно записывать:

```text
A -> П3
B -> П6
C -> П1
D -> ?
```

И отдельно степени:

```text
A: 3
B: 2
C: 3
D: 4
```

Так вероятность запутаться заметно уменьшается.

# Альтернативный способ: перебор на Python

Python полезен, если:

- граф симметричный;
- трудно вручную восстановить соответствие;
- хочется проверить уже полученный ответ;
- нужно перебрать все допустимые соответствия.

## Идея

Представим граф и таблицу как множества рёбер.

Например:

```python
edges_graph = {
    ('A', 'B'),
    ('A', 'C'),
    ('B', 'D'),
    ('C', 'D')
}
```

Для таблицы можно записать связи номеров:

```python
edges_table = {
    (1, 2),
    (1, 4),
    (2, 3),
    (3, 4)
}
```

Затем перебрать все перестановки номеров и проверить, сохраняются ли все рёбра.

```python
from itertools import permutations

letters = ['A', 'B', 'C', 'D']
numbers = [1, 2, 3, 4]

edges_graph = {
    frozenset(('A', 'B')),
    frozenset(('A', 'C')),
    frozenset(('B', 'D')),
    frozenset(('C', 'D'))
}

edges_table = {
    frozenset((1, 2)),
    frozenset((1, 4)),
    frozenset((2, 3)),
    frozenset((3, 4))
}

for p in permutations(numbers):
    correspondence = dict(zip(letters, p))

    converted = {
        frozenset((correspondence[a], correspondence[b]))
        for a, b in (tuple(edge) for edge in edges_graph)
    }

    if converted == edges_table:
        print(correspondence)
```

Для реального задания код нужно адаптировать под конкретный граф.

## Что важно понимать

Перебор не заменяет понимание графа.

В ЕГЭ ручной анализ часто быстрее, чем ввод всей структуры в программу. Python здесь прежде всего хороший инструмент проверки или решения особенно симметричных вариантов.

# Как понять, какой способ выбрать

## Ручное решение лучше, если

- есть вершины с уникальными степенями;
- после одного соответствия остальные быстро восстанавливаются;
- граф небольшой и не слишком симметричный.

## Python удобнее, если

- несколько вершин имеют одинаковые степени;
- много симметрии;
- после ручного анализа остаётся несколько допустимых вариантов;
- нужно проверить своё соответствие.

Практический принцип:

```text
сначала 20–30 секунд анализируем граф;
если структура быстро раскрывается — решаем вручную;
если начинается длинный перебор вариантов — можно подключать Python
```

# Мини-пример

Пусть степени вершин графа такие:

```text
A = 4
B = 2
C = 3
D = 2
E = 3
```

А число связей в строках таблицы:

```text
П1 = 2
П2 = 3
П3 = 4
П4 = 3
П5 = 2
```

Сразу получаем:

```text
A = П3
```

потому что только `A` и `П3` имеют степень 4.

Далее смотрим соседей `A` и строку `П3`. Среди соседей сравниваем степени 2 и 3, после чего постепенно восстанавливаем оставшиеся соответствия.

И только когда нужные вершины определены, берём из таблицы вес требуемого ребра.

---

# Частые ошибки

## 1. Смотреть только на степень вершины

Одинаковая степень ещё не означает, что вершины соответствуют друг другу.

Нужно проверять и соседей.

## 2. Использовать длины рёбер слишком рано

Вес ребра — дополнительный признак. Сначала лучше восстановить структуру графа.

## 3. Путать строку и вершину

Если `A = П3`, это означает, что **вся строка и столбец П3** относятся к вершине `A`.

## 4. Не проверять полученное соответствие

После восстановления полезно быстро проверить несколько рёбер:

```text
есть ребро на графе -> должна быть заполнена соответствующая ячейка таблицы
нет ребра -> ячейка должна быть пустой
```

## 5. Считать веса вместо количества соседей

Для степени вершины важно количество связей, а не сумма длин дорог.

# Быстрая памятка

```text
1. Посчитать степени.
2. Найти уникальную вершину.
3. Сопоставить её со строкой таблицы.
4. Посмотреть соседей.
5. Восстановить остальные вершины.
6. Использовать дополнительное условие при симметрии.
7. Найти требуемый вес.
```

Главный вопрос при решении №1:

> Какая особенность этой вершины отличает её от остальных?

Если постоянно задавать его для графа и таблицы одновременно, задание обычно разбирается очень быстро.
