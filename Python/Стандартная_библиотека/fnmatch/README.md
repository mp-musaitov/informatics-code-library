# fnmatch в Python

Модуль проверяет, соответствует ли строка простой маске. Он подходит для имён файлов и десятичных записей чисел. Сам модуль не ищет файлы на диске: ему передают готовые строки.

## Основные функции и классы

| Инструмент | Что делает |
| --- | --- |
| `fnmatch(строка, маска)` | Проверить совпадение; обработка регистра зависит от операционной системы. |
| `fnmatchcase(строка, маска)` | Проверить совпадение с учётом регистра на любой системе. |
| `filter(имена, маска)` | Отобрать строки по правилам fnmatch; результат — список. |

## Как пользоваться

В маске `?` означает ровно один произвольный символ, `*` — любое количество символов, включая ноль, `[135]` — один из указанных символов, `[!0]` — один символ, кроме нуля. Маска проверяет всю строку.

Это не регулярные выражения: точка означает обычную точку, а `*` не повторяет предыдущий символ. Для числовых задач используйте `fnmatchcase(str(number), mask)`. В строке, полученной из положительного целого числа, все символы являются цифрами; в произвольном тексте `?` может совпасть и с буквой.

`fnmatch` учитывает правила нормализации имён операционной системы: в Windows сравнение обычно не зависит от регистра. Для одинакового поведения учебных примеров используем `fnmatchcase`. При работе с числами различия регистра нет.

Маска не делает полный перебор быстрым. Сначала ограничьте диапазон и, если требуется делимость на d, перебирайте кратные d с шагом d. Правая граница `range` не включается.

## Типовые школьные задачи

Найти числа заданной маски, кратные делителю; вывести число и частное; выбрать имена с нужным расширением; различать обязательную цифру и произвольное число цифр.

## Короткие примеры

### Один обязательный символ

```python
from fnmatch import fnmatchcase

print(fnmatchcase('1235', '12?5'))  # True
print(fnmatchcase('125', '12?5'))   # False
```

### Звёздочка может быть пустой

```python
from fnmatch import fnmatchcase

print(fnmatchcase('125', '12*5'))    # True
print(fnmatchcase('12005', '12*5'))  # True
```

### Перебор кратных по маске

```python
from fnmatch import fnmatchcase

# Положительные числа не больше 2000, кратные 25.
for number in range(25, 2000 + 1, 25):
    if fnmatchcase(str(number), '12?5'):
        print(number, number // 25)
# 1225 49
# 1275 51
```

### Выбор файлов с учётом регистра

```python
from fnmatch import fnmatchcase

names = ['task.txt', 'photo.png', 'DATA.TXT', 'notes.txt']
selected = [name for name in names if fnmatchcase(name, '*.txt')]
print(selected)  # ['task.txt', 'notes.txt']
```

### Набор допустимых цифр

```python
from fnmatch import fnmatchcase

for text in ['120', '130', '140', '150']:
    if fnmatchcase(text, '1[35]0'):
        print(text)
# 130, затем 150
```

### Обычная проверка и отбор списка

```python
from fnmatch import fnmatch, filter

# Имена в одном регистре: результат одинаков в Windows и Linux.
names = ['a.txt', 'b.csv', 'c.txt']
print(fnmatch('a.txt', '*.txt'))  # True
print(filter(names, '*.txt'))  # ['a.txt', 'c.txt']
```

## Частые ошибки

- Передавать число вместо строки.
- Считать, что `*` обязательно заменяет хотя бы один символ.
- Ожидать от `?` только цифру при проверке произвольного текста.
- Путать шаблоны re и fnmatch.
- Перебирать все числа до огромной границы, не используя делимость и ограничения длины.

## Памятка

- `fnmatch(строка, маска)` — Проверить совпадение; обработка регистра зависит от операционной системы.
- `fnmatchcase(строка, маска)` — Проверить совпадение с учётом регистра на любой системе.
- `filter(имена, маска)` — Отобрать строки по правилам fnmatch; результат — список.
