# 📚 Стандартная библиотека Python

Стандартная библиотека — модули, которые поставляются вместе с Python и подключаются через `import`. Устанавливать их через `pip` не нужно. В отличие от [встроенных функций](../Основы/11_Полезные_встроенные_функции/), функции модулей сначала импортируют.

Это первый набор инструментов для школьных задач, ЕГЭ/ОГЭ и работы с [практическими шаблонами](../Шаблоны/). Здесь разобраны только основные функции и классы, без полного справочника API. Примеры рассчитаны на Python 3.9 и новее; автоматические проверки репозитория используют Python 3.12.

## Как пользоваться разделом

1. Выберите модуль по задаче и прочитайте его README: назначение, основные инструменты, примеры, ошибки и памятку.
2. Откройте `examples.py` и найдите подходящий `БЛОК`. Каждый блок независим: содержит собственные импорты и исходные данные.
3. Скопируйте нужный блок в своё решение и замените демонстрационные данные данными задачи.
4. Проверьте ограничения: пустой ввод, допустимые числа, размер перебора, важность порядка и повторов.

Файлы `examples.py` можно запускать обычным способом: их имена не совпадают с названиями стандартных модулей и не мешают `import`.

## Как подключать модули

Два равноправных способа:

```python
import math

print(math.gcd(18, 24))  # 6
```

```python
from math import gcd

print(gcd(18, 24))  # 6
```

В первом случае имя модуля показывает, откуда функция; во втором запись короче. Для копируемых блоков импорт повторяется намеренно. Запись `from ... import *` здесь не нужна: лучше видеть, какие инструменты использует решение.

## Как выбрать инструмент

- Все слова с повторами — `itertools.product`; выбор без учёта порядка — `combinations`.
- Нужен только комбинаторный ответ без проверки каждого варианта — рассмотрите `math.comb` или формулу.
- Простая маска со звёздочкой и вопросительным знаком — `fnmatch`; более точный шаблон текста — `re`.
- Частоты значений — `Counter`; очередь по порядку поступления — `deque`; сначала наименьшее значение — `heapq`.
- Адрес сети и биты IPv4 — `ipaddress`.

Модуль сокращает запись, но не заменяет алгоритм. Для одноразовой сортировки обычно достаточно `sorted`, для одной подстроки — строкового метода, для небольшого перебора — цикла.
