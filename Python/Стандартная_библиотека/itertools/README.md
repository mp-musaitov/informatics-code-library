# itertools в Python

Модуль помогает перебирать слова, наборы и варианты выбора без нескольких вложенных циклов. Здесь нужны только три функции: `product`, `permutations` и `combinations`.

## Основные функции и классы

| Инструмент | Что делает |
| --- | --- |
| `product(алфавит, repeat=k)` | Все последовательности длины k; символы могут повторяться. |
| `permutations(данные, k)` | Упорядоченный выбор k позиций без повторного использования позиции. |
| `combinations(данные, k)` | Выбор k позиций, где порядок выбора не важен. |

## Как пользоваться

Результат каждого шага — кортеж: набор элементов в круглых скобках. Для букв превращайте его в слово через `''.join(letters)`. Для чисел можно сразу получать элементы в отдельные переменные.

Функции выдают варианты по одному. Используйте цикл; `list(...)` нужен только для маленьких демонстраций. Для повторного перебора снова вызовите функцию. Порядок выдачи зависит от порядка исходных элементов: для алфавитной нумерации сначала задайте правильный алфавит.

Если в алфавите n разных символов, `product(..., repeat=k)` проверяет n ** k вариантов. Даже короткая запись может работать очень долго. Для подсчёта без дополнительных условий часто достаточно формулы.

## Типовые школьные задачи

Посчитать слова с заданным числом букв; найти номер слова; перебрать значения логических переменных; выбрать пару участников. Перед выбором функции решите: важен ли порядок и разрешены ли повторы.

## Короткие примеры

### Все двубуквенные слова

```python
from itertools import product

for letters in product('АБ', repeat=2):
    print(''.join(letters))
# АА, АБ, БА, ББ — каждое слово с новой строки
```

### Слова с одной буквой А

```python
from itertools import product

count = 0
for letters in product('АБВ', repeat=3):
    word = ''.join(letters)
    if word.count('А') == 1:
        count += 1
print(count)  # 12
```

### Номер слова

```python
from itertools import product

for number, letters in enumerate(product('АБВ', repeat=3), start=1):
    if ''.join(letters) == 'БАВ':
        print(number)  # 12
        break
```

### Перестановки без повторения позиций

```python
from itertools import permutations

words = []
for letters in permutations('АБВ', 2):
    words.append(''.join(letters))
print(words)  # ['АБ', 'АВ', 'БА', 'БВ', 'ВА', 'ВБ']
```

### Пары с чётной суммой

```python
from itertools import combinations

numbers = [1, 2, 3, 4]
count = 0
for a, b in combinations(numbers, 2):
    if (a + b) % 2 == 0:
        count += 1
print(count)  # 2
```

### Таблица истинности

```python
from itertools import product

for x, y in product([0, 1], repeat=2):
    result = x and not y
    print(x, y, int(result))
# 0 0 0
# 0 1 0
# 1 0 1
# 1 1 0
```

## Частые ошибки

- Путать перестановки с сочетаниями: пары AB и BA различны только при важном порядке.
- Считать, что одинаковые значения автоматически удаляются: в `permutations('ААБ')` возможны одинаковые слова, потому что выбираются позиции.
- Считать элементы результата строками: для слова нужен `join`.
- Создавать список всех длинных слов вместо подсчёта в цикле.
- Забывать запрет ведущего нуля при составлении чисел.

## Памятка

- `product(алфавит, repeat=k)` — Все последовательности длины k; символы могут повторяться.
- `permutations(данные, k)` — Упорядоченный выбор k позиций без повторного использования позиции.
- `combinations(данные, k)` — Выбор k позиций, где порядок выбора не важен.
