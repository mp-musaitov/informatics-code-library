# math в Python

Модуль содержит готовые математические функции. Он полезен для делителей, точного целочисленного корня, комбинаторных подсчётов и простых геометрических вычислений.

## Основные функции и классы

| Инструмент | Что делает |
| --- | --- |
| `gcd(a, b)`, `lcm(a, b)` | Наибольший общий делитель и наименьшее общее кратное. |
| `isqrt(n)`, `sqrt(x)` | Целая часть корня для целого n ≥ 0 и вещественный корень для x ≥ 0. |
| `ceil(x)`, `floor(x)` | Округление вверх и вниз до целого. |
| `factorial(n)`, `comb(n, k)` | n! и число способов выбрать k объектов из n без учёта порядка. |
| `hypot(x, y)`, `pi` | Длина гипотенузы и число π. |

## Как пользоваться

Импортируйте только нужное: `from math import gcd`. Обычные `abs`, `round`, `min` и `max` доступны без этого модуля.

`isqrt(n)` работает с целыми числами точно: удобно проверять квадрат через `r * r == n`. Для больших целых `int(sqrt(n))` может дать ошибку из-за округления вещественного результата. `sqrt` и `hypot` возвращают вещественные числа.

`ceil` округляет к большему целому, `floor` — к меньшему; это важно и для отрицательных чисел. Для положительного количества объектов n и вместимости k число упаковок лучше считать точно: `(n + k - 1) // k`.

Для `factorial` нужны целые n ≥ 0; для `comb` — целые n, k ≥ 0. При k > n результат `comb` равен 0. `0!` равен 1. `lcm` доступен начиная с Python 3.9.

## Короткие примеры

### НОД и НОК

```python
from math import gcd, lcm

a, b = 18, 24
print(gcd(a, b))  # 6
print(lcm(a, b))  # 72
```

### Проверка полного квадрата

```python
from math import isqrt

n = 144
if n >= 0:
    root = isqrt(n)
    print(root * root == n)  # True
else:
    print(False)
```

### Все делители положительного числа

```python
from math import isqrt

n = 36  # n > 0
divisors = []
for d in range(1, isqrt(n) + 1):
    if n % d == 0:
        divisors.append(d)
        if d != n // d:
            divisors.append(n // d)
print(sorted(divisors))  # [1, 2, 3, 4, 6, 9, 12, 18, 36]
```

### Округление вверх и вниз

```python
from math import ceil, floor

print(ceil(2.3), floor(2.3))    # 3 2
print(ceil(-2.3), floor(-2.3))  # -2 -3
n, capacity = 101, 10
print((n + capacity - 1) // capacity)  # 11 упаковок
```

### Подсчёт без перебора

```python
from math import factorial, comb

print(factorial(5))  # 120 порядков для пяти разных объектов
print(comb(5, 2))    # 10 пар без учёта порядка
```

### Корень и расстояние

```python
from math import sqrt, hypot, pi

print(sqrt(49))  # 7.0
x1, y1 = 1, 2
x2, y2 = 4, 6
print(hypot(x2 - x1, y2 - y1))  # 5.0
radius = 2
print(round(pi * radius ** 2, 2))  # 12.57
```

## Частые ошибки

- Перебирать делители только до `isqrt(n)`, не включая сам корень.
- Добавлять корень дважды в список делителей полного квадрата.
- Использовать `sqrt` для точной проверки огромных целых.
- Путать `int(-2.7)` и `floor(-2.7)`: это -2 и -3.
- Передавать отрицательные числа в `sqrt`, `isqrt` или `factorial`.
