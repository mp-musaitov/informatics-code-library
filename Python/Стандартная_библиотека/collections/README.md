# collections в Python

Модуль дополняет обычные списки и словари. Для школьных задач начнём с `Counter` для частот, `defaultdict` для группировки и `deque` для очереди.

## Основные функции и классы

| Инструмент | Что делает |
| --- | --- |
| `Counter(данные)` | Счётчик: элемент → число появлений. |
| `counter.most_common(k)` | k самых частых элементов вместе с частотами. |
| `defaultdict(list)` | Словарь, создающий пустой список для нового ключа. |
| `deque(данные)` | Очередь с добавлением и удалением с обоих концов. |
| `append(x)`, `popleft()` | Добавить справа; удалить и вернуть первый элемент слева. |
| `appendleft(x)`, `pop()` | Добавить слева; удалить и вернуть последний элемент справа. |

## Как пользоваться

`Counter` похож на словарь: можно обращаться по ключу и перебирать `items()`. Для отсутствующего ключа он возвращает 0. В `most_common` при равных частотах первым идёт элемент, который раньше встретился; если условие требует другой порядок, задайте его отдельно.

В `defaultdict(list)` передаём саму функцию `list`, без скобок. Когда обращаемся к отсутствующему ключу через квадратные скобки, создаётся отдельный пустой список для этого ключа. Это удобно для распределения чисел по остаткам.

Очередь обслуживает элементы в порядке поступления: добавление справа, удаление слева. У `deque` удаление слева не сдвигает все оставшиеся элементы, как `list.pop(0)`. Перед удалением проверьте, что очередь не пуста.

## Типовые школьные задачи

Посчитать частоты букв или оценок; вывести элементы, встретившиеся один раз; сравнить состав двух слов; сгруппировать числа по остатку; смоделировать очередь заявок.

## Короткие примеры

### Частоты оценок

```python
from collections import Counter

marks = [5, 4, 5, 3, 4, 5]
counts = Counter(marks)
print(counts[5])  # 3
print(counts[2])  # 0
print(len(counts))  # 3 разные оценки
```

### Два самых частых символа

```python
from collections import Counter

counts = Counter('АБАВБА')
print(counts.most_common(2))  # [('А', 3), ('Б', 2)]
```

### Элементы, встретившиеся один раз

```python
from collections import Counter

numbers = [4, 2, 4, 7, 2, 9]
counts = Counter(numbers)
unique = []
for number, count in counts.items():
    if count == 1:
        unique.append(number)
print(sorted(unique))  # [7, 9]
```

### Одинаковый набор букв

```python
from collections import Counter

first = 'ток'
second = 'кот'
print(Counter(first) == Counter(second))  # True
```

### Группировка по остатку

```python
from collections import defaultdict

numbers = [4, 7, 6, 2, 5]
groups = defaultdict(list)
for number in numbers:
    groups[number % 3].append(number)
print(groups[1])  # [4, 7]
print(groups[0])  # [6]
```

### Очередь заявок

```python
from collections import deque

queue = deque(['Адам', 'Амина'])
queue.append('Муса')
while queue:
    print(queue.popleft())
# Адам, Амина, Муса — каждый с новой строки
queue.appendleft('Первый')
print(queue.pop())  # Первый
```

## Частые ошибки

- Путать число разных ключей `len(counter)` с суммой частот.
- Ожидать алфавитный порядок при равных частотах в `most_common`.
- Писать `defaultdict(list())` вместо `defaultdict(list)`.
- Удалять элемент из пустой очереди.
- Считать, что сравнение Counter игнорирует регистр или пробелы: сначала нужно обработать строки.

- `deque(данные)` — Очередь с добавлением и удалением с обоих концов.
- `append(x)`, `popleft()` — Добавить справа; удалить и вернуть первый элемент слева.
- `appendleft(x)`, `pop()` — Добавить слева; удалить и вернуть последний элемент справа.
