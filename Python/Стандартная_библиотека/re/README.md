# re в Python

Модуль ищет фрагменты строк по шаблону — регулярному выражению. Он удобен, когда нужно выделить числа или группы допустимых символов. Для простой замены или поиска одной подстроки сначала рассмотрите строковые методы.

## Основные функции и классы

| Инструмент | Что делает |
| --- | --- |
| `findall(шаблон, строка)` | Список всех неперекрывающихся совпадений; в наших примерах — строки. |
| `search(шаблон, строка)` | Первое совпадение в любом месте либо None. |
| `fullmatch(шаблон, строка)` | Совпадение со всей строкой либо None. |
| `sub(шаблон, замена, строка)` | Новая строка с заменёнными совпадениями. |
| `split(шаблон, строка)` | Разбиение по разделителям, заданным шаблоном. |

## Как пользоваться

Основные обозначения: `[0-9]` — одна цифра от 0 до 9, `[ABC]` — один из перечисленных символов, `+` — одно или больше повторений, `*` — ноль или больше, `?` — ноль или одно повторение, `{3}` — ровно три повторения. Точка `.` означает почти любой символ (кроме перевода строки по умолчанию); `\.` — саму точку.

Пишите шаблоны как сырые строки, например `r'[0-9]+'`: префикс `r` сохраняет обратные слеши для регулярного выражения. Совпадение `search` можно проверить через `if match is not None`, а текст получить через `match.group()`.

В примерах `findall` нет захватывающих скобок: с ними форма результата меняется. Все найденные числа сначала являются строками. Для арифметики преобразуйте их через `int`.

`findall` не ищет перекрывающиеся совпадения: в строке `AAAA` шаблон `AA` даст два совпадения. Для задачи о трёх возможных началах подстроки нужен обычный цикл по индексам.

## Короткие примеры

### Извлечение целых чисел

```python
from re import findall

text = 'Температуры: -12, 7 и 0'
numbers = list(map(int, findall(r'-?[0-9]+', text)))
print(numbers)  # [-12, 7, 0]
print(sum(numbers))  # -5
```

### Проверка всего кода

```python
from re import fullmatch

code = 'AB123'
print(fullmatch(r'[A-Z]{2}[0-9]{3}', code) is not None)  # True
print(fullmatch(r'[A-Z]{2}[0-9]{3}', 'AB123x') is not None)  # False
```

### Первое найденное число

```python
from re import search

text = 'Задача 24, вариант 3'
match = search(r'[0-9]+', text)
if match is not None:
    print(match.group())  # 24
else:
    print('Чисел нет')
```

### Самая длинная серия из A и B

```python
from re import findall

text = 'CAABBCABX'
parts = findall(r'[AB]+', text)
if parts:
    print(len(max(parts, key=len)))  # 4
else:
    print(0)
```

### Замена нескольких пробелов

```python
from re import sub

text = 'кот   и  дом'
print(sub(r' +', ' ', text))  # кот и дом
```

### Разные разделители

```python
from re import split

line = '10,20;30 40'
parts = split(r'[,; ]+', line.strip())
numbers = [int(part) for part in parts if part]
print(numbers)  # [10, 20, 30, 40]
```

## Частые ошибки

- Считать `search` проверкой всей строки: для этого нужен `fullmatch`.
- Вызывать `.group()` у None, когда совпадения нет.
- Путать маску `*` из fnmatch и повторение предыдущего элемента в re.
- Забывать знак минус при извлечении отрицательных чисел.
- Применять `max` к пустому списку найденных серий.

## Памятка

- `findall(шаблон, строка)` — Список всех неперекрывающихся совпадений; в наших примерах — строки.
- `search(шаблон, строка)` — Первое совпадение в любом месте либо None.
- `fullmatch(шаблон, строка)` — Совпадение со всей строкой либо None.
- `sub(шаблон, замена, строка)` — Новая строка с заменёнными совпадениями.
- `split(шаблон, строка)` — Разбиение по разделителям, заданным шаблоном.
