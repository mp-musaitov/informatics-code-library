# heapq в Python

Модуль помогает многократно выбирать наименьший элемент, когда данные добавляются по ходу работы. Основа — куча: список, в котором наименьший элемент находится на позиции 0.

## Основные функции и классы

| Инструмент | Что делает |
| --- | --- |
| `heapify(список)` | Превратить существующий список в кучу на месте. |
| `heappush(куча, x)` | Добавить элемент с сохранением устройства кучи. |
| `heappop(куча)` | Удалить и вернуть минимум. |
| `nsmallest(k, данные)` | Список k наименьших значений по возрастанию. |
| `nlargest(k, данные)` | Список k наибольших значений по убыванию. |

## Как пользоваться

Куча не является полностью отсортированным списком. Надёжно читать минимум можно через `heap[0]`; для получения следующего минимума сначала удалите предыдущий через `heappop`.

`heapify` меняет исходный список и возвращает `None`. После создания кучи добавляйте элементы через `heappush`, а не `append`; иначе свойство кучи может нарушиться. `heappop` и обращение к `heap[0]` требуют непустой кучи.

Если нужно один раз упорядочить небольшой список, `sorted` проще. Куча полезна при чередовании добавлений и извлечений. Построение через `heapify` занимает O(n), добавление и извлечение — O(log n): при увеличении количества элементов стоимость одной операции растёт медленно.

`nsmallest` и `nlargest` принимают обычные данные, предварительная куча им не нужна. Повторы сохраняются, а если элементов меньше k, возвращаются все имеющиеся.

## Типовые школьные задачи

Обрабатывать сначала самую короткую заявку; извлекать минимальные числа после добавлений; выбрать несколько лучших результатов. Пример объединения двух самых коротких отрезков показывает механику кучи; применимость такого жадного выбора нужно обосновывать условием задачи.

## Короткие примеры

### Построение кучи и минимум

```python
from heapq import heapify

heap = [7, 2, 9, 4]
heapify(heap)
print(heap[0])  # 2
```

### Добавление и извлечение

```python
from heapq import heappush, heappop

heap = []
for number in [7, 2, 9]:
    heappush(heap, number)
print(heappop(heap))  # 2
heappush(heap, 1)
print(heappop(heap))  # 1
```

### Извлечение всех значений

```python
from heapq import heapify, heappop

heap = [5, 1, 5, 3]
heapify(heap)
result = []
while heap:
    result.append(heappop(heap))
print(result)  # [1, 3, 5, 5]
```

### Несколько наименьших и наибольших

```python
from heapq import nsmallest, nlargest

scores = [7, 2, 9, 4, 9]
print(nsmallest(3, scores))  # [2, 4, 7]
print(nlargest(2, scores))   # [9, 9]
```

### Сначала короткая заявка

```python
from heapq import heapify, heappop

# Пара содержит длительность и имя.
# При равной длительности имена сравниваются как строки.
heap = [(5, 'Муса'), (2, 'Адам'), (3, 'Амина')]
heapify(heap)
while heap:
    duration, name = heappop(heap)
    print(name, duration)
# Адам 2
# Амина 3
# Муса 5
```

### Объединение двух самых коротких отрезков

```python
from heapq import heapify, heappop, heappush

heap = [2, 3, 7]
heapify(heap)
total = 0
while len(heap) > 1:
    first = heappop(heap)
    second = heappop(heap)
    joined = first + second
    total += joined
    heappush(heap, joined)
print(total)  # 17: сначала 2 + 3 = 5, затем 5 + 7 = 12
```

## Частые ошибки

- Считать, что весь список после `heapify` отсортирован.
- Писать `heap = heapify(numbers)` и получать None.
- Вызывать `heappop` для пустой кучи.
- Добавлять через `append` после построения кучи.
- Ожидать, что `nlargest` удалит выбранные элементы из исходного списка.
