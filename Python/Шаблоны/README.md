# 🧩 Шаблоны Python

Готовые фрагменты кода для типовых задач. Здесь не разбирается синтаксис с нуля: идея раздела — быстро найти подходящий приём, скопировать его и адаптировать под условие задачи.

## План раздела

### Подсчёт и поиск

1. `01_Сумма_и_количество.py` — сумма, количество, среднее.
2. `02_Максимум_и_минимум.py` — поиск максимума и минимума.
3. `03_Максимум_среди_подходящих.py` — экстремум среди элементов, удовлетворяющих условию.
4. `04_Два_максимума.py` — два наибольших элемента без сортировки.

### Числа

5. `05_Делители_числа.py` — поиск и подсчёт делителей.
6. `06_Простое_число.py` — проверка числа на простоту.
7. `07_НОД_и_НОК.py` — наибольший общий делитель и наименьшее общее кратное.
8. `08_Цифры_числа.py` — сумма, количество и перебор цифр.
9. `09_Системы_счисления.py` — перевод и работа с записью числа.

### Последовательности

10. `10_Последовательности.py` — обработка числовой последовательности.
11. `11_Соседние_элементы.py` — пары соседних элементов.
12. `12_Тройки_элементов.py` — тройки подряд идущих элементов.
13. `13_Длины_серий.py` — самая длинная серия элементов.
14. `14_Пары_элементов.py` — перебор всех пар.

### Строки

15. `15_Подсчёт_символов.py` — частоты и количество символов.
16. `16_Поиск_подстрок.py` — поиск и подсчёт подстрок.
17. `17_Замена_и_обработка_строк.py` — типовые преобразования строк.

### Списки

18. `18_Фильтрация_списка.py` — отбор элементов по условию.
19. `19_Сортировка_по_условию.py` — сортировка и ключ `key=`.
20. `20_Уникальные_элементы.py` — множество и удаление повторов.
21. `21_Частоты_элементов.py` — словарь частот.

### Файлы и ЕГЭ

22. `22_Чтение_чисел_из_файла.py` — основные форматы входных файлов.
23. `23_Счётчик_и_экстремум_из_файла.py` — частый шаблон для задач ЕГЭ.
24. `24_Пары_из_файла.py` — обработка пар данных.
25. `25_Скользящее_окно.py` — обработка фрагментов фиксированной длины.

### Перебор и моделирование

26. `26_Полный_перебор.py` — перебор вариантов циклами.
27. `27_Перебор_product.py` — декартово произведение через `itertools.product`.
28. `28_Перестановки.py` — `itertools.permutations`.
29. `29_Комбинации.py` — `itertools.combinations`.
30. `30_Динамическое_программирование.py` — базовый шаблон накопления состояний.

## Формат каждого файла

Каждый шаблон по возможности содержит:

1. задачу, которую он решает;
2. готовый код;
3. небольшой пример;
4. пояснение, когда применять;
5. типичные ошибки.

Раздел будет пополняться постепенно: сначала наиболее универсальные и часто используемые приёмы.
