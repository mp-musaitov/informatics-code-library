# Условия в Python

Условный оператор позволяет выполнять разные действия в зависимости от результата проверки.

## Простое условие

```python
age = 18

if age >= 18:
    print('Совершеннолетний')
```

После условия ставится двоеточие, а команды внутри `if` записываются с отступом.

## if, elif и else

```python
score = 72

if score >= 90:
    print('Отлично')
elif score >= 70:
    print('Хорошо')
else:
    print('Нужно повторить тему')
```

Проверки идут сверху вниз. После первой истинной проверки остальные ветки пропускаются.

## Сравнения

```text
==  равно
!=  не равно
>   больше
<   меньше
>=  больше или равно
<=  меньше или равно
```

Один знак `=` присваивает значение, два знака `==` сравнивают.

## and, or и not

Оба условия:

```python
x = 8

if x > 0 and x < 10:
    print('Число находится от 1 до 9')
```

То же условие можно записать короче:

```python
if 0 < x < 10:
    print('Число находится от 1 до 9')
```

Достаточно одного условия:

```python
if weekday == 'суббота' or weekday == 'воскресенье':
    print('Выходной')
```

Отрицание:

```python
if not is_raining:
    print('Можно идти гулять без зонта')
```

## Проверка через in

```python
answer = 'да'

if answer in ('да', 'yes', 'y'):
    print('Ответ положительный')
```

## Частые ошибки

- использовать `=` вместо `==`;
- забыть двоеточие;
- нарушить отступы;
- путать `and` и `or`;
- неправильно расположить условия в цепочке `if / elif / else`.

## Памятка

```python
if условие:
    действие_1
elif другое_условие:
    действие_2
else:
    действие_3
```
