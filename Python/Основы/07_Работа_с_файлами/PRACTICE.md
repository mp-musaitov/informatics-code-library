# Практика: 07 Работа с файлами

[← К теории](README.md)

Используйте файлы и конструкции тем 01–06. Для каждого задания отдельно подготовьте описанный входной файл в папке запуска программы. Все файлы текстовые, в UTF-8; открывайте их через `with`. В числовых файлах данные корректны. При записи нескольких строк завершайте каждую переводом строки. На экран выводите только то, что явно запрошено.

Задания независимы друг от друга. Если указан ввод, напишите отдельную программу; все входные данные соответствуют условию. Не выводите приглашения к вводу и поясняющие подписи. Пустая строка во входе — отдельная строка, на которой нет символов.

## Разминка

### 1. Первая строка

Файл `input.txt` содержит хотя бы одну строку. Прочитайте только первую строку, удалите пробельные символы по её краям и выведите результат на экран.

### 2. Сумма чисел

В `input.txt` записаны целые числа, по одному в строке, без пустых строк. Файл может быть пустым. Выведите сумму на экран; для пустого файла — 0.

### 3. Запись результата

Вводятся два целых числа через пробел. Запишите их сумму в `output.txt` одной строкой с переводом строки в конце. Предыдущее содержимое выходного файла должно заменяться.

## Основной уровень

### 4. Непустые строки

Файл `input.txt` содержит произвольные строки и может быть пустым. Выведите количество строк, которые после удаления пробельных символов по краям не пусты.

### 5. Количество в первой строке

Первая строка `input.txt` содержит целое `n` от 1 до 100; далее идут ровно `n` целых чисел, по одному в строке. Выведите на экран минимальное и максимальное из этих `n` чисел через пробел. Само `n` не входит в данные.

### 6. Суммы по строкам

В каждой строке `input.txt` записано от 1 до 10 целых чисел через пробел, пустых строк нет. Для каждой строки запишите её сумму отдельной строкой в `output.txt`, сохраняя порядок. Пустому входному файлу соответствует пустой выходной. Выходной файл перезаписывается.

### 7. Добавить запись

Файл `log.txt` существует и либо пуст, либо заканчивается переводом строки. Вводится одна строка текста. Добавьте её и перевод строки в конец файла, сохранив всё прежнее содержимое. На экран ничего выводить не нужно.

## Повышенный уровень

### 8. Отбор строк

В `input.txt` находятся строки произвольного текста. Удалите пробельные символы по краям каждой строки. Запишите в `output.txt` только строки длиной не меньше 5, сохраняя порядок, каждую с переводом строки. Выходной файл перезаписывается; если подходящих строк нет, он пуст.

### 9. Отчёт о положительных

В `input.txt` записаны целые числа по одному в строке, без пустых строк; файл может быть пустым. Запишите в `output.txt` количество и сумму положительных чисел через пробел, с переводом строки в конце. Если их нет, запишите `0 0`. Выходной файл перезаписывается.

## Мини-задача в стиле ЕГЭ/ОГЭ

Учебная задача по мотивам экзаменационных форматов, не официальный вариант.

### 10. пары из файла

В `input.txt` записаны от 2 до 100 целых чисел по одному в строке. Рассмотрите пары соседних чисел; пары могут перекрываться. Выведите на экран количество пар, в которых хотя бы одно число делится на 5, и наибольшую сумму среди таких пар через пробел. Если подходящих пар нет, выведите `0 NONE`. Суммы могут быть отрицательными.
