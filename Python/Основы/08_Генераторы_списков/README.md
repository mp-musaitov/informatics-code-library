# Генераторы списков в Python

Генератор списка (list comprehension) — короткая запись для создания нового списка из элементов другой последовательности. Он удобен, когда нужно преобразовать значения или отобрать подходящие.

В этой теме результат сразу является списком. Конструкции с круглыми скобками вместо квадратных работают иначе и здесь не рассматриваются.

## Базовый синтаксис

Общая запись: `[выражение for x in последовательность]`.

Например, получим квадраты чисел от 1 до 5:

```python
squares = [x ** 2 for x in range(1, 6)]
print(squares)  # [1, 4, 9, 16, 25]
```

То же самое через обычный цикл:

```python
squares = []
for x in range(1, 6):
    squares.append(x ** 2)
```

Сначала читаем часть `for`: откуда берутся значения `x`. Затем выражение слева: что добавляется в новый список.

## Отбор по условию

Условие после `for` оставляет только подходящие элементы:

```python
numbers = [-3, 0, 4, 7, 10]
even = [x for x in numbers if x % 2 == 0]
print(even)  # [0, 4, 10]
```

Можно одновременно отбирать и преобразовывать:

```python
numbers = [-3, 0, 4, 7, 10]
squares = [x ** 2 for x in numbers if x > 0]
print(squares)  # [16, 49, 100]
```

Если ни один элемент не подходит, получится пустой список.

## Ввод чисел и обработка строк

```python
numbers = [int(x) for x in input().split()]
```

`split()` разбивает строку на части, а `int(x)` превращает каждую часть в целое число.

```python
words = ['кот', 'информатика', 'код']
lengths = [len(word) for word in words]
print(lengths)  # [3, 11, 3]
```

## Замена значений через if/else

Если нужно сохранить каждый элемент, но выбрать для него одно из двух значений, `if/else` пишется **перед** `for`:

```python
numbers = [-3, 0, 4, -1]
result = [x if x >= 0 else 0 for x in numbers]
print(result)  # [0, 0, 4, 0]
```

Фильтр после `for` может уменьшить длину списка. Выбор через `if/else` перед `for` сам по себе длину не меняет.

## Создание таблицы

Для каждой строки создаём отдельный список:

```python
rows = 2
cols = 3
matrix = [[0] * cols for _ in range(rows)]
matrix[0][0] = 5
print(matrix)  # [[5, 0, 0], [0, 0, 0]]
```

Запись `[[0] * cols] * rows` повторяет ссылку на одну строку: изменение элемента затронет сразу несколько строк.

## Когда лучше обычный цикл

Если для одного элемента нужно выполнить несколько действий или условие трудно читать, используйте обычный `for`. Короткая запись полезна, пока она остаётся понятной.

## Частые ошибки

- забывать выражение перед `for`;
- путать фильтр после `for` и выбор `if/else` перед ним;
- ожидать, что новый список автоматически изменит исходный;
- забывать `int()` при вводе чисел;
- создавать таблицу повторением одной и той же строки;
- использовать `min()` или `max()` после фильтрации без проверки: список может оказаться пустым.

## Памятка

```python
numbers = [-2, 0, 3, 4]
squares = [x ** 2 for x in numbers]
positive = [x for x in numbers if x > 0]
replaced = [x if x >= 0 else 0 for x in numbers]
```
