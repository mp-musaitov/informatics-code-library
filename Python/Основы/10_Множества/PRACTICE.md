# Практика: 10 Множества

[← К теории](README.md)

Используйте множества и конструкции тем 01–09. Для вывода набора чисел сортируйте его: порядок самого множества не гарантирован.

Задания независимы друг от друга. Если указан ввод, напишите отдельную программу; все входные данные соответствуют условию. Не выводите приглашения к вводу и поясняющие подписи. Пустая строка во входе — отдельная строка, на которой нет символов.

Если требуется вывести список, используйте обычный вид Python: `[1, 2, 3]`, для пустого списка — `[]`. Если условие задаёт другой формат, следуйте ему.

## Разминка

### 1. Разные числа

Вводится строка целых чисел через пробел, возможно пустая. Выведите количество различных значений.

### 2. Разные символы

Вводится строка из строчных латинских букв, возможно пустая. Выведите количество разных букв.

### 3. Добавить и удалить

В первой строке вводится строка целых чисел, возможно пустая, во второй — два целых числа `x` и `y`. Создайте множество, добавьте `x`, затем удалите `y`, если оно есть. Выведите отсортированный список оставшихся значений.

## Основной уровень

### 4. Общие значения

В двух строках вводятся целые числа через пробел; каждая строка может быть пустой. Выведите отсортированный список разных чисел, встречающихся в обеих строках.

### 5. Все значения

В двух строках вводятся целые числа через пробел; каждая строка может быть пустой. Выведите отсортированный список всех разных чисел из обеих строк.

### 6. Только в первом

В двух строках вводятся целые числа через пробел; каждая строка может быть пустой. Выведите отсортированный список чисел, которые есть в первой строке и отсутствуют во второй.

### 7. Все необходимые буквы

В первой строке вводятся необходимые буквы, во второй — текст; обе строки состоят из строчных латинских букв и могут быть пустыми. Выведите `YES`, если каждая различная буква первой строки встречается во второй, иначе `NO`. Для пустой первой строки ответ `YES`; число повторов букв не важно.

## Повышенный уровень

### 8. Ровно в одном наборе

В двух строках вводятся целые числа через пробел; каждая строка может быть пустой. Выведите отсортированный список разных чисел, присутствующих ровно в одной из строк. Повторы внутри одной строки ничего не меняют.

### 9. Первое повторение

Вводится строка целых чисел, возможно пустая. Перебирайте её слева направо и с помощью множества уже встреченных значений найдите первое число, встретившееся повторно. Выведите это число или `NONE`. Для `4 2 2 4` ответ 2.

## Мини-задача в стиле ЕГЭ/ОГЭ

Учебная задача по мотивам экзаменационных форматов, не официальный вариант.

### 10. поисковые запросы

В первой строке перечислены целые идентификаторы страниц по запросу A, во второй — по запросу B; строки могут быть пустыми, идентификаторы могут повторяться. Выведите через пробел количество разных страниц по запросам «A И B» и «A ИЛИ B» соответственно.
