# Множества в Python

Множество хранит **уникальные элементы**. Оно удобно, когда нужно убрать повторы, проверить наличие значения или найти общие элементы двух наборов.

## Создание множества

```python
numbers = {3, 1, 3, 2}
print(len(numbers))  # 3
print(sorted(numbers))  # [1, 2, 3]

empty = set()
```

`{}` создаёт пустой **словарь**. Для пустого множества нужна запись `set()`.

В простых задачах элементами служат числа или строки. Список добавить в множество нельзя.

## Удаление повторов

```python
numbers = [5, 2, 5, 3, 2]
unique = set(numbers)
print(len(unique))     # 3
print(sorted(unique))  # [2, 3, 5]
```

Множество не сохраняет порядок исходного списка, а повторения теряются. Если важны позиции или количество повторов, сохраняйте исходный список.

Из строки можно получить множество её символов:

```python
letters = set('мама')
print(len(letters))  # 2
```

## Проверка наличия и перебор

```python
numbers = {2, 4, 6}
print(4 in numbers)      # True
print(5 not in numbers)  # True

for x in sorted(numbers):
    print(x)  # 2, затем 4, затем 6
```

У множества нет индексов и срезов. Порядок обычного перебора не гарантирован. `sorted()` возвращает отсортированный **список**.

## Добавление и удаление

```python
numbers = {2, 4}
numbers.add(6)
numbers.add(4)  # повтор не добавится
numbers.update([8, 10])
numbers.remove(2)
numbers.discard(100)  # ошибки нет
print(sorted(numbers))  # [4, 6, 8, 10]
```

`add()` добавляет один элемент, `update()` — элементы переданной последовательности. `remove()` вызывает `KeyError`, если значения нет; `discard()` в этом случае ничего не делает.

## Операции над множествами

```python
a = {1, 2, 3}
b = {3, 4}

print(sorted(a | b))  # [1, 2, 3, 4] — объединение
print(sorted(a & b))  # [3] — пересечение
print(sorted(a - b))  # [1, 2] — есть в a, но нет в b
print(sorted(b - a))  # [4] — есть в b, но нет в a
print(sorted(a ^ b))  # [1, 2, 4] — есть ровно в одном
```

Эти операции создают новые множества. При разности порядок операндов важен.

## Подмножество

```python
required = {'a', 'b'}
letters = set('abac')
print(required <= letters)  # True
```

`a <= b` проверяет, что каждый элемент `a` есть в `b`. Равенство множеств при этом допускается.

## Типовая задача: общие значения

```python
first = [2, 5, 2, 7]
second = [5, 5, 8, 7]
common = set(first) & set(second)
print(len(common))     # 2 разных общих значения
print(sorted(common))  # [5, 7]
```

## Проверка повторов

```python
numbers = [2, 5, 2, 7]
has_duplicates = len(set(numbers)) < len(numbers)
print(has_duplicates)  # True

all_unique = len(set(numbers)) == len(numbers)
print(all_unique)  # False
```

`has_duplicates` проверяет, есть ли повторы, а `all_unique` — все ли элементы различны.

## Частые ошибки

- создавать пустое множество через `{}`;
- обращаться к элементу по индексу;
- ожидать сохранения порядка или повторов;
- путать `add()` и `append()`: у множества нет `append()`;
- удалять отсутствующее значение через `remove()`;
- путать `&` и `|` с логическими `and` и `or`;
- менять размер множества во время его перебора.

## Памятка

```python
a = set([1, 2, 2, 3])
b = {2, 4}
a.add(5)
a.discard(10)
print(len(a))
print(sorted(a & b))
print(sorted(a | b))
print(sorted(a - b))
```
