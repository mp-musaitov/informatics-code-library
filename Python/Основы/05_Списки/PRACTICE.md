# Практика: 05 Списки

[← К теории](README.md)

Используйте списки и уже изученные строки, циклы и условия. Генераторы списков не обязательны: для отбора достаточно обычного цикла.

Задания независимы друг от друга. Если указан ввод, напишите отдельную программу; все входные данные соответствуют условию. Не выводите приглашения к вводу и поясняющие подписи. Пустая строка во входе — отдельная строка, на которой нет символов.

Если требуется вывести список, используйте обычный вид Python: `[1, 2, 3]`, для пустого списка — `[]`. Если условие задаёт другой формат, следуйте ему.

## Разминка

### 1. Сумма списка

Вводится непустая строка целых чисел через пробел. Сохраните их в списке и выведите сумму.

### 2. Заменить элемент

В первой строке вводится непустой список целых чисел через пробел, во второй — индекс `i` и новое значение `x`. Индекс корректен и отсчитывается с нуля. Замените элемент с индексом `i` и выведите список.

### 3. Развернуть список

Вводится непустой список целых чисел через пробел. Выведите новый список в обратном порядке с помощью среза.

## Основной уровень

### 4. Добавление и удаление

В первой строке вводится непустой список целых чисел, во второй — целое `x`. Добавьте `x` в конец, затем удалите первый элемент по индексу. Выведите итоговый список.

### 5. Частота и позиция

В первой строке вводится непустой список целых чисел, во второй — число `x`. Выведите через пробел количество вхождений `x` и индекс первого вхождения. Если `x` нет, выведите `0 -1`.

### 6. Независимая копия

Вводится непустой список целых чисел. Создайте независимую копию и отсортируйте её по возрастанию. Выведите исходный список, затем на новой строке — отсортированную копию. Исходный список должен сохранить порядок.

### 7. Отбор положительных

Вводится непустой список целых чисел. Обычным циклом и `append()` создайте список строго положительных чисел с сохранением порядка и повторов. Выведите его; если подходящих чисел нет, выведите `[]`.

## Повышенный уровень

### 8. Сдвиг вправо

Вводится непустой список целых чисел. Перенесите последний элемент в начало, сохранив порядок остальных. Выведите результат. Для одного элемента список не меняется.

### 9. Суммы строк таблицы

Вводятся ровно три строки, по три целых числа в каждой. Сохраните их как список из трёх списков. Выведите список из сумм строк в исходном порядке.

## Мини-задача в стиле ЕГЭ/ОГЭ

Учебная задача по мотивам экзаменационных форматов, не официальный вариант.

### 10. соседние элементы

Вводится список из 2–100 целых чисел. Рассмотрите все пары соседних элементов; пары могут перекрываться. Выведите количество пар, у которых сумма чётная. Для списка `1 3 5` ответ 2.
