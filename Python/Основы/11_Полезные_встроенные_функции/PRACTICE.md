# Практика: 11 Полезные встроенные функции

[← К теории](README.md)

Используйте встроенные функции из README и конструкции тем 01–10. Импорты не нужны.

Задания независимы друг от друга. Если указан ввод, напишите отдельную программу; все входные данные соответствуют условию. Не выводите приглашения к вводу и поясняющие подписи. Пустая строка во входе — отдельная строка, на которой нет символов.

Если требуется вывести список, используйте обычный вид Python: `[1, 2, 3]`, для пустого списка — `[]`. Если условие задаёт другой формат, следуйте ему.

## Разминка

### 1. Сумма с начальным значением

В первой строке вводится целое начальное значение `start`, во второй — целые числа через пробел, возможно пустая строка. Используя `sum()` с начальным значением, выведите итоговую сумму.

### 2. Крайние значения

Вводится непустая строка целых чисел. Используя `min()` и `max()`, выведите минимум и максимум через пробел.

### 3. Нумерация слов

Вводится строка слов через пробел, возможно пустая. Используйте `enumerate()` и выведите номер и слово через пробел, по одной паре в строке. Номера начинаются с 1. Если слов нет, выведите `EMPTY`.

## Основной уровень

### 4. Сортировка по длине

Вводится строка слов через пробел, возможно пустая. Используйте `sorted()` с `key=len`. Выведите слова по возрастанию длины через один пробел. При равных длинах сохраняйте исходный порядок. Для пустого ввода выведите пустую строку.

### 5. Ближе к нулю

Вводится непустая строка целых чисел. С помощью `min()` с `key=abs` выберите ближайшее к нулю число. Если модуль одинаков, выберите первое во входе. Выведите само число.

### 6. Две проверки

Вводится строка целых чисел, возможно пустая. Используя `any()` и `all()`, выведите через пробел два логических значения: есть ли отрицательное число и все ли числа строго положительные. Для пустого ввода используйте поведение этих функций: `False True`.

### 7. Модули через map

Вводится строка целых чисел, возможно пустая. Через `map()` и `abs` получите список модулей. Выведите этот список, затем на новой строке — его сумму. Сохраните список, чтобы использовать результат дважды.

## Повышенный уровень

### 8. Стоимость корзины

В первой строке вводятся целые неотрицательные цены, во второй — целые неотрицательные количества через пробел. Каждая строка может быть пустой. Если длины различаются, выведите `ERROR`. Иначе используйте `zip()` и выведите сумму произведений цены на соответствующее количество. Для двух пустых строк результат 0.

### 9. Номера лучших результатов

Вводится непустая строка целых баллов от 0 до 100. Найдите максимум и с помощью `enumerate()` выведите номера всех участников с этим баллом, каждый на новой строке, по возрастанию номера. Нумерация начинается с 1.

## Мини-задача в стиле ЕГЭ/ОГЭ

Учебная задача по мотивам экзаменационных форматов, не официальный вариант.

### 10. количество и максимум

Вводится непустая строка из не более 100 целых чисел. Отберите числа, делящиеся на 7. Выведите их количество и максимум через пробел. Если таких чисел нет, выведите `0 NONE`. Используйте встроенные функции и проверяйте результат отбора перед поиском максимума.
