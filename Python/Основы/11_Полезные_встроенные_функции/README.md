# Полезные встроенные функции в Python

Встроенные функции доступны сразу, без `import`. Они помогают найти сумму и крайние значения, упорядочить данные, перебрать списки и проверить условия.

## sum(): сумма чисел

Запись `sum(числа)` возвращает сумму элементов. В `sum(числа, start)` к сумме прибавляется начальное значение `start`; по умолчанию оно равно 0.

```python
numbers = [4, 7, 2]
print(sum(numbers))      # 13
print(sum(numbers, 10))  # 23
print(sum([]))           # 0
```

Типовые задачи: сумма баллов, общая стоимость, сумма подходящих чисел. Для среднего арифметического используйте `sum(numbers) / len(numbers)`, предварительно проверив, что список не пуст. `sum()` не склеивает строки.

## min() и max(): минимум и максимум

Записи `min(данные)` и `max(данные)` возвращают наименьший и наибольший элементы. Можно передать несколько отдельных значений: `min(a, b)` или `max(a, b, c)`.

```python
numbers = [4, 7, 2]
print(min(numbers))  # 2
print(max(numbers))  # 7
print(max(3, 8, 5))  # 8
print(max(numbers) - min(numbers))  # 5 — размах
```

Функции возвращают **значение**, а не его индекс. Типовые задачи: лучший результат, самая низкая температура, разность максимума и минимума.

Для пустого списка `min([])` и `max([])` вызывают `ValueError`. После отбора по условию проверяйте результат:

```python
numbers = [-3, 0, -1]
positive = [x for x in numbers if x > 0]
if positive:
    print(max(positive))
else:
    print('Подходящих чисел нет')
```

## sorted(): сортировка

`sorted(данные)` возвращает новый **список** по возрастанию. Запись `sorted(данные, reverse=True)` задаёт убывание.

```python
numbers = [5, 2, 5, 1]
print(sorted(numbers))                # [1, 2, 5, 5]
print(sorted(numbers, reverse=True))  # [5, 5, 2, 1]
print(numbers)                       # [5, 2, 5, 1]
```

Исходные данные не меняются, повторы сохраняются. Типовые задачи: вывести результаты по порядку, выбрать несколько наибольших чисел. `sorted([])` возвращает `[]`.

Метод `numbers.sort()` меняет сам список и возвращает `None`. Поэтому запись `numbers = numbers.sort()` — ошибка: вместо списка в переменной окажется `None`.

Числа в строках сравниваются как строки: `sorted(['2', '10'])` даёт `['10', '2']`. Для числового порядка сначала преобразуйте строки в числа через `int`.

## key=: по какому признаку сравнивать

Параметр `key=функция` работает у `sorted()`, `min()` и `max()`. Он задаёт функцию, результат которой используется для сравнения каждого элемента. Сами элементы не заменяются этим результатом.

```python
words = ['кот', 'информатика', 'дом', 'я']
print(sorted(words, key=len))  # ['я', 'кот', 'дом', 'информатика']
print(min(words, key=len))     # я
print(max(words, key=len))     # информатика
```

`len` вычисляет длину слова: так можно найти самое короткое или длинное слово. Пишем `key=len`, а не `key=len()`: передаём саму функцию, которую Python применит к каждому элементу.

При одинаковом значении признака `sorted()` сохраняет исходный порядок элементов, а `min()` и `max()` выбирают первый встретившийся.

```python
numbers = [-8, 3, -2, 5]
print(sorted(numbers, key=abs))  # [-2, 3, 5, -8]
print(min(numbers, key=abs))     # -2 — ближайшее к нулю
print(max(numbers, key=abs))     # -8 — самое далёкое от нуля
```

`abs(x)` возвращает модуль числа. При необходимости параметры можно сочетать: `sorted(words, key=len, reverse=True)` упорядочит слова по убыванию длины.

## enumerate(): номер и элемент

`enumerate(данные, start=0)` позволяет получать в цикле номер и соответствующий элемент. По умолчанию нумерация начинается с 0; `start=1` удобен для нумерованного вывода.

```python
names = ['Адам', 'Амина', 'Муса']
for number, name in enumerate(names, start=1):
    print(number, name)
# 1 Адам
# 2 Амина
# 3 Муса
```

Типовые задачи: пронумеровать строки, найти позиции подходящих элементов. `start=1` меняет только выдаваемые номера, индексы исходного списка всё равно начинаются с 0.

## zip(): совместный перебор

`zip(первый_список, второй_список)` объединяет элементы с одинаковыми позициями в пары. В цикле каждую пару удобно получать в две переменные.

```python
names = ['Адам', 'Амина', 'Муса']
scores = [85, 92, 78]
for name, score in zip(names, scores):
    print(name, score)
# Адам 85
# Амина 92
# Муса 78
```

Типовые задачи: связать имена и баллы, сравнить два списка, посчитать стоимость по ценам и количествам. Можно передать и больше двух списков.

`zip()` заканчивает работу на **самом коротком** списке: `list(zip([1, 2, 3], [10, 20]))` даёт `[(1, 10), (2, 20)]`. Если нужны все пары, заранее убедитесь, что длины совпадают.

## any() и all(): проверка условий

`any(проверки)` возвращает `True`, если хотя бы одна проверка истинна. `all(проверки)` возвращает `True`, если истинны все проверки. Иначе результат — `False`.

```python
numbers = [-3, 0, 4, 7]
print(any([x < 0 for x in numbers]))   # True — есть отрицательное
print(all([x > 0 for x in numbers]))   # False — не все положительные
print(all([x >= 0 for x in numbers]))  # False — есть отрицательное
```

В квадратных скобках создаётся список результатов сравнения (`True` и `False`). Такой приём помогает проверить, есть ли подходящее число и все ли значения удовлетворяют условию.

Если передать сами числа, проверяется их истинность: 0 считается ложью, любое ненулевое число, включая отрицательное, — истиной. Поэтому `all(numbers)` **не означает** «все числа положительные». Пустые строки и пустые списки также считаются ложью.

```python
print(any([]))  # False — нет ни одной истинной проверки
print(all([]))  # True — нет ни одной ложной проверки
```

Если по условию список должен быть непустым и все числа должны быть положительными, проверяйте оба требования: `len(numbers) > 0 and all([x > 0 for x in numbers])`.

## map(): применить функцию к каждому элементу

`map(функция, данные)` применяет функцию к каждому элементу. Для получения обычного списка используйте `list(map(функция, данные))`.

```python
line = '12 -5 0 8'
numbers = list(map(int, line.split()))
print(numbers)  # [12, -5, 0, 8]
# Для ввода с клавиатуры:
# numbers = list(map(int, input().split()))
```

`split()` разбивает строку по пробельным символам, `int` переводит каждую часть в целое число, `list()` собирает результат. Запись равнозначна `[int(x) for x in line.split()]`. Если часть строки не является целым числом, например `'кот'` или `'2.5'`, `int` вызовет `ValueError`.

```python
words = ['кот', 'информатика', 'код']
lengths = list(map(len, words))
print(lengths)  # [3, 11, 3]
```

Типовые задачи: ввод чисел, вычисление длин слов и модулей чисел. Как и с `key=`, передаём `int` или `len` без скобок.

`map()`, `zip()` и `enumerate()` сами по себе не возвращают список. Их удобно использовать в цикле; если нужно хранить результат, обращаться по индексу или повторно его перебирать, сохраните `list(...)`. Без такого сохранения после полного перебора тот же объект повторно не выдаст элементы.

## Типовая задача: сумма чётных чисел

```python
numbers = [3, 4, -2, 7, 6]
even = [x for x in numbers if x % 2 == 0]
print(sum(even))  # 8
```

Если чётных чисел нет, получится 0: отдельная проверка для `sum()` не нужна.

## Частые ошибки

- называть переменные `sum`, `min`, `max`, `sorted`, `list`: это мешает затем вызывать одноимённые функции;
- передавать отдельные числа в `sum(2, 3)` вместо списка `sum([2, 3])`;
- вызывать `min()` или `max()` для пустого списка;
- ожидать, что `sorted()` изменит исходный список, или присваивать результат `.sort()`;
- сортировать строки с числами без преобразования, смешивать числа и строки при обычной сортировке;
- писать `key=len()` или `map(int(), данные)` вместо передачи функции без скобок;
- считать номер из `enumerate(..., start=1)` индексом списка;
- забывать, что `zip()` останавливается на коротком списке;
- путать «хотя бы один» (`any`) и «все» (`all`), забывать их поведение на пустых данных;
- ожидать готовый список от `map()` или повторно перебирать уже использованный результат без сохранения.

## Памятка

| Что нужно | Запись |
| --- | --- |
| Сумма чисел | `sum(numbers)` |
| Минимум и максимум непустого списка | `min(numbers)`, `max(numbers)` |
| Новый список по возрастанию / убыванию | `sorted(numbers)`, `sorted(numbers, reverse=True)` |
| Сортировка по длине | `sorted(words, key=len)` |
| Самое длинное слово в непустом списке | `max(words, key=len)` |
| Номер и элемент | `for i, x in enumerate(numbers):` |
| Пары элементов | `for a, b in zip(first, second):` |
| Есть отрицательное | `any([x < 0 for x in numbers])` |
| Все положительные | `all([x > 0 for x in numbers])` |
| Числа из строки | `list(map(int, line.split()))` |
