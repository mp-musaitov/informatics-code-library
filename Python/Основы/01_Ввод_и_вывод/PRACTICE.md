# Практика: 01 Ввод и вывод

[← К теории](README.md)

Используйте только ввод, вывод, переменные, преобразование в `int`, сложение чисел и соединение строк. Условия и циклы не нужны.

Задания независимы друг от друга. Если указан ввод, напишите отдельную программу; все входные данные соответствуют условию. Не выводите приглашения к вводу и поясняющие подписи. Пустая строка во входе — отдельная строка, на которой нет символов.

## Разминка

### 1. Приветствие

Вводится имя одной строкой. Выведите `Привет,` и имя через один пробел. Например, для `Амина` выведите `Привет, Амина`.

### 2. Следующее число

Вводится целое число от −1000 до 1000. Выведите число, которое на 1 больше введённого.

### 3. Две строки

Вводятся название города и название школы, каждое на отдельной строке. Выведите их в том же порядке, каждое на отдельной строке, без пояснений.

## Основной уровень

### 4. Сумма покупок

Вводятся две целые неотрицательные стоимости, каждая на отдельной строке. Выведите их сумму одним числом.

### 5. Три результата

В одной строке вводятся три целых числа от 0 до 100. Выведите их сумму.

### 6. Обратный порядок

Вводятся два слова, каждое на отдельной строке. Выведите сначала второе, затем первое слово в одной строке через пробел.

### 7. Склеить части

Вводятся две непустые строки. Соедините их без разделителя и выведите результат. Например, строки `12` и `03` должны дать `1203`; преобразовывать их в числа не нужно.

## Повышенный уровень

### 8. Два способа прочитать числа

Вводятся две строки, каждая содержит запись целого числа от 1 до 99 без ведущих нулей. Сначала выведите соединение исходных строк без разделителя, затем на новой строке — сумму чисел. Для строк `2` и `15` результат: `215`, затем `17`.

### 9. Отчёт о баллах

В первой строке вводится имя, во второй — три целых балла через пробел. Выведите в одной строке имя и сумму баллов через пробел. Для `Муса` и `10 20 30` выведите `Муса 60`.

## Мини-задача в стиле ЕГЭ/ОГЭ

Учебная задача по мотивам экзаменационных форматов, не официальный вариант.

### 10. исполнитель

Исполнитель получает целое число `x` и последовательно выполняет команды «прибавить 3», «прибавить 5», «прибавить 3». Введите `x` и выведите итоговое число. Достаточно ввода, сложения и вывода.
