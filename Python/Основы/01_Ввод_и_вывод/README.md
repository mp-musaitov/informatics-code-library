# Ввод и вывод данных в Python

В этой теме разберём, как программа получает данные от пользователя и как выводит результат на экран.

## Вывод данных

Для вывода используется функция `print()`.

```python
print('Привет, мир!')
```

Текст записывается в кавычках.

Можно вывести несколько значений:

```python
name = 'Адам'
age = 16

print(name, age)
```

`print()` автоматически поставит между ними пробел.

## Ввод данных

Функция `input()` позволяет получить значение от пользователя.

```python
name = input('Введите имя: ')
print('Привет,', name)
```

Важно: результат `input()` — **строка**, даже если пользователь ввёл цифры.

Например:

```python
a = input()
b = input()

print(a + b)
```

Если ввести `2` и `3`, программа выведет:

```text
23
```

Потому что строки соединяются.

## Ввод целого числа

Если число нужно использовать в вычислениях, строку преобразуют в `int`.

```python
age = int(input('Введите возраст: '))
print(age + 1)
```

Теперь значение `age` — целое число.

Например:

```python
a = int(input())
b = int(input())

print(a + b)
```

При вводе `2` и `3` программа выведет:

```text
5
```

## Несколько чисел в одной строке

Если числа вводятся через пробел:

```text
10 25
```

можно использовать:

```python
a, b = map(int, input().split())
print(a + b)
```

Здесь по шагам:

```python
input()       # получаем строку
.split()      # разделяем её по пробелам
map(int, ...) # превращаем части строки в целые числа
a, b = ...    # записываем числа в переменные
```

Это одна из самых частых конструкций в задачах.

## Что выводить

Можно выводить текст вместе со значением:

```python
score = 75
print('Результат:', score)
```

Но в задачах с автоматической проверкой обычно нужно выводить **только то, что требует условие**.

Если ожидается одно число:

```python
print(score)
```

лишний текст может привести к неверному ответу.

## Частые ошибки

- забыть `int()` и получить строку вместо числа;
- использовать `+` для строк, ожидая сложение чисел;
- забыть `.split()`, когда несколько чисел вводятся в одной строке;
- ожидать два значения слева, если во входной строке другое количество чисел;
- выводить поясняющий текст там, где проверяющая система ждёт только ответ.

## Памятка

```python
print(value)                         # вывести значение
text = input()                       # ввести строку
number = int(input())                # ввести целое число
a, b = map(int, input().split())     # ввести два целых числа через пробел
```
