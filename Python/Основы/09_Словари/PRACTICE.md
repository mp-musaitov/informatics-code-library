# Практика: 09 Словари

[← К теории](README.md)

Используйте обычные словари без `Counter` и других модулей. Можно применять конструкции тем 01–08.

Задания независимы друг от друга. Если указан ввод, напишите отдельную программу; все входные данные соответствуют условию. Не выводите приглашения к вводу и поясняющие подписи. Пустая строка во входе — отдельная строка, на которой нет символов.

## Разминка

### 1. Поиск цены

В программе задан словарь `prices = {'pen': 20, 'book': 100}`. Вводится название товара. Выведите его цену или 0, если ключ отсутствует. Словарь изменять не нужно.

### 2. Заменить балл

Задан словарь `scores = {'Адам': 70, 'Амина': 90}`. Вводится новый целый балл Адама от 0 до 100. Обновите значение и выведите балл Адама и количество ключей через пробел.

### 3. Безопасное удаление

Задан словарь `stock = {'pen': 3, 'book': 2}`. Вводится ключ. Удалите его, если он есть. Выведите количество оставшихся ключей; отсутствие ключа не должно вызывать ошибку.

## Основной уровень

### 4. Частоты чисел

Вводится строка целых чисел через пробел, возможно пустая. Словарём подсчитайте частоты. Выведите пары «число частота» по возрастанию числа, по одной паре в строке. Для пустого ввода выведите `EMPTY`.

### 5. Последняя запись

Вводится `n` от 0 до 100, затем `n` строк вида `имя балл`; имя — одно слово, балл — целое от 0 до 100. При повторе имени сохраните последний балл. Выведите имя и балл через пробел, по одной паре в строке, по алфавиту имён. При `n = 0` выведите `EMPTY`.

### 6. Сумма покупок

Задан словарь `prices = {'pen': 20, 'book': 100, 'pencil': 10}`. Вводится строка названий покупок через пробел, возможно пустая. Все названия есть в словаре. Выведите общую стоимость с учётом повторов.

### 7. Кто прошёл

Вводится `n` от 0 до 100, затем `n` строк `имя балл` с разными именами и целыми баллами от 0 до 100. Сохраните данные в словаре. Выведите по алфавиту имена с баллом не меньше 60, каждое на новой строке, или `NONE`, если таких нет.

## Повышенный уровень

### 8. Самое частое число

Вводится непустая строка целых чисел. Подсчитайте частоты словарём. Выведите число с наибольшей частотой и саму частоту через пробел. При равенстве частот выберите наименьшее число.

### 9. Общий склад

Вводится `n` от 0 до 100, затем `n` строк `товар количество`; товар — одно слово, количество — целое от 0 до 100. Накопите суммарное количество для каждого товара. Выведите товар и сумму через пробел по алфавиту товаров, по одной паре в строке. При `n = 0` выведите `EMPTY`; товары с нулевой суммой сохраняйте.

## Мини-задача в стиле ЕГЭ/ОГЭ

Учебная задача по мотивам экзаменационных форматов, не официальный вариант.

### 10. повторяющиеся результаты

Вводится непустая строка из не более 100 целых чисел от 0 до 100. Используйте словарь частот и выведите количество различных значений, встретившихся ровно два раза. Считайте значения, а не их отдельные вхождения.
