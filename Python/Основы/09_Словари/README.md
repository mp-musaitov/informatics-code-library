# Словари в Python

Словарь хранит пары **ключ — значение**. По ключу можно получить связанное с ним значение: например, по имени ученика — его балл.

## Создание и доступ к значениям

```python
scores = {'Адам': 85, 'Амина': 92}
print(scores['Адам'])  # 85
print(len(scores))    # 2

empty = {}
```

В списке обращаются по индексу, а в словаре — по ключу. Ключи уникальны, значения могут повторяться. В простых задачах ключами обычно служат строки или числа; список ключом быть не может.

## Добавление и изменение

```python
scores = {'Адам': 85}
scores['Амина'] = 92  # новый ключ
scores['Адам'] = 90   # изменение значения
print(scores)        # {'Адам': 90, 'Амина': 92}
```

Повторная запись по тому же ключу заменяет значение, а не создаёт вторую пару.

## Проверка наличия ключа и get()

Обращение `scores['Муса']` вызовет `KeyError`, если такого ключа нет.

```python
scores = {'Адам': 85, 'Амина': 92}
if 'Адам' in scores:
    print(scores['Адам'])

print(scores.get('Муса', 0))  # 0
print('Муса' in scores)      # False
```

`get(ключ, значение_по_умолчанию)` возвращает запасное значение, если ключ не найден. Сам ключ при этом не добавляется. Без второго аргумента запасное значение — `None`.

`in` проверяет **ключи**. Чтобы проверить значения, используйте `85 in scores.values()`.

## Перебор словаря

```python
scores = {'Адам': 85, 'Амина': 92}

for name in scores:
    print(name)  # ключи

for score in scores.values():
    print(score)  # значения

for name, score in scores.items():
    print(name, score)  # ключ и значение
```

Словарь сохраняет порядок добавления ключей. Если нужен вывод по алфавиту, перебирайте `sorted(scores)`.

## Подсчёт частот

Посчитаем, сколько раз встречается каждое число:

```python
numbers = [5, 2, 5, 3, 2, 5]
counts = {}

for x in numbers:
    counts[x] = counts.get(x, 0) + 1

print(counts)  # {5: 3, 2: 2, 3: 1}
```

Для нового числа берём 0 и прибавляем 1. Для уже встречавшегося — увеличиваем накопленный счётчик. Тот же приём работает для символов строки и слов.

## Удаление

```python
scores = {'Адам': 85, 'Амина': 92}
del scores['Адам']
score = scores.pop('Амина')
print(score)  # 92
print(scores)  # {}
```

`del` удаляет пару, а `pop()` ещё и возвращает её значение. Если ключ может отсутствовать, используйте проверку `in` или `scores.pop('Муса', 0)`.

## Частые ошибки

- обращаться к отсутствующему ключу через квадратные скобки;
- считать, что `in` ищет среди значений;
- забывать `.items()` при переборе пар;
- начинать подсчёт с `counts[x] += 1`, когда ключ ещё не создан;
- ожидать сохранения нескольких значений при повторной записи по одному ключу;
- добавлять или удалять ключи во время перебора самого словаря;
- считать, что `copy_scores = scores` создаёт копию: для словаря с числами используйте `scores.copy()`.

## Памятка

```python
counts = {}
counts[5] = counts.get(5, 0) + 1
print(5 in counts)
print(counts.get(7, 0))
for key, value in counts.items():
    print(key, value)
```
