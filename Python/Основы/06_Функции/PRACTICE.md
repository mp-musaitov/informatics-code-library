# Практика: 06 Функции

[← К теории](README.md)

Используйте функции и конструкции тем 01–05. В заданиях 1–9 реализуйте указанную функцию и проверьте её вызовами с разными аргументами; ввод с клавиатуры не требуется. Кроме задания 3, функции возвращают результат и ничего не печатают.

Задания независимы друг от друга. Если указан ввод, напишите отдельную программу; все входные данные соответствуют условию. Не выводите приглашения к вводу и поясняющие подписи. Пустая строка во входе — отдельная строка, на которой нет символов.

## Разминка

### 1. Сумма двух чисел

Напишите функцию `add(a, b)`, которая возвращает сумму двух целых чисел.

### 2. Проверка знака

Напишите функцию `is_positive(x)`, возвращающую `True` для положительного целого числа и `False` для остальных.

### 3. Приветствие по умолчанию

Напишите функцию `greet(name='Гость')`, которая печатает `Привет,` и имя через пробел. Вызов без аргументов должен печатать `Привет, Гость`. Возвращать текст не требуется.

## Основной уровень

### 4. Количество чётных

Напишите функцию `count_even(numbers)`, возвращающую количество чётных целых чисел в списке. Пустому списку соответствует 0; ноль считается чётным.

### 5. Ограничение значения

Напишите функцию `clamp(x, low, high)` для целых аргументов, где `low <= high`. Она возвращает `low`, если `x < low`, `high`, если `x > high`, иначе `x`. Проверьте также вызов с именованными аргументами в другом порядке.

### 6. Слово наоборот

Напишите функцию `is_palindrome(word)`, возвращающую `True`, если строка совпадает со своим разворотом, иначе `False`. Учитывайте регистр и все символы. Для пустой строки верните `True`.

### 7. Прибавить без изменения

Напишите функцию `add_to_each(numbers, delta=1)`, возвращающую новый список, где к каждому целому числу прибавлено `delta`. Исходный список не меняйте. Для пустого списка верните `[]`.

## Повышенный уровень

### 8. Одна функция вызывает другую

Напишите `is_long(word, limit)`, возвращающую результат проверки `len(word) >= limit`, и `count_long(words, limit=5)`, считающую такие слова через вызовы `is_long`. `limit` — неотрицательное целое. Для пустого списка результат 0.

### 9. Первый положительный индекс

Напишите функцию `first_positive_index(numbers)`, возвращающую индекс первого положительного целого числа в списке или −1, если его нет. Индексы начинаются с нуля. Завершайте функцию через `return` сразу после находки.

## Мини-задача в стиле ЕГЭ/ОГЭ

Учебная задача по мотивам экзаменационных форматов, не официальный вариант.

### 10. функция отбора

Напишите функцию `suitable(x)`, которая возвращает `True`, если целое число делится на 3 и больше 10. В программе введите `n` от 1 до 100 и затем `n` целых чисел, по одному в строке. Используя функцию, выведите количество подходящих чисел.
