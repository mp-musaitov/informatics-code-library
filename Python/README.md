# Python

Раздел с базовыми конструкциями Python, примерами и готовыми заготовками.

## Подразделы

- [`Basics`](Basics/) — базовый синтаксис и основные конструкции языка.
- [`Templates`](Templates/) — короткие шаблоны кода, которые удобно копировать и адаптировать.

## План пополнения `Basics`

- `input-output.py` — ввод и вывод данных;
- `conditions.py` — `if`, `elif`, `else`;
- `loops.py` — циклы `for` и `while`;
- `strings.py` — строки, индексы, срезы и методы;
- `lists.py` — списки и основные операции;
- `functions.py` — функции, параметры и `return`;
- `files.py` — чтение и запись файлов.
