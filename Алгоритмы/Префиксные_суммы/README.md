# Префиксные суммы

Префиксные суммы помогают быстро находить сумму элементов на любом отрезке последовательности.

Рассмотрим список:

```python
numbers = [8, 3, 12, 5, 17, 2]
```

Например, сумма элементов с индексами от `1` до `4` равна:

```text
3 + 12 + 5 + 17 = 37
```

Для одного запроса эту сумму легко найти обычным циклом. Но если запросов много, каждый раз заново перебирать один и тот же участок неудобно.

Префиксные суммы позволяют:

1. один раз обработать исходный список;
2. после этого находить сумму любого отрезка с помощью вычитания двух значений.

Тот же приём можно использовать не только для суммы чисел, но и для подсчёта элементов, удовлетворяющих условию.

---

## 1. Обычный подсчёт суммы на отрезке

Пусть границы отрезка заданы индексами Python: `left` и `right`. Обе границы входят в отрезок.

```python
numbers = [8, 3, 12, 5, 17, 2]

left = 1
right = 4

segment_sum = 0

for i in range(left, right + 1):
    segment_sum += numbers[i]

print(segment_sum)
```

Результат:

```text
37
```

Этот способ прост и хорошо подходит для одного запроса.

Но для каждого нового отрезка цикл снова проходит по его элементам. Если список большой и запросов много, значительная часть работы повторяется.

---

## 2. Идея префиксной суммы

Создадим список `prefix`, в котором:

```text
prefix[k] = сумма первых k элементов
```

Важно: `prefix[k]` — это сумма именно первых `k` элементов, а не сумма до индекса `k` включительно.

Для списка:

```python
numbers = [8, 3, 12, 5, 17, 2]
```

получатся такие значения:

| `k` | Какие элементы сложены | `prefix[k]` |
|---:|---|---:|
| 0 | ни одного | 0 |
| 1 | 8 | 8 |
| 2 | 8, 3 | 11 |
| 3 | 8, 3, 12 | 23 |
| 4 | 8, 3, 12, 5 | 28 |
| 5 | 8, 3, 12, 5, 17 | 45 |
| 6 | 8, 3, 12, 5, 17, 2 | 47 |

В результате:

```python
prefix = [0, 8, 11, 23, 28, 45, 47]
```

Список `prefix` на один элемент длиннее исходного списка. Первым элементом специально записывается `0`.

---

## 3. Построение префиксных сумм

Универсальный шаблон:

```python
numbers = [8, 3, 12, 5, 17, 2]

prefix = [0]

for x in numbers:
    prefix.append(prefix[-1] + x)

print(prefix)
```

Результат:

```text
[0, 8, 11, 23, 28, 45, 47]
```

На каждом шаге:

- `prefix[-1]` — уже найденная сумма предыдущих элементов;
- `x` — очередной элемент;
- их сумма добавляется в конец списка `prefix`.

Исходный список обрабатывается только один раз.

---

## 4. Сумма отрезка при индексах Python

Пусть `left` и `right` — индексы элементов, причём обе границы входят в отрезок.

Формула:

```python
segment_sum = prefix[right + 1] - prefix[left]
```

Пример:

```python
numbers = [8, 3, 12, 5, 17, 2]

prefix = [0]

for x in numbers:
    prefix.append(prefix[-1] + x)

left = 1
right = 4

segment_sum = prefix[right + 1] - prefix[left]

print(segment_sum)
```

Результат:

```text
37
```

Почему формула работает:

- `prefix[right + 1]` содержит сумму элементов от начала списка до `right` включительно;
- `prefix[left]` содержит сумму элементов, расположенных перед `left`;
- после вычитания остаётся только нужный отрезок.

Для нашего примера:

```text
prefix[5] - prefix[1] = 45 - 8 = 37
```

---

## 5. Сумма отрезка при нумерации с единицы

В условиях задач позиции элементов часто нумеруются не с нуля, а с единицы.

Для той же последовательности:

| Позиция в условии | 1 | 2 | 3 | 4 | 5 | 6 |
|---:|---:|---:|---:|---:|---:|---:|
| Значение | 8 | 3 | 12 | 5 | 17 | 2 |

Если нужно найти сумму с позиции `left` до позиции `right` включительно, используется формула:

```python
segment_sum = prefix[right] - prefix[left - 1]
```

Пример для позиций от `2` до `5`:

```python
numbers = [8, 3, 12, 5, 17, 2]

prefix = [0]

for x in numbers:
    prefix.append(prefix[-1] + x)

left = 2
right = 5

segment_sum = prefix[right] - prefix[left - 1]

print(segment_sum)
```

Результат:

```text
37
```

Это тот же отрезок, который в индексах Python имеет границы от `1` до `4`.

Перед применением формулы обязательно определите, как пронумерованы элементы в условии.

---

## 6. Зачем нужен начальный ноль

Рассмотрим сумму элементов от индекса `0` до индекса `2`:

```text
8 + 3 + 12 = 23
```

По общей формуле:

```python
segment_sum = prefix[2 + 1] - prefix[0]
```

Получаем:

```text
23 - 0 = 23
```

Начальный ноль позволяет использовать одну и ту же формулу даже для отрезка, который начинается с первого элемента.

Без него пришлось бы отдельно проверять случай `left == 0`.

---

## 7. Несколько запросов

После построения префиксных сумм каждый запрос обрабатывается одной формулой.

```python
numbers = [8, 3, 12, 5, 17, 2]

prefix = [0]

for x in numbers:
    prefix.append(prefix[-1] + x)

queries = [
    [1, 4],
    [0, 2],
    [3, 5]
]

for left, right in queries:
    segment_sum = prefix[right + 1] - prefix[left]
    print(segment_sum)
```

Результат:

```text
37
23
24
```

Границы в этом примере являются индексами Python.

Префиксный список строится один раз, а затем используется для всех запросов.

---

## 8. Префиксный подсчёт элементов с условием

Префиксный подход можно использовать для подсчёта элементов, удовлетворяющих условию.

Например, найдём количество чётных чисел на отрезке.

```python
numbers = [8, 3, 12, 5, 17, 2]

prefix_even = [0]

for x in numbers:
    if x % 2 == 0:
        prefix_even.append(prefix_even[-1] + 1)
    else:
        prefix_even.append(prefix_even[-1])

print(prefix_even)
```

Результат:

```text
[0, 1, 1, 2, 2, 2, 3]
```

Теперь `prefix_even[k]` хранит количество чётных чисел среди первых `k` элементов.

Подсчитаем чётные числа на отрезке с индексами от `1` до `5`:

```python
left = 1
right = 5

even_count = prefix_even[right + 1] - prefix_even[left]

print(even_count)
```

Результат:

```text
2
```

На этом отрезке чётными являются `12` и `2`.

Таким же способом можно подсчитывать:

- положительные числа;
- отрицательные числа;
- числа, кратные заданному значению;
- элементы, удовлетворяющие любому другому условию.

Короткая форма построения:

```python
prefix_even = [0]

for x in numbers:
    prefix_even.append(prefix_even[-1] + (x % 2 == 0))
```

В Python значение `True` при сложении считается единицей, а `False` — нулём. Полный вариант с `if` обычно понятнее при первом знакомстве.

## 9. Среднее значение на отрезке

Среднее значение находится по формуле:

```text
сумма элементов / количество элементов
```

Для отрезка с индексами от `left` до `right` количество элементов равно:

```python
length = right - left + 1
```

Полный пример:

```python
numbers = [8, 3, 12, 5, 17, 2]

prefix = [0]

for x in numbers:
    prefix.append(prefix[-1] + x)

left = 1
right = 4

segment_sum = prefix[right + 1] - prefix[left]
length = right - left + 1

average = segment_sum / length

print(average)
```

Результат:

```text
9.25
```

Префиксные суммы быстро дают сумму отрезка, после чего остаётся разделить её на количество элементов.

## 10. Данные и запросы из файла

Пусть файл `data.txt` имеет такой формат:

```text
6
8 3 12 5 17 2
3
2 5
1 3
4 6
```

Здесь:

- первая строка — количество чисел;
- вторая строка — числа;
- третья строка — количество запросов;
- каждый запрос содержит левую и правую позиции, пронумерованные с единицы.

Решение:

```python
with open('data.txt') as f:
    n = int(f.readline())
    numbers = list(map(int, f.readline().split()))
    q = int(f.readline())

    prefix = [0]

    for x in numbers:
        prefix.append(prefix[-1] + x)

    for _ in range(q):
        left, right = map(int, f.readline().split())

        segment_sum = prefix[right] - prefix[left - 1]

        print(segment_sum)
```

В конкретной задаче формат файла может отличаться. Перед написанием программы нужно определить:

- где записана последовательность;
- есть ли количество элементов;
- есть ли количество запросов;
- с нуля или с единицы нумеруются границы.

Переменная `n` в этом шаблоне показывает ожидаемое количество чисел. При необходимости можно дополнительно проверить, что `len(numbers) == n`.

## 11. Когда использовать префиксные суммы

Префиксные суммы особенно полезны, если:

- дана неизменяемая последовательность;
- нужно обработать много запросов;
- в каждом запросе требуется сумма или количество элементов на отрезке;
- повторный перебор одних и тех же участков занимает слишком много времени.

Если значения исходного списка изменяются, построенные префиксные суммы перестают соответствовать данным. После изменения последовательности их нужно построить заново.

Для одного небольшого запроса обычный цикл часто проще и понятнее.

## 12. Частые ошибки

### Ошибка 1. Забыть начальный ноль

Правильно:

```python
prefix = [0]
```

Благодаря этому `prefix[k]` означает сумму первых `k` элементов и общая формула работает для отрезка с самого начала списка.

### Ошибка 2. Перепутать индексы и позиции

Для индексов Python:

```python
prefix[right + 1] - prefix[left]
```

Для позиций с единицы:

```python
prefix[right] - prefix[left - 1]
```

Сначала определите способ нумерации в условии.

### Ошибка 3. Забыть, что правая граница входит в отрезок

В обычном цикле требуется:

```python
for i in range(left, right + 1):
    ...
```

В префиксной формуле для индексов Python также появляется `right + 1`.

### Ошибка 4. Построить префиксы заново для каждого запроса

Префиксный список нужно построить один раз до обработки запросов.

Неправильно:

```python
for left, right in queries:
    prefix = [0]

    for x in numbers:
        prefix.append(prefix[-1] + x)
```

Правильно:

```python
prefix = [0]

for x in numbers:
    prefix.append(prefix[-1] + x)

for left, right in queries:
    segment_sum = prefix[right + 1] - prefix[left]
```

### Ошибка 5. Использовать старые префиксы после изменения списка

Если элемент исходного списка изменился, значения в `prefix` нужно пересчитать.

---

## Краткая памятка

```python
# Построение префиксных сумм
prefix = [0]

for x in numbers:
    prefix.append(prefix[-1] + x)


# Границы — индексы Python
segment_sum = prefix[right + 1] - prefix[left]


# Границы — позиции с единицы
segment_sum = prefix[right] - prefix[left - 1]


# Количество элементов на отрезке
length = right - left + 1


# Среднее значение на отрезке
average = segment_sum / length
```

Главное:

- `prefix[k]` хранит сумму первых `k` элементов;
- начальный ноль делает формулы одинаковыми для всех отрезков;
- префиксный список строится один раз;
- один запрос обрабатывается вычитанием двух значений;
- формула зависит от того, с нуля или с единицы нумеруются границы;
- вместо суммы можно накапливать количество элементов, удовлетворяющих условию.
