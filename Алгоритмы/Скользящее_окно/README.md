# Скользящее окно

Скользящее окно — это непрерывный участок списка или строки, ограниченный левой и правой границами.

Метод полезен, когда нужно рассмотреть много соседних отрезков:

- найти наибольшую сумму среди всех отрезков длины `k`;
- вычислить среднее значение в каждом таком отрезке;
- подсчитать подходящие элементы внутри окна;
- найти самый длинный или самый короткий отрезок с заданным свойством.

Главная идея: при сдвиге окна не пересчитывать всё заново. Мы удаляем из результата элемент, который вышел слева, и добавляем элемент, который вошёл справа.

---

## 1. Полный перебор окон фиксированного размера

Найдём максимальную сумму трёх соседних элементов.

```python
numbers = [4, 2, 7, 1, 3, 6, 2]
k = 3

maximum = None

for left in range(len(numbers) - k + 1):
    window_sum = 0

    for i in range(left, left + k):
        window_sum += numbers[i]

    if maximum is None or window_sum > maximum:
        maximum = window_sum

print(maximum)
```

Результат:

```text
13
```

Возможные окна:

| Границы | Элементы | Сумма |
|---|---|---:|
| 0–2 | 4, 2, 7 | 13 |
| 1–3 | 2, 7, 1 | 10 |
| 2–4 | 7, 1, 3 | 11 |
| 3–5 | 1, 3, 6 | 10 |
| 4–6 | 3, 6, 2 | 11 |

Способ работает, но каждое окно суммируется заново. Соседние окна отличаются только двумя элементами.

---

## 2. Первое окно

Сначала отдельно найдём сумму первых `k` элементов:

```python
numbers = [4, 2, 7, 1, 3, 6, 2]
k = 3

window_sum = sum(numbers[:k])

print(window_sum)
```

Результат:

```text
13
```

Это начальное состояние окна. Далее будем не создавать новые срезы, а изменять `window_sum`.

Перед работой должно выполняться условие:

```python
1 <= k <= len(numbers)
```

Иначе окно такого размера построить нельзя.

---

## 3. Сдвиг окна

При сдвиге вправо:

1. левый элемент выходит из окна;
2. новый правый элемент входит в окно.

```text
новая сумма = старая сумма − вышедший элемент + вошедший элемент
```

Если `right` — индекс нового правого элемента, то вышедший элемент имеет индекс `right - k`.

```python
for right in range(k, len(numbers)):
    window_sum -= numbers[right - k]
    window_sum += numbers[right]

    print(window_sum)
```

Для нашего списка будут получены суммы:

```text
10
11
10
11
```

Сумма первого окна уже была найдена до цикла.

---

## 4. Максимальная сумма фиксированного окна

Полный шаблон:

```python
numbers = [4, 2, 7, 1, 3, 6, 2]
k = 3

window_sum = sum(numbers[:k])
maximum = window_sum

for right in range(k, len(numbers)):
    window_sum -= numbers[right - k]
    window_sum += numbers[right]

    if window_sum > maximum:
        maximum = window_sum

print(maximum)
```

Каждый элемент добавляется в сумму один раз и удаляется из неё один раз. Повторно складывать все элементы окна не требуется.

Если нужен минимум, достаточно заменить сравнение:

```python
if window_sum < minimum:
    minimum = window_sum
```

## 5. Границы лучшего окна

Иногда нужно сохранить не только максимальную сумму, но и сам отрезок.

```python
numbers = [1, 4, 2, 7, 3, 6, 2]
k = 3

window_sum = sum(numbers[:k])
maximum = window_sum

best_left = 0

for right in range(k, len(numbers)):
    window_sum -= numbers[right - k]
    window_sum += numbers[right]

    if window_sum > maximum:
        maximum = window_sum
        best_left = right - k + 1

best_right = best_left + k - 1

print(maximum)
print(best_left, best_right)
print(numbers[best_left:best_right + 1])
```

Переменная `right` обозначает правую границу текущего окна. Поэтому его левая граница равна:

```python
right - k + 1
```

---

## 6. Среднее значение в каждом окне

Размер окна не меняется, поэтому среднее равно сумме окна, делённой на `k`.

```python
numbers = [4, 2, 7, 1, 3, 6, 2]
k = 3

window_sum = sum(numbers[:k])

print(window_sum / k)

for right in range(k, len(numbers)):
    window_sum -= numbers[right - k]
    window_sum += numbers[right]

    print(window_sum / k)
```

Так можно последовательно получить среднее для всех соседних отрезков одинаковой длины.

## 7. Количество подходящих элементов в окне

В окне можно поддерживать не только сумму. Найдём наибольшее количество чётных чисел среди всех отрезков длины `k`.

```python
numbers = [4, 3, 8, 6, 5, 2, 10]
k = 4

even_count = 0

for x in numbers[:k]:
    if x % 2 == 0:
        even_count += 1

maximum = even_count

for right in range(k, len(numbers)):
    left_value = numbers[right - k]
    right_value = numbers[right]

    if left_value % 2 == 0:
        even_count -= 1

    if right_value % 2 == 0:
        even_count += 1

    if even_count > maximum:
        maximum = even_count

print(maximum)
```

Когда чётное число выходит из окна, счётчик уменьшается. Когда чётное число входит, счётчик увеличивается.

По тому же принципу можно поддерживать количество положительных чисел, нулей или элементов с другим условием.

## 8. Окно изменяемого размера

Теперь размер окна заранее не задан.

Найдём самый длинный непрерывный отрезок, сумма которого не превышает `limit`.

Важно: этот шаблон рассчитан на неотрицательные числа и неотрицательное ограничение.

```python
numbers = [2, 1, 3, 2, 1, 1, 4]
limit = 7

left = 0
window_sum = 0

best_length = 0
best_left = 0
best_right = -1

for right in range(len(numbers)):
    window_sum += numbers[right]

    while window_sum > limit:
        window_sum -= numbers[left]
        left += 1

    length = right - left + 1

    if length > best_length:
        best_length = length
        best_left = left
        best_right = right

print(best_length)
print(numbers[best_left:best_right + 1])
```

Правая граница расширяет окно. Если сумма стала слишком большой, левая граница двигается вправо, пока условие снова не выполнится.

## 9. Самый короткий отрезок с необходимой суммой

Пусть нужно найти минимальную длину непрерывного отрезка с суммой не меньше `target`.

Здесь также предполагаются неотрицательные числа и положительное значение `target`.

```python
numbers = [2, 1, 5, 2, 3, 2]
target = 7

left = 0
window_sum = 0

best_length = None

for right in range(len(numbers)):
    window_sum += numbers[right]

    while window_sum >= target:
        length = right - left + 1

        if best_length is None or length < best_length:
            best_length = length

        window_sum -= numbers[left]
        left += 1

print(best_length)
```

Результат:

```text
2
```

Подходит, например, отрезок `[5, 2]`.

Цикл `while` продолжает сжимать окно, пока его сумма остаётся достаточной.

## 10. Работа с файлом

Пусть файл `data.txt` имеет формат:

```text
7 3
4 2 7 1 3 6 2
```

В первой строке записаны количество чисел и размер окна. Во второй — последовательность.

```python
with open('data.txt') as f:
    n, k = map(int, f.readline().split())
    numbers = list(map(int, f.readline().split()))

window_sum = sum(numbers[:k])
maximum = window_sum

for right in range(k, len(numbers)):
    window_sum -= numbers[right - k]
    window_sum += numbers[right]

    if window_sum > maximum:
        maximum = window_sum

print(maximum)
```

Переменная `n` хранит ожидаемое количество чисел. При необходимости можно проверить, что `len(numbers) == n`.

---

## 11. Ограничение для отрицательных чисел

В окне изменяемого размера мы используем рассуждение:

- добавление нового числа не уменьшает сумму;
- удаление левого числа не увеличивает сумму.

Это верно для неотрицательных чисел.

Если встречаются отрицательные значения, после расширения сумма может уменьшиться, а после удаления — увеличиться. Простое движение границ тогда может пропустить правильный ответ.

Окно фиксированного размера можно использовать и с отрицательными числами: из суммы всё равно точно удаляется один элемент и добавляется другой.

Ограничение относится именно к показанным шаблонам изменяемого окна.

---

## 12. Отличие от метода двух указателей

В обоих методах используются две позиции.

В задаче на пару два указателя обычно выбирают два отдельных элемента и движутся по отсортированному списку навстречу друг другу.

В скользящем окне указатели являются границами непрерывного отрезка. Вместе с ними поддерживается состояние всего окна:

- сумма;
- количество элементов;
- количество подходящих значений;
- другое накопленное свойство.

## 13. Частые ошибки

### Ошибка 1. Каждый раз пересчитывать окно

Неправильно:

```python
window_sum = sum(numbers[left:right + 1])
```

при каждом сдвиге.

Правильно обновлять прежний результат:

```python
window_sum -= numbers[right - k]
window_sum += numbers[right]
```

### Ошибка 2. Забыть обработать первое окно

Сумма первых `k` элементов вычисляется до цикла:

```python
window_sum = sum(numbers[:k])
maximum = window_sum
```

### Ошибка 3. Неверно найти вышедший элемент

При новом правом индексе `right` окно покидает элемент:

```python
numbers[right - k]
```

### Ошибка 4. Использовать недопустимый размер

Должно выполняться:

```python
1 <= k <= len(numbers)
```

### Ошибка 5. Без проверки применять изменяемое окно к отрицательным числам

Шаблоны с расширением и сжатием по сумме требуют неотрицательных элементов.

---

## Краткая памятка

```python
# Фиксированное окно
window_sum = sum(numbers[:k])
maximum = window_sum

for right in range(k, len(numbers)):
    window_sum -= numbers[right - k]
    window_sum += numbers[right]

    if window_sum > maximum:
        maximum = window_sum


# Изменяемое окно для неотрицательных чисел
left = 0
window_sum = 0

for right in range(len(numbers)):
    window_sum += numbers[right]

    while window_sum > limit:
        window_sum -= numbers[left]
        left += 1
```

Главное:

- окно всегда является непрерывным отрезком;
- первое окно обрабатывается отдельно;
- при сдвиге один элемент выходит, а другой входит;
- границы лучшего окна сохраняются вместе с лучшим результатом;
- изменяемое окно по сумме требует учитывать знак чисел;
- условия задачи определяют, когда окно нужно расширять и когда сжимать.
