# Поиск минимума и максимума

Поиск минимума и максимума — один из самых частых приёмов при обработке числовых данных.

Программа просматривает элементы по одному, сравнивает каждый элемент с лучшим найденным значением и при необходимости обновляет результат.

Главная идея:

```text
взять начальное значение
→ пройти по данным
→ сравнить текущий элемент с найденным экстремумом
→ при необходимости обновить результат
```

Минимум и максимум вместе называют **экстремальными значениями**.

---

## 1. Готовые функции `min()` и `max()`

Если у нас уже есть непустой список и дополнительных условий нет, проще всего использовать встроенные функции Python:

```python
numbers = [8, 3, 12, 5, 17, 2]

print(min(numbers))
print(max(numbers))
```

Результат:

```text
2
17
```

Такое решение правильно и удобно. Не нужно писать цикл вручную, если задача требует только найти минимум или максимум готового списка.

Но ручной поиск понадобится, если:

- учитывать нужно только элементы, удовлетворяющие условию;
- данные читаются из файла по одному;
- вместе со значением нужно сохранить связанный объект;
- нужно найти несколько наибольших или наименьших значений.

---

## 2. Поиск минимума за один проход

Рассмотрим список:

```python
numbers = [8, 3, 12, 5, 17, 2]
```

Сначала примем первый элемент за минимальный:

```python
minimum = numbers[0]
```

Затем сравним с ним каждый элемент списка:

```python
numbers = [8, 3, 12, 5, 17, 2]

minimum = numbers[0]

for x in numbers:
    if x < minimum:
        minimum = x

print(minimum)
```

Что происходит:

```text
minimum = 8
встретили 3  → 3 меньше 8  → minimum = 3
встретили 12 → 12 не меньше 3
встретили 5  → 5 не меньше 3
встретили 17 → 17 не меньше 3
встретили 2  → 2 меньше 3  → minimum = 2
```

Список просматривается один раз. Хранить все промежуточные результаты не нужно.

---

## 3. Поиск максимума за один проход

Для поиска максимума меняется только знак сравнения:

```python
numbers = [8, 3, 12, 5, 17, 2]

maximum = numbers[0]

for x in numbers:
    if x > maximum:
        maximum = x

print(maximum)
```

Теперь значение обновляется, когда встречается число **больше** найденного максимума.

Общий шаблон:

```python
extreme = numbers[0]

for x in numbers:
    if x лучше extreme:
        extreme = x
```

Для минимума «лучше» означает меньше, для максимума — больше.

---

## 4. Как выбрать начальное значение

От начального значения зависит правильность всего алгоритма.

### Первый элемент списка

```python
minimum = numbers[0]
```

Это удобный вариант, если:

- список уже существует;
- список точно не пустой;
- минимум ищется среди всех элементов.

Если список пуст, обращение к `numbers[0]` вызовет ошибку.

### Заведомо большое или маленькое число

Иногда пишут:

```python
minimum = 10 ** 10
maximum = -10 ** 10
```

Так можно делать, если диапазон входных данных точно известен.

Но `10 ** 10` — не бесконечность. Это обычное число `10000000000`. Если во входных данных встретится ещё большее число, неудачно выбранное начальное значение может привести к неправильному ответу.

### Значение `None`

Более безопасный вариант:

```python
minimum = None
```

`None` означает, что подходящее значение пока не найдено.

При обновлении проверяем два случая:

```python
if minimum is None or x < minimum:
    minimum = x
```

Если подходящее число встретилось впервые, оно сразу становится минимумом. Все следующие значения уже сравниваются с ним.

Краткое сравнение:

| Начальное значение | Когда удобно | Ограничение |
|---|---|---|
| `numbers[0]` | Есть непустой готовый список | Не подходит для пустого списка |
| `10 ** 10` | Диапазон значений точно известен | Это конкретное число, а не бесконечность |
| `None` | Диапазон неизвестен или есть условие | Нужна проверка `is None` |

## 5. Минимум или максимум с условием

Пусть нужно найти минимальное чётное число.

Нельзя просто использовать `numbers[0]`: первый элемент может не быть чётным. Поэтому начнём с `None`.

```python
numbers = [9, 7, 12, 5, 8, 21, 4]

minimum = None

for x in numbers:
    if x % 2 == 0:
        if minimum is None or x < minimum:
            minimum = x

print(minimum)
```

Сначала проверяется условие:

```python
if x % 2 == 0:
```

Только после этого число участвует в поиске минимума.

Аналогично можно найти максимальное число, делящееся на 7:

```python
maximum = None

for x in numbers:
    if x % 7 == 0:
        if maximum is None or x > maximum:
            maximum = x
```

Начинать максимум с нуля опасно:

```python
maximum = 0
```

Если все подходящие числа отрицательные, ноль так и останется ответом, хотя его может вообще не быть среди данных.

---

## 6. Если подходящих элементов нет

После цикла переменная может остаться равной `None`.

```python
numbers = [1, 3, 5, 7]

minimum = None

for x in numbers:
    if x % 2 == 0:
        if minimum is None or x < minimum:
            minimum = x

if minimum is None:
    print('Подходящих значений нет')
else:
    print(minimum)
```

В экзаменационной задаче условие иногда гарантирует, что подходящий элемент существует. Тогда достаточно вывести найденное значение. В общей программе отсутствие результата лучше обработать явно.

---

## 7. Одновременный поиск минимума и максимума

Оба значения можно найти за один проход:

```python
numbers = [8, 3, 12, 5, 17, 2]

minimum = numbers[0]
maximum = numbers[0]

for x in numbers:
    if x < minimum:
        minimum = x

    if x > maximum:
        maximum = x

print(minimum)
print(maximum)
```

Для каждого числа выполняются две независимые проверки.

---

## 8. Сохраняем не только значение, но и объект

Иногда нужно узнать не только максимальный результат, но и кому он принадлежит.

Например, найдём ученика с наибольшим баллом:

```python
students = [
    ['Али', 72],
    ['Марьям', 91],
    ['Умар', 84],
]

best_name = None
best_score = None

for name, score in students:
    if best_score is None or score > best_score:
        best_score = score
        best_name = name

print(best_name)
print(best_score)
```

При нахождении нового максимума одновременно обновляются две переменные:

```python
best_score = score
best_name = name
```

Если обновить только балл, информация об ученике потеряется.

Этот же приём подходит для товаров и цен, городов и температур, файлов и размеров, точек и расстояний.

---

## 9. Два наибольших значения

Иногда одного максимума недостаточно.

Найдём два наибольших элемента списка:

```python
numbers = [8, 3, 12, 5, 17, 12]

maximum1 = None
maximum2 = None

for x in numbers:
    if maximum1 is None or x > maximum1:
        maximum2 = maximum1
        maximum1 = x
    elif maximum2 is None or x > maximum2:
        maximum2 = x

print(maximum1)
print(maximum2)
```

Здесь одинаковые значения разрешены. Например, для списка `[9, 9, 8]` ответом будут `9` и `9`.

Если требуется второе **различное** максимальное значение, нужно дополнительно исключить повтор первого максимума:

```python
numbers = [9, 9, 8, 7]

maximum1 = None
maximum2 = None

for x in numbers:
    if maximum1 is None or x > maximum1:
        if x != maximum1:
            maximum2 = maximum1
        maximum1 = x
    elif x != maximum1 and (maximum2 is None or x > maximum2):
        maximum2 = x

print(maximum1)
print(maximum2)
```

Важно внимательно читать условие: «два наибольших элемента» и «два наибольших различных значения» — разные задачи.

## 10. Обработка данных из файла

Если в файле каждое число записано на отдельной строке, не обязательно сначала загружать все числа в список.

Найдём максимальное число, делящееся на 7:

```python
maximum = None

with open('data.txt') as f:
    for s in f:
        x = int(s)

        if x % 7 == 0:
            if maximum is None or x > maximum:
                maximum = x

print(maximum)
```

Программа читает и обрабатывает по одному числу. Это особенно удобно для больших файлов.

Схема остаётся прежней:

```text
прочитать очередное число
→ проверить условие
→ сравнить с найденным экстремумом
→ при необходимости обновить результат
```

---

## 11. Когда использовать `min()` и `max()`, а когда цикл

```text
готовый непустой список без дополнительных условий
→ min() или max()

минимум или максимум только среди подходящих элементов
→ цикл с условием

данные читаются по одному из файла
→ цикл

нужно сохранить связанный объект
→ цикл и несколько переменных

нужно найти несколько экстремальных значений
→ цикл с несколькими результатами
```

Не нужно отказываться от `min()` и `max()` без причины. Ручной алгоритм нужен тогда, когда задача сложнее обычного поиска одного значения в готовом списке.

---

## 12. Частые ошибки

1. Начинать максимум с `0`, когда все подходящие числа могут быть отрицательными.
2. Считать `10 ** 10` настоящей бесконечностью.
3. Использовать `numbers[0]`, не убедившись, что список не пуст.
4. Сравнивать значение с `None` без проверки `is None`.
5. Обновлять минимум или максимум до проверки основного условия.
6. При поиске связанного объекта обновлять значение, но забывать обновить сам объект.
7. Не учитывать случай, когда подходящих элементов нет.
8. Путать второй элемент по величине и второе различное значение.

---

## Главное

```text
1. Определи, среди каких элементов ищется экстремум.
2. Выбери безопасное начальное значение.
3. Просмотри данные один раз.
4. Сравнивай каждый подходящий элемент с текущим результатом.
5. При необходимости обновляй не только значение, но и связанный объект.
6. Проверь случай, когда подходящих элементов нет.
```

Поиск минимума и максимума за один проход — основа многих задач на обработку последовательностей и файлов.
