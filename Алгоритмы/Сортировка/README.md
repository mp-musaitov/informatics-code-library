# Сортировка

Сортировка — это расположение элементов в определённом порядке.

Чаще всего числа сортируют по возрастанию или убыванию, а строки — по алфавиту. Но сортировать можно и более сложные данные: например, учеников по баллам, товары по цене или результаты по нескольким условиям.

Сортировка полезна, когда нужно:

- вывести данные в нужном порядке;
- быстро найти несколько наибольших или наименьших элементов;
- расположить записи по выбранному полю;
- упростить дальнейшую обработку данных.

В большинстве задач на Python достаточно готовых средств `sorted()` и `.sort()`. Ручной алгоритм сортировки полезно понимать, но обычно писать его самостоятельно не требуется.

---

## 1. Функция `sorted()`: получаем новый список

Функция `sorted()` возвращает новый отсортированный список. Исходные данные при этом не изменяются.

```python
numbers = [8, 3, 12, 5, 17, 2]

sorted_numbers = sorted(numbers)

print(sorted_numbers)
print(numbers)
```

Результат:

```text
[2, 3, 5, 8, 12, 17]
[8, 3, 12, 5, 17, 2]
```

Это удобно, если исходный порядок ещё понадобится.

Можно сразу вывести отсортированные данные:

```python
print(sorted(numbers))
```

---

## 2. Метод `.sort()`: изменяем сам список

Метод `.sort()` сортирует список на месте, то есть изменяет его.

```python
numbers = [8, 3, 12, 5, 17, 2]

numbers.sort()

print(numbers)
```

Результат:

```text
[2, 3, 5, 8, 12, 17]
```

После выполнения `numbers.sort()` первоначальный порядок элементов потерян.

Важно: метод `.sort()` ничего не возвращает. Поэтому так писать нельзя:

```python
numbers = numbers.sort()
```

После этой строки в переменной `numbers` окажется `None`.

Правильные варианты:

```python
numbers.sort()
```

или:

```python
numbers = sorted(numbers)
```

---

## 3. Сортировка по убыванию

По умолчанию элементы располагаются по возрастанию. Для обратного порядка используется параметр `reverse=True`.

```python
numbers = [8, 3, 12, 5, 17, 2]

print(sorted(numbers, reverse=True))
```

Результат:

```text
[17, 12, 8, 5, 3, 2]
```

С методом `.sort()` параметр работает так же:

```python
numbers.sort(reverse=True)
```

---

## 4. Сортировка строк

Строки тоже можно сортировать.

```python
words = ['груша', 'яблоко', 'апельсин', 'банан']

words.sort()

print(words)
```

Python сравнивает строки посимвольно.

Регистр букв влияет на порядок. Если в списке встречаются и заглавные, и строчные буквы, для сортировки без учёта регистра можно использовать `key=str.lower`.

```python
words = ['груша', 'Яблоко', 'апельсин', 'Банан']

words.sort(key=str.lower)

print(words)
```

Параметр `key` сообщает, какое значение использовать при сравнении. Сами строки при этом не изменяются.

---

## 5. Сортировка пар и записей

Данные часто хранятся в виде пар:

```python
students = [
    ['Вера', 78],
    ['Антон', 91],
    ['Борис', 84]
]
```

Если вызвать обычную сортировку, Python сначала сравнит первые элементы пар. Если они равны, будут сравниваться вторые.

```python
students.sort()

print(students)
```

Результат:

```text
[['Антон', 91], ['Борис', 84], ['Вера', 78]]
```

Такой порядок называют сортировкой по порядку полей: сначала по первому полю, затем по второму.

---

## 6. Сортировка по выбранному полю

Чтобы отсортировать учеников по баллам, нужно указать ключ сортировки.

Сначала рассмотрим вариант с обычной функцией:

```python
students = [
    ['Вера', 78],
    ['Антон', 91],
    ['Борис', 84]
]

def get_score(student):
    return student[1]

students.sort(key=get_score, reverse=True)

print(students)
```

Функция `get_score()` получает одну запись и возвращает её балл. Именно эти значения Python сравнивает при сортировке.

Короткий вариант с `lambda`:

```python
students.sort(key=lambda student: student[1], reverse=True)
```

Оба варианта делают одно и то же. Обычная функция часто понятнее при первом знакомстве, а `lambda` удобна для короткого простого правила.

---

## 7. Несколько условий сортировки

Иногда нужно учитывать сразу несколько условий.

Например:

1. сначала расположить учеников по убыванию баллов;
2. при равных баллах — по имени в алфавитном порядке.

```python
students = [
    ['Вера', 84],
    ['Антон', 91],
    ['Борис', 84],
    ['Галина', 91]
]

def sort_key(student):
    score = student[1]
    name = student[0]
    return -score, name

students.sort(key=sort_key)

print(students)
```

Результат:

```text
[['Антон', 91], ['Галина', 91], ['Борис', 84], ['Вера', 84]]
```

Ключ `(-score, name)` состоит из двух частей:

- отрицательный балл ставит большие баллы раньше;
- имя располагает учеников с одинаковыми баллами по алфавиту.

В короткой записи:

```python
students.sort(key=lambda student: (-student[1], student[0]))
```

## 8. Поиск нескольких лучших элементов

После сортировки легко взять несколько наибольших или наименьших элементов.

Найдём три наибольших числа:

```python
numbers = [8, 3, 12, 5, 17, 2, 10]

numbers.sort(reverse=True)

top_3 = numbers[:3]

print(top_3)
```

Результат:

```text
[17, 12, 10]
```

Если нужны три наименьших числа:

```python
numbers.sort()

bottom_3 = numbers[:3]
```

Такой способ удобен, когда по условию нужно вывести несколько лучших результатов.

## 9. Сортировка данных из файла

Предположим, что в каждой строке файла `data.txt` записано одно число.

```text
8
3
12
5
17
2
```

Прочитаем все числа и отсортируем их:

```python
numbers = []

with open('data.txt') as f:
    for s in f:
        numbers.append(int(s))

numbers.sort()

print(numbers)
```

Если первая строка содержит количество чисел, её нужно прочитать отдельно:

```python
with open('data.txt') as f:
    n = int(f.readline())
    numbers = [int(f.readline()) for _ in range(n)]

numbers.sort()
```

В конкретной задаче всегда сначала проверьте формат файла.

## 10. Ручная сортировка: метод пузырька

Полезно понимать, как сортировка может быть устроена внутри.

В методе пузырька соседние элементы сравниваются. Если левый элемент больше правого, они меняются местами.

```python
numbers = [8, 3, 12, 5, 17, 2]

n = len(numbers)

for i in range(n - 1):
    for j in range(n - 1 - i):
        if numbers[j] > numbers[j + 1]:
            numbers[j], numbers[j + 1] = numbers[j + 1], numbers[j]

print(numbers)
```

После каждого внешнего прохода один из наибольших оставшихся элементов перемещается в конец списка. Поэтому внутренний цикл с каждым разом становится короче.

Метод пузырька понятен и подходит для изучения принципа сортировки, но работает медленно на больших списках. В обычных задачах Python следует использовать `sorted()` или `.sort()`.

## 11. Частые ошибки

### Ошибка 1. Присвоить результат `.sort()`

Неправильно:

```python
numbers = numbers.sort()
```

Правильно:

```python
numbers.sort()
```

или:

```python
numbers = sorted(numbers)
```

### Ошибка 2. Потерять исходный порядок

Если исходный список ещё нужен, используйте `sorted()`:

```python
sorted_numbers = sorted(numbers)
```

### Ошибка 3. Забыть `reverse=True`

Для порядка по убыванию:

```python
numbers.sort(reverse=True)
```

### Ошибка 4. Выбрать не то поле

Для записи `['Антон', 91]`:

- `student[0]` — имя;
- `student[1]` — балл.

Поэтому для сортировки по баллам нужен ключ `student[1]`.

### Ошибка 5. Не учесть равные значения

Если основное поле может совпадать, заранее решите, какое дополнительное правило должно определить порядок.

## Краткая памятка

```python
# Новый отсортированный список
result = sorted(numbers)

# Изменение исходного списка
numbers.sort()

# По убыванию
numbers.sort(reverse=True)

# По выбранному полю
records.sort(key=lambda record: record[1])

# По нескольким условиям:
# число — по убыванию, строка — по возрастанию
records.sort(key=lambda record: (-record[1], record[0]))

# Три наибольших элемента
top_3 = sorted(numbers, reverse=True)[:3]
```

Главное:

- `sorted()` создаёт новый список;
- `.sort()` изменяет существующий список;
- `reverse=True` задаёт обратный порядок;
- `key` задаёт правило сравнения элементов;
- для обычных задач используйте готовую сортировку Python.
