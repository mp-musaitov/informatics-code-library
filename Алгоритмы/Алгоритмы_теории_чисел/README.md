# Алгоритмы теории чисел

Алгоритмы теории чисел помогают работать с делимостью, делителями, простыми числами, наибольшим общим делителем и другими свойствами целых чисел.

Во многих школьных задачах достаточно обычного перебора. Но если число большое или проверок много, перебор всех значений становится слишком медленным. Тогда используются специальные алгоритмы.

В примерах ниже рассматриваются целые положительные числа, если отдельно не указано иное.

---

## 1. Делимость и остаток от деления

Оператор `%` вычисляет остаток от деления:

```python
n = 42

print(n % 5)
```

Результат:

```text
2
```

Число `n` делится на `d` без остатка, если:

```python
n % d == 0
```

Например:

```python
n = 42
d = 7

if n % d == 0:
    print('Делится')
else:
    print('Не делится')
```

С помощью остатка можно проверять и другие свойства:

```python
n = 47

print(n % 2 == 0)   # является ли число чётным
print(n % 10)       # последняя цифра
print(n % 7 == 3)   # остаток 3 при делении на 7
```

Важно: деление на ноль невозможно. Выражение `n % 0` вызовет ошибку.

---

## 2. Поиск всех делителей простым перебором

Делитель числа `n` — это положительное число, на которое `n` делится без остатка.

Самый понятный способ — проверить все числа от `1` до `n`:

```python
n = 36
divisors = []

for d in range(1, n + 1):
    if n % d == 0:
        divisors.append(d)

print(divisors)
```

Результат:

```text
[1, 2, 3, 4, 6, 9, 12, 18, 36]
```

Такой способ прост, но для большого `n` выполняет много лишних проверок.

---

## 3. Поиск делителей до квадратного корня

Делители образуют пары. Если `d` делит число `n`, то вторым делителем является `n // d`.

Для числа `36` получаются пары:

```text
1 и 36
2 и 18
3 и 12
4 и 9
6 и 6
```

Поэтому достаточно проверять значения, пока выполняется условие:

```python
d * d <= n
```

```python
n = 36
divisors = []

d = 1

while d * d <= n:
    if n % d == 0:
        divisors.append(d)

        second = n // d

        if second != d:
            divisors.append(second)

    d += 1

divisors.sort()
print(divisors)
```

Проверка `second != d` нужна для полного квадрата. У числа `36` делитель `6` не должен добавляться дважды.

Сортировка выполняется потому, что делители из пар добавляются не по возрастанию.

## 4. Количество и сумма делителей

Если сами делители не нужны, их можно не сохранять в список.

```python
n = 36
count = 0
total = 0

d = 1

while d * d <= n:
    if n % d == 0:
        second = n // d

        if d == second:
            count += 1
            total += d
        else:
            count += 2
            total += d + second

    d += 1

print(count)
print(total)
```

Для каждой пары добавляются два делителя. Если `d * d == n`, найден только один новый делитель.

## 5. Проверка числа на простоту

Простое число имеет ровно два положительных делителя: `1` и само число.

Числа `0` и `1` не являются простыми.

```python
n = 37

is_prime = n >= 2
d = 2

while d * d <= n and is_prime:
    if n % d == 0:
        is_prime = False

    d += 1

print(is_prime)
```

Если у составного числа есть делитель больше квадратного корня, у него обязательно есть и парный делитель меньше квадратного корня. Поэтому проверять значения дальше не нужно.

Удобно оформить алгоритм как функцию:

```python
def is_prime(n):
    if n < 2:
        return False

    d = 2

    while d * d <= n:
        if n % d == 0:
            return False

        d += 1

    return True


print(is_prime(37))
print(is_prime(42))
```

## 6. Разложение на простые множители

Будем последовательно делить число на наименьший подходящий делитель.

```python
n = 756
original = n
factors = []

d = 2

while d * d <= n:
    while n % d == 0:
        factors.append(d)
        n //= d

    d += 1

if n > 1:
    factors.append(n)

print(original, factors)
```

Результат:

```text
756 [2, 2, 3, 3, 3, 7]
```

Внутренний цикл `while` нужен, потому что один простой множитель может встречаться несколько раз.

Во время работы значение `n` изменяется. Если исходное число потребуется позже, его нужно заранее сохранить в другой переменной.

После цикла может остаться простой множитель больше квадратного корня. Его добавляет проверка:

```python
if n > 1:
    factors.append(n)
```

## 7. Наибольший общий делитель

Наибольший общий делитель, или НОД, — самое большое положительное число, на которое делятся оба числа.

Алгоритм Евклида заменяет пару чисел `a` и `b` на `b` и остаток `a % b`:

```python
a = 84
b = 30

while b != 0:
    a, b = b, a % b

print(a)
```

Результат:

```text
6
```

Когда второе число становится равным нулю, в первом находится НОД.

Готовая функция есть в модуле `math`:

```python
from math import gcd

print(gcd(84, 30))
```

`gcd()` удобно использовать в обычной задаче, а ручной алгоритм полезно понимать и уметь воспроизводить.

---

## 8. Наименьшее общее кратное

Наименьшее общее кратное, или НОК, — наименьшее положительное число, которое делится на оба исходных числа.

Для ненулевых чисел:

```text
НОК(a, b) = |a · b| / НОД(a, b)
```

```python
from math import gcd

a = 12
b = 18

if a == 0 or b == 0:
    lcm_value = 0
else:
    lcm_value = abs(a * b) // gcd(a, b)

print(lcm_value)
```

В современных версиях Python можно использовать готовую функцию:

```python
from math import lcm

print(lcm(12, 18))
```

Не нужно искать НОК перебором кратных, если его можно вычислить через НОД.

## 9. Решето Эратосфена

Если нужно проверить одно число, подходит функция `is_prime()`.

Если нужны все простые числа до заданной границы, выгоднее один раз построить решето Эратосфена.

```python
limit = 50

prime = [True] * (limit + 1)
prime[0] = False
prime[1] = False

for p in range(2, int(limit ** 0.5) + 1):
    if prime[p]:
        for multiple in range(p * p, limit + 1, p):
            prime[multiple] = False

primes = []

for number in range(2, limit + 1):
    if prime[number]:
        primes.append(number)

print(primes)
```

Для каждого найденного простого числа вычёркиваются его кратные.

Начинать можно с `p * p`: меньшие кратные уже были вычеркнуты при обработке предыдущих простых чисел.

После построения решета проверка числа выполняется быстро:

```python
print(prime[47])
```

Индекс должен находиться в пределах от `0` до `limit`.

## 10. Как выбрать алгоритм

| Задача | Подход |
|---|---|
| Проверить делимость | `n % d == 0` |
| Найти делители небольшого числа | обычный перебор от `1` до `n` |
| Найти делители большого числа | перебор до `√n` парами |
| Проверить одно число на простоту | перебор делителей до `√n` |
| Разложить число на множители | последовательное деление |
| Найти НОД | алгоритм Евклида или `math.gcd()` |
| Найти НОК | формула через НОД или `math.lcm()` |
| Найти все простые числа до границы | решето Эратосфена |

Выбор зависит не только от вида задачи, но и от размера данных и количества повторных проверок.

## 11. Частые ошибки

### Ошибка 1. Считать единицу простым числом

Простые числа начинаются с `2`.

```python
def is_prime(n):
    if n < 2:
        return False
```

### Ошибка 2. Проверять деление на ноль

Ноль не может быть делителем. Перебор делителей начинается с `1`, а проверка простоты — с `2`.

### Ошибка 3. Потерять второй делитель пары

Если найден `d`, второй делитель равен:

```python
n // d
```

### Ошибка 4. Дважды добавить квадратный корень

Для полного квадрата два делителя пары совпадают:

```python
if second != d:
    divisors.append(second)
```

### Ошибка 5. Неверно задать границу цикла

Квадратный корень тоже нужно проверить:

```python
while d * d <= n:
    ...
```

### Ошибка 6. Потерять последний простой множитель

После основного цикла нужна проверка:

```python
if n > 1:
    factors.append(n)
```

### Ошибка 7. Забыть, что факторизация изменяет число

Если исходное значение ещё понадобится, сохраните его:

```python
original = n
```

## Краткая памятка

```python
# Делимость
if n % d == 0:
    print('d — делитель n')

# Проверка до квадратного корня
d = 1

while d * d <= n:
    if n % d == 0:
        second = n // d

    d += 1
```

Главное:

- остаток `0` означает делимость;
- делители удобно искать парами;
- при переборе до квадратного корня используется `<=`;
- `0` и `1` не являются простыми числами;
- полный квадрат требует защиты от двойного добавления корня;
- для многих проверок простоты до одной границы используется решето Эратосфена.
