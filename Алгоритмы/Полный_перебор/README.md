# Полный перебор

Полный перебор — это алгоритмический приём, при котором программа рассматривает **все возможные варианты**, проверяет каждый из них и выбирает подходящие.

Это один из самых простых и полезных алгоритмических приёмов в школьных задачах.

Главная идея:

```text
сгенерировать вариант → проверить условие → сохранить результат
```

Если вариантов немного, полный перебор часто оказывается самым простым и надёжным способом решения.

---

## 1. Простейший перебор

Пусть нужно найти все числа от 1 до 100, которые делятся на 7.

```python
for x in range(1, 101):
    if x % 7 == 0:
        print(x)
```

Здесь программа последовательно рассматривает все возможные значения `x`:

```text
1, 2, 3, ..., 100
```

и для каждого проверяет условие.

Общий шаблон:

```python
for x in варианты:
    if условие:
        действие
```

---

## 2. Поиск количества подходящих вариантов

Иногда сами варианты выводить не нужно. Нужно только узнать их количество.

Например, посчитаем числа от 1 до 1000, которые делятся на 7 и не делятся на 5.

```python
count = 0

for x in range(1, 1001):
    if x % 7 == 0 and x % 5 != 0:
        count += 1

print(count)
```

Общий шаблон:

```python
count = 0

for x in варианты:
    if условие:
        count += 1

print(count)
```

---

## 3. Поиск первого подходящего значения

Если нужно найти **минимальное** значение и перебор идёт по возрастанию, можно остановиться сразу после первого подходящего варианта.

Например:

```python
for x in range(1, 1000):
    if x % 17 == 0 and x > 100:
        print(x)
        break
```

После выполнения `break` цикл прекращается.

Это важная оптимизация:

```text
нашли ответ → дальше перебирать не нужно
```

---

## 4. Перебор нескольких объектов

Иногда одного цикла недостаточно.

Пусть нужно найти все пары чисел `a` и `b` от 1 до 10, для которых:

```text
a + b = 12
```

Можно использовать два вложенных цикла:

```python
for a in range(1, 11):
    for b in range(1, 11):
        if a + b == 12:
            print(a, b)
```

Программа проверит:

```text
(1, 1)
(1, 2)
...
(1, 10)
(2, 1)
...
(10, 10)
```

Общий шаблон:

```python
for a in варианты_a:
    for b in варианты_b:
        if условие:
            действие
```

Для трёх объектов можно использовать три вложенных цикла:

```python
for a in варианты_a:
    for b in варианты_b:
        for c in варианты_c:
            if условие:
                действие
```

Но с каждым новым циклом количество проверяемых комбинаций быстро увеличивается.

---

## 5. Поиск лучшего варианта

Полный перебор особенно удобен, когда нужно найти минимум или максимум среди всех допустимых вариантов.

Например, найдём пару положительных целых чисел с суммой 20, у которой произведение максимально.

```python
best = None
best_pair = None

for a in range(1, 20):
    for b in range(1, 20):
        if a + b == 20:
            value = a * b

            if best is None or value > best:
                best = value
                best_pair = (a, b)

print(best_pair)
print(best)
```

Здесь программа:

```text
перебирает все пары
→ оставляет только допустимые
→ вычисляет характеристику
→ запоминает лучший вариант
```

Универсальный шаблон:

```python
best = None

for вариант in варианты:
    if допустим(вариант):
        value = характеристика(вариант)

        if best is None or value < best:
            best = value
```

Для поиска максимума:

```python
if best is None or value > best:
    best = value
```

---

## 6. Как уменьшить перебор

Полный перебор не означает, что нужно бездумно проверять всё подряд.

Если заранее известно, что часть вариантов не подходит, их лучше сразу отбросить.

Вместо:

```python
for a in range(1, 100):
    for b in range(1, 100):
        if a < b and условие:
            ...
```

можно написать:

```python
for a in range(1, 100):
    for b in range(a + 1, 100):
        if условие:
            ...
```

Теперь варианты, где `b <= a`, вообще не рассматриваются.

Это уменьшает количество проверок.

---

## 7. Раннее отсечение

При сложном переборе иногда можно понять, что текущий вариант уже не сможет привести к ответу.

Тогда используется `continue`.

```python
for a in варианты_a:
    if не_подходит(a):
        continue

    for b in варианты_b:
        if условие(a, b):
            ...
```

После `continue` программа сразу переходит к следующему значению `a`.

Такой подход особенно полезен при вложенных циклах.

## 8. Пример: условие Фано

Рассмотрим более сложный пример.

Известны кодовые слова:

```text
Н → 0
К → 10
```

Нужно подобрать ещё два кодовых слова так, чтобы выполнялось условие Фано, а суммарная длина всех кодовых слов была минимальной.

Жадный подход:

```text
нашли первый подходящий код → взяли его
```

не гарантирует, что после добавления второго кода получится лучший результат.

Поэтому переберём **все допустимые пары**.

```python
def fano(codes):
    for a in codes:
        for b in codes:
            if a != b and b.startswith(a):
                return False
    return True


codes = ['0', '10']
MAX_LENGTH = 5

best_sum = 10 ** 9
best_codes = None

for length1 in range(1, MAX_LENGTH + 1):
    for n1 in range(2 ** length1):
        code1 = bin(n1)[2:].zfill(length1)

        if code1 in codes:
            continue

        if not fano(codes + [code1]):
            continue

        for length2 in range(length1, MAX_LENGTH + 1):
            for n2 in range(2 ** length2):
                code2 = bin(n2)[2:].zfill(length2)

                if code2 in codes or code2 == code1:
                    continue

                if fano(codes + [code1, code2]):
                    total = sum(map(len, codes)) + length1 + length2

                    if total < best_sum:
                        best_sum = total
                        best_codes = [code1, code2]

print(best_codes)
print(best_sum)
```

Один из оптимальных наборов:

```text
Н → 0
К → 10
Л → 110
М → 111
```

Суммарная длина:

```text
1 + 2 + 3 + 3 = 9
```

---

## 9. Почему `length2` начинается с `length1`

Если два новых кодовых слова равноправны, нет смысла проверять одну и ту же пару дважды.

Например:

```text
110 и 111
```

и

```text
111 и 110
```

для нашей задачи представляют один и тот же набор кодовых слов.

Поэтому используется:

```python
for length2 in range(length1, MAX_LENGTH + 1):
```

Так мы исключаем часть повторяющихся вариантов.

## 10. Полный перебор и жадный алгоритм

Полный перебор:

```text
проверить все допустимые варианты
→ сравнить результаты
→ выбрать лучший
```

Жадный алгоритм:

```text
сделать лучший выбор прямо сейчас
→ зафиксировать его
→ продолжить
```

Жадный алгоритм обычно быстрее, но подходит только тогда, когда можно обосновать правильность такого выбора.

Если вариантов немного и есть сомнения, полный перебор часто проще и надёжнее.

---

## Когда использовать полный перебор

Полный перебор подходит, если:

- количество вариантов достаточно небольшое;
- нужно найти все решения;
- нужно посчитать количество решений;
- нужно найти минимальный или максимальный допустимый вариант;
- варианты влияют друг на друга;
- нет более простого способа сразу получить ответ.

Главный вопрос перед использованием:

```text
Сколько вариантов программе придётся проверить?
```

Если вариантов тысячи или миллионы, Python часто легко справится с перебором.

Если количество комбинаций становится огромным, нужно искать способ сократить перебор или использовать другой алгоритм.

---

## Главное

```text
1. Определи, что именно перебираем.
2. Определи границы перебора.
3. Проверь условие.
4. Сохрани или выведи подходящий результат.
5. Если ищешь лучший вариант — сравнивай результаты.
6. Не перебирай то, что можно заранее исключить.
```

Полный перебор — не «плохой» алгоритм сам по себе.

Если количество вариантов небольшое, простой перебор часто лучше сложного решения.
