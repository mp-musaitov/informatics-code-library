# Алгоритмы

Общие алгоритмы и типовые приёмы, которые не привязаны к конкретному номеру ЕГЭ или ОГЭ.

Раздел предназначен не для изучения алгоритмов ради самих алгоритмов, а для освоения практических приёмов, которые помогают решать школьные задачи по программированию, ЕГЭ и ОГЭ.

## Как пользоваться разделом

Если нужен короткий готовый фрагмент кода, сначала проверьте [шаблоны Python](../Python/Шаблоны/). Здесь материалы подробнее: каждый раздел объясняет идею алгоритма, показывает типовые реализации и отдельно разбирает ограничения и ошибки.

Разделы расположены примерно от базовых приёмов обработки данных к более алгоритмическим темам. Читать их строго по порядку необязательно.

## Разделы

- [Полный перебор](Полный_перебор/) — перебор вариантов, подсчёт решений, поиск первого подходящего значения, поиск минимума и максимума, сокращение перебора.
- [Поиск минимума и максимума](Поиск_минимума_и_максимума/) — поиск экстремума за один проход, условный минимум и максимум, связанные объекты, несколько экстремальных значений и обработка файлов.
- [Подсчёт и накопление](Подсчёт_и_накопление/) — счётчики, сумма, среднее, несколько накопителей, произведение и обработка данных из файла.
- [Сортировка](Сортировка/) — сортировка списков, строк и записей, выбор ключа, несколько критериев, поиск лучших элементов и простой ручной алгоритм.
- [Словари и частоты](Словари_и_частоты/) — хранение пар «ключ — значение», подсчёт частот, поиск самых частых элементов и обработка данных из файла.
- [Префиксные суммы](Префиксные_суммы/) — быстрый подсчёт суммы, количества и среднего значения на отрезке, обработка нескольких запросов и данных из файла.
- [Два указателя](Два_указателя/) — поиск пары в отсортированных данных, сохранение исходных индексов, проверка палиндрома, слияние и сравнение последовательностей.
- [Скользящее окно](Скользящее_окно/) — обработка непрерывных отрезков фиксированного и изменяемого размера без повторного пересчёта.
- [Двоичный поиск](Двоичный_поиск/) — поиск в отсортированных данных, первое и последнее вхождение, модуль `bisect` и поиск по ответу.
- [Жадные алгоритмы](Жадные_алгоритмы/) — локальный выбор, отбор объектов при ограничении, непересекающиеся мероприятия и границы применимости жадного подхода.
- [Поиск с возвратом](Поиск_с_возвратом/) — построение решения по частям, раннее отсечение, перестановки, поиск первого варианта и подсчёт решений.
- [DFS и BFS](DFS_и_BFS/) — представление графа, обход в глубину и ширину, компоненты связности, расстояния и восстановление пути.
- [Алгоритм Дейкстры](Алгоритм_Дейкстры/) — кратчайшие пути во взвешенном графе, очередь с приоритетом, восстановление маршрута и чтение данных из файла.
- [Динамическое программирование](Динамическое_программирование/) — состояния и переходы, количество способов, оптимальная стоимость, размен монет и восстановление решения.
- [Алгоритмы теории чисел](Алгоритмы_теории_чисел/) — делимость, делители, простые числа, разложение на множители, НОД, НОК и решето Эратосфена.

Каждый раздел содержит полноценное объяснение алгоритма и практические примеры на Python.
