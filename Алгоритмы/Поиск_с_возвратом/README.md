# Поиск с возвратом

Поиск с возвратом строит решение постепенно.

На каждом шаге алгоритм:

1. делает один из возможных выборов;
2. продолжает строить решение;
3. если ветвь завершена или не подходит, возвращается назад;
4. отменяет выбор и пробует следующий вариант.

Этот подход похож на полный перебор, но позволяет отбрасывать неподходящие ветви ещё до построения полного варианта.

---

## 1. Построение решения по частям

Построим все двоичные последовательности длины `3`.

```python
n = 3

def generate(sequence):
    if len(sequence) == n:
        print(sequence)
        return

    generate(sequence + '0')
    generate(sequence + '1')


generate('')
```

Результат:

```text
000
001
010
011
100
101
110
111
```

Каждый вызов функции получает уже построенную часть последовательности и добавляет к ней очередной символ.

Условие:

```python
if len(sequence) == n:
    ...
```

называется базовым случаем. Оно останавливает дальнейшие рекурсивные вызовы, когда решение полностью построено.

---

## 2. Дерево вариантов

После пустой строки можно выбрать `0` или `1`. После каждого выбора снова доступны два варианта.

Каждая последовательность решений образует отдельную ветвь:

```text
'' → '0' → '00' → '000'
                  → '001'
         → '01' → '010'
                  → '011'
```

Функция сначала проходит одну ветвь до конца, затем возвращается к последнему месту выбора и переходит к следующей.

Для построения строки отдельная отмена выбора не нужна: выражение `sequence + '0'` создаёт новую строку, а исходная строка не изменяется.

---

## 3. Раннее отсечение

Построим последовательности, в которых нет двух единиц подряд.

```python
n = 4

def generate(sequence):
    if '11' in sequence:
        return

    if len(sequence) == n:
        print(sequence)
        return

    generate(sequence + '0')
    generate(sequence + '1')


generate('')
```

Как только появляется `'11'`, дальнейшее продолжение этой ветви уже не может стать правильным. Команда `return` сразу прекращает её обработку.

Ещё лучше не создавать заведомо неправильную ветвь:

```python
def generate(sequence):
    if len(sequence) == n:
        print(sequence)
        return

    generate(sequence + '0')

    if not sequence or sequence[-1] != '1':
        generate(sequence + '1')
```

Чем раньше отбрасывается неподходящий вариант, тем меньше лишней работы выполняет программа.

---

## 4. Выбрать, продолжить, отменить

При работе с изменяемым списком используется основной шаблон возврата:

```python
current.append(value)  # сделать выбор

generate()             # продолжить поиск

current.pop()          # отменить выбор
```

После завершения рекурсивного вызова список `current` всё ещё содержит выбранный элемент. Его нужно удалить, чтобы попробовать другой вариант из того же состояния.

Именно отмена выбора дала методу название «поиск с возвратом».

---

## 5. Перестановки без повторений

Построим все перестановки чисел `1`, `2` и `3`.

```python
numbers = [1, 2, 3]

current = []
used = [False] * len(numbers)

def generate():
    if len(current) == len(numbers):
        print(current)
        return

    for i in range(len(numbers)):
        if not used[i]:
            used[i] = True
            current.append(numbers[i])

            generate()

            current.pop()
            used[i] = False


generate()
```

Список `used` показывает, какие элементы уже находятся в текущей перестановке.

На каждом шаге:

1. элемент помечается как использованный;
2. добавляется в решение;
3. выполняется рекурсивный вызов;
4. элемент удаляется;
5. отметка снимается.

Если забыть снять отметку, элемент останется недоступным для других ветвей.

---

## 6. Сохранение всех решений

Если решения нужно не вывести, а сохранить, нельзя добавлять один и тот же изменяемый список.

Неправильно:

```python
answers.append(current)
```

Правильно:

```python
answers.append(current.copy())
```

Полный пример:

```python
numbers = [1, 2, 3]

current = []
used = [False] * len(numbers)
answers = []

def generate():
    if len(current) == len(numbers):
        answers.append(current.copy())
        return

    for i in range(len(numbers)):
        if not used[i]:
            used[i] = True
            current.append(numbers[i])

            generate()

            current.pop()
            used[i] = False


generate()

print(answers)
```

Метод `.copy()` сохраняет отдельную копию текущего решения. Без него все элементы `answers` ссылались бы на один список, который продолжает изменяться.

## 7. Поиск первого решения

Иногда достаточно найти один подходящий вариант. Тогда функция может возвращать `True`, если решение найдено.

```python
numbers = [3, 5, 7, 9]
target = 12

selected = []

def search(index, total):
    if total == target:
        return True

    if index == len(numbers) or total > target:
        return False

    selected.append(numbers[index])

    if search(index + 1, total + numbers[index]):
        return True

    selected.pop()

    if search(index + 1, total):
        return True

    return False


if search(0, 0):
    print(selected)
else:
    print('Решение не найдено')
```

Для каждого числа рассматриваются два варианта:

- взять его;
- не брать его.

Как только один рекурсивный вызов возвращает `True`, поиск завершается.

---

## 8. Сумма выбранных чисел и отсечение

В предыдущем примере используется условие:

```python
def search(total):
    if total > target:
        return False
```

Оно корректно, потому что все числа положительные. Добавление следующих элементов может только увеличить сумму.

Если среди чисел есть отрицательные значения, сумма после превышения цели может снова уменьшиться. Такое отсечение тогда применять нельзя.

Отсечение всегда должно опираться на свойства конкретной задачи.

---

## 9. Подсчёт количества решений

Рекурсивная функция может не сохранять варианты, а возвращать их количество.

Посчитаем двоичные последовательности длины `5`, в которых нет двух единиц подряд.

```python
n = 5

def count_sequences(sequence):
    if len(sequence) == n:
        return 1

    count = count_sequences(sequence + '0')

    if not sequence or sequence[-1] != '1':
        count += count_sequences(sequence + '1')

    return count


print(count_sequences(''))
```

Результат:

```text
13
```

Каждый полностью построенный допустимый вариант возвращает единицу. Результаты всех ветвей складываются.

## 10. Когда использовать `itertools`

Если нужно получить обычные варианты без сложного промежуточного отсечения, готовые функции часто проще.

```python
from itertools import product, permutations

print(*product('01', repeat=3))
print(*permutations([1, 2, 3]))
```

Используйте:

- `product()` — когда элементы могут повторяться;
- `permutations()` — когда нужны перестановки без повторного использования элементов;
- поиск с возвратом — когда решение строится по особым правилам или ветви можно рано отсекать.

Писать рекурсию только ради замены одной строки с `itertools` не требуется.

---

## 11. Отличие от DFS по графу

Поиск с возвратом обычно перебирает дерево решений: на каждом уровне выполняется очередной выбор.

DFS обходит вершины и рёбра готового графа.

Оба подхода используют движение в глубину и могут быть записаны рекурсивно, но решают разные задачи. Обход графов будет рассмотрен отдельно в разделе «DFS и BFS».

## 12. Работа с файлом

Пусть файл `data.txt` имеет формат:

```text
4 12
3 5 7 9
```

В первой строке записаны количество чисел и целевая сумма. Во второй — положительные числа.

```python
with open('data.txt') as f:
    n, target = map(int, f.readline().split())
    numbers = list(map(int, f.readline().split()))

selected = []

def search(index, total):
    if total == target:
        return True

    if index == len(numbers) or total > target:
        return False

    selected.append(numbers[index])

    if search(index + 1, total + numbers[index]):
        return True

    selected.pop()

    return search(index + 1, total)


if search(0, 0):
    print(selected)
else:
    print('Решение не найдено')
```

Переменная `n` хранит ожидаемое количество чисел. Отсечение по сумме предполагает, что все числа положительные.

## 13. Частые ошибки

### Ошибка 1. Нет базового случая

Без условия остановки рекурсивные вызовы будут продолжаться, пока программа не получит ошибку глубины рекурсии.

### Ошибка 2. Забыть отменить выбор

После рекурсивного вызова нужно восстановить состояние:

```python
current.pop()
used[i] = False
```

### Ошибка 3. Сохранить исходный список вместо копии

Для сохранения решения:

```python
answers.append(current.copy())
```

### Ошибка 4. Выполнить неправильное отсечение

Нельзя отбрасывать ветвь только потому, что она выглядит невыгодной. Нужно доказать, что продолжение уже не может привести к ответу.

### Ошибка 5. Не передавать изменённое состояние

Рекурсивный вызов должен переходить к следующему шагу, например:

```python
search(index + 1, total + numbers[index])
```

## Краткая памятка

```python
current = []

def backtrack():
    if решение_готово:
        обработать_решение()
        return

    for value in варианты:
        if подходит(value):
            current.append(value)

            backtrack()

            current.pop()
```

Это универсальная схема, а условия готовности, варианты и проверки зависят от задачи.

Главное:

- решение строится по частям;
- базовый случай останавливает рекурсию;
- после рекурсивного вызова изменяемое состояние восстанавливается;
- неподходящие ветви желательно отсекать как можно раньше;
- для сохранения списка нужна копия;
- для обычного перебора готовые функции `itertools` часто проще.
