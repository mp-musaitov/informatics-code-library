# Динамическое программирование

Динамическое программирование помогает решать задачи, в которых одни и те же промежуточные результаты используются много раз.

Вместо повторного вычисления программа сохраняет ответы для меньших состояний и на их основе получает следующие.

Для построения решения нужно ответить на три вопроса:

1. Что хранит элемент `dp[i]`?
2. Как задаются начальные значения?
3. Из каких предыдущих состояний получается текущее?

---

## 1. Количество способов

Пусть исполнитель начинает в позиции `0` и может сделать шаг на `1` или `2`. Найдём количество способов попасть в позицию `n`.

```python
n = 6

ways = [0] * (n + 1)
ways[0] = 1

for position in range(1, n + 1):
    ways[position] = ways[position - 1]

    if position >= 2:
        ways[position] += ways[position - 2]

print(ways[n])
```

Здесь:

```text
ways[position] = количество способов попасть в position
```

В позицию можно прийти:

- из `position - 1` шагом на один;
- из `position - 2` шагом на два.

Поэтому количества способов складываются.

Начальное значение `ways[0] = 1` означает, что в стартовой позиции существует один исходный способ.

---

## 2. Запрещённые позиции

Пусть некоторые позиции нельзя посещать.

```python
n = 7
forbidden = {3, 6}

ways = [0] * (n + 1)
ways[0] = 1

for position in range(1, n + 1):
    if position in forbidden:
        ways[position] = 0
        continue

    ways[position] = ways[position - 1]

    if position >= 2:
        ways[position] += ways[position - 2]

print(ways[n])
```

Для запрещённой позиции количество способов равно нулю. Из неё нельзя продолжить допустимый маршрут.

Сначала проверяется ограничение, затем выполняется обычный переход.

---

## 3. Минимальная стоимость пути

Теперь каждая позиция имеет стоимость посещения. Разрешены шаги на одну или две позиции.

```python
cost = [0, 5, 2, 4, 1, 3]

dp = [0] * len(cost)
dp[1] = cost[1]

for position in range(2, len(cost)):
    dp[position] = cost[position] + min(
        dp[position - 1],
        dp[position - 2]
    )

print(dp[-1])
```

Здесь:

```text
dp[position] = минимальная стоимость пути до position
```

Чтобы попасть в текущую позицию, выбирается более дешёвый из двух предыдущих путей, а затем добавляется стоимость текущей позиции.

Начальные состояния нужно задавать отдельно, потому что для первых позиций ещё нет двух предшественников.

---

## 4. Максимальная сумма на пути

Если требуется получить наибольшую сумму, используется `max()`.

```python
values = [0, 5, 2, 10, 1, 4]

dp = [0] * len(values)
dp[1] = values[1]

for position in range(2, len(values)):
    dp[position] = values[position] + max(
        dp[position - 1],
        dp[position - 2]
    )

print(dp[-1])
```

Смысл состояния:

```text
dp[position] = максимальная сумма пути до position
```

Формула перехода зависит от условия задачи. Нельзя механически заменять `min()` на `max()`, не определив смысл `dp`.

## 5. Минимальное количество монет

Рассмотрим номиналы:

```python
coins = [1, 3, 4]
amount = 6
```

Жадный алгоритм выберет `4 + 1 + 1`, хотя лучший вариант — `3 + 3`.

Динамическое программирование:

```python
dp = [None] * (amount + 1)
dp[0] = 0

for current in range(1, amount + 1):
    for coin in coins:
        if current >= coin and dp[current - coin] is not None:
            new_count = dp[current - coin] + 1

            if dp[current] is None or new_count < dp[current]:
                dp[current] = new_count

print(dp[amount])
```

Результат:

```text
2
```

Значение `None` означает, что сумма пока недостижима.

## 6. Восстановление выбранных монет

Одного оптимального значения иногда недостаточно. Сохраним последнюю монету, использованную для каждой суммы.

```python
coins = [1, 3, 4]
amount = 6

dp = [None] * (amount + 1)
previous_coin = [None] * (amount + 1)

dp[0] = 0

for current in range(1, amount + 1):
    for coin in coins:
        if current >= coin and dp[current - coin] is not None:
            new_count = dp[current - coin] + 1

            if dp[current] is None or new_count < dp[current]:
                dp[current] = new_count
                previous_coin[current] = coin

if dp[amount] is not None:
    selected = []
    current = amount

    while current > 0:
        coin = previous_coin[current]
        selected.append(coin)
        current -= coin

    print(selected)
else:
    print('Сумму набрать нельзя')
```

Восстановление идёт от конечной суммы к нулю.

## 7. Можно ли набрать сумму

Пусть каждое число разрешено использовать не более одного раза.

```python
numbers = [3, 5, 7, 9]
target = 12

possible = [False] * (target + 1)
possible[0] = True

for number in numbers:
    for current in range(target, number - 1, -1):
        if possible[current - number]:
            possible[current] = True

print(possible[target])
```

Результат:

```text
True
```

Сумму `12` можно получить, например, как `3 + 9` или `5 + 7`.

Суммы просматриваются справа налево, чтобы одно число не использовалось несколько раз в рамках одной итерации.

## 8. Простейшая двумерная динамика

Найдём количество путей из левой верхней клетки таблицы в правую нижнюю. Разрешены движения вправо и вниз.

```python
rows = 3
columns = 4

dp = [
    [0] * columns
    for _ in range(rows)
]

dp[0][0] = 1

for row in range(rows):
    for column in range(columns):
        if row > 0:
            dp[row][column] += dp[row - 1][column]

        if column > 0:
            dp[row][column] += dp[row][column - 1]

print(dp[rows - 1][columns - 1])
```

Каждая клетка получает количество путей из верхней и левой клеток.

Двумерная динамика использует те же идеи: состояние, начальное значение и переход. Отличается только форма таблицы.

## 9. Динамика, жадность и поиск с возвратом

Жадный алгоритм делает один выбор и не возвращается назад. Он подходит только тогда, когда локальный выбор гарантирует лучший общий результат.

Поиск с возвратом рассматривает разные варианты и может повторно решать похожие подзадачи.

Динамическое программирование сохраняет лучшие результаты промежуточных состояний и повторно использует их.

Перед выбором метода нужно определить свойства конкретной задачи.

## 10. Работа с файлом

Пусть файл `data.txt` содержит конечную позицию и список запрещённых позиций:

```text
7
3 6
```

```python
with open('data.txt') as f:
    n = int(f.readline())
    forbidden = set(map(int, f.readline().split()))

ways = [0] * (n + 1)
ways[0] = 1

for position in range(1, n + 1):
    if position in forbidden:
        continue

    ways[position] = ways[position - 1]

    if position >= 2:
        ways[position] += ways[position - 2]

print(ways[n])
```

Формат файла и правила перехода в конкретной задаче могут отличаться.

## 11. Частые ошибки

### Ошибка 1. Не определить смысл `dp`

Перед кодом запишите словами:

```text
dp[i] — это ...
```

### Ошибка 2. Неправильно задать начало

Переходы не исправят ошибочное начальное состояние.

### Ошибка 3. Обратиться к отрицательному индексу

Для перехода из `position - 2` нужна проверка:

```python
if position >= 2:
    ...
```

### Ошибка 4. Перепутать минимум и максимум

Операция должна соответствовать смыслу состояния и вопросу задачи.

### Ошибка 5. Восстанавливать недостижимое решение

Перед восстановлением проверьте:

```python
if dp[amount] is not None:
    ...
```

### Ошибка 6. Неверно выбрать направление цикла

В задаче, где каждый элемент используется один раз, суммы часто просматриваются справа налево.

## Краткая памятка

```python
# Количество способов
dp = [0] * (n + 1)
dp[0] = 1

for position in range(1, n + 1):
    dp[position] = dp[position - 1]

    if position >= 2:
        dp[position] += dp[position - 2]
```

Главное:

- сначала определяется смысл состояния;
- затем задаются начальные значения;
- формула перехода использует уже найденные результаты;
- недостижимое состояние удобно обозначать `None`;
- для восстановления решения хранится предыдущий выбор;
- порядок обработки состояний должен соответствовать переходам.
