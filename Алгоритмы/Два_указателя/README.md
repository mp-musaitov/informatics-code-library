# Два указателя

Метод двух указателей использует две переменные, которые обозначают позиции в последовательности.

Указатели могут:

- начинать с разных концов списка и двигаться навстречу друг другу;
- двигаться по двум разным спискам;
- пропускать элементы, которые уже не могут участвовать в ответе.

Главная идея: не перебирать заново все возможные сочетания, а после каждого сравнения понимать, какой указатель нужно передвинуть.

Часто этот метод применяется к отсортированным данным.

---

## 1. Поиск пары полным перебором

Пусть нужно найти два различных элемента, сумма которых равна `target`.

Обычный способ — проверить все пары:

```python
numbers = [2, 4, 7, 9, 12, 15]
target = 19

found = False

for i in range(len(numbers)):
    for j in range(i + 1, len(numbers)):
        if numbers[i] + numbers[j] == target:
            print(numbers[i], numbers[j])
            found = True
            break

    if found:
        break
```

Результат:

```text
4 15
```

Начальное значение `j = i + 1` не позволяет взять один элемент дважды и не проверяет одну пару в обратном порядке.

Такой полный перебор понятен, но при большом количестве элементов выполняет много сравнений.

---

## 2. Идея двух указателей

Если список отсортирован, можно поставить:

- `left` на первый элемент;
- `right` на последний элемент.

```python
numbers = [2, 4, 7, 9, 12, 15]

left = 0
right = len(numbers) - 1
```

На каждом шаге вычисляем сумму:

```python
current_sum = numbers[left] + numbers[right]
```

Дальше возможны три случая:

1. сумма равна `target` — пара найдена;
2. сумма меньше `target` — нужно увеличить левое число, поэтому двигаем `left` вправо;
3. сумма больше `target` — нужно уменьшить правое число, поэтому двигаем `right` влево.

Указатели постепенно приближаются друг к другу. Уже отброшенные элементы снова проверять не нужно.

---

## 3. Пара с заданной суммой

Полный шаблон:

```python
numbers = [2, 4, 7, 9, 12, 15]
target = 19

left = 0
right = len(numbers) - 1

found = False

while left < right:
    current_sum = numbers[left] + numbers[right]

    if current_sum == target:
        print(numbers[left], numbers[right])
        found = True
        break
    elif current_sum < target:
        left += 1
    else:
        right -= 1

if not found:
    print('Пара не найдена')
```

Результат:

```text
4 15
```

Условие цикла именно `left < right`. При `left == right` оба указателя стоят на одном элементе, а по условию нужны два различных элемента.

Если требуется только проверить существование пары, вместо вывода можно сохранить ответ:

```python
answer = None

while left < right:
    current_sum = numbers[left] + numbers[right]

    if current_sum == target:
        answer = [numbers[left], numbers[right]]
        break
    elif current_sum < target:
        left += 1
    else:
        right -= 1

print(answer)
```

Если пары нет, значение `answer` останется равным `None`.

## 4. Почему список должен быть отсортирован

Решение опирается на порядок элементов.

Если:

```python
current_sum < target
```

мы увеличиваем `left`, потому что следующий элемент справа не меньше текущего.

Если:

```python
current_sum > target
```

мы уменьшаем `right`, потому что предыдущий элемент слева не больше текущего.

В неотсортированном списке такое движение не гарантирует правильный результат.

Если порядок элементов не важен, список можно сначала отсортировать:

```python
numbers = [12, 4, 15, 2, 9, 7]

numbers.sort()
```

Получим:

```text
[2, 4, 7, 9, 12, 15]
```

Важно: сортировка изменяет порядок элементов. Если задача требует вывести первоначальные индексы, одного списка значений недостаточно.

## 5. Сохранение исходных индексов

Будем хранить пары:

```text
[значение, исходный индекс]
```

Пример:

```python
numbers = [12, 4, 15, 2, 9, 7]
target = 19

pairs = []

for index, value in enumerate(numbers):
    pairs.append([value, index])

pairs.sort()

left = 0
right = len(pairs) - 1

while left < right:
    current_sum = pairs[left][0] + pairs[right][0]

    if current_sum == target:
        print(pairs[left][1], pairs[right][1])
        break
    elif current_sum < target:
        left += 1
    else:
        right -= 1
```

Результат:

```text
1 2
```

В исходном списке:

- индекс `1` содержит число `4`;
- индекс `2` содержит число `15`;
- их сумма равна `19`.

После сортировки пары располагаются по значению, но исходный индекс остаётся рядом с каждым элементом.

Если в условии позиции нумеруются с единицы, при выводе нужно прибавить `1`:

```python
print(pairs[left][1] + 1, pairs[right][1] + 1)
```

## 6. Пара с суммой, ближайшей к цели

Иногда точная сумма может отсутствовать. Тогда нужно найти пару, сумма которой наиболее близка к `target`.

```python
numbers = [2, 4, 7, 9, 12, 15]
target = 20

left = 0
right = len(numbers) - 1

best_pair = None
best_difference = None

while left < right:
    current_sum = numbers[left] + numbers[right]
    difference = abs(current_sum - target)

    if best_difference is None or difference < best_difference:
        best_difference = difference
        best_pair = [numbers[left], numbers[right]]

    if current_sum < target:
        left += 1
    elif current_sum > target:
        right -= 1
    else:
        break

print(best_pair)
print(sum(best_pair))
```

Результат:

```text
[4, 15]
19
```

Переменная `best_difference` хранит наименьшее найденное отклонение от цели, а `best_pair` — связанную с ним пару.

Если несколько пар одинаково близки к цели, правило выбора между ними должно определяться условием задачи.

Для этого алгоритма в списке должно быть не меньше двух элементов.

## 7. Проверка строки на палиндром

Палиндром одинаково читается слева направо и справа налево.

Например:

```text
топот
```

Поставим указатели на первый и последний символы:

```python
text = 'топот'

left = 0
right = len(text) - 1

is_palindrome = True

while left < right:
    if text[left] != text[right]:
        is_palindrome = False
        break

    left += 1
    right -= 1

print(is_palindrome)
```

Результат:

```text
True
```

Для фразы можно предварительно убрать пробелы и привести буквы к одному регистру:

```python
text = 'А роза упала на лапу Азора'

clean_text = text.lower().replace(' ', '')
```

После этого к `clean_text` применяется тот же алгоритм.

Если в тексте нужно игнорировать знаки препинания, их обработка зависит от условия задачи.

## 8. Слияние двух отсортированных списков

Два указателя могут двигаться по двум разным спискам.

Нужно объединить два отсортированных списка так, чтобы результат тоже был отсортирован:

```python
first = [1, 4, 7, 10]
second = [2, 3, 8, 12]

i = 0
j = 0

result = []

while i < len(first) and j < len(second):
    if first[i] < second[j]:
        result.append(first[i])
        i += 1
    else:
        result.append(second[j])
        j += 1

while i < len(first):
    result.append(first[i])
    i += 1

while j < len(second):
    result.append(second[j])
    j += 1

print(result)
```

Результат:

```text
[1, 2, 3, 4, 7, 8, 10, 12]
```

Пока в обоих списках есть элементы, сравниваются текущие значения. В результат добавляется меньшее из них.

Когда один список закончился, оставшиеся элементы второго списка добавляются без дополнительных сравнений.

## 9. Общие элементы двух отсортированных списков

Найдём различные значения, которые присутствуют в обоих списках.

```python
first = [1, 2, 2, 4, 6, 8]
second = [2, 2, 3, 4, 7, 8]

i = 0
j = 0

common = []

while i < len(first) and j < len(second):
    if first[i] == second[j]:
        if not common or common[-1] != first[i]:
            common.append(first[i])

        i += 1
        j += 1
    elif first[i] < second[j]:
        i += 1
    else:
        j += 1

print(common)
```

Результат:

```text
[2, 4, 8]
```

Логика движения:

- значения равны — элемент общий, двигаем оба указателя;
- элемент первого списка меньше — двигаем `i`;
- элемент второго списка меньше — двигаем `j`.

Проверка:

```python
if not common or common[-1] != first[i]:
    common.append(first[i])
```

не позволяет добавлять одно и то же значение несколько раз.

Если по условию повторения нужно сохранять, эта проверка не требуется.

## 10. Работа с файлом

Пусть файл `data.txt` имеет формат:

```text
6 19
12 4 15 2 9 7
```

В первой строке записаны количество чисел и целевая сумма. Во второй строке находятся числа.

Если нужно вывести только значения найденной пары, исходные числа можно отсортировать:

```python
with open('data.txt') as f:
    n, target = map(int, f.readline().split())
    numbers = list(map(int, f.readline().split()))

numbers.sort()

left = 0
right = len(numbers) - 1

answer = None

while left < right:
    current_sum = numbers[left] + numbers[right]

    if current_sum == target:
        answer = [numbers[left], numbers[right]]
        break
    elif current_sum < target:
        left += 1
    else:
        right -= 1

print(answer)
```

Переменная `n` показывает ожидаемое количество элементов. При необходимости можно проверить:

```python
if len(numbers) != n:
    print('Неверное количество чисел')
```

Формат файла в конкретной задаче может отличаться.

## 11. Отличие от скользящего окна

В методе двух указателей обе позиции помогают исключать неподходящие варианты.

Например, при поиске пары:

- левый указатель выбирает меньшее число;
- правый указатель выбирает большее число;
- указатели движутся навстречу.

Скользящее окно тоже использует левую и правую границы, но они обозначают непрерывный отрезок последовательности. При движении границ поддерживается информация обо всём отрезке: его сумма, длина, количество подходящих элементов и так далее.

Задачи на расширение и сжатие непрерывного отрезка будут рассмотрены отдельно в разделе «Скользящее окно».

## 12. Частые ошибки

### Ошибка 1. Применить метод к неотсортированному списку

Для поиска пары по сумме список должен быть отсортирован:

```python
numbers.sort()
```

Иначе по текущей сумме нельзя правильно определить направление движения.

### Ошибка 2. Использовать `left <= right`

Неправильно:

```python
while left <= right:
    ...
```

При равных указателях один элемент может быть использован дважды.

Правильно:

```python
while left < right:
    ...
```

### Ошибка 3. Передвинуть не тот указатель

Если сумма слишком мала:

```python
left += 1
```

Если сумма слишком велика:

```python
right -= 1
```

### Ошибка 4. Забыть передвинуть указатель

Если ни один указатель не изменяется, цикл может стать бесконечным.

### Ошибка 5. Потерять исходные индексы

После обычной сортировки индексы относятся уже к новому порядку.

Если нужны первоначальные позиции, храните вместе значение и индекс:

```python
[value, index]
```

### Ошибка 6. Не проверить отсутствие ответа

Если подходящей пары может не быть, заранее задайте:

```python
answer = None
```

и изменяйте значение только после нахождения пары.

## Краткая памятка

```python
# Пара с заданной суммой в отсортированном списке
left = 0
right = len(numbers) - 1

answer = None

while left < right:
    current_sum = numbers[left] + numbers[right]

    if current_sum == target:
        answer = [numbers[left], numbers[right]]
        break
    elif current_sum < target:
        left += 1
    else:
        right -= 1

print(answer)
```

Главное:

- для поиска пары по сумме данные должны быть отсортированы;
- при слишком маленькой сумме двигается левый указатель;
- при слишком большой сумме двигается правый указатель;
- условие `left < right` не позволяет использовать один элемент дважды;
- при необходимости исходные индексы хранятся вместе со значениями;
- два указателя также применяются к строкам и двум отсортированным последовательностям.
