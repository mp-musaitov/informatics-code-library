# Словари и частоты

Словарь хранит данные в виде пар:

```text
ключ → значение
```

Например:

- имя ученика → его результат;
- товар → его цена;
- число → количество его появлений;
- символ → количество повторений в строке.

Особенно часто словари используются для подсчёта частот. Частота элемента — это количество раз, которое он встретился в последовательности.

Рассмотрим список:

```python
numbers = [3, 5, 3, 2, 5, 3]
```

Число `3` встретилось три раза, число `5` — два раза, а число `2` — один раз. Это можно записать так:

```python
frequency = {
    3: 3,
    5: 2,
    2: 1
}
```

Словарь позволяет за один проход подсчитать частоты всех элементов.

---

## 1. Создание словаря

Пустой словарь создаётся с помощью фигурных скобок:

```python
data = {}
```

Готовый словарь можно записать сразу с элементами:

```python
scores = {
    'Антон': 91,
    'Борис': 84,
    'Вера': 78
}
```

Здесь имена — ключи, а результаты — значения.

Получить значение по ключу:

```python
print(scores['Антон'])
```

Результат:

```text
91
```

Добавить новую пару:

```python
scores['Галина'] = 88
```

Изменить существующее значение:

```python
scores['Борис'] = 87
```

Одинаковых ключей в словаре быть не может. Если ключ уже существует, новое присваивание изменяет его значение.

---

## 2. Проверка наличия ключа

Оператор `in` проверяет, есть ли ключ в словаре.

```python
scores = {
    'Антон': 91,
    'Борис': 84
}

if 'Антон' in scores:
    print(scores['Антон'])
```

Если обратиться к отсутствующему ключу напрямую, программа получит ошибку `KeyError`:

```python
print(scores['Вера'])
```

Поэтому перед таким обращением иногда нужно проверить ключ:

```python
if 'Вера' in scores:
    print(scores['Вера'])
else:
    print('Нет данных')
```

Проверка `key in dictionary` относится именно к ключам, а не к значениям.

---

## 3. Безопасное получение значения через `.get()`

Метод `.get()` позволяет получить значение без ошибки.

```python
scores = {
    'Антон': 91,
    'Борис': 84
}

print(scores.get('Антон'))
print(scores.get('Вера'))
```

Результат:

```text
91
None
```

Если ключа нет, метод возвращает `None`. Можно указать другое значение по умолчанию:

```python
print(scores.get('Вера', 0))
```

Результат:

```text
0
```

Для подсчёта частот особенно полезна запись:

```python
frequency.get(x, 0)
```

Она означает: получить текущую частоту элемента `x`, а если такого ключа ещё нет — использовать `0`.

---

## 4. Подсчёт частот через `if`

Сначала рассмотрим полный вариант с проверкой ключа.

```python
numbers = [3, 5, 3, 2, 5, 3]

frequency = {}

for x in numbers:
    if x in frequency:
        frequency[x] += 1
    else:
        frequency[x] = 1

print(frequency)
```

Результат:

```text
{3: 3, 5: 2, 2: 1}
```

Что происходит в цикле:

1. берём очередное число `x`;
2. если оно уже есть в словаре, увеличиваем его частоту;
3. если число встретилось впервые, добавляем его с частотой `1`.

Этот вариант хорошо показывает сам принцип подсчёта.

---

## 5. Короткий подсчёт через `.get()`

Тот же алгоритм можно записать короче:

```python
numbers = [3, 5, 3, 2, 5, 3]

frequency = {}

for x in numbers:
    frequency[x] = frequency.get(x, 0) + 1

print(frequency)
```

Строка:

```python
frequency[x] = frequency.get(x, 0) + 1
```

работает так:

- если `x` уже встречался, берётся его текущая частота;
- если `x` встретился впервые, берётся `0`;
- к полученному значению прибавляется `1`;
- новый результат записывается в словарь.

Это основной универсальный шаблон подсчёта частот.

---

## 6. Подсчёт символов в строке

Ключами словаря могут быть не только числа, но и строки или отдельные символы.

```python
text = 'информатика'

frequency = {}

for symbol in text:
    frequency[symbol] = frequency.get(symbol, 0) + 1

print(frequency)
```

Пробелы и знаки препинания тоже являются символами. Если их не нужно учитывать, это следует явно указать в условии:

```python
text = 'мама мыла раму'

frequency = {}

for symbol in text:
    if symbol != ' ':
        frequency[symbol] = frequency.get(symbol, 0) + 1

print(frequency)
```

При необходимости можно предварительно привести текст к одному регистру:

```python
text = text.lower()
```

Тогда, например, `'А'` и `'а'` будут учитываться как один символ.

---

## 7. Подсчёт слов

Сначала строку можно разделить на слова, а затем подсчитать их частоты.

```python
text = 'кот пёс кот лиса пёс кот'

words = text.split()

frequency = {}

for word in words:
    frequency[word] = frequency.get(word, 0) + 1

print(frequency)
```

Результат:

```text
{'кот': 3, 'пёс': 2, 'лиса': 1}
```

Если регистр не должен влиять на результат:

```python
words = text.lower().split()
```

Обычный `.split()` отделяет слова по пробелам, но не убирает знаки препинания. Например, `'кот'` и `'кот,'` будут разными ключами. В конкретной задаче нужно учитывать формат исходного текста.

---

## 8. Поиск самого частого элемента

После построения словаря можно найти элемент с наибольшей частотой.

```python
numbers = [3, 5, 3, 2, 5, 3]

frequency = {}

for x in numbers:
    frequency[x] = frequency.get(x, 0) + 1

most_frequent = max(frequency, key=frequency.get)

print(most_frequent)
print(frequency[most_frequent])
```

Результат:

```text
3
3
```

В выражении:

```python
max(frequency, key=frequency.get)
```

Python перебирает ключи словаря, но сравнивает соответствующие им значения.

Этот способ требует, чтобы словарь не был пустым. Если исходная последовательность может оказаться пустой, нужна проверка:

```python
if frequency:
    most_frequent = max(frequency, key=frequency.get)
    print(most_frequent)
else:
    print('Нет данных')
```

---

## 9. Несколько элементов с максимальной частотой

Иногда несколько элементов встречаются одинаковое наибольшее количество раз.

```python
numbers = [4, 2, 4, 3, 2, 5]

frequency = {}

for x in numbers:
    frequency[x] = frequency.get(x, 0) + 1
```

Числа `2` и `4` встретились по два раза.

Сначала найдём максимальную частоту:

```python
maximum = max(frequency.values())
```

Затем соберём все элементы с такой частотой:

```python
most_frequent = []

for x, count in frequency.items():
    if count == maximum:
        most_frequent.append(x)

print(most_frequent)
```

Если по условию среди них нужно выбрать наименьший элемент:

```python
answer = min(most_frequent)
```

Правило выбора при равных частотах всегда берётся из условия задачи.

---

## 10. Вывод таблицы частот

Метод `.items()` позволяет одновременно получить ключ и значение.

```python
frequency = {
    3: 3,
    5: 2,
    2: 1
}

for x, count in frequency.items():
    print(x, count)
```

Если ключи нужно вывести по возрастанию:

```python
for x in sorted(frequency):
    print(x, frequency[x])
```

Результат:

```text
2 1
3 3
5 2
```

Если нужен порядок по убыванию частоты:

```python
pairs = list(frequency.items())

pairs.sort(key=lambda pair: (-pair[1], pair[0]))

for x, count in pairs:
    print(x, count)
```

Здесь элементы с большей частотой идут раньше, а при равной частоте ключи располагаются по возрастанию.

## 11. Подсчёт частот в файле

Предположим, что в каждой строке файла `data.txt` записано одно число:

```text
3
5
3
2
5
3
```

Можно обрабатывать файл построчно, не сохраняя все числа в список:

```python
frequency = {}

with open('data.txt') as f:
    for s in f:
        x = int(s)
        frequency[x] = frequency.get(x, 0) + 1

print(frequency)
```

Такой способ особенно удобен для больших файлов: в памяти хранится только словарь частот.

Если первая строка содержит количество элементов, её нужно прочитать отдельно:

```python
frequency = {}

with open('data.txt') as f:
    n = int(f.readline())

    for _ in range(n):
        x = int(f.readline())
        frequency[x] = frequency.get(x, 0) + 1
```

Перед решением всегда проверяйте формат входного файла.

## 12. `Counter` — готовый подсчёт частот

В модуле `collections` есть специальный инструмент `Counter`.

```python
from collections import Counter

numbers = [3, 5, 3, 2, 5, 3]

frequency = Counter(numbers)

print(frequency)
```

Результат:

```text
Counter({3: 3, 5: 2, 2: 1})
```

Получить частоту отдельного элемента:

```python
print(frequency[3])
```

Получить несколько самых частых элементов:

```python
print(frequency.most_common(2))
```

Результат:

```text
[(3, 3), (5, 2)]
```

`Counter` удобен и сокращает код. Но сначала важно понимать обычный алгоритм со словарём:

```python
frequency[x] = frequency.get(x, 0) + 1
```

Именно этот шаблон можно легко изменить под дополнительные условия задачи.

## 13. Частые ошибки

### Ошибка 1. Увеличить отсутствующий ключ

Неправильно:

```python
frequency = {}
frequency[x] += 1
```

При первом появлении `x` такого ключа ещё нет.

Правильно:

```python
frequency[x] = frequency.get(x, 0) + 1
```

или использовать проверку через `if`.

### Ошибка 2. Перепутать ключ и значение

В словаре частот:

```python
frequency[x] = count
```

- `x` — сам элемент;
- `count` — количество его появлений.

### Ошибка 3. Искать максимум среди ключей

```python
max(frequency)
```

возвращает наибольший ключ, а не самый частый элемент.

Для поиска элемента с наибольшей частотой:

```python
max(frequency, key=frequency.get)
```

### Ошибка 4. Не учесть пустые данные

Функция `max()` не работает с пустым словарём. Если данных может не быть, сначала выполните проверку:

```python
if frequency:
    ...
```

### Ошибка 5. Не определить правило при равных частотах

Если несколько элементов встречаются одинаково часто, условие задачи может требовать выбрать:

- наименьший;
- наибольший;
- встретившийся первым;
- все подходящие элементы.

Нельзя выбирать правило самостоятельно — его нужно взять из условия.

## Краткая памятка

```python
# Подсчёт частот
frequency = {}

for x in data:
    frequency[x] = frequency.get(x, 0) + 1


# Частота элемента x
count = frequency.get(x, 0)


# Самый частый элемент
most_frequent = max(frequency, key=frequency.get)


# Максимальная частота
maximum = max(frequency.values())


# Все элементы с максимальной частотой
most_frequent = []

for x, count in frequency.items():
    if count == maximum:
        most_frequent.append(x)


# Вывод по возрастанию ключей
for x in sorted(frequency):
    print(x, frequency[x])
```

Главное:

- словарь хранит пары «ключ — значение»;
- оператор `in` проверяет наличие ключа;
- метод `.get(x, 0)` безопасно получает текущее значение;
- частоты всех элементов подсчитываются за один проход;
- правило обработки одинаковых частот определяется условием задачи;
- `Counter` полезен как готовая альтернатива, но не заменяет понимание обычного алгоритма.
