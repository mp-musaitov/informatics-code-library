# Подсчёт и накопление

Подсчёт и накопление — базовые приёмы обработки последовательностей.

Они используются, когда нужно узнать количество элементов, найти сумму, вычислить среднее или одновременно получить несколько характеристик данных.

Главная идея:

```text
создать переменную с начальным значением
→ пройти по данным
→ при необходимости изменить накопленный результат
```

Такая переменная называется **счётчиком** или **накопителем**.

---

## 1. Простой счётчик

Счётчик хранит количество произошедших событий и обычно начинается с нуля:

```python
count = 0
```

Каждый раз, когда происходит нужное событие, увеличиваем его:

```python
count += 1
```

Например, посчитаем количество элементов списка:

```python
numbers = [8, 3, 12, 5, 17, 2]

count = 0

for x in numbers:
    count += 1

print(count)
```

Для готового списка количество проще узнать через `len(numbers)`. Ручной счётчик особенно полезен, когда учитывать нужно не все элементы.

---

## 2. Подсчёт элементов по условию

Посчитаем количество чётных чисел:

```python
numbers = [8, 3, 12, 5, 17, 2]

count = 0

for x in numbers:
    if x % 2 == 0:
        count += 1

print(count)
```

Счётчик увеличивается только тогда, когда условие выполняется.

Общий шаблон:

```python
count = 0

for x in данные:
    if условие:
        count += 1

print(count)
```

Если подходящих элементов нет, ответом будет `0`.

---

## 3. Накопление суммы

Для суммы используется накопитель, который сначала равен нулю:

```python
numbers = [8, 3, 12, 5, 17, 2]

total = 0

for x in numbers:
    total += x

print(total)
```

Значение `total` постепенно изменяется:

```text
0 → 8 → 11 → 23 → 28 → 45 → 47
```

Для готового списка без условий можно использовать `sum(numbers)`. Цикл нужен, когда суммируются только определённые элементы или данные поступают по одному.

### Сумма по условию

Найдём сумму положительных чисел:

```python
numbers = [-4, 7, 0, 12, -3, 5]

total = 0

for x in numbers:
    if x > 0:
        total += x

print(total)
```

Обновление накопителя должно находиться внутри условия. Иначе программа сложит все числа.

---

## 4. Количество и сумма за один проход

Часто нужно одновременно найти количество подходящих элементов и их сумму:

```python
numbers = [-4, 7, 0, 12, -3, 5]

count = 0
total = 0

for x in numbers:
    if x > 0:
        count += 1
        total += x

print(count)
print(total)
```

Переменные отвечают на разные вопросы:

```text
count → сколько подходящих элементов найдено
total → какова сумма их значений
```

Не нужно проходить по данным дважды.

### Не путайте количество и сумму

```python
count += 1   # найден ещё один подходящий элемент
total += x   # прибавлено значение подходящего элемента
```

Для списка `[2, 5, 8]` количество элементов равно `3`, а сумма — `15`. Среди чётных чисел количество равно `2`, а сумма — `10`.

---

## 5. Среднее значение

Среднее вычисляется по формуле:

```text
среднее = сумма / количество
```

Найдём среднее только среди положительных чисел:

```python
numbers = [-4, 7, 0, 12, -3, 5]

count = 0
total = 0

for x in numbers:
    if x > 0:
        count += 1
        total += x

if count > 0:
    average = total / count
    print(average)
else:
    print('Подходящих значений нет')
```

Проверка `count > 0` защищает от деления на ноль.

Если суммировались только подходящие элементы, делить нужно на `count`, а не на `len(numbers)`.

---

## 6. Несколько счётчиков

За один проход можно считать несколько групп:

```python
numbers = [-4, 7, 0, 12, -3, 0, 5]

positive = 0
negative = 0
zeros = 0

for x in numbers:
    if x > 0:
        positive += 1
    elif x < 0:
        negative += 1
    else:
        zeros += 1

print(positive)
print(negative)
print(zeros)
```

`if / elif / else` используется здесь потому, что одно число относится только к одной группе.

Если условия могут выполняться одновременно, нужны отдельные `if`:

```python
if x > 0:
    positive += 1

if x % 2 == 0:
    even += 1
```

Одно число может одновременно оказаться положительным и чётным.

---

## 7. Накопление произведения

Для произведения начальное значение равно единице:

```python
numbers = [2, 3, 4, 5]

product = 1

for x in numbers:
    product *= x

print(product)
```

Результат:

```text
120
```

Произведение нельзя начинать с нуля, потому что `0 · любое число = 0`.

Краткое правило:

```text
сумма начинается с 0
произведение начинается с 1
```

---

## 8. Обработка данных из файла

Если каждое число записано на отдельной строке, количество и сумму можно найти без создания списка.

Найдём количество и сумму чисел, делящихся на 7:

```python
count = 0
total = 0

with open('data.txt') as f:
    for s in f:
        x = int(s)

        if x % 7 == 0:
            count += 1
            total += x

print(count)
print(total)
```

Программа читает и обрабатывает числа по одному:

```text
прочитать число
→ проверить условие
→ обновить счётчик и накопитель
→ перейти к следующему числу
```

Такой способ удобен для больших файлов: хранить все числа в памяти не требуется.

---

## 9. Когда использовать готовые функции, а когда цикл

```text
количество элементов готового списка
→ len(numbers)

сумма всех элементов готового списка
→ sum(numbers)

количество или сумма по условию
→ цикл с if

одновременно нужны несколько показателей
→ один цикл и несколько накопителей

данные читаются из файла по одному
→ цикл
```

Готовые функции удобны для простых случаев. Цикл позволяет учитывать условия и одновременно накапливать несколько результатов.

---

## 10. Частые ошибки

1. Забыть присвоить счётчику начальное значение `0`.
2. Поставить `count += 1` за пределами нужного условия.
3. Путать `count += 1` и `total += x`.
4. Прибавлять к сумме единицу вместо самого элемента.
5. Делить среднее на количество всех элементов вместо количества подходящих.
6. Не проверять `count > 0` перед вычислением среднего.
7. Начинать произведение с нуля.
8. Использовать `elif`, когда один элемент может удовлетворять нескольким условиям.
9. Делать несколько проходов там, где все показатели можно найти за один цикл.

---

## Главное

```text
1. Определи, что нужно найти: количество, сумму, произведение или несколько показателей.
2. Выбери правильное начальное значение.
3. Пройди по данным.
4. Проверь условие отбора.
5. Обнови нужные счётчики и накопители.
6. Перед делением проверь, что количество не равно нулю.
```

Основные начальные значения:

```python
count = 0
total = 0
product = 1
```

Подсчёт и накопление позволяют получить несколько характеристик последовательности за один проход.
